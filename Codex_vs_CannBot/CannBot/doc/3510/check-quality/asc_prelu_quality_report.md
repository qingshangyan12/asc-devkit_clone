**问题1：返回值说明章节缺失 - asc_prelu.md:49-59**
- **问题描述：** 文档包含 2 个返回值重载（`vector_float asc_prelu(...)` 和 `vector_half asc_prelu(...)`），但缺少独立的"返回值说明"章节。
- **原始证据：**
  ```cpp
  // float类型PReLU运算，返回结果矢量
  __simd_callee__ inline vector_float asc_prelu(vector_float src0, vector_float alpha, vector_bool mask)
  ```
- **修复操作：**
  ```markdown
  ## 返回值说明

  仅适用于无 dst 参数的重载版本。

  | 返回值类型 | 含义 |
  |-----------|------|
  | vector_float | float 类型 PReLU 计算结果矢量 |
  | vector_half | half 类型 PReLU 计算结果矢量 |
  ```
- **修复说明：** 有返回值的 API 必须有返回值说明章节，列出返回值类型和含义。

**问题2：调用示例使用未定义常量 PAT_ALL - asc_prelu.md:112**
- **问题描述：** 示例代码中使用 `asc_create_mask_b32(PAT_ALL)`，但 `PAT_ALL` 在 `asc-devkit/include/` 全目录及整个仓库中均未找到定义。读者无法理解该常量的来源和取值范围。
- **原始证据：**
  ```cpp
  vector_bool mask = asc_create_mask_b32(PAT_ALL); // 通过掩码设置接口预先赋值
  ```
- **修复操作：**
  ```cpp
  // 方案1：说明 PAT_ALL 来源
  vector_bool mask = asc_create_mask_b32(PAT_ALL); // PAT_ALL 为编译器内置 pattern 枚举值，表示全部元素置 1

  // 方案2：替换为文档化的 mask 设置方式
  vector_bool mask;
  uint32_t maskValue = 0xFFFFFFFF;
  mask = asc_update_mask_b32(maskValue);
  ```
- **修复说明：** 示例代码中使用的常量必须在文档中说明来源，或替换为对外文档中可查到的 API。
