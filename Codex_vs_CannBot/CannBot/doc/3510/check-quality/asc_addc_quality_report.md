**问题1：地址重叠约束完全缺失 - asc_addc.md:70-75**
- **问题描述：** 约束说明段未说明src0、src1、dst、carry参数是否允许地址重叠，以及重叠时的使用条件和行为
- **原始证据：**
  ```markdown
  - 本接口在非 AIV 上调用直接返回。
  - `mask` 需通过掩码设置接口预先赋值后再传入，未赋值的掩码寄存器内容不确定，会导致有效元素位置错误。
  - 运算输出完整计算结果（包含进位位），不受 asc_set_ctrl 影响，硬件不会对输出进行饱和或截断。
  - 本接口在 Vector Function（`__simd_vf__` 标记的函数）内调用。
  ```
- **修复操作：**
  ```markdown
  - src0、src1、dst 分别使用不同的矢量数据寄存器，carry 和 carry_src 使用不同的掩码寄存器，不允许地址重叠。

- **修复说明：** 地址重叠约束是API安全使用的关键信息，开发者需明确知道是否可以复用寄存器，缺少此约束可能导致计算结果不确定。

  Carry flag（进位/借位标志）用于表示加法进位或减法无借位。若src0、src1、carry_src输入按位相加后最高位有进位，在carry中对应位置每4bit的最低位写1，否则写0。

  ```
