1. 优先修复影响内容正确性、接口可用性或关键结构完整性的问题：

   - **API-PROD-01**（强制）：调整产品支持顺序，将Kirin X90和Kirin 9030移至Atlas 200I/500 A2推理产品之后、Atlas 推理系列产品之前（规范顺序：950 → A3 → 910b → 310b → x90 → 9030 → 310p → 910）。
   - **API-CHECK-023**（强制）：将第20行的`#include`语句从行内代码改为带`cpp`语言标记的代码块呈现。
   - **API-CHECK-008**（强制）：为首次出现的术语AIV（第22行）、VL（第22行）添加解释或超链接；为关联API表中的asc_float2half（第150行）、asc_exp_sub_half2float（第151行）添加超链接。
   - **API-CHECK-007**（强制）：在第136行补充完整样例的相对路径链接；在调用示例末尾补充结果描述。
