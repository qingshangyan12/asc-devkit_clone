# 协作组

协作组（cooperative_groups）是Ascend C SIMT 编程模型的一种拓展，用于组织协作线程组。协作组使开发者能够控制线程协作的粒度，从而帮助他们实现更高效的并行分解方式。

所有协作组api均在`cooperative_groups`命名空间下。

当前提供协作组类型:

- [thread_block](thread_block/简介.md)
- [coalesced_group](coalesced_group/简介.md)
- [thread_block_tile](thread_block_tile/简介.md)

协作组支持将一个父组划分为多个子组，提供以下划分操作：

- [tiled_partition](tiled_partition.md)
- [binary_partition](binary_partition.md)
