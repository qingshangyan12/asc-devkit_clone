# Built-in Data Types

SIMT programming provides a series of data types applicable to the device side, including scalars, short vectors, and the dim3 structure.

## Scalar Types

Scalar data types cover the boolean type (bool), integer types (uint8/int8 to uint64/int64), and floating-point types (float8\_e4m3, float8\_e5m2, hifloat8, half, bfloat16, and float).

- Boolean type:  
  bool: All zeros indicate false; otherwise, true. It occupies 8 bits of memory. The value is true or false.
- Integer types:
  - uint8_t: unsigned char; occupies 8 bits of memory; value range: [0, 255].
  - int8_t: signed char; occupies 8 bits of memory; value range: [-128, 127].
  - uint16_t: unsigned short; occupies 16 bits of memory; value range: [0, 65535].
  - int16_t: signed short; occupies 16 bits of memory; value range: [-32768, 32767].
  - uint32_t: unsigned int; occupies 32 bits of memory; value range: [0, 4294967295].
  - int32_t: signed int; occupies 32 bits of memory; value range: [-2147483648, 2147483647].
  - uint64_t: unsigned long; occupies 64 bits of memory; value range: [0, 18446744073709551615].
  - int64_t: signed long; occupies 64 bits of memory; value range: [-9223372036854775808, 9223372036854775807].
- Floating-point types:
  - float8_e4m3_t: 1 sign bit, 4 exponent bits, and 3 mantissa bits; occupies 8 bits of memory; value range: [2^6 - 2^9, 2^9 - 2^6].
  - float8_e5m2_t: 1 sign bit, 5 exponent bits, and 2 mantissa bits; occupies 8 bits of memory; value range: [2^13 - 2^16, 2^16 - 2^13].
  - hifloat8_t: 1 sign bit and 2 dot-field bits, with the exponent and mantissa bit widths determined by the dot-field encoding; occupies 8 bits of memory; the dot-field encoding determines the data precision and value range.
  - half: 1 sign bit, 5 exponent bits, and 10 mantissa bits; occupies 16 bits of memory; value range: [2^5 - 2^16, 2^16 - 2^5].
  - bfloat16_t: 1 sign bit, 8 exponent bits, and 7 mantissa bits; occupies 16 bits of memory; value range: [2^120 - 2^128, 2^128 - 2^120].
  - float: 1 sign bit, 8 exponent bits, and 23 mantissa bits; occupies 32 bits of memory; value range: [2^104 - 2^128, 2^128 - 2^104].

## Short Vector Types

A short vector type is a fixed-length vector type provided in the SIMT programming model to simplify the representation and manipulation of vector data. This type is suitable for processing data that contains multiple components, such as coordinates, colors, and vector operations.

-   Memory characteristics:

    Compact storage: Short vector types are stored contiguously in memory without padding.

    Alignment requirement: The natural alignment principle is followed to improve access efficiency.

    Cross-thread sharing: Short vectors can be stored in the Unified Buffer for sharing within a thread block.

    Direct memory access: Loading from and storing to the global memory are supported.

-   Application scenarios:

    Color processing: operations on RGB/RGBA color values.

    Vector operations: vector computation in physical simulation and graphics rendering.

    Data packing: packing multiple related values for processing.

    Memory access optimization: improving memory bandwidth utilization through vectorization.

-   Short vector variable access:

    Variables are accessed by using .x, .y, .z, and .w.

To use the short vector constructors, the simt\_api/vector\_functions.h header file must be included. An example of the call is as follows:

```cpp
#include "simt_api/vector_functions.h"
__global__ __launch_bounds__(1024) void kernel_make_int2(int2* dst, int* x, int* y)
{
    int idx = threadIdx.x + blockIdx.x * blockDim.x;
    dst[idx] = make_int2(x[idx], y[idx]);
}
```

## dim3<a name="section02911713103312"></a>

A built-in structure that specifies and obtains the x, y, and z dimensions of a thread grid and a thread block.

dim3 is a built-in structure type that consists of three unsigned integers. The structure is defined as follows:

```cpp
struct dim3{
    unsigned int x, y, z;
    dim3(unsigned int x, unsigned int y = 1, unsigned int z = 1)
        :x(x), y(y), z(z) {}
};
```

It is used to specify the sizes of three different dimensions. The total number of the three dimensions is x \* y \* z. Developers can create a dim3 structure in the following ways.

```cpp
dim3(x); // Creates a one-dimensional structure. dimy and dimz use the default value 1.
dim3(x, y); // Creates a two-dimensional structure. dimz uses the default value 1.
dim3(x, y, z); // Creates a three-dimensional structure.
```
