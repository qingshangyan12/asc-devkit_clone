## 功能说明<a name="section618mcpsimp"></a>

- 核心功能：计算输入整数二进制表示中从最高有效位开始连续的前导零的个数。
- 实现原理/公式：
  - 当输入为 0 时，返回值的位宽等于输入类型的位宽（例如 32 位输入返回 32，64 位输入返回 64）。
  - 当输入非零时，返回值范围为 $[0, N-1]$，其中 $N$ 为类型位宽（32 或 64）。

## 函数原型<a name="section620mcpsimp"></a>

```
int __clz(int x)
```

```
int __clz(long long x)
```

```
int __clz(long x)
```

## 参数说明<a name="section0866173114710"></a>

| 参数名 | 输入/输出 | 描述 |
|---|---|---|
| x | 输入 | 源操作数。 |

## 返回值说明<a name="section640mcpsimp"></a>

返回输入整数二进制表示中从最高有效位开始连续的前导零的位数。当输入为 0 时，对于 32 位类型返回 32，对于 64 位类型返回 64。特殊值测试结果如下：

| 输入 | 返回值 |
|---|---|
| 0（32 位） | 32 |
| 0（64 位） | 64 |
| 1（32 位） | 31 |
| 1（64 位） | 63 |
| -1（32 位） | 0 |
| -1（64 位） | 0 |
| int_max（32 位） | 1 |
| int_min（32 位） | 0 |
| ll_max（64 位） | 1 |
| ll_min（64 位） | 0 |

## 调用示例<a name="section134121647154719"></a>

-   SIMT编程场景：

    ```
    __global__ __launch_bounds__(1024) void KernelClz(int* dst, int* x)
    {
        int idx = threadIdx.x + blockIdx.x * blockDim.x;
        dst[idx] = __clz(x[idx]);
    }
    ```

    ```
    __global__ __launch_bounds__(1024) void KernelClz(int* dst, long long* x)
    {
        int idx = threadIdx.x + blockIdx.x * blockDim.x;
        dst[idx] = __clz(x[idx]);
    }
    ```

    {
