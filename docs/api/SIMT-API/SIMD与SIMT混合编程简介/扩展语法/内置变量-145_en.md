# Built-in Variables

The following built-in variables of the dim3 type are available only on the device:

-   <a id="blockdim"></a>blockDim

    A built-in global variable that can be used directly in a kernel function. It obtains the three-dimensional hierarchy of the threads configured in a thread block. blockDim.x, blockDim.y, and blockDim.z indicate the number of threads in each of the three dimensions of the thread block.

-   <a id="griddim"></a>gridDim

    A built-in global variable that can be used only in a kernel function. It indicates how many thread blocks the entire computing task consists of in each dimension.

-   blockIdx

    A built-in global variable that can be used only in a kernel function. It obtains the block index, that is, the position coordinates of the thread block to which the current thread belongs in the entire grid. The value of blockIdx.x ranges from 0 to gridDim.x - 1, and blockIdx.y and blockIdx.z can currently return only 0.

-   threadIdx

    A built-in global variable that can be used directly in a kernel function. It obtains the index of the current thread within the thread block. threadIdx.x, threadIdx.y, and threadIdx.z indicate the index of the current thread in each of the three dimensions. The value of threadIdx.x is in the range \[0, blockDim.x\), that of threadIdx.y is in the range \[0, blockDim.y\), and that of threadIdx.z is in the range \[0, blockDim.z\). The index of a thread within a thread block is calculated as follows:

    -   For a one-dimensional thread block, the index of a thread within the thread block is threadIdx.x.
    -   For a two-dimensional thread block, the index of a thread within the thread block is \(threadIdx.x + threadIdx.y \* blockDim.x\).
    -   For a three-dimensional thread block, the index of a thread within the thread block is \(threadIdx.x + threadIdx.y \* blockDim.x + threadIdx.z \* blockDim.x \* blockDim.y\).

The following built-in variable of the int type is available only on the device:

-   warpSize

    A variable of the const int32_t type that indicates the number of threads in a warp. Currently, the value is fixed at 32.
