# 矢量数据搬运

矢量数据搬运类API，用于Global Memory与Unified Buffer之间的数据搬运，单独使用时需要引入 `vector_datamove.h`。

| API名称 | 说明 |
|----------|-----------|
| [asc_copy_gm2ub](asc_copy_gm2ub.md) | 将数据从Global Memory搬运到 Unified Buffer。 |
| [asc_copy_gm2ub_align](asc_copy_gm2ub_align/asc_copy_gm2ub_align_arch_2201.md) | 提供数据非对齐搬运的功能，将数据从Global Memory搬运到 Unified Buffer，并支持8位/16位/32位数据类型搬运。 |
| [asc_copy_ub2gm](asc_copy_ub2gm.md) | 将数据从Unified Buffer搬运到 Global Memory。 |
| [asc_copy_ub2gm_align](asc_copy_ub2gm_align/asc_copy_ub2gm_align_arch_2201.md) | 将数据从Unified Buffer搬运到 Global Memory，支持8位/16位/32位分块拷贝操作。 |
| [asc_copy_ub2l1](asc_copy_ub2l1.md) | 将数据从Unified Buffer (UB) 搬运到L1 Buffer。 |
| [asc_copy_ub2ub](asc_copy_ub2ub.md) | 将数据从Unified Buffer搬运到Unified Buffer。 |
| [asc_ndim_copy_gm2ub](asc_ndim_copy_gm2ub.md) | N维GM到UB拷贝。 |
| [asc_set_copy_pad_val](asc_set_copy_pad_val.md) | 设置连续搬运数据块左右两侧需要填补的数据值。 |
| [asc_set_gm2ub_loop_size](asc_set_gm2ub_loop_size.md) | 设置GM到UB拷贝循环大小。 |
| [asc_set_gm2ub_loop1_stride](asc_set_gm2ub_loop1_stride.md) | 设置GM到UB拷贝第一维循环步长。 |
| [asc_set_gm2ub_loop2_stride](asc_set_gm2ub_loop2_stride.md) | 设置GM到UB拷贝第二维循环步长。 |
| [asc_set_ndim_loop_stride](asc_set_ndim_loop_stride.md) | 设置N维拷贝循环步长。 |
| [asc_set_ndim_pad_count](asc_set_ndim_pad_count.md) | 设置N维拷贝填充计数。 |
| [asc_set_ndim_pad_value](asc_set_ndim_pad_value.md) | 设置N维拷贝填充值。 |
| [asc_set_ub2gm_loop_size](asc_set_ub2gm_loop_size.md) | 设置UB到GM拷贝循环大小。 |
| [asc_set_ub2gm_loop1_stride](asc_set_ub2gm_loop1_stride.md) | 设置UB到GM拷贝第一维循环步长。 |
| [asc_set_ub2gm_loop2_stride](asc_set_ub2gm_loop2_stride.md) | 设置UB到GM拷贝第二维循环步长。 |
