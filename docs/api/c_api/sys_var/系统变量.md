# 系统变量

系统变量类API，用于获取和设置系统寄存器、核编号等系统信息，单独使用时需要引入 `sys_var.h`。

| API名称 | 说明 |
|----------|-----------|
| [asc_get_arch_ver](asc_get_arch_ver.md) | 获取当前AI处理器架构版本号。 |
| [asc_get_ar_spr](asc_get_ar_spr.md) | 获取AR寄存器的值。 |
| [asc_get_block_idx](asc_get_block_idx.md) | 获取当前运行核的索引。 |
| [asc_get_block_num](asc_get_block_num.md) | 获取AI核数。 |
| [asc_get_core_id](asc_get_core_id.md) | 获取当前核的编号。 |
| [asc_get_ctrl](asc_get_ctrl.md) | 读取CTRL寄存器（控制寄存器）的值。 |
| [asc_get_ffts_base_addr](asc_get_ffts_base_addr.md) | 获取核间同步寄存器的基地址。 |
| [asc_get_phy_buf_addr](asc_get_phy_buf_addr.md) | 基于偏移量获取片上实际物理地址。 |
| [asc_get_phy_stack_base](asc_get_phy_stack_base.md) | 获取物理堆栈基地址。 |
| [asc_get_program_counter](asc_get_program_counter.md) | 获取程序计数器的指针。 |
| [asc_get_smmu_tag_version](asc_get_smmu_tag_version.md) | 获取SMMU版本信息。 |
| [asc_get_status](asc_get_status.md) | 获取状态信息。 |
| [asc_get_sub_block_id](asc_get_sub_block_id.md) | 获取AI Core上Vector核的ID。 |
| [asc_get_sub_block_num](asc_get_sub_block_num.md) | 获取一个AI Core上Cube Core或Vector Core的数量。 |
| [asc_get_sys_virtual_base](asc_get_sys_virtual_base.md) | 获取系统虚拟基地址。 |
| [asc_get_system_cycle](asc_get_system_cycle.md) | 获取当前系统cycle数。 |
| [asc_get_vf_len](asc_get_vf_len.md) | 获取Tensor位宽VL的大小。 |
| [asc_set_ctrl](asc_set_ctrl.md) | 设置CTRL寄存器的值。 |
| [asc_set_ffts_base_addr](asc_set_ffts_base_addr.md) | 设置核间同步寄存器的基地址。 |
| [asc_set_gm2l1_nz_para](asc_set_gm2l1_nz_para.md) | 设置MTE2_NZ_PARA寄存器的值。 |
| [asc_set_l0c2gm_channel_para](asc_set_l0c2gm_channel_para.md) | 对通道步长参数的专用寄存器的比特位进行设置。 |
| [asc_set_l0c2gm_quant_post](asc_set_l0c2gm_quant_post.md) | 设置QUANT_POST寄存器的值。 |
| [asc_set_l0c2gm_relu_alpha](asc_set_l0c2gm_relu_alpha.md) | 设置RELU_ALPHA寄存器的值。 |
| [asc_set_l12l0_padding_val](asc_set_l12l0_padding_val.md) | 设置PADDING_B寄存器的值。 |
| [asc_set_l3d_rpt_b](asc_set_l3d_rpt_b.md) | 设置asc_copy_l12l0a、asc_copy_l12l0b的2D格式搬运的repeat参数。 |
