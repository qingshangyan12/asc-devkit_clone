# 矩阵数据搬运

矩阵计算相关的数据搬运类API，用于Global Memory、L1 Buffer与L0 Buffer之间的数据搬运，单独使用时需要引入 `cube_datamove.h`。

| API名称 | 说明 |
|----------|-----------|
| [asc_copy_gm2l0a](asc_copy_gm2l0a.md) | 将GM中的数据搬运到L0A中。 |
| [asc_copy_gm2l0b](asc_copy_gm2l0b.md) | 将GM中的数据搬运到L0B中。 |
| [asc_copy_gm2l1](asc_copy_gm2l1/asc_copy_gm2l1_arch_2201.md) | 将GM中的数据搬运到L1中。 |
| [asc_copy_gm2l1_align](asc_copy_gm2l1_align.md) | 将GM中的数据padding后搬运到L1中。 |
| [asc_copy_gm2l1_dn2nz](asc_copy_gm2l1_dn2nz.md) | 将GM中的数据搬运到L1中，执行DN->NZ/NCHW->NC1HWC0操作。 |
| [asc_copy_gm2l1_nd2nz](asc_copy_gm2l1_nd2nz/asc_copy_gm2l1_nd2nz_arch_2201.md) | 将GM中的数据搬运到L1中并执行ND2NZ转换。 |
| [asc_copy_l0c2gm](asc_copy_l0c2gm/asc_copy_l0c2gm_arch_2201.md) | 将L0C中的数据搬运到GM中。 |
| [asc_copy_l0c2l1](asc_copy_l0c2l1/asc_copy_l0c2l1_arch_2201.md) | 矩阵计算完成后对结果进行量化处理并搬运到L1中。 |
| [asc_copy_l0c2ub](asc_copy_l0c2ub.md) | 将L0C中的数据搬运到UB中。 |
| [asc_copy_l12bt](asc_copy_l12bt/asc_copy_l12bt_arch_2201.md) | 将MMAD指令的Bias数据从L1 Buffer搬运到BiasTable Buffer中。 |
| [asc_copy_l12fb](asc_copy_l12fb/asc_copy_l12fb_arch_2201.md) | 将数据从L1 Buffer搬运到Fixpipe Buffer中。 |
| [asc_copy_l12fb_v2](asc_copy_l12fb_v2.md) | 将数据从L1 Buffer搬运到Fixpipe Buffer中。 |
| [asc_copy_l12gm](asc_copy_l12gm.md) | 将数据从L1搬运到GM。 |
| [asc_copy_l12l0a](asc_copy_l12l0a/asc_copy_l12l0a_arch_2201.md) | 用于搬运存放在L1 Buffer里的512B大小的矩阵到L0A Buffer里。 |
| [asc_copy_l12l0a_mx](asc_copy_l12l0a_mx.md) | 将Mx scale矩阵从L1 Buffer搬运到L0A Buffer。 |
| [asc_copy_l12l0a_trans](asc_copy_l12l0a_trans.md) | 带转置的2D格式数据从L1 Buffer到L0A Buffer的加载。 |
| [asc_copy_l12l0b](asc_copy_l12l0b/asc_copy_l12l0b_arch_2201.md) | 用于搬运存放在L1 Buffer里的512B大小的矩阵到L0B Buffer里。 |
| [asc_copy_l12l0b_mx](asc_copy_l12l0b_mx.md) | 将Mx scale矩阵从L1 Buffer搬运到L0B Buffer。 |
| [asc_copy_l12l0b_sparse](asc_copy_l12l0b_sparse.md) | 搬运512B大小的稠密权重矩阵到L0B Buffer并读取128B大小的索引矩阵用于稀疏化。 |
| [asc_copy_l12l0b_trans](asc_copy_l12l0b_trans/asc_copy_l12l0b_trans_arch_2201.md) | 带转置的2D格式数据从L1 Buffer到L0B Buffer的加载。 |
| [asc_copy_l12l0c](asc_copy_l12l0c.md) | 将矩阵由L1 Buffer搬运到L0C Buffer中。 |
| [asc_copy_l12ub](asc_copy_l12ub.md) | 将数据从L1 Buffer搬运到Unified Buffer中。 |
| [asc_fill_l0a](asc_fill_l0a.md) | 将L0A Buffer的Local Memory初始化为某一具体数值。 |
| [asc_fill_l0b](asc_fill_l0b.md) | 将L0B Buffer的Local Memory初始化为某一具体数值。 |
| [asc_fill_l1](asc_fill_l1.md) | 将L1 Buffer的Local Memory初始化为某一具体数值。 |
| [asc_load_image_to_cbuf](asc_load_image_to_cbuf.md) | 将图像数据从Global Memory搬运到L1 Buffer。 |
| [asc_set_gm2l1_loop_size](asc_set_gm2l1_loop_size.md) | 设置GM到L1拷贝循环大小。 |
| [asc_set_gm2l1_loop1_stride](asc_set_gm2l1_loop1_stride.md) | 设置GM到L1拷贝第一维循环步长。 |
| [asc_set_gm2l1_loop2_stride](asc_set_gm2l1_loop2_stride.md) | 设置GM到L1拷贝第二维循环步长。 |
| [asc_set_gm2l1_pad](asc_set_gm2l1_pad.md) | 设置GM到L1拷贝填充配置。 |
| [asc_set_l0c_copy_params](asc_set_l0c_copy_params.md) | 设置随路格式转换的相关配置。 |
| [asc_set_l0c_copy_prequant](asc_set_l0c_copy_prequant.md) | 设置量化流程中的标量量化参数。 |
| [asc_set_l0c2gm_lrelu_alpha](asc_set_l0c2gm_lrelu_alpha.md) | 设置asc_copy_l0c2l1或asc_copy_l0c2gm接口的Leaky ReLU alpha值。 |
| [asc_set_l13d_fmatrix](asc_set_l13d_fmatrix.md) | 设置Feature map属性描述（左矩阵）。 |
| [asc_set_l13d_fmatrix_b](asc_set_l13d_fmatrix_b.md) | 设置Feature map属性描述（右矩阵）。 |
| [asc_set_l13d_padding](asc_set_l13d_padding.md) | 设置Pad属性描述。 |
| [asc_set_l13d_rpt](asc_set_l13d_rpt.md) | 用于设置Load3Dv2接口的repeat参数。 |
| [asc_set_l13d_size](asc_set_l13d_size.md) | 设置3D格式搬运接口在L1 Buffer的边界值。 |
