# 标量计算

标量计算类API，用于位操作、计数等标量计算，单独使用时需要引入 `scalar_compute.h`。

| API名称 | 说明 |
|----------|-----------|
| [asc_clear_nthbit](asc_clear_nthbit.md) | 将一个uint64_t整数bits的第idx位设置为0。 |
| [asc_clz](asc_clz.md) | 计算参数前导零的数量。 |
| [asc_ffs](asc_ffs.md) | 从最低位向最高位查找第一个值为1的位并返回其位置。 |
| [asc_ffz](asc_ffz.md) | 获取二进制中从最低有效位开始的第一个0出现的位置。 |
| [asc_float2int32](asc_float2int32.md) | 将float类型数据转换为int32_t类型（标量）。 |
| [asc_popc](asc_popc.md) | 获取一个uint64_t类型数字的二进制中1的个数。 |
| [asc_set_nthbit](asc_set_nthbit.md) | 计算一个uint64_t类型数字的指定二进制位置为1。 |
| [asc_sflbits](asc_sflbits.md) | 计算从最高数值位开始与符号位相同的连续比特位的个数。 |
| [asc_store_dev](asc_store_dev.md) | 标量存储操作。 |
| [asc_zero_bits_cnt](asc_zero_bits_cnt.md) | 获取一个uint64_t类型数字的二进制中0的个数。 |
