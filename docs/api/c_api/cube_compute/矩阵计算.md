# 矩阵计算

矩阵计算类API，用于执行矩阵乘加等操作，单独使用时需要引入 `cube_compute.h`。

| API名称 | 说明 |
|----------|-----------|
| [asc_enable_hf32](asc_enable_hf32.md) | 用于设置Mmad计算开启HF32模式。 |
| [asc_enable_hf32_trans](asc_enable_hf32_trans.md) | 设置HF32模式取整方式。 |
| [asc_get_l0c2gm_prequant](asc_get_l0c2gm_prequant.md) | 获取量化操作前矢量的起始地址。 |
| [asc_get_l0c2gm_relu](asc_get_l0c2gm_relu.md) | 获取ReLU操作前矢量的起始地址。 |
| [asc_get_l0c2gm_unitflag](asc_get_l0c2gm_unitflag.md) | 获取unit_flag设置。 |
| [asc_mmad](asc_mmad.md) | 完成矩阵乘加操作。 |
| [asc_mmad_mx](asc_mmad_mx.md) | 完成矩阵乘加操作（MX模式）。 |
| [asc_mmad_sparse](asc_mmad_sparse.md) | 完成矩阵乘加操作，左矩阵A为稀疏矩阵。 |
| [asc_set_fp32_mode](asc_set_fp32_mode.md) | 设置Mmad计算开启FP32模式。 |
| [asc_set_l0c2gm_config](asc_set_l0c2gm_config.md) | 设置量化流程中的矢量量化参数。 |
| [asc_set_l0c2gm_nz2nd](asc_set_l0c2gm_nz2nd.md) | 设置NZ2ND格式转换。 |
| [asc_set_mmad_direction_m](asc_set_mmad_direction_m.md) | 设置mmad计算时优先通过N方向。 |
| [asc_set_mmad_direction_n](asc_set_mmad_direction_n.md) | 设置mmad计算时优先通过M方向。 |
