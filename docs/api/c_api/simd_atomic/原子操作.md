# 原子操作

原子操作类API，用于在数据传输过程中执行原子累加、原子比较（最大/最小值）等操作，单独使用时需要引入 `atomic.h`。

| API名称 | 说明 |
|----------|-----------|
| [asc_get_store_atomic_config](asc_get_store_atomic_config.md) | 获取原子操作使能位与原子操作类型的值。 |
| [asc_set_atomic_add](asc_set_atomic_add.md) | 设置对后续的从UB/L0C Buffer/L1 Buffer到Global Memory的数据传输开启原子累加。 |
| [asc_set_atomic_max](asc_set_atomic_max.md) | 设置计算结果以原子比较的方式传输到GM（最大值）。 |
| [asc_set_atomic_min](asc_set_atomic_min.md) | 设置计算结果以原子比较的方式传输到GM（最小值）。 |
| [asc_set_atomic_none](asc_set_atomic_none.md) | 清空原子操作的状态。 |
| [asc_set_store_atomic_config_v1](asc_set_store_atomic_config_v1.md) | 设置原子操作使能位与原子操作类型的值（V1版本）。 |
| [asc_set_store_atomic_config_v2](asc_set_store_atomic_config_v2.md) | 设置原子操作使能位与原子操作类型的值（V2版本）。 |
