# 同步控制

同步控制类API，用于控制不同流水线之间的执行顺序和同步标志，单独使用时需要引入 `sync.h`。

| API名称 | 说明 |
|----------|-----------|
| [asc_lock](asc_lock.md) | 用于AI Core内部异步流水线同步的接口。 |
| [asc_sync](asc_sync.md) | 等待所有流水线操作完成。 |
| [asc_sync_block_arrive](asc_sync_block_arrive.md) | 发送同步信息数据到核间同步寄存器，设置同步点。 |
| [asc_sync_block_wait](asc_sync_block_wait.md) | 等待所有同步对象到达flagID对应的同步点。 |
| [asc_sync_data_barrier](asc_sync_data_barrier.md) | 阻塞后续指令执行直到之前的内存访问指令执行结束。 |
| [asc_sync_inter_wait](asc_sync_inter_wait.md) | 等待block内同步标志。 |
| [asc_sync_intra_arrive](asc_sync_intra_arrive.md) | 向核间同步寄存器发送同步信号。 |
| [asc_sync_intra_wait](asc_sync_intra_wait.md) | 等待核间同步寄存器同步标志。 |
| [asc_sync_mte2](asc_sync_mte2.md) | 等待PIPE_MTE2流水完成。 |
| [asc_sync_mte3](asc_sync_mte3.md) | 等待PIPE_MTE3流水完成。 |
| [asc_sync_notify](asc_sync_notify.md) | 设置同步标志。 |
| [asc_sync_pipe](asc_sync_pipe.md) | 等待指定流水线操作完成。 |
| [asc_sync_vec](asc_sync_vec.md) | 同步所有流水线。 |
| [asc_sync_wait](asc_sync_wait.md) | 等待同步标志。 |
| [asc_unlock](asc_unlock.md) | 释放缓存。 |
