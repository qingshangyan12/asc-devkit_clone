# 构造函数<a name="ZH-CN_TOPIC_0000002568744376"></a>

## 函数功能<a name="zh-cn_topic_0000001936560960_section36583473819"></a>

coalesced\_group不提供默认的构造函数，用户使用coalesced\_threads函数获取对象。

## 函数原型<a name="zh-cn_topic_0000001936560960_section13230182415108"></a>

```
coalesced_group coalesced_threads();
```

## 参数说明<a name="section424393218389"></a>

无

## 返回值说明<a name="zh-cn_topic_0000001936560960_section25791320141317"></a>

返回一个coalesced\_group对象。

## 约束说明<a name="section13341813114116"></a>

无

## 调用示例<a name="zh-cn_topic_0000001936560960_section320753512363"></a>

```
if (threadIdx.x % 2 == 0) {
    coalesced_group active = coalesced_threads(); // 该coalesced_group中包含一个warp内所有线程id为偶数的线程
}
```
