# 概述

**表 1**  Reg数据搬出

| 接口 | 描述 |
| --- | --- |
| [连续对齐搬出（StoreAlign）](连续对齐搬出（StoreAlign）.md) | 将RegTensor中的数据对齐搬出至UB中，支持单搬出和双搬出模式。 |
| [非连续对齐搬出（StoreAlign）](非连续对齐搬出（StoreAlign）.md) | 将RegTensor中的数据以DataBlock为单位搬出至UB中。 |
| [连续非对齐搬出（StoreUnAlign）](连续非对齐搬出（StoreUnAlign）.md) | 将RegTensor中的数据非对齐搬出至UB中。 |
| [MaskReg搬出（StoreAlign）](MaskReg搬出（StoreAlign）.md) | 将MaskReg中的数据搬出至UB中。 |
| [MaskReg非对齐搬出（StoreUnAlign）](MaskReg非对齐搬出（StoreUnAlign）.md) | 将MaskReg中的数据非对齐搬出至UB中。 |
| [离散搬出（Scatter）](离散搬出（Scatter）.md) | 根据索引值将RegTensor中的元素分散到UB中。 |
| [Store](Store.md) | 将RegTensor中的数据搬出至UB地址中。 |
