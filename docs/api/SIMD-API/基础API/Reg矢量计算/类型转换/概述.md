# 概述

**表 1**  类型转换

| 接口 | 描述 |
| --- | --- |
| [Cast](Cast.md) | 将源操作数数据类型转换成目的操作数数据类型，能够实现浮点转整数、浮点转浮点、整数转浮点、整数转整数的数据类型转换。该接口可通过模板参数配置：[RegLayout](../数据类型/RegLayout.md)、[SatMode](../数据类型/SatMode.md)、[MaskMergeMode](../数据类型/MaskMergeMode.md)、[RoundMode](../数据类型/RoundMode.md)。 |
| [Truncate](Truncate.md) | 将源操作数中的浮点数元素截断为整数值（保留原数据类型），并存入目的操作数。目的操作数和源操作数数据类型需保持一致，支持hlaf、float、bfloat16_t数据类型 |
