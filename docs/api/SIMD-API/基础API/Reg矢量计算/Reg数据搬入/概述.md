# 概述

**表 1**  Reg数据搬入

| 接口 | 描述 |
| --- | --- |
| [连续对齐搬入（LoadAlign）](连续对齐搬入（LoadAlign）.md) | 将UB地址的数据对齐搬入至RegTensor中，支持单搬入和双搬入模式。 |
| [非连续对齐搬入（LoadAlign）](非连续对齐搬入（LoadAlign）.md) | 将UB地址的数据以DataBlock为单位搬入至RegTensor中。 |
| [连续非对齐搬入（LoadUnAlign）](连续非对齐搬入（LoadUnAlign）.md) | 将UB地址的数据非对齐搬入至RegTensor中。 |
| [MaskReg搬入（LoadAlign）](MaskReg搬入（LoadAlign）.md) | 将UB地址的数据搬入至MaskReg中。 |
| [MaskReg搬入（MaskGenWithRegTensor）](MaskReg搬入（MaskGenWithRegTensor）.md) | 将RegTensor中的数据搬入至MaskReg中。 |
| [离散搬入（Gather）](离散搬入（Gather）.md) | 根据索引值将数据按元素收集到RegTensor中。 |
| [离散搬入（GatherB）](离散搬入（GatherB）.md) | 根据索引值将数据按DataBlock收集到RegTensor中。 |
| [Load](Load.md) | 将UB地址的数据搬入至RegTensor中。 |
| [Move](Move.md) | 将srcReg中的元素逐个复制到dstReg中。 |
