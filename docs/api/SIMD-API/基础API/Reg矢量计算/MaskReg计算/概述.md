# 概述<a name="ZH-CN_TOPIC_0000001925092250"></a>

MaskReg计算接口用于对MaskReg寄存器进行位操作，包括数据搬移、交织、解交织、选择、打包、解包等操作。

**表 1 MaskReg计算接口**

| API | 功能说明 |
| --- | --- |
| [Move](Move-10.md) | 将src中的元素复制到dst中的对应位置。如果有输入mask，则仅复制被mask选定的有效元素，无效元素填0。 |
| [Interleave](Interleave-11.md) | 将源操作数src0和src1中的元素交织存入目的操作数dst0和dst1中。 |
| [DeInterleave](DeInterleave-12.md) | 将源操作数src0和src1中的元素解交织存入目的操作数dst0和dst1中。 |
| [Select](Select-13.md) | 给定两个源操作数src0和src1，根据mask的比特位值选取元素，得到目的操作数dst。 |
| [Pack](Pack.md) | 根据所选的低位模式或高位模式，将输入MaskReg的偶数位bit提取到输出MaskReg的低半部分或高半部分。 |
| [UnPack](UnPack.md) | 根据所选的低位模式或高位模式，将输入MaskReg的低半部分或高半部分展开到输出MaskReg。 |
| [MoveMask](MoveMask.md) | 从特殊寄存器SPR{MASK1, MASK0}读取mask值并根据数据类型格式写入函数返回值MaskReg。 |
