# 内存结构<a name="ZH-CN_TOPIC_0000002573902869"></a>

Unified Buffer缓存总大小为192KB，包含16个bank group，每个bank group包含3个bank。每个bank大小为4KB，由128行组成，每行长度为32B。

UB的地址编码格式：

```
UB_ADDR[17:0] = {BANK[1:0], BANK_DEPTH[6:0], BG[3:0], BANK_WIDTH[4:0]}
```

**图 1**  UB内存结构图<a name="zh-cn_topic_0000002525288414_fig199915485811"></a>  
![](figures/UB内存结构图.png "UB内存结构图")

根据内存结构，bank冲突主要可以分为以下三种类型：

-   **读写冲突**：读操作和写操作同时尝试访问同一个bank。
-   **写写冲突**：多个写操作同时尝试访问同一个bank group。
-   **读读冲突**：多个读操作同时尝试访问同一个bank group。

**注：bank冲突的场景与Unified Buffer的规格密切相关，规格的变化通常会导致bank冲突场景的变化。**

## 基于地址重叠场景的Bank冲突分析<a name="zh-cn_topic_0000002525288414_section474617392321"></a>

Vector指令的读操作和写操作地址完全重叠时，由于读和写不在同一拍完成，不会发生Bank冲突。开发者可以利用这一项优化合理复用源操作数和目的操作数。

注：由于存在指令Pipeline，读写冲突可能发生在前一个DataBlock的写操作和当前DataBlock的读操作之间（取决于指令时延）。
