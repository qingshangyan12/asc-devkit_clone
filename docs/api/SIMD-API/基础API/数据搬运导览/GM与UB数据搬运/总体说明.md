# 总体说明<a name="ZH-CN_TOPIC_0000002543422566"></a>

Global Memory（GM）与 Unified Buffer（UB）之间的数据搬运提供了多样化的接口，支持丰富的数据搬运场景（见[表1](#zh-cn_topic_0000002565937657_table12546123753110)）。为实现高效的向量（Vector）计算，系统支持将数据从 GM 搬运至 UB，供Vector计算单元进行向量计算；计算完成后，再将结果从 UB 搬回 GM，完成数据闭环。开发者能够通过灵活配置结构体参数，精确控制数据块数量、每个地址长度及地址间隔等关键属性，实现连续和非连续数据搬运（高维切分数据搬运），充分释放硬件的数据搬运与计算协同能力，显著提升向量算子的执行效率与整体性能。
