# 总体说明<a name="ZH-CN_TOPIC_0000002538231192"></a>

矩阵计算的搬出是AscendC编程框架中用于数据搬运的核心接口系列，主要实现L0C Buffer与Global Memory、L1 Buffer、UB之间的数据高效传输。该接口系列提供了多种数据搬运模式，能够满足矩阵计算中左右矩阵等数据的搬运需求，通常在Mmad接口后配合使用。

矩阵计算的搬出接口支持多种随路搬运场景，包括**随路量化、随路Relu、随路格式转换（NZ2ND、NZ2DN）、随路通道拆分（channel split）、随路通道合并（channel merge）、UB双目标模式**。通过灵活配置不同的参数结构体，开发者可以精确控制数据的搬运路径、起始位置、搬运长度、随路搬运能力等关键信息，充分利用硬件的数据搬运能力，最大化算子的整体执行性能。

**数据通路与存储层级**

矩阵计算的搬出接口支持多种数据通路，每种通路对应特定的存储层级和访问特性。

<cann-filter npu_type = "A3,910b">

针对Atlas A3 训练系列产品/Atlas A3 推理系列产品和Atlas A2 训练系列产品/Atlas A2 推理系列产品：

| 源位置 | 源地址对齐要求 | 目的位置 | 目的地址对齐要求 | 典型应用场景 |
|----------|---------------|----------|----------------|--------------|
| L0C Buffer | 64字节 | Global Memory | 1字节/32字节 | 从L0C Buffer搬出数据至GM（NZ2NZ/NZ2ND） |
| L0C Buffer | 64字节 | L1 Buffer | 32字节 | 从L0C Buffer搬出数据至L1 Buffer(NZ2NZ) |

</cann-filter>
