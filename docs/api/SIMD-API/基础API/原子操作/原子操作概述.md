# 原子操作概述<a name="ZH-CN_TOPIC_0000002555621180"></a>

**表1**  Scalar原子操作接口

| 对应接口 | 接口功能描述 |
| --- | --- |
| [AtomicAdd](AtomicAdd.md) | 用于在指定GM地址上进行原子加操作，将输入值原子加到address指向的GM地址上，返回该地址修改前的值。 |
| [AtomicMin](AtomicMin.md) | 用于在指定GM地址上进行原子取最小值操作，将地址中的旧值与输入标量值做比较，取最小值写回该地址。 |
| [AtomicMax](AtomicMax.md) | 用于在指定GM地址上进行原子取大操作，将GM地址上的旧值与输入的标量值进行比较，将较大值写回GM地址，并返回GM地址上做原子操作前的数据。 |
| [AtomicCas](AtomicCas.md) | 在指定GM地址上进行原子比较，如果和value1相等，则把value2的值赋值到GM上；如果和value1不相等，则GM上的值不变。 |
| [AtomicExch](AtomicExch.md) | 用于在GM内存中执行原子交换操作，读取指定GM地址上的数据并将新值存储回同一地址，返回交换前的旧值。 |

**表2**  数据搬运随路原子操作接口

| 对应接口 | 接口功能描述 |
| --- | --- |
| [SetAtomicAdd](SetAtomicAdd.md) | 对后续目的地址为GM的数据搬运开启原子累加。原子累加过程：将待拷贝的内容和GM已有内容进行求和，然后将求和结果写入GM。 |
| [SetAtomicType](SetAtomicType.md) | 通过设置模板参数来设定原子操作不同的数据类型。 |
| [DisableDmaAtomic](DisableDmaAtomic.md) | 关闭数据搬运随路原子操作功能。 |
| [SetAtomicMax(ISASI)](SetAtomicMax(ISASI).md) | 设置后续搬运到GM的数据是否执行原子比较：将待拷贝的内容和GM已有内容进行比较，然后将最大值写入GM。 |
| [SetAtomicMin(ISASI)](SetAtomicMin(ISASI).md) | 设置后续搬运到GM的数据是否执行原子比较：将待拷贝的内容和GM已有内容进行比较，然后将最小值写入GM。 |
| [SetStoreAtomicConfig(ISASI)](SetStoreAtomicConfig(ISASI).md) | 设置数据搬运的原子操作配置。 |
| [GetStoreAtomicConfig(ISASI)](GetStoreAtomicConfig(ISASI).md) | 获取数据搬运的原子操作配置。 |

如下图1的左侧子图所示，未开启原子操作时，写入GM的数据搬运完成后，GM中原始数据将被新搬运数据完全覆盖。如图1右侧子图所示，当数据搬运随路原子操作接口被调用后，系统将为后续写入GM的数据搬运开启原子操作。此时，数据搬运完成后，GM中的最终数据由原始GM数据与新搬运数据共同决定。
