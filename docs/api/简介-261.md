# 简介<a name="ZH-CN_TOPIC_0000002599343623"></a>

在Ascend 950 的SIMT架构中，硬件层面上处理器以32个线程为一组（一个warp）来执行线程。如果程序代码中存在数据依赖的条件分支，导致warp内的线程出现分支，那么warp会串行执行每个分支，并禁用不在该路径上的线程。那些在路径上保持活跃的线程被称为“合并线程”。coalesced\_group 用于发现并创建一个包含所有合并线程的协作组。

## 需要包含的头文件<a name="section78885814919"></a>

```
#include <simt_api/cooperative_groups.h>
```
