## 功能说明

原子操作函数支持配置：从计算单元向全局内存传输数据时，是否对目标内存地址执行原子化比较更新操作--将待写入数据与全局内存中已有数据进行比较，仅将二者中的最大值写入全局内存。  \
该函数可通过模版参数指定不同的数据类型，适配多样化的数值处理场景。

## 函数原型
