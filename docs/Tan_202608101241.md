## 功能说明

按元素计算输入Tensor的正切值（tan），将结果写入输出Tensor。输入数据类型`T`为half或float，计算时内部将输入归约到 $(-\pi/2, \pi/2)$ 区间后通过多项式逼近方法求解。

计算公式如下：
$$
dst[i] = \tan(src[i]), \quad 0 \le i < calCount
$$

其中，$dst$ 为输出Tensor（`dstTensor`），类型为LocalTensor<T>；$src$ 为输入Tensor（`srcTensor`），类型为LocalTensor<T>；$i$ 为元素索引，取值范围 $0 \le i < calCount$；$calCount$ 为参与计算的元素数量，未传入`calCount`参数时默认为`srcTensor`的全部元素数量。

## 函数原型

- 通过`sharedTmpBuffer`入参传入临时空间
  - 源操作数Tensor全部参与计算
    ```cpp
    template <typename T, bool isReuseSource = false>
    __aicore__ inline void Tan(
        const LocalTensor<T>& dstTensor, const LocalTensor<T>& srcTensor, const LocalTensor<uint8_t>& sharedTmpBuffer)
    ```
  - 源操作数Tensor部分参与计算
    ```cpp
    template <typename T, bool isReuseSource = false>
    __aicore__ inline void Tan(
        const LocalTensor<T>& dstTensor, const LocalTensor<T>& srcTensor, const LocalTensor<uint8_t>& sharedTmpBuffer,
        const uint32_t calCount)
    ```
- 接口框架申请临时空间
  - 源操作数Tensor部分参与计算
    ```cpp
    template <typename T, bool isReuseSource = false>
    __aicore__ inline void Tan(const LocalTensor<T>& dstTensor, const LocalTensor<T>& srcTensor, const uint32_t calCount)
    ```
  - 源操作数Tensor全部参与计算
    ```cpp
    template <typename T, bool isReuseSource = false>
    __aicore__ inline void Tan(const LocalTensor<T>& dstTensor, const LocalTensor<T>& srcTensor)
    ```

通过`sharedTmpBuffer`入参传入临时空间的原型由用户手动管理临时空间，`sharedTmpBuffer`所需空间大小需参考对应的tiling接口获取。分配的空间越大性能越好，当buffer大小达到tiling接口计算的最大值时性能达到峰值。接口框架申请临时空间的原型由框架自动申请临时空间，使用更简单但需预留栈空间。

## 返回值说明

无

## 约束说明

- `dstTensor`、`srcTensor`、`sharedTmpBuffer`之间不允许地址复用，即起始地址相同且Tensor大小相同的地址复用关系不被允许。
- 该接口仅在AI Vector Core上执行。在AI Cube Core上调用时直接返回，不执行计算。
- 通过`sharedTmpBuffer`入参传入临时空间时，所需空间大小与数据类型相关：数据类型为half时，每个元素需要的临时空间约为10个float大小的存储空间；数据类型为float时，每个元素需要的临时空间约为4个float大小的存储空间。具体大小请参考对应的tiling接口。
- 接口原型包含`#pragma begin_pipe(V)`。
- 该接口不支持SIMT模式编译。

## 调用示例

【示例为基于函数原型构造】

```cpp
// 假设已通过TQue/TPipe等管理方式获取到LocalTensor
// 输入数据位于srcTensor中，数据类型为float
// 输出结果将写入dstTensor中

// 方式一：通过sharedTmpBuffer传入临时空间，指定计算元素数量
// sharedTmpBuffer由TPipe分配管理
LocalTensor<uint8_t> sharedTmpBuffer = tmpBufferQue.AllocTensor<LocalTensor<uint8_t>>();
// 按元素计算tan值，calCount为待计算元素数量
Tan<float>(dstTensor, srcTensor, sharedTmpBuffer, calCount);
// sharedTmpBuffer由框架管理，无需手动释放

// 方式二：框架自动申请临时空间，计算全部元素
Tan<float>(dstTensor, srcTensor);
```

结果示例如下：

```text
输入数据(srcTensor): [0.0, 0.5, 1.0, 1.5]
输出数据(dstTensor): [0.0, 0.5463, 1.5574, 14.1014]
```
