样例固定使用8个AI Core，主块长度`MAIN_TILE_LENGTH`为3200个`half`元素，数据整体长度为256000个`half`元素。数据平均分配到8个AI Core上运行，每个AI Core计算32000个元素；每个AI Core内共切分成10个主块，不涉及尾块和尾核处理。



## Tiling实现<a name="zh-cn_topic_0000002236197677_section480741815522"></a>

前述场景中算子的输入和输出均为固定shape，然而在实际的算子开发场景中，这些信息是支持动态变化的，场景会更加灵活和复杂。动态shape场景下，输入的shape是未知的。一些与输入shape相关的变量（比如每个AI Core处理的数据量、核内主块数量等），需要通过Tiling计算出来，然后传递到kernel侧，kernel侧使用该参数进行后续的计算。

具体实现方式为：分析设计Tiling参数、定义Tiling结构体，在Host侧通过上下文获取输入输出的shape信息，根据shape信息，计算Tiling参数并设置到对应的Tiling结构体中；通过核函数入口参数将Tiling信息传入核函数，在核函数内通过解析Tiling结构体，获取并使用相关参数来实现核函数内部逻辑，详细介绍请参考[Host侧tiling实现](../../../../编程指南/高级编程/Aclnn算子工程化开发/Host侧Tiling实现/基本流程.md)。本节将以上述分析中的切分策略为例，说明如何实现Tiling。

基于本节的切分策略，Tiling需要定义如下参数：

-   blockLength：每个AI Core的计算数据长度。
-   tileNum：每个AI Core需要计算的主块个数。

根据确定的Tiling参数，使用C++语法定义`MainTileOnlyTiling`结构体，代码如下。

```cpp
struct MainTileOnlyTiling {
    uint32_t blockLength; // 每个核处理的数据量
    uint32_t tileNum;     // 主块数量
};
```

接下来完成Tiling参数的计算。样例固定使用8个AI Core，主块长度由`MAIN_TILE_LENGTH`指定。先将总数据量按32字节对齐，再计算每个AI Core内的主块数量。代码示例如下：

```cpp
constexpr uint32_t NUM_BLOCKS = 8;
constexpr uint32_t BLOCK_SIZE = 32;
constexpr uint32_t SIZE_OF_HALF = 2;
constexpr uint32_t ALIGN_NUM = BLOCK_SIZE / SIZE_OF_HALF;
constexpr uint32_t MAIN_TILE_LENGTH = 3200;

uint32_t AlignUp(uint32_t value, uint32_t align)
{
    return ((value + align - 1U) / align) * align;
}

void LaunchAddByTiling(uint8_t* xDevice, uint8_t* yDevice, uint8_t* zDevice, uint32_t totalLength,
                       aclrtStream stream)
{
    uint32_t totalLengthAligned = AlignUp(totalLength, ALIGN_NUM);
    uint32_t mainTileNum = totalLengthAligned / (NUM_BLOCKS * MAIN_TILE_LENGTH);
    uint32_t mainTileRemainder = totalLengthAligned % (NUM_BLOCKS * MAIN_TILE_LENGTH);
    uint32_t baseLength = mainTileNum * MAIN_TILE_LENGTH;
    uint32_t baseTileNum = mainTileNum;

    if (mainTileRemainder == 0U) {
        MainTileOnlyTiling tiling{baseLength, baseTileNum};
        add_custom<MainTileOnlyTiling><<<NUM_BLOCKS, 0, stream>>>(xDevice, yDevice, zDevice, tiling);
    }
}
```

## 算子类实现<a name="zh-cn_topic_0000002236197677_section849945172010"></a>

Kernel侧算子实现仍遵循[矢量算子核函数实现流程](../基础矢量算子.md#zh-cn_topic_0000002201157438_fig16061570280)，接下来重点介绍本场景中算子类实现的不同点。

-   设置输入输出Global Tensor的Global Memory内存地址。

    由于本样例中将数据分配到了多个AI Core上进行处理，每个AI Core处理不同的数据，因此不同AI Core要处理的数据在Global Memory上的地址不同，在初始化函数`Init`中，需要获取单个AI Core所需处理的输入输出在Global Memory上的内存偏移地址，并将该偏移地址设置到GlobalTensor中。

    以获取输入x在Global Memory上的内存偏移地址为例，数据整体长度为256000，平均分配到8个AI Core上运行，每个AI Core上处理的数据长度`blockLength`为32000。调用[GetBlockIdx](https://gitcode.com/cann/asc-devkit/blob/master/docs/api/SIMD-API/基础API/工具接口/系统资源与变量/GetBlockIdx.md)接口获取当前AI Core的索引，`x + blockLength * GetBlockIdx()`即为单个AI Core处理程序中x在Global Memory上的内存偏移地址。获取偏移地址后，使用GlobalTensor类的[SetGlobalBuffer](https://gitcode.com/cann/asc-devkit/blob/master/docs/api/SIMD-API/基础API/数据结构/LocalTensor和GlobalTensor定义/GlobalTensor/SetGlobalBuffer.md)接口设定该AI Core上Global Memory的起始地址以及长度，具体示意图请参考[图2](#zh-cn_topic_0000002236197677_fig398721711313)。代码如下所示：

    ```cpp
    uint32_t offset = AscendC::GetBlockIdx() * tiling.blockLength;
    xGm.SetGlobalBuffer((__gm__ half*)x + offset, tiling.blockLength);
    ```

    **图2**  多核并行处理示意图<a name="zh-cn_topic_0000002236197677_fig398721711313"></a>
    ![](../../../../figures/多核并行处理示意图-38.png "多核并行处理示意图-38")

-   使用`MAIN_TILE_LENGTH`作为每次处理的主块长度。

    对于单个AI Core上的处理数据，可以进行数据切块。在本示例中，单个AI Core上的32000个数据被切分成10个主块，每个主块包含3200个`half`元素。数据切分示意图如[图3](#zh-cn_topic_0000002236197677_fig1319211154719)所示。

    **图3**  单核数据切分示意图<a name="zh-cn_topic_0000002236197677_fig1319211154719"></a>
    ![](../../../../figures/单核数据切分示意图-39.png "单核数据切分示意图-39")

完整的初始化函数代码如下：

```cpp
__aicore__ inline void Init(__gm__ uint8_t* x, __gm__ uint8_t* y, __gm__ uint8_t* z,
                            MainTileOnlyTiling tiling)
{
    uint32_t offset = AscendC::GetBlockIdx() * tiling.blockLength;
    InitGm(x, y, z, offset, tiling.blockLength);
    this->tileNum = tiling.tileNum;
    this->lastTileLength = 0U;
}
```

每个AI Core需要对`tileNum`个主块分别进行搬入、计算、搬出处理。样例中统一使用`Process`函数处理主块和尾块，主块均分场景下`lastTileLength`为0，因此循环只处理主块。

```cpp
__aicore__ inline void Process()
{
    AscendC::LocalTensor<half> xLocal(AscendC::TPosition::VECCALC, xAddr, MAIN_TILE_LENGTH);
    AscendC::LocalTensor<half> yLocal(AscendC::TPosition::VECCALC, yAddr, MAIN_TILE_LENGTH);
    AscendC::LocalTensor<half> zLocal(AscendC::TPosition::VECCALC, zAddr, MAIN_TILE_LENGTH);

    uint32_t totalLoop = this->tileNum + (this->lastTileLength > 0U ? 1U : 0U);
    for (uint32_t loopIdx = 0; loopIdx < totalLoop; loopIdx++) {
        uint32_t curLen = (loopIdx < this->tileNum) ? MAIN_TILE_LENGTH : this->lastTileLength;
        uint32_t startElement = loopIdx * MAIN_TILE_LENGTH;
        AscendC::DataCopy(xLocal, xGm[startElement], curLen);
        AscendC::DataCopy(yLocal, yGm[startElement], curLen);
        AscendC::Add(zLocal, xLocal, yLocal, curLen);
        AscendC::DataCopy(zGm[startElement], zLocal, curLen);
    }
}
```
