# 主块均分<a name="ZH-CN_TOPIC_0000002236197677"></a>

本节对应样例[场景0：主块均分](https://gitcode.com/cann/asc-devkit/blob/master/examples/01_simd_cpp_api/02_features/02_tiling_selector/vector_tiling_strategy/README.md#scenario0-main-tile-only)。如[图 1](#zh-cn_topic_0000002236197677_fig1986021174914)所示，该场景中输入数据可以按参与计算的AI Core数量和主块长度`MAIN_TILE_LENGTH`均匀切分，每个AI Core都处理`tileNum`个主块长度的数据。完成主块分配后没有剩余数据，各AI Core处理的数据量相同，且核内只包含主块。

**图 1**  数据切分示意图<a name="zh-cn_topic_0000002236197677_fig1986021174914"></a>
![数据切分示意图](../../../../figures/main_tiles.png "数据切分示意图")

样例中固定使用8个AI Core，主块长度`MAIN_TILE_LENGTH`为3200个`half`元素，数据整体长度为256000个`half`元素。数据平均分配到8个AI Core上运行，每个AI Core计算32000个元素；每个AI Core内共切分成10个主块，不涉及尾块和尾核处理。

本场景的32字节对齐、Unified Buffer利用和多核均衡原则请参见[概述](概述.md)。

## Tiling实现<a name="zh-cn_topic_0000002236197677_section480741815522"></a>

基于本节的切分策略，Tiling需要定义如下参数：

- blockLength：每个AI Core的计算数据长度。
- tileNum：每个AI Core需要计算的主块个数。

根据确定的Tiling参数，使用C++语法定义`MainTileOnlyTiling`结构体，代码如下。

```cpp
struct MainTileOnlyTiling {
    uint32_t blockLength; // 每个核处理的数据量
    uint32_t tileNum;     // 主块数量
};
```

接下来完成Tiling参数的计算。样例固定使用8个AI Core，主块长度由`MAIN_TILE_LENGTH`指定。步骤如下：

1. 先将总数据量`totalLength`按32字节对齐至`totalLengthAligned`。

    ```cpp
    constexpr uint32_t BLOCK_SIZE = 32;
    constexpr uint32_t SIZE_OF_HALF = 2;
    constexpr uint32_t ALIGN_NUM = BLOCK_SIZE / SIZE_OF_HALF;

    uint32_t totalLengthAligned = AlignUp(totalLength, ALIGN_NUM);
    ```

2. 按参与计算的AI Core数量和主块长度`MAIN_TILE_LENGTH`计算每个AI Core上的主块数量，并得到基础数据长度`baseLength`和基础主块数量`baseTileNum`。

    ```cpp
    constexpr uint32_t NUM_BLOCKS = 8;
    constexpr uint32_t MAIN_TILE_LENGTH = 3200;

    uint32_t mainTileNum = totalLengthAligned / (NUM_BLOCKS * MAIN_TILE_LENGTH);
    uint32_t mainTileRemainder = totalLengthAligned % (NUM_BLOCKS * MAIN_TILE_LENGTH);
    uint32_t baseLength = mainTileNum * MAIN_TILE_LENGTH;
    uint32_t baseTileNum = mainTileNum;
    ```

3. 当`mainTileRemainder`为0时，表示所有数据都能按主块均匀分配到各AI Core，此时使用`MainTileOnlyTiling`。

    ```cpp
    if (mainTileRemainder == 0U) {
        MainTileOnlyTiling tiling{baseLength, baseTileNum};
        add_custom<MainTileOnlyTiling><<<NUM_BLOCKS, 0, stream>>>(xDevice, yDevice, zDevice, tiling);
        return;
    }
    ```

## 算子类实现<a name="zh-cn_topic_0000002236197677_section849945172010"></a>

Kernel侧算子采用[静态Tensor编程](../../../../编程指南/编程模型/AI-Core-SIMD编程/基于Tensor的CPP编程/静态Tensor编程.md)方式实现，通过`LocalTensor`构造函数直接指定Local Memory地址。静态Tensor编程中的内存管理和同步管理请参考对应章节，本文重点说明Tiling结果如何传入Kernel侧，并指导GM地址计算和主块循环处理。

- Kernel入口通过模板参数接收Host侧传入的Tiling结构体，并将`tiling`传入算子类`Init`函数。主块均分场景中，传入的结构体类型为`MainTileOnlyTiling`。

    ```cpp
    template <typename TilingData>
    __vector__ __global__ void add_custom(__gm__ uint8_t* x, __gm__ uint8_t* y, __gm__ uint8_t* z, TilingData tiling)
    {
        AscendC::InitSocState();
        KernelAdd op;
        op.Init(x, y, z, tiling);
        op.Process();
        AscendC::PipeBarrier<PIPE_ALL>();
    }
    ```

- 由于本样例中将数据分配到多个AI Core上处理，每个AI Core访问的Global Memory地址不同。`Init`函数通过`tiling.blockLength`获取每个AI Core处理的数据长度，并结合[GetBlockIdx](https://gitcode.com/cann/asc-devkit/blob/master/docs/api/SIMD-API/基础API/工具接口/系统资源与变量/GetBlockIdx.md)计算当前AI Core的Global Memory偏移。以输入x为例，`x + tiling.blockLength * GetBlockIdx()`即为当前AI Core处理的x在Global Memory上的起始地址。获取偏移后，`InitGm`通过[SetGlobalBuffer](https://gitcode.com/cann/asc-devkit/blob/master/docs/api/SIMD-API/基础API/数据结构/LocalTensor和GlobalTensor定义/GlobalTensor/SetGlobalBuffer.md)设置输入输出`GlobalTensor`。多核并行处理的数据分配关系可参考本文开头的[数据切分示意图](#zh-cn_topic_0000002236197677_fig1986021174914)。

    ```cpp
    __aicore__ inline void Init(__gm__ uint8_t* x, __gm__ uint8_t* y, __gm__ uint8_t* z,
                                MainTileOnlyTiling tiling)
    {
        uint32_t offset = AscendC::GetBlockIdx() * tiling.blockLength;
        InitGm(x, y, z, offset, tiling.blockLength);
        this->tileNum = tiling.tileNum;
        this->lastTileLength = 0U;
    }

    __aicore__ inline void InitGm(
        __gm__ uint8_t* x, __gm__ uint8_t* y, __gm__ uint8_t* z, uint32_t offset, uint32_t length)
    {
        xGm.SetGlobalBuffer((__gm__ half*)x + offset, length);
        yGm.SetGlobalBuffer((__gm__ half*)y + offset, length);
        zGm.SetGlobalBuffer((__gm__ half*)z + offset, length);
    }
    ```

- `Process`函数基于`tiling.tileNum`保存的主块数量循环处理数据。主块均分场景下，每个AI Core只包含主块，`lastTileLength`为0，因此循环次数为`tileNum`。每轮循环使用`MAIN_TILE_LENGTH`作为当前主块长度，通过`loopIdx * MAIN_TILE_LENGTH`计算核内偏移，依次完成输入搬入、Add计算和输出搬出。单核内的主块切分关系可参考本文开头的[数据切分示意图](#zh-cn_topic_0000002236197677_fig1986021174914)。

    ```cpp
    __aicore__ inline void Process()
    {
        AscendC::LocalTensor<half> xLocal(AscendC::TPosition::VECCALC, xAddr, MAIN_TILE_LENGTH);
        AscendC::LocalTensor<half> yLocal(AscendC::TPosition::VECCALC, yAddr, MAIN_TILE_LENGTH);
        AscendC::LocalTensor<half> zLocal(AscendC::TPosition::VECCALC, zAddr, MAIN_TILE_LENGTH);

        uint32_t totalLoop = this->tileNum + (this->lastTileLength > 0U ? 1U : 0U);
        for (uint32_t loopIdx = 0; loopIdx < totalLoop; loopIdx++) {
            uint32_t curLen = (loopIdx < this->tileNum) ? MAIN_TILE_LENGTH : this->lastTileLength;
            uint32_t startElement = loopIdx * MAIN_TILE_LENGTH;
            AscendC::DataCopy(xLocal, xGm[startElement], curLen);
            AscendC::DataCopy(yLocal, yGm[startElement], curLen);
            AscendC::Add(zLocal, xLocal, yLocal, curLen);
            AscendC::DataCopy(zGm[startElement], zLocal, curLen);
        }
    }
    ```
