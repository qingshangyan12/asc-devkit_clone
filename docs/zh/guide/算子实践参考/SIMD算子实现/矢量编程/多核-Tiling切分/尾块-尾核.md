# 尾块-尾核<a name="ZH-CN_TOPIC_0000002500468234"></a>

本节对应样例[场景3：尾块-尾核](https://gitcode.com/cann/asc-devkit/blob/master/examples/01_simd_cpp_api/02_features/02_tiling_selector/vector_tiling_strategy/README.md#scenario3-tail-block-tail-core)。

该场景中，主块均分后仍有较多剩余数据，各AI Core都可以继续按DataBlock粒度分配到若干尾块数据，但最后仍有少量DataBlock只能分配给部分AI Core。获得额外DataBlock的AI Core为整核，其余为尾核；整核和尾核内都存在尾块，且整核处理的数据量更多。

DataBlock粒度和32字节对齐约束请参见[概述](概述.md)。

样例中固定使用8个AI Core，主块长度`MAIN_TILE_LENGTH`为3200个`half`元素，数据整体长度为258112个`half`元素。数据按32字节对齐后，前4个AI Core各处理32272个元素，后4个AI Core各处理32256个元素；整核包含10个主块和272个元素的尾块，尾核包含10个主块和256个元素的尾块。数据切分示意如[图 1](#zh-cn_topic_0000002500468234_fig11467165513409)所示：

## Tiling实现<a name="zh-cn_topic_0000002236277533_section132981926144714"></a>

基于本节的切分策略，Tiling需要定义如下参数：

- formerNum：分配到数据量较多的核数，即整核的核数。
- formerLength：整核计算的数据长度。
- formerTileNum：整核中主块的数量。
- formerLastTileLength：整核中尾块的数据量。
- tailLength：尾核计算的数据长度。
- tailTileNum：尾核中主块的数量。
- tailLastTileLength：尾核中尾块的数据量。

Tiling结构体定义如下：

```cpp
struct TailBlockAndTailCoreTiling {
    uint32_t formerNum;            // 整核数量
    uint32_t formerLength;         // 整核处理的数据量
    uint32_t formerTileNum;        // 整核中主块的数量
    uint32_t formerLastTileLength; // 整核中尾块的数据量
    uint32_t tailLength;           // 尾核处理的数据量
    uint32_t tailTileNum;          // 尾核中主块的数量
    uint32_t tailLastTileLength;   // 尾核中尾块的数据量
};
```

Host侧Tiling实现的主要内容为计算以上成员变量。步骤如下：

1. 先将总数据量`totalLength`按32字节对齐至`totalLengthAligned`。

    ```cpp
    constexpr uint32_t BLOCK_SIZE = 32;
    constexpr uint32_t SIZE_OF_HALF = 2;
    constexpr uint32_t ALIGN_NUM = BLOCK_SIZE / SIZE_OF_HALF;

    uint32_t totalLengthAligned = AlignUp(totalLength, ALIGN_NUM);
    ```

2. 按参与计算的AI Core数量和主块长度`MAIN_TILE_LENGTH`计算每个AI Core上的主块数量，并得到主块分配后的剩余数据量`mainTileRemainder`。

    ```cpp
    constexpr uint32_t NUM_BLOCKS = 8;
    constexpr uint32_t MAIN_TILE_LENGTH = 3200;

    uint32_t mainTileNum = totalLengthAligned / (NUM_BLOCKS * MAIN_TILE_LENGTH);
    uint32_t mainTileRemainder = totalLengthAligned % (NUM_BLOCKS * MAIN_TILE_LENGTH);
    uint32_t baseLength = mainTileNum * MAIN_TILE_LENGTH;
    uint32_t baseTileNum = mainTileNum;
    ```

3. 尝试将剩余数据按DataBlock粒度均匀补到每个AI Core上，并更新每个AI Core的基础数据长度`baseLength`和基础尾块长度`baseLastTileLength`。

    ```cpp
    uint32_t tailBlockNumEachCore = mainTileRemainder / (NUM_BLOCKS * ALIGN_NUM);
    uint32_t formerCoreRemainder = mainTileRemainder % (NUM_BLOCKS * ALIGN_NUM);
    uint32_t baseLastTileLength = tailBlockNumEachCore * ALIGN_NUM;
    baseLength += baseLastTileLength;
    ```

4. 当`formerCoreRemainder`不为0时，表示最后剩余的DataBlock无法均匀分配到每个AI Core，只能分配给前`formerNum`个整核。整核比尾核多处理一个DataBlock的数据。

    ```cpp
    uint32_t formerNum = formerCoreRemainder / ALIGN_NUM;
    uint32_t formerLength = baseLength + ALIGN_NUM;
    uint32_t tailLength = baseLength;
    ```

5. 分别计算整核和尾核的主块数量及尾块长度。整核在基础尾块长度上再增加一个DataBlock；如果整核尾块长度等于`MAIN_TILE_LENGTH`，则进位为一个主块。尾核使用基础尾块长度作为尾块长度。

    ```cpp
    uint32_t formerTileNum = baseTileNum;
    uint32_t formerLastTileLength = baseLastTileLength + ALIGN_NUM;
    if (formerLastTileLength == MAIN_TILE_LENGTH) {
        formerTileNum += 1U;
        formerLastTileLength = 0U;
    }
    uint32_t tailTileNum = baseTileNum;
    uint32_t tailLastTileLength = baseLastTileLength;
    ```

6. 当`tailLastTileLength`不为0时，表示尾核内也存在尾块，此时使用`TailBlockAndTailCoreTiling`。

    ```cpp
    if (tailLastTileLength != 0U) {
        TailBlockAndTailCoreTiling tiling{
            formerNum,  formerLength, formerTileNum, formerLastTileLength,
            tailLength, tailTileNum,  tailLastTileLength};
        add_custom<TailBlockAndTailCoreTiling><<<NUM_BLOCKS, 0, stream>>>(xDevice, yDevice, zDevice, tiling);
    }
    ```

（1，258112）形状的输入数据计算后，Tiling结构体内各个变量的值如下：

```cpp
TailBlockAndTailCoreTiling tiling{
    4,     // formerNum：前4个AI Core为整核
    32272, // formerLength：整核计算32272个half
    10,    // formerTileNum：整核包含10个主块
    272,   // formerLastTileLength：整核包含272个half的尾块
    32256, // tailLength：尾核计算32256个half
    10,    // tailTileNum：尾核包含10个主块
    256    // tailLastTileLength：尾核包含256个half的尾块
};
```

## 算子类实现<a name="zh-cn_topic_0000002236277533_section182075114713"></a>

Kernel侧算子仍采用[静态Tensor编程](../../../../编程指南/编程模型/AI-Core-SIMD编程/基于Tensor的CPP编程/静态Tensor编程.md)方式实现。与[主块-尾核](主块-尾核.md)相比，本场景中整核和尾核都包含尾块，因此`Init`函数需要根据`GetBlockIdx()`判断当前AI Core是整核还是尾核，并分别设置Global Memory偏移、`tileNum`和`lastTileLength`。

整核使用`formerLength`、`formerTileNum`和`formerLastTileLength`。整核输入的Global Memory偏移计算如下：

```cpp
uint32_t offset = tiling.formerLength * blockIdx;
InitGm(x, y, z, offset, tiling.formerLength);
```

尾核使用`tailLength`、`tailTileNum`和`tailLastTileLength`。尾核输入的Global Memory偏移需要在全部整核数据之后继续计算，代码如下：

```cpp
uint32_t offset = tiling.formerLength * tiling.formerNum + tiling.tailLength * (blockIdx - tiling.formerNum);
InitGm(x, y, z, offset, tiling.tailLength);
```

完整的`Init`函数实现代码如下：

```cpp
__aicore__ inline void Init(__gm__ uint8_t* x, __gm__ uint8_t* y, __gm__ uint8_t* z,
                            TailBlockAndTailCoreTiling tiling)
{
    uint32_t blockIdx = AscendC::GetBlockIdx();
    if (blockIdx < tiling.formerNum) {
        uint32_t offset = tiling.formerLength * blockIdx;
        InitGm(x, y, z, offset, tiling.formerLength);
        this->tileNum = tiling.formerTileNum;
        this->lastTileLength = tiling.formerLastTileLength;
    } else {
        uint32_t offset =
            tiling.formerLength * tiling.formerNum + tiling.tailLength * (blockIdx - tiling.formerNum);
        InitGm(x, y, z, offset, tiling.tailLength);
        this->tileNum = tiling.tailTileNum;
        this->lastTileLength = tiling.tailLastTileLength;
    }
}
```

完成`Init`后，`Process`函数仍按照`tileNum`和`lastTileLength`进行循环处理。整核和尾核都需要处理主块和尾块，循环次数和当前分块长度由以下逻辑控制：

```cpp
uint32_t totalLoop = this->tileNum + (this->lastTileLength > 0U ? 1U : 0U);
for (uint32_t loopIdx = 0; loopIdx < totalLoop; loopIdx++) {
    uint32_t curLen = (loopIdx < this->tileNum) ? MAIN_TILE_LENGTH : this->lastTileLength;
    uint32_t startElement = loopIdx * MAIN_TILE_LENGTH;
    // 基于curLen和startElement完成数据搬运、计算和写回。
}
```
