# 尾块-尾核<a name="ZH-CN_TOPIC_0000002500468234"></a>

本节对应样例[场景3：尾块-尾核](../../../../../../examples/01_simd_cpp_api/02_features/02_tiling_selector/vector_tiling_strategy/README.md#scenario3-tail-block-tail-core)。

对于不同shape的输入进行数据切分时，可能会发生数据无法平均分配到多个核、同时每个核内的数据无法只由主块组成的情况。参考[核间均分场景下的尾块处理](主块-尾块.md)与[核间不均分场景下的尾核处理](主块-尾核.md)的处理方式，将两者结合起来考虑整核的尾块、尾核的尾块的处理方式。

## Tiling实现<a name="zh-cn_topic_0000002236277533_section132981926144714"></a>

由于本场景中核间、核内的数据均无法均分，在[核间不均分场景下的尾核处理](主块-尾核.md)定义的Tiling结构体的基础上增加`tailLastTileLength`成员变量，用来表示尾核中尾块的数据量。

算子的Tiling结构体定义如下：

```cpp
struct TailBlockAndTailCoreTiling {
    uint32_t formerNum;            // 整核数量
    uint32_t formerLength;         // 整核处理的数据量
    uint32_t formerTileNum;        // 整核中主块的数量
    uint32_t formerLastTileLength; // 整核中尾块的数据量
    uint32_t tailLength;           // 尾核处理的数据量
    uint32_t tailTileNum;          // 尾核中主块的数量
    uint32_t tailLastTileLength;   // 尾核中尾块的数据量
};
```

Host侧Tiling计算时，先按[主块-尾核](主块-尾核.md)中提到的分核策略，计算每个核的基础数据量、整核数量、整核数据量和尾核数据量。

```cpp
uint32_t totalLengthAligned = AlignUp(totalLength, ALIGN_NUM);
uint32_t mainTileNum = totalLengthAligned / (NUM_BLOCKS * MAIN_TILE_LENGTH);
uint32_t mainTileRemainder = totalLengthAligned % (NUM_BLOCKS * MAIN_TILE_LENGTH);
uint32_t baseLength = mainTileNum * MAIN_TILE_LENGTH;
uint32_t baseTileNum = mainTileNum;

if (mainTileRemainder == 0U) {
    MainTileOnlyTiling tiling{baseLength, baseTileNum};
    add_custom<MainTileOnlyTiling><<<NUM_BLOCKS, 0, stream>>>(xDevice, yDevice, zDevice, tiling);
    return;
}

uint32_t tailBlockNumEachCore = mainTileRemainder / (NUM_BLOCKS * ALIGN_NUM);
uint32_t formerCoreRemainder = mainTileRemainder % (NUM_BLOCKS * ALIGN_NUM);
baseLength += tailBlockNumEachCore * ALIGN_NUM;
uint32_t baseLastTileLength = tailBlockNumEachCore * ALIGN_NUM;

uint32_t formerNum = formerCoreRemainder / ALIGN_NUM;
uint32_t formerLength = baseLength + ALIGN_NUM;
uint32_t tailLength = baseLength;
uint32_t formerTileNum = baseTileNum;
uint32_t formerLastTileLength = baseLastTileLength + ALIGN_NUM;
if (formerLastTileLength == MAIN_TILE_LENGTH) {
    formerTileNum += 1U;
    formerLastTileLength = 0U;
}
uint32_t tailTileNum = baseTileNum;
uint32_t tailLastTileLength = baseLastTileLength;
```

如果整核和尾核都存在需要记录的尾块，则使用`TailBlockAndTailCoreTiling`结构体将Tiling参数传入Kernel侧。

```cpp
TailBlockAndTailCoreTiling tiling{
    formerNum,  formerLength, formerTileNum, formerLastTileLength,
    tailLength, tailTileNum,  tailLastTileLength};
add_custom<TailBlockAndTailCoreTiling><<<NUM_BLOCKS, 0, stream>>>(xDevice, yDevice, zDevice, tiling);
```

## 算子类实现<a name="zh-cn_topic_0000002236277533_section182075114713"></a>

Kernel侧`Init`函数的实现需将[核间均分场景下的尾块处理](主块-尾块.md)与[核间不均分场景下的尾核处理](主块-尾核.md)的实现结合起来。整核和尾核对应的`tileNum`与`lastTileLength`不同，因此需要根据当前AI Core索引分别处理。

`Init`函数实现代码如下：

```cpp
__aicore__ inline void Init(__gm__ uint8_t* x, __gm__ uint8_t* y, __gm__ uint8_t* z,
                            TailBlockAndTailCoreTiling tiling)
{
    uint32_t blockIdx = AscendC::GetBlockIdx();
    if (blockIdx < tiling.formerNum) {
        uint32_t offset = tiling.formerLength * blockIdx;
        InitGm(x, y, z, offset, tiling.formerLength);
        this->tileNum = tiling.formerTileNum;
        this->lastTileLength = tiling.formerLastTileLength;
    } else {
        uint32_t offset =
            tiling.formerLength * tiling.formerNum + tiling.tailLength * (blockIdx - tiling.formerNum);
        InitGm(x, y, z, offset, tiling.tailLength);
        this->tileNum = tiling.tailTileNum;
        this->lastTileLength = tiling.tailLastTileLength;
    }
}
```

后续对主块和尾块的处理方式与[核间均分场景下的处理](主块-尾块.md)方式相同。`Process`函数根据`lastTileLength`判断是否需要多处理一次尾块，主块长度统一使用`MAIN_TILE_LENGTH`。

```cpp
uint32_t totalLoop = this->tileNum + (this->lastTileLength > 0U ? 1U : 0U);
for (uint32_t loopIdx = 0; loopIdx < totalLoop; loopIdx++) {
    uint32_t curLen = (loopIdx < this->tileNum) ? MAIN_TILE_LENGTH : this->lastTileLength;
    uint32_t startElement = loopIdx * MAIN_TILE_LENGTH;
    AscendC::DataCopy(xLocal, xGm[startElement], curLen);
    AscendC::DataCopy(yLocal, yGm[startElement], curLen);
    AscendC::Add(zLocal, xLocal, yLocal, curLen);
    AscendC::DataCopy(zGm[startElement], zLocal, curLen);
}
```
