# 编程接口overview<a name="ZH-CN_TOPIC_0000001976190182"></a>

>[!NOTE]说明 
>本章提供编程API的overview。具体API参考见[Ascend C API](../../../api/api_list.md)。

Ascend C提供一组类库API，开发者使用标准C++语法和类库API进行编程。Ascend C编程类库API示意图如下所示，分为：

-   **语言扩展层C API**：开放芯片完备编程能力，支持数组分配内存，一般基于指针编程，提供与业界一致的C语言编程体验。

-   **basic_api**：实现对硬件能力的抽象，开放芯片的能力，保证完备性和兼容性。标注为ISASI（Instruction Set Architecture Special Interface，硬件体系结构相关的接口）类别的API，不能保证跨硬件版本兼容。
-   **high_level_api**：实现一些常用的计算algorithms，用于提高编程开发效率，通常会调用多种basic_api实现。high_level_api包括数学库、Matmul、Softmax等API。high_level_api可以保证兼容性。
-   **Utils API（公共辅助函数）**：丰富的general_utils类，涵盖标准库、platform_info、运行时编译及日志输出等功能，支持开发者高效实现算子开发与性能优化。

>[!NOTE]说明 
>Ascend C API所在头文件目录为：
> - 语言扩展层C API：`${INSTALL_DIR}/asc/include/c_api`
> - basic_api：`${INSTALL_DIR}/asc/include/basic_api`
> - high_level_api：（注意，如下目录头文件中包含的接口如果未在资料中声明，属于间接调用接口，开发者无需关注）
>    - `${INSTALL_DIR}/asc/include/adv_api`
>    - `${INSTALL_DIR}/asc/include/tiling`，
> - Utils API：`${INSTALL_DIR}/asc/include/utils`
>`${INSTALL_DIR}`请替换为CANN软件安装后文件存储路径。以root用户安装为例，安装后文件默认存储路径为：/usr/local/Ascend/cann。
> 
> 使用Ascend C API依赖的库文件说明如下：
> - 语言扩展层C API：不涉及 
> - basic_api：不涉及
> - high_level_api：因high_level_api配套Host Tiling接口，需要链接libtiling\_api.a。
> - Utils API：不涉及
