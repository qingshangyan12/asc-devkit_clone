# 概述

SIMT API是面向AI处理器的并行计算编程接口，可以实现高效的数据并行计算。SIMT API支持两种编程模型：SIMT编程、SIMD与SIMT混合编程，用户可先阅读[SIMT编程简介](SIMT编程简介/SIMT编程简介.md)和[SIMD与SIMT混合编程简介](SIMD与SIMT混合编程简介/SIMD与SIMT混合编程简介.md)，以了解编程基础，后续章节将详细介绍API接口。

**表1**  SIMT API分类列表

| 类别 | 功能 |
| --- | --- |
| [同步与内存栅栏](同步与内存栅栏/同步与内存栅栏.md) | 内存管理与同步接口，解决不同核内的线程间可能存在的数据竞争以及线程的同步问题。 |
| [原子操作](原子操作/原子操作-149.md) | 对Unified Buffer或Global Memory上的数据与指定数据执行原子操作的一系列接口。 |
| [Warp函数](Warp函数/Warp函数.md) | 对单个Warp内32个线程的数据进行处理的相关操作的一系列API接口。 |
| [数学函数](数学函数/数学函数.md) | 用于处理数学运算的函数集合以及不同精度、数据类型的转换函数集合 |
| [地址空间谓词函数](地址空间谓词函数/地址空间谓词函数.md) | 判断输入指针是否为指定空间的地址。 |
| [地址空间转换函数](地址空间转换函数/地址空间转换函数.md) | 将指定地址空间的地址值转换为指针，或将输入的指针转换为对应内存空间的地址值的接口。 |
| [访存函数](访存函数/访存函数.md) | 数据加载和数据缓存相关接口。 |
| [协作组](协作组/协作组.md) | 提供一套标准且安全的机制，实现更高效的线程并行协作。 |
| [调测接口](../Utils-API/调测接口/调测接口.md) | SIMT VF调试场景下使用的相关接口。 |

## 调用接口依赖的头文件说明

安装CANN软件包并配置Ascend C编译环境后，编译SIMT源文件时才能引用SIMT API头文件。SIMT API公开头文件位于`${INSTALL_DIR}/asc/include/simt_api/`目录下，代码中通过`#include "simt_api/xxx.h"`方式引用。`${INSTALL_DIR}`请替换为CANN软件安装后文件存储路径，以root用户安装为例，默认路径为`/usr/local/Ascend/cann`。

使用SIMT API时，请根据实际调用的接口包含对应头文件。若同一源文件中调用多类基础SIMT API，可包含聚合头文件`simt_api/asc_simt.h`；该头文件已包含`common_functions.h`、`math_functions.h`、`device_functions.h`和`vector_functions.h`。使用协作组接口，或使用`half`、`half2`、`bfloat16_t`、`bfloat16x2_t`、`hifloat8x2_t`、`float8_e4m3x2_t`、`float8_e5m2x2_t`等数据类型相关接口时，还需按表3包含对应扩展头文件。

SIMT API属于Kernel侧基础接口，不涉及按接口额外链接的库文件。编译SIMT源文件时需要启用SIMT编译模式，例如在bisheng命令中增加`--enable-simt`，或在CMake工程中设置`CMAKE_ASC_ENABLE_SIMT`为`ON`；整体编译链接依赖请以AI Core算子编译流程为准。

**表2**  各类SIMT API需要包含的头文件

| 类别 | 需要包含的头文件 |
| --- | --- |
| [同步与内存栅栏](同步与内存栅栏/同步与内存栅栏.md) | `#include "simt_api/device_sync_functions.h"` |
| [原子操作](原子操作/原子操作-149.md) | `#include "simt_api/device_atomic_functions.h"` |
| [Warp函数](Warp函数/Warp函数.md) | `#include "simt_api/device_warp_functions.h"` |
| [数学函数](数学函数/数学函数.md) | `#include "simt_api/math_functions.h"`<br><br>`#include "simt_api/device_functions.h"` |
| [地址空间谓词函数](地址空间谓词函数/地址空间谓词函数.md)<br><br>[地址空间转换函数](地址空间转换函数/地址空间转换函数.md)<br><br>[访存函数](访存函数/访存函数.md) | `#include "simt_api/device_functions.h"` |
| [协作组](协作组/协作组.md) | `#include "simt_api/cooperative_groups.h"` |

> 表2为按接口类别给出的最小依赖头文件；若已包含`simt_api/asc_simt.h`，则无需再单独包含`device_sync_functions.h`、`device_atomic_functions.h`、`device_warp_functions.h`、`math_functions.h`、`device_functions.h`和`vector_functions.h`。
