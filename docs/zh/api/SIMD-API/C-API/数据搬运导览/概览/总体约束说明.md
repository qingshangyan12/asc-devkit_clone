# 总体约束说明

## 地址与长度

- 源、目的地址必须与函数原型中的地址空间限定符一致。
- 地址对齐、搬运长度对齐和分形对齐是不同约束，应分别核对。
- 连续搬运重载中的`size`通常按字节计量；分块搬运重载中`len_burst`、gap或stride的单位由接口和NPU架构决定。
- 不应将某个接口的32字节或512字节粒度推广为全部C API的统一约束。

具体要求以单接口文档的“参数说明”和“约束说明”为准。

## 地址重叠

源、目的地址重叠时，搬运结果可能与指令执行顺序有关。连续搬运、分块搬运和不同流水间搬运对地址重叠的支持情况不同；单接口文档未明确允许时，应使用互不重叠的地址区域。

同一流水的前后指令访问重叠地址时，根据接口约束使用[asc_sync_pipe](../../sync/asc_sync_pipe.md)。不同流水存在生产者、消费者依赖时，使用[asc_sync_notify](../../sync/asc_sync_notify.md)和[asc_sync_wait](../../sync/asc_sync_wait.md)。

## 产品和架构差异

C API在NPU架构2201和3510上的重载、支持数据类型、参数单位及数据通路可能不同。概览仅用于选择接口，完整原型和产品支持情况应以对应单接口文档为准。
