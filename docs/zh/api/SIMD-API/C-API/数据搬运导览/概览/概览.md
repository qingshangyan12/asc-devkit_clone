# 数据搬运概览

Ascend C API通过地址空间限定符区分Global Memory、Unified Buffer、L1 Buffer、L0A Buffer、L0B Buffer、L0C Buffer、BiasTable Buffer和Fixpipe Buffer。不同存储位置之间的数据通路由不同接口提供。

- [数据搬运概念](数据搬运概念.md)：说明连续搬运、分块搬运、多维搬运、非对齐搬运及同步要求。
- [数据通路](数据通路.md)：按源和目的存储位置查询公开C API。
- [总体约束说明](总体约束说明.md)：说明地址、长度、重叠访问和架构差异。
- [GM与UB数据搬运](../../vector_datamove/数据搬运导览/GM与UB数据搬运.md)：查询矢量搬入和搬出接口。
- [UB与UB数据搬运](../../vector_datamove/数据搬运导览/UB与UB数据搬运.md)：查询UB内部搬运接口。
- [矩阵数据搬运](../../cube_datamove/矩阵数据搬运.md)：查询矩阵计算相关数据通路。

概览不替代单接口文档。调用接口前，应核对其产品支持情况、完整函数原型、参数单位和约束说明。
