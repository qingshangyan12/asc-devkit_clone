# 矢量计算概述

C API提供Memory矢量计算和Reg矢量计算两种编程方式。Memory矢量接口直接处理`__ubuf__`地址中的数据；Reg矢量接口将数据显式搬入矢量寄存器，在Vector Function中完成计算后再搬回UB。
