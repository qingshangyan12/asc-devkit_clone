# 数据搬运导览

数据搬运负责在GM、UB、L1 Buffer、L0A Buffer、L0B Buffer、L0C Buffer、BiasTable Buffer和Fixpipe Buffer之间传递数据。C API通过地址空间限定数组、裸指针和显式函数参数表达存储位置、搬运规模与地址间隔。
