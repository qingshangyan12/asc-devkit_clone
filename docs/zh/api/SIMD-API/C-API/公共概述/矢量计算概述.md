# 矢量计算概述（C API）

C API保留了基础API中“Memory矢量计算”和“Reg矢量计算”的两类能力，但以两种不同的C风格编程模型呈现。两者最终在`dav-3510`上大量复用相同的CCE矢量指令；是否可互换取决于数据位置、掩码形式、repeat/循环和接口约束，而非仅取决于运算名称。

## Memory矢量计算：UB数组模型

Memory矢量计算的源、目的数据位于`__ubuf__`数组，由[Memory矢量计算](../vector_compute/Memory矢量计算.md)中的接口执行。常用分类如下：

| 功能 | C API入口 | 与基础API的同一CCE关系 |
|---|---|---|
| 基础算术 | [asc_add](../vector_compute/asc_add.md)、[asc_sub](../vector_compute/asc_sub.md)、[asc_mul](../vector_compute/asc_mul.md)、[asc_div](../vector_compute/asc_div.md)、[asc_max](../vector_compute/asc_max.md)、[asc_min](../vector_compute/asc_min.md) | 对应`vadd/vsub/vmul/vdiv/vmax/vmin`，为直接同名CCE映射。 |
| 标量算术 | [asc_add_scalar](../vector_compute/asc_add_scalar.md)、[asc_mul_scalar](../vector_compute/asc_mul_scalar.md)等 | 对应`vadds/vmuls`等指令；标量位置和参数顺序不一定与Basic API相同。 |
| 一元/复合 | [asc_abs](../vector_compute/asc_abs.md)、[asc_exp](../vector_compute/asc_exp.md)、[asc_relu](../vector_compute/asc_relu.md)、[asc_add_relu](../vector_compute/asc_add_relu.md)、[asc_mul_add](../vector_compute/asc_mul_add.md) | 前三者有直接CCE映射；Ln/Log、Sqrt、复合融合路径可能由多条CCE或软实现组成。 |
| 比较与选择 | [asc_eq](../vector_compute/asc_eq.md)、[asc_lt](../vector_compute/asc_lt.md)、[asc_select](../vector_compute/asc_select.md) | 对应`vcmp*`与`vsel`指令族。 |
| 逻辑、归约、重排 | [asc_and](../vector_compute/asc_and.md)、[asc_reduce](../vector_compute/asc_reduce.md)、[asc_transpose](../vector_compute/asc_transpose.md)、[asc_duplicate](../vector_compute/asc_duplicate.md) | 对应`vand`、归约、转置、duplicate指令族；具体接口选型按数据类型和粒度核对。 |
| 类型转换 | C API的[转换接口列表](../vector_compute/Memory矢量计算.md) | 大多对应`vconv`指令族；舍入、饱和与特殊类型转换须按接口文档确认。 |

掩码、repeat、stride和地址间隔决定一次指令实际处理的元素集合。C API使用的配置接口（例如[asc_set_vector_mask](../vector_compute/asc_set_vector_mask.md)、[asc_set_mask_count](../vector_compute/asc_set_mask_count.md)）与Basic API的模板/结构体形式不同，不能机械替换。

## Reg矢量计算：UB与寄存器之间的显式搬运

[reg矢量计算](../reg/reg.md)将UB与寄存器的搬入、寄存器计算、搬出分开表达：

```text
__ubuf__数据--reg load-->向量寄存器--reg compute-->向量寄存器--reg store-->__ubuf__数据
```

| 阶段 | C API章节 | 典型接口 |
|---|---|---|
| 寄存器与掩码 | [寄存器数据类型](../reg/reg_data_types/reg_data_types.md) | [asc_create_mask](../reg/reg_data_types/asc_create_mask.md)、[asc_update_mask](../reg/reg_data_types/asc_update_mask.md) |
| UB->寄存器 | [reg数据搬入](../reg/reg_load/reg_load.md) | [asc_load](../reg/reg_load/asc_load.md)、[asc_loadalign](../reg/reg_load/asc_loadalign.md) |
| 寄存器计算 | [基础算术](../reg/arithmetic_compute/arithmetic_compute.md)、[复合计算](../reg/compound_compute/compound_compute.md)、[比较与选择](../reg/compare_and_select/compare_and_select.md) | [asc_add](../reg/arithmetic_compute/asc_add.md)、[asc_madd](../reg/compound_compute/asc_madd.md)、[asc_select](../reg/compare_and_select/asc_select.md) |
| 寄存器->UB | [reg数据搬出](../reg/reg_store/reg_store.md) | [asc_store](../reg/reg_store/asc_store.md)、[asc_storealign](../reg/reg_store/asc_storealign.md) |

Reg API与Basic API的Reg实现通常同用`reg_mov`、`vadd`、`vsel`、`vconv`等CCE指令，但Basic API的VF封装、硬件循环和掩码对象属于上层编程模型。C API使用数组与C API向量/掩码类型；实际VL、对齐和循环约束应以[系统变量](../sys_var/系统变量.md)及每个Reg接口文档为准。

完整映射及复合/候选关系见[dav-3510 CCE指令索引](../../implementation_indexes/dav_3510/README.md)。
