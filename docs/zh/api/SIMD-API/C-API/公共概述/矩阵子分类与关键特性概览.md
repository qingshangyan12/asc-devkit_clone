# 矩阵子分类与关键特性概览

本页迁移基础API矩阵计算的概述、矩阵搬入/搬出子分类及Mmad、搬出关键特性说明。C API以显式L1 Buffer、L0A Buffer、L0B Buffer和L0C Buffer数组及配置函数表达相同硬件流程。

## 计算流程

**图 1**  矩阵计算流程

![](../../../figures/matrix_computation_workflow.png)

| 基础API子分类 | C API落点 |
|---|---|
| 矩阵分形和输入搬运 | [矩阵数据搬运](../cube_datamove/矩阵数据搬运.md)、[asc_copy_gm2l1](../cube_datamove/asc_copy_gm2l1/asc_copy_gm2l1.md)、[asc_copy_l12l0a](../cube_datamove/asc_copy_l12l0a/asc_copy_l12l0a.md)、[asc_copy_l12l0b](../cube_datamove/asc_copy_l12l0b/asc_copy_l12l0b.md) |
| 转置、MX、稀疏、3D/卷积搬入 | [asc_copy_l12l0a_trans](../cube_datamove/asc_copy_l12l0a_trans.md)、[asc_copy_l12l0b_trans](../cube_datamove/asc_copy_l12l0b_trans/asc_copy_l12l0b_trans.md)、[asc_copy_l12l0b_sparse](../cube_datamove/asc_copy_l12l0b_sparse.md)、[asc_load_image_to_cbuf](../cube_datamove/asc_load_image_to_cbuf.md) |

`mad`及L1 Buffer->L0A Buffer/L0B Buffer装载在高优先级Basic API和C API实现中有同一CCE指令或指令族对应。布局、尺寸、K对齐、GEMV、量化和双目标输出仍须按每个C API文档确认。
