# 特殊寄存器访问概览

基础API“特殊寄存器访问”中的读取、清除和控制寄存器操作，在C API中分布在系统变量与Reg系统变量访问章节。

| 基础API概念 | C API入口 |
|---|---|
| GetSpr、ClearSpr | [系统变量](../sys_var/系统变量.md)、[asc_get_ar_spr](../sys_var/asc_get_ar_spr_deprecated.md)、[asc_clear_ar_spr](../reg/system_variables_access/asc_clear_ar_spr.md) |
| SetCtrlSpr、GetCtrlSpr、ResetCtrlSpr | [asc_set_ctrl](../sys_var/asc_set_ctrl.md)、[asc_get_ctrl](../sys_var/asc_get_ctrl.md) |
| GetSaturationFlag、SetSaturationFlag | C API当前公开目录中未发现同名通用接口；不得按Basic API名称猜测替代。 |
| 地址、掩码和状态相关寄存器 | [asc_update_addr_reg](../reg/reg_data_types/asc_update_addr_reg.md)、[asc_get_mask_spr](../reg/reg_data_types/asc_get_mask_spr.md)、[asc_get_status](../sys_var/asc_get_status.md) |

同一CCE或候选对应关系见[dav-3510 CCE指令索引](../../implementation_indexes/dav_3510/cce_instruction_index.json)。产品支持和寄存器副作用以目标C API文档为准。
