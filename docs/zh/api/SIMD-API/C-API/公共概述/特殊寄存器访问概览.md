# 特殊寄存器访问概览

特殊寄存器访问用于读取、设置或清除控制、状态、地址和掩码相关寄存器。完整导航见[特殊寄存器访问](特殊寄存器访问/特殊寄存器访问.md)。

C API接口分布在以下章节：

- [系统变量](../sys_var/系统变量.md)
- [Reg系统变量访问](../reg/system_variables_access/system_variables_access.md)
- [Reg寄存器数据类型](../reg/reg_data_types/reg_data_types.md)

寄存器读写可能改变后续指令行为，调用前应核对接口的产品支持、作用域、副作用和恢复要求。
