# 同步、原子与缓存概述

## 同步控制

同步控制用于建立流水内、流水间、核内与核间的数据依赖。完整说明请参见[系统同步能力概述](同步原子缓存/系统同步能力概述.md)、[核内同步能力概述](同步原子缓存/核内同步能力概述.md)、[核内同步关键特性说明](同步原子缓存/核内同步关键特性说明.md)、[核间同步能力概述](同步原子缓存/核间同步能力概述.md)和[核间同步关键特性说明](同步原子缓存/核间同步关键特性说明.md)。

接口入口参见[同步控制](../sync/同步控制.md)。

## 原子操作

原子操作用于多个执行单元并发更新同一GM地址。完整说明请参见[原子操作概述](同步原子缓存/原子操作概述.md)和[原子操作关键特性说明](同步原子缓存/原子操作关键特性说明.md)。

接口入口参见[原子操作](../simd_atomic/原子操作.md)和[标量计算](../scalar_compute/标量计算.md)。

## 缓存控制

缓存控制覆盖数据缓存、指令缓存、预取、失效和多核可见性。完整说明请参见[系统缓存概述](同步原子缓存/系统缓存概述.md)，接口入口参见[缓存控制](../cache_ctrl/缓存控制.md)。
