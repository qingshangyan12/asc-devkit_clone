# 数据通路

| 源->目的 | 流水 | C API |
|---|---|---|
| GM->UB、UB->GM | MTE2、MTE3 | [GM与UB数据搬运](../GM与UB数据搬运.md) |
| GM->L1 Buffer、GM->L0 Buffer、L0C Buffer->GM | MTE2、Fixpipe | [GM与L1或L0数据搬运](../GM与L1或L0数据搬运.md) |
| L1 Buffer->L0 Buffer、L0C Buffer->L1 Buffer | MTE1、Fixpipe | [L1与L0数据搬运](../L1与L0数据搬运.md) |
| UB->L1 Buffer、L1 Buffer->UB、L0C Buffer->UB | MTE3、MTE1、Fixpipe/MTE3 | [L1或L0C与UB数据搬运](../L1或L0C与UB数据搬运.md) |
| UB->UB | Vector | [UB与UB数据搬运](../UB与UB数据搬运.md) |
| L1 Buffer->Fixpipe Buffer/BiasTable Buffer | Fixpipe、MTE1 | [Fixpipe](../L1与Fixpipe-Buffer数据搬运.md)、[BiasTable](../L1与BiasTable-Buffer数据搬运.md) |

`dav-3510`不支持L1 Buffer->GM，也不提供GM->L0A Buffer/L0B Buffer通路；对应限制见目标API的产品支持情况。
