# 总体约束说明

- GM地址、UB、L1 Buffer、L0 Buffer和专用Buffer的对齐要求不同，先阅读[通用说明和约束](../../../通用说明和约束.md)，再以目标接口约束为准。
- DataBlock通常为32 B，但L0和专用Buffer可能有更严格的粒度与地址要求；长度参数可能以字节、DataBlock或分形计量。
- 同一流水内多条搬运的目的地址重叠时，使用[asc_sync_pipe](../../../sync/asc_sync_pipe.md)等待相应流水；跨流水消费者依赖使用[asc_sync_notify](../../../sync/asc_sync_notify.md)和[asc_sync_wait](../../../sync/asc_sync_wait.md)。
- 非对齐、格式转换、量化/激活和高维搬运都有额外限制，不能用连续搬运参数替代。
