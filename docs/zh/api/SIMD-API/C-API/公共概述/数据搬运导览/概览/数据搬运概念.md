# 数据搬运概念

| 基础API功能分类 | C API对应或状态 |
|---|---|
| 连续搬运 | [asc_copy_gm2ub](../../../vector_datamove/asc_copy_gm2ub/asc_copy_gm2ub.md)、[asc_copy_ub2gm](../../../vector_datamove/asc_copy_ub2gm/asc_copy_ub2gm.md)、[asc_copy_gm2l1](../../../cube_datamove/asc_copy_gm2l1/asc_copy_gm2l1.md)等。 |
| 高维切分 | C API的二维burst/stride重载、[asc_ndim_copy_gm2ub](../../../vector_datamove/asc_ndim_copy_gm2ub.md)及各接口配套setter；参数单位不沿用Basic API。 |
| 切片 | 基础API标为软仿接口；当前C API目录未找到同名、同语义的通用切片搬运接口。 |
| ND2NZ/NZ2ND/DN2NZ | [asc_copy_gm2l1_nd2nz](../../../cube_datamove/asc_copy_gm2l1_nd2nz/asc_copy_gm2l1_nd2nz.md)、[asc_copy_gm2l1_dn2nz](../../../cube_datamove/asc_copy_gm2l1_dn2nz.md)、L0C搬出的[asc_set_l0c2gm_nz2nd](../../../cube_compute/asc_set_l0c2gm_nz2nd.md)。GM↔UB软仿转换不强行映射。 |
| 非对齐与Padding | [asc_copy_gm2ub_align](../../../vector_datamove/asc_copy_gm2ub_align/asc_copy_gm2ub_align.md)、[asc_copy_ub2gm_align](../../../vector_datamove/asc_copy_ub2gm_align/asc_copy_ub2gm_align.md)、[asc_copy_gm2l1_align](../../../cube_datamove/asc_copy_gm2l1_align.md)。 |
| UB内部搬运 | [asc_copy_ub2ub](../../../vector_datamove/asc_copy_ub2ub.md)、[asc_copy](../../../vector_compute/asc_copy.md)。 |
| 矩阵分形与Fixpipe | [矩阵数据搬运](../../../cube_datamove/矩阵数据搬运.md)、[矩阵计算](../../../cube_compute/矩阵计算.md)。 |
| NDDMA | [asc_ndim_copy_gm2ub](../../../vector_datamove/asc_ndim_copy_gm2ub.md)。 |

`blockLen`、`blockCount`、`stride`、`repeat`等概念在C API中仍用于描述长度与间隔，但单位及参数含义随接口变化；必须阅读目标接口的“参数说明”。
