# 矩阵计算概述（C API）

C API的矩阵计算由矩阵搬运、Mmad和L0C Buffer搬出组成。它迁移基础API矩阵计算总览的核心数据流，但以显式`__cbuf__`、`__ca__`、`__cb__`、`__cc__`数组和C API调用替代Tensor/ISASI对象。

```text
GM->L1 Buffer（`__cbuf__`）->L0A Buffer（`__ca__`）/L0B Buffer（`__cb__`）->Mmad->L0C Buffer（`__cc__`）->GM/L1 Buffer/UB
                                                ->BiasTable Buffer/Fixpipe Buffer（按场景）
```

## 计算流程

1. 使用[矩阵数据搬运](../cube_datamove/矩阵数据搬运.md)中的GM->L1 Buffer或GM->L0 Buffer接口准备输入。ND/NZ/DN格式转换和L2缓存控制须按目标接口单独配置。
2. 使用L1 Buffer->L0A Buffer/L0B Buffer接口装载矩阵分形：例如[asc_copy_l12l0a](../cube_datamove/asc_copy_l12l0a/asc_copy_l12l0a.md)、[asc_copy_l12l0b](../cube_datamove/asc_copy_l12l0b/asc_copy_l12l0b.md)及其转置/稀疏变体。
3. 在MTE1完成输入后，通过[asc_sync_notify](../sync/asc_sync_notify.md)/[asc_sync_wait](../sync/asc_sync_wait.md)建立到矩阵流水的依赖，再调用[asc_mmad](../cube_compute/asc_mmad.md)或[asc_mmad_sparse](../cube_compute/asc_mmad_sparse.md)。
4. 在Mmad完成后，使用[asc_copy_l0c2gm](../cube_datamove/asc_copy_l0c2gm/asc_copy_l0c2gm.md)、[asc_copy_l0c2l1](../cube_datamove/asc_copy_l0c2l1/asc_copy_l0c2l1.md)或[asc_copy_l0c2ub](../cube_datamove/asc_copy_l0c2ub.md)搬出结果；NZ2ND、量化和激活由相应配置接口和搬出接口共同决定。

## 功能到C API入口

| 基础API公共章节概念 | C API文档 |
|---|---|
| 矩阵输入搬运、ND2NZ/DN2NZ | [asc_copy_gm2l1](../cube_datamove/asc_copy_gm2l1/asc_copy_gm2l1.md)、[asc_copy_gm2l1_nd2nz](../cube_datamove/asc_copy_gm2l1_nd2nz/asc_copy_gm2l1_nd2nz.md)、[asc_copy_gm2l1_dn2nz](../cube_datamove/asc_copy_gm2l1_dn2nz.md) |
| L1 Buffer装载L0A Buffer/L0B Buffer和转置/稀疏 | [矩阵数据搬运](../cube_datamove/矩阵数据搬运.md) |
| Mmad、方向与精度模式 | [矩阵计算](../cube_compute/矩阵计算.md)、[asc_mmad](../cube_compute/asc_mmad.md)、[asc_enable_hf32](../cube_compute/asc_enable_hf32.md) |
| BiasTable与Fixpipe参数 | [asc_copy_l12bt](../cube_datamove/asc_copy_l12bt/asc_copy_l12bt.md)、[asc_copy_l12fb](../cube_datamove/asc_copy_l12fb/asc_copy_l12fb.md)、[asc_set_l0c2gm_config](../cube_compute/asc_set_l0c2gm_config.md) |
| L0C Buffer输出、NZ2ND、量化/激活 | [asc_copy_l0c2gm](../cube_datamove/asc_copy_l0c2gm/asc_copy_l0c2gm.md)、[asc_set_l0c2gm_nz2nd](../cube_compute/asc_set_l0c2gm_nz2nd.md) |

`Mmad`及L1 Buffer->L0 Buffer装载在高优先级Basic API实现和C API实现中存在直接CCE对应（如`mad`、`load_cbuf_to_ca/cb`）；但矩阵布局、矩阵尺寸、转置、稀疏和量化参数为接口层语义，必须逐一核对，不能仅凭同一CCE名称断言等价。详情见[dav-3510 CCE指令索引](../../implementation_indexes/dav_3510/appendix.md)。
