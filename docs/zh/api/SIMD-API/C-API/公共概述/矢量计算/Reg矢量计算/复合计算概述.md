# 概述

复合计算支持以下接口：

**表1**  复合计算接口

| 接口 | 描述 |
| :--- | :--- |
| [asc_abs_sub](../../../reg/compound_compute/asc_abs_sub.md) | $dstReg_i = \lvert srcReg0_i - srcReg1_i \rvert$ |
| [asc_axpy](../../../reg/compound_compute/asc_axpy.md) | $dstReg_i = scalarValue \times srcReg_i + dstReg_i$ |
| [asc_exp_sub（废弃）](../../../reg/compound_compute/asc_exp_sub_deprecated.md) | • srcReg数据类型为float时：<br>$dstReg_i = e^{srcReg0_i - srcReg1_i}$<br>• srcReg数据类型为half时：<br>$dstReg_i = e^{cast\_f16\_to\_f32(srcReg0_i) - cast\_f16\_to\_f32(srcReg1_i)}$ |
| [asc_madd](../../../reg/compound_compute/asc_madd.md) | $dstReg_i = dstReg_i \times srcReg0_i + srcReg1_i$ |
| 乘加到目的寄存器 | 当前Reg C API无直接接口，可按精度与性能要求组合乘法和加法，$dstReg_i = srcReg0_i \times srcReg1_i + dstReg_i$。 |
| 标量乘法后类型转换 | 当前Reg C API无直接融合接口，可组合`asc_mul_scalar`和类型转换接口，$dst_i = cast\_round\_to\_f16(src_i \times scalarValue)$。 |
