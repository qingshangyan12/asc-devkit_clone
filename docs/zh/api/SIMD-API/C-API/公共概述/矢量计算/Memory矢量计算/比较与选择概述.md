# 概述

`asc_eq`、`asc_ne`、`asc_lt`、`asc_le`、`asc_gt`和`asc_ge`用于逐元素比较矢量或标量的大小，并根据比较结果生成掩码；`asc_select`和`asc_reduce`用于根据掩码选择或提取源操作数中的元素。推荐使用场景如下：

**表1**  比较与选择接口推荐使用场景

| API | 核心功能 | Mask类型 | 应用场景 |
| --- | --- | --- | --- |
| [asc_eq / asc_ne / asc_lt / asc_le / asc_gt / asc_ge](../../../vector_compute/Memory矢量计算.md) | 逐元素比较两个tensor大小，如果比较后的结果为真，则输出结果的对应比特位为1，否则为0。支持多种比较模式（等于、小于、大于...）。<br>不支持Vector计算的Mask设置。结果存入UB。 | 未使用 | 逐元素比较，结果写入内存。 |
| [asc_eq / asc_ne / asc_lt / asc_le / asc_gt / asc_ge（结果存入寄存器）](../../../vector_compute/Memory矢量计算.md) | 逐元素比较两个tensor大小，如果比较后的结果为真，则输出结果的对应比特位为1，否则为0。支持多种比较模式。<br>支持Vector计算的Mask设置。结果暂存CmpMask寄存器。详情参考[表2 CmpMask与VectorMask](#cmpMask-vectorMask)。 | src传参mask用于Vector计算；<br>输出结果为CmpMask（比较掩码）。 | 逐元素比较，结果写寄存器。 |
| [asc_eq_scalar/asc_ne_scalar/asc_lt_scalar/asc_le_scalar/asc_gt_scalar/asc_ge_scalar](../../../vector_compute/Memory矢量计算.md) | 逐元素比较一个矢量中的元素和标量的大小，如果比较结果为真，则输出结果的对应比特位为1，否则为0。<br>支持多种比较模式。 | 未使用 | 矢量和标量逐元素比较，结果写入内存。 |
| [asc_select](../../../vector_compute/asc_select.md) | 给定两个源操作数src0和src1，根据selMask（用于选择的Mask掩码）的比特位值选取元素。<br>支持CmpMask设置，支持用于Vector计算的Mask的设置。详情参考[表2 CmpMask与VectorMask](#cmpMask-vectorMask)。 | src传参mask用于Vector计算；<br>src传参selMask为CmpMask（比较掩码）。 | 掩码条件选择输出。 |
| [asc_get_cmp_mask](../../../vector_compute/asc_get_cmp_mask.md) | 此接口用于获取[asc_eq / asc_ne / asc_lt / asc_le / asc_gt / asc_ge（结果存入寄存器）](../../../vector_compute/Memory矢量计算.md)指令的比较结果。 | CmpMask（比较掩码） | 读取寄存器比较掩码。 |
| [asc_set_cmp_mask](../../../vector_compute/asc_set_cmp_mask.md) | 为[asc_select](../../../vector_compute/asc_select.md)不传入mask参数的接口设置比较寄存器。 | CmpMask（比较掩码） | 设置寄存器比较掩码。 |
| [asc_reduce](../../../vector_compute/asc_reduce.md) | 基于数据收集掩码从输入矢量中提取有效元素。 | src1传入数据收集掩码。 | 按掩码提取有效元素。 |

**表2**  CmpMask与VectorMask<a id="cmpMask-vectorMask"></a>

| 名称 | 描述 | 数据来源 | 作用范围 |
| --- | --- | --- | --- |
| CmpMask | asc_eq / asc_ne / asc_lt / asc_le / asc_gt / asc_ge比较指令的“结果寄存器”。 | &bull;由[asc_eq / asc_ne / asc_lt / asc_le / asc_gt / asc_ge（结果存入寄存器）](../../../vector_compute/Memory矢量计算.md)接口的结果写入。<br>&bull;通过`asc_select`的selMask参数传入。<br>&bull;通过`asc_set_cmp_mask`设置。 | 用于记录元素比较的布尔结果，主要供后续`asc_select`使用。 |
| VectorMask | 控制数据元素是否参与计算的标识位序列的Mask寄存器。详情参考[掩码](../../../vector_compute/Memory矢量计算.md)。 | &bull; [接口内设置mask](../../../vector_compute/Memory矢量计算.md#接口内设置mask)<br>&bull; [接口外设置mask](../../../vector_compute/Memory矢量计算.md#接口外设置mask) | 用于逐元素控制向量计算，决定哪些数据元素参与计算。 |
