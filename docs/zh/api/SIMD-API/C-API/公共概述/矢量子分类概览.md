# 矢量子分类概览

## Memory矢量计算

Memory矢量计算以UB地址为输入和输出，包含基础算术、复合计算、比较与选择、逻辑计算、类型转换、归约、数据重排、排序组合、数据填充及离散聚合等能力。分类入口和全部接口参见[Memory矢量计算](../vector_compute/Memory矢量计算.md)。

公共说明包括[总体概述](矢量计算/Memory矢量计算/概述.md)、[复合计算概述](矢量计算/Memory矢量计算/复合计算概述.md)、[比较与选择概述](矢量计算/Memory矢量计算/比较与选择概述.md)和[排序组合概述](矢量计算/Memory矢量计算/排序组合概述.md)。

## Reg矢量计算

Reg矢量计算包含寄存器数据类型、搬入、搬出、基础算术、复合计算、逻辑计算、比较与选择、类型转换、归约、数据压缩、数据填充、数据重排、直方图、索引、同步和系统变量访问等分类。完整入口参见[Reg矢量计算](../reg/reg.md)。

公共说明包括[总体概述](矢量计算/Reg矢量计算/概述.md)、[关键特性说明](矢量计算/Reg矢量计算/关键特性说明.md)以及各计算子分类概述。
