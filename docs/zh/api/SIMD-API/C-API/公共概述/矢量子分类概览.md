# 矢量子分类概览

本页逐项迁移基础API的Memory/Reg矢量子分类概览。C API与Basic API共享大量`dav-3510` CCE矢量指令；对应关系是指令级检索入口，不表示公开接口参数等价。

## Memory矢量计算

基础API的SIMD计算说明、Vector逻辑架构、连续/高维切分和掩码概念，在C API中由`__ubuf__`数组、掩码配置及各Vector接口表达。

**图 1**  Memory矢量计算模式示意图

![](../../../figures/multi_level_vector_api.png)

| 基础API子分类 | C API章节或接口 |
|---|---|
| 基础算术、逻辑计算、复合计算 | [Memory矢量计算](../vector_compute/Memory矢量计算.md)：如[asc_add](../vector_compute/asc_add.md)、[asc_and](../vector_compute/asc_and.md)、[asc_mul_add](../vector_compute/asc_mul_add.md) |
| 比较与选择、掩码操作 | [asc_eq](../vector_compute/asc_eq.md)、[asc_select](../vector_compute/asc_select.md)、[asc_set_vector_mask](../vector_compute/asc_set_vector_mask.md)、[asc_set_mask_count](../vector_compute/asc_set_mask_count.md) |
| 类型转换及辅助配置 | [Memory矢量计算转换接口](../vector_compute/Memory矢量计算.md)、[asc_set_deq_scale](../vector_compute/asc_set_deq_scale.md) |
| 归约计算及辅助配置 | [asc_reduce](../vector_compute/asc_reduce.md)、[asc_repeat_reduce_sum](../vector_compute/asc_repeat_reduce_sum.md)、[asc_datablock_reduce_sum](../vector_compute/asc_datablock_reduce_sum.md) |
| 数据排布转换、数据重排、数据填充 | [asc_transpose](../vector_compute/asc_transpose.md)、[asc_duplicate](../vector_compute/asc_duplicate.md)；Interleave/DeInterleave在C API中位于Reg的[asc_intlv](../reg/data_rearrange/asc_intlv.md)、[asc_deintlv](../reg/data_rearrange/asc_deintlv.md)，不作为Memory C API同名接口。 |
| 排序组合、离散与聚合 | [asc_mrgsort4](../vector_compute/asc_mrgsort4.md)、[asc_bitsort](../vector_compute/asc_bitsort.md)、[asc_gather](../vector_compute/asc_gather.md) |
| 数据搬运及辅助配置 | [矢量数据搬运](../vector_datamove/矢量数据搬运.md)、[数据搬运导览](数据搬运导览/数据搬运导览.md) |

基础API中的ISASI专有排序/重排接口、软仿切片和未在C API中公开的辅助对象不建立伪映射，详见[迁移问题和疑问](迁移问题和疑问.md)。

## Reg矢量计算

Reg路径为UB->寄存器->UB，分类与C API`reg`目录一一对应：

| 基础API子分类 | C API章节 |
|---|---|
| 寄存器数据类型、辅助数据类型、MaskReg计算 | [寄存器数据类型](../reg/reg_data_types/reg_data_types.md) |
| Reg数据搬入、Reg数据搬出 | [reg数据搬入](../reg/reg_load/reg_load.md)、[reg数据搬出](../reg/reg_store/reg_store.md) |
| 基础算术、复合计算、逻辑计算、比较与选择、归约计算 | [基础算术](../reg/arithmetic_compute/arithmetic_compute.md)、[复合计算](../reg/compound_compute/compound_compute.md)、[逻辑计算](../reg/logic_compute/logic_compute.md)、[比较与选择](../reg/compare_and_select/compare_and_select.md)、[归约计算](../reg/reduce_compute/reduce_compute.md) |
| 类型转换、数据压缩、数据填充、数据重排 | [类型转换](../reg/data_type_convert/data_type_convert.md)、[数据压缩](../reg/data_compress/data_compress.md)、[数据填充](../reg/data_fill/data_fill.md)、[数据重排](../reg/data_rearrange/data_rearrange.md) |
| 直方图、索引、离散操作、系统变量访问、同步控制 | [直方图计算](../reg/histogram_compute/histogram_compute.md)、[索引操作](../reg/index_operate/index_operate.md)、[reg数据搬入](../reg/reg_load/reg_load.md)、[系统变量访问](../reg/system_variables_access/system_variables_access.md)、[同步控制](../reg/sync_control/sync_control.md) |

基础API的VF调用、Hardware Loop和VF融合是Basic API/编译器编程模型；C API不提供同名VF封装。C API的Reg计算应按寄存器类型、掩码和每个接口的VL约束编写。
