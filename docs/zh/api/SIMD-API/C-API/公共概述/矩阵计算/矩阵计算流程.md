# 普通矩阵计算流程<a name="ZH-CN_TOPIC_0000002568950891"></a>

Ascend C针对矩阵计算编程模型提供了四类接口，分别承载Cube核中各个通路的搬运能力和计算能力，如下图所示：

**图1** 普通矩阵基础计算流程图<a name="zh-cn_topic_0000002535567224_fig135639216485"></a>
![](../../../../figures/matrix_computation_workflow.png "普通矩阵基础计算流程图")

1. 通过`asc_copy_gm2l1`将A、B原始矩阵的GM数据搬运到L1 Buffer中（如果存在Bias或随路量化参数，则同样搬运到L1 Buffer中）。详细内容请参考[矩阵数据搬入至L1 Buffer](矩阵计算搬入总体说明.md)。

2. 通过`asc_copy_l12l0a`和`asc_copy_l12l0b`将A、B矩阵分别加载到L0A Buffer和L0B Buffer上准备计算（如果存在Bias/随路量化，则通过`asc_copy_l12bt`或`asc_copy_l12fb`将L1 Buffer中的bias数据或量化系数数据搬运到BT Buffer/Fixpipe Buffer上）。详细内容请参考[矩阵数据搬入至L0A Buffer/L0B Buffer](../../cube_datamove/矩阵数据搬运.md)。

3. 通过asc_mmad接口对L0A Buffer、L0B Buffer、BT Buffer上面的数据进行矩阵计算，并输出结果到L0C Buffer上。详细内容请参考[asc_mmad计算](../../cube_compute/asc_mmad.md)。

4. 通过`asc_copy_l0c2gm`将L0C Buffer的数据进行处理并搬出到GM；该接口可以利用Fixpipe Buffer数据进行随路量化、ReLU等操作。详细内容请参考[asc_copy_l0c2gm_arch_3510（L0C到GM数据搬运）](../../cube_datamove/asc_copy_l0c2gm/asc_copy_l0c2gm_arch_3510.md)。

# Mx矩阵计算流程<a name="ZH-CN_TOPIC_0000002568950892"></a>

Mx矩阵计算仅在Ascend 950PR/Ascend 950DT型号支持。

MxMmad（全称Microscaling asc_mmad）为带有量化系数的矩阵乘法，即左矩阵和右矩阵均有对应的量化系数矩阵，左量化系数矩阵scaleA和右量化系数矩阵scaleB。MxMmad场景中，左量化系数矩阵与左矩阵乘积，右量化系数矩阵与右矩阵乘积，对两个乘积的结果做矩阵乘法。Ascend C针对Mx矩阵计算编程模型提供了对应Mx类接口，如下图所示：

**图 2** Mx矩阵基础计算流程图<a name="zh-cn_topic_0000002535567225_fig135639216486"></a>
![](../../../../figures/mx_matrix_computation_workflow.png "Mx矩阵基础计算流程图")

1. 通过`asc_copy_gm2l1`将A、B原始矩阵、[左系数矩阵scaleA](../../cube_compute/矩阵计算.md#section_mx_scalea_fractal_format)、[右系数矩阵scaleB](../../cube_compute/矩阵计算.md#section_mx_scaleb_fractal_format)的GM数据搬运到L1 Buffer中（如果存在Bias或随路量化参数，则同样搬运到L1 Buffer中）。详细内容请参考[矩阵数据搬入至L1 Buffer](矩阵计算搬入总体说明.md)。

2. 通过[asc_copy_l12l0a_mx](../../cube_datamove/asc_copy_l12l0a_mx.md)和[asc_copy_l12l0b_mx](../../cube_datamove/asc_copy_l12l0b_mx.md)将A矩阵与scaleA矩阵加载到L0A Buffer与内置L0A_MX Buffer、将B矩阵与scaleB矩阵加载到L0B Buffer与L0B_MX Buffer上准备计算（如果存在Bias或随路量化参数，则通过`asc_copy_l12bt`或`asc_copy_l12fb`搬运到BT Buffer/Fixpipe Buffer）。详细内容请参考[矩阵数据搬入至L0A Buffer/L0B Buffer](矩阵计算搬入总体说明.md)。

3. 通过MmadMx接口对L0A Buffer、L0A_MX Buffer、L0B Buffer、L0B_MX Buffer、BT Buffer上面的数据进行矩阵计算，并输出结果到L0C Buffer上。详细内容请参考[asc_mmad_mx计算](../../cube_compute/asc_mmad_mx.md)。

4. 通过`asc_copy_l0c2gm`将L0C Buffer的数据进行处理并搬出到GM；该接口可以利用Fixpipe Buffer数据进行随路量化、ReLU等操作。详细内容请参考[asc_copy_l0c2gm_arch_3510（L0C到GM数据搬运）](../../cube_datamove/asc_copy_l0c2gm/asc_copy_l0c2gm_arch_3510.md)。

# 4选2稀疏矩阵计算流程<a name="ZH-CN_TOPIC_0000002538231116"></a>

稀疏矩阵是一种特殊类型的矩阵，即矩阵中包含较多的零元素。4选2结构化稀疏矩阵计算，要求一个连续的4个权重或激活值的组（通常是张量中的一行或一列）中，最多只有2个值为非零，其余2个强制为零。针对Atlas A2训练系列产品/Atlas A2推理系列产品和Atlas A3训练系列产品/Atlas A3推理系列产品，Ascend C针对4选2稀疏矩阵计算编程模型提供了对应sparse类接口，如下图所示：

**图 3** 4选2稀疏矩阵基础计算流程图<a name="zh-cn_topic_0000002566526987_fig12280145134813"></a>
![](../../../../figures/sparse_matrix_computation_workflow.png "4选2稀疏矩阵基础计算流程图")

1. 首先将原始矩阵B按照固定粒度划分连续4个元素为一组，按照固定结构稠密算法，离线生成对应的稠密矩阵B与[索引矩阵](../../cube_compute/矩阵计算.md#zh-cn_topic_0000002563445163_section1873692415233)作为输入。

2. 通过`asc_copy_gm2l1`将原始矩阵A（稀疏矩阵）、稠密矩阵B、索引矩阵的GM数据搬运到L1 Buffer中（如果存在随路量化参数，则同样搬运到L1 Buffer中）。详细内容请参考[矩阵数据搬入至L1 Buffer](矩阵计算搬入总体说明.md)。

3. 通过`asc_copy_l12l0a`将原始矩阵A加载到L0A Buffer，通过[asc_copy_l12l0b_sparse](../../cube_datamove/asc_copy_l12l0b_sparse.md)将稠密矩阵B与索引矩阵分别加载到L0B Buffer与内置IDX Buffer上准备计算（如果存在随路量化，则通过`asc_copy_l12fb`将L1 Buffer中的量化系数数据搬运到Fixpipe Buffer上）。详细内容请参考[矩阵数据搬入至L0A Buffer/L0B Buffer](../../cube_datamove/矩阵数据搬运.md)。

4. 通过asc_mmad_sparse接口对L0A Buffer、L0B Buffer、内置IDX Buffer上面的数据进行4选2稀疏矩阵计算，并输出结果到L0C Buffer上。详细内容请参考[asc_mmad_sparse计算](../../cube_compute/asc_mmad_sparse.md)。

5. 通过`asc_copy_l0c2gm`将L0C Buffer的数据进行处理并搬出到GM；该接口可以利用Fixpipe Buffer数据进行随路量化、ReLU等操作。详细内容请参考[asc_copy_l0c2gm_arch_3510（L0C到GM数据搬运）](../../cube_datamove/asc_copy_l0c2gm/asc_copy_l0c2gm_arch_3510.md)。

# Conv2D前向计算流程<a name="ZH-CN_TOPIC_0000002568950893"></a>

Conv2D前向计算的本质是将卷积运算转换为矩阵乘：先通过img2col（Image to Column）将FeatureMap按卷积核滑动窗口展开为左矩阵A，将Weight作为右矩阵B，再做矩阵乘累加得到输出。与[普通矩阵计算流程](#ZH-CN_TOPIC_0000002568950891)的区别在于：A矩阵从GM直接搬入后，由[asc_copy_l12l0a / asc_copy_l12l0b](../../cube_compute/矩阵计算.md)在L1 Buffer到L0A Buffer的搬运过程中，根据卷积核尺寸、stride、dilation、padding在线完成img2col空间展开生成，如下图所示：

**图 4** Conv2D前向计算流程图<a name="zh-cn_topic_0000002568950893_fig135639216487"></a>
![](../../../../figures/conv2d_forward.png "Conv2D前向计算流程图")

1. 通过`asc_copy_gm2l1`或其格式转换重载将FeatureMap、Weight的GM数据搬运到L1 Buffer中。FeatureMap搬运时完成到[NC1HWC0格式](../../cube_compute/矩阵计算.md#zh-cn_topic_0000002545089965_section217615301084)的随路转换；Weight搬运到L1 Buffer得到Nz分形布局。详细内容请参考[矩阵计算搬入总体说明](矩阵计算搬入总体说明.md)。

2. 通过[asc_copy_l12l0a](../../cube_datamove/asc_copy_l12l0a/asc_copy_l12l0a_arch_3510.md)将L1 Buffer中的FeatureMap执行img2col，根据卷积核尺寸、stride、dilation、padding完成空间展开与padding填充，生成L0A Buffer上的左矩阵A；通过[asc_copy_l12l0b](../../cube_datamove/asc_copy_l12l0b/asc_copy_l12l0b_arch_3510.md)将L1 Buffer中的Weight搬运到L0B Buffer得到右矩阵B。FeatureMap属性通过[asc_set_l13d_fmatrix](../../cube_datamove/asc_set_l13d_fmatrix.md)配置，img2col的repeat参数通过[asc_set_l13d_rpt](../../cube_datamove/asc_set_l13d_rpt.md)配置，padding填充值通过[asc_set_l12l0_padding_val](../../sys_var/asc_set_l12l0_padding_val.md)设置。详细内容请参考[矩阵计算搬入总体说明](矩阵计算搬入总体说明.md)。

3. 通过asc_mmad接口对L0A Buffer、L0B Buffer上的数据进行矩阵计算，并输出结果到L0C Buffer上。详细内容请参考[asc_mmad计算](../../cube_compute/asc_mmad.md)。

4. 通过`asc_copy_l0c2gm`将L0C Buffer的数据进行处理并按指定格式搬出到GM；该接口可以利用Fixpipe Buffer数据进行随路量化、ReLU等操作。L0C Buffer上存放的卷积结果为NC1HWC0格式，接口通过[NZ2ND](矩阵搬出关键特性说明/NZ2ND.md)能力将其转为NHWC格式输出。<!-- npu="950" id3 -->特别地，针对Ascend 950PR/Ascend 950DT产品，还支持通过[NZ2DN](矩阵搬出关键特性说明/NZ2DN.md)能力将L0C Buffer上的卷积结果转为NCHW格式输出。<!-- end id3 -->详细内容请参考[卷积格式转换](矩阵搬出关键特性说明/卷积格式转换.md)。更多搬出相关内容请参考[矩阵计算搬出总体说明](矩阵计算搬出总体说明.md)。
