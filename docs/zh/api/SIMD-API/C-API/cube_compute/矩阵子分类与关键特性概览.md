# 矩阵子分类与关键特性概览

矩阵计算分为以下阶段：

1. 搬入：GM/UB到L1 Buffer，以及L1 Buffer到L0A Buffer/L0B Buffer。
2. 计算：普通矩阵乘加、Mx矩阵乘加和稀疏矩阵乘加。
3. 搬出：L0C Buffer到GM、L1 Buffer或UB，可按接口能力配置格式转换、量化及激活。

各阶段的完整说明和约束分别见[矩阵计算单元](概述/矩阵计算单元.md)、[矩阵计算流程](概述/矩阵计算流程.md)、[矩阵计算搬入总体说明](../cube_datamove/矩阵计算的搬入/总体说明.md)、[矩阵计算输入搬运约束](../cube_datamove/矩阵计算的搬入/矩阵计算输入搬运约束.md)、[Mmad计算关键特性说明](Mmad计算关键特性说明/Mmad计算关键特性说明.md)、[矩阵计算搬出总体说明](../cube_datamove/矩阵计算的搬出/总体说明.md)和[矩阵搬出关键特性说明](../cube_datamove/矩阵计算的搬出/矩阵搬出关键特性说明/矩阵搬出关键特性说明.md)。
