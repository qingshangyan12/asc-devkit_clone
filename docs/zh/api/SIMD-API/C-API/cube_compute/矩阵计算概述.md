# 矩阵计算概述

C API矩阵计算由矩阵搬入、矩阵乘加和矩阵搬出组成。矩阵数据通常从GM或UB搬入L1 Buffer，再搬入L0A Buffer和L0B Buffer，`asc_mmad`在Cube流水完成乘加，结果写入L0C Buffer，最后搬出到GM、L1 Buffer或UB。
