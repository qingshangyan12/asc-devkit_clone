# 矩阵计算单元

Cube Unit用于执行矩阵运算。L0A Buffer通常存储左矩阵，L0B Buffer通常存储右矩阵，L0C Buffer存储累加初值和矩阵计算结果。

矩阵计算关联的存储单元如下：

| 存储单元 | 说明 |
| --- | --- |
| L0A Buffer | 存储矩阵计算的左矩阵。 |
| L0B Buffer | 存储矩阵计算的右矩阵。 |
| L0C Buffer | 存储矩阵计算的结果和累加初值。 |
| L1 Buffer | 缓存矩阵输入数据，并向L0A Buffer、L0B Buffer等存储单元供数。 |
| BiasTable Buffer | 存储矩阵计算所需的Bias数据。 |
| Fixpipe Buffer | 存储矩阵结果搬出时所需的量化或激活参数。 |
