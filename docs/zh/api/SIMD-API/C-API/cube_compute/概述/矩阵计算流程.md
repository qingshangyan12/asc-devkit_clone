# 矩阵计算流程

## 普通矩阵计算

1. 使用[asc_copy_gm2l1](../../cube_datamove/asc_copy_gm2l1/asc_copy_gm2l1.md)等接口将左右矩阵从GM搬入L1 Buffer。
2. 使用[asc_copy_l12l0a](../../cube_datamove/asc_copy_l12l0a/asc_copy_l12l0a.md)和[asc_copy_l12l0b](../../cube_datamove/asc_copy_l12l0b/asc_copy_l12l0b.md)将左右矩阵分别搬入L0A Buffer和L0B Buffer。Bias通过[asc_copy_l12bt](../../cube_datamove/asc_copy_l12bt/asc_copy_l12bt.md)搬入BiasTable Buffer，Fixpipe参数通过[asc_copy_l12fb](../../cube_datamove/asc_copy_l12fb/asc_copy_l12fb.md)搬入Fixpipe Buffer。
3. 使用[asc_mmad](../asc_mmad.md)完成矩阵乘加，结果写入L0C Buffer。
4. 使用[asc_copy_l0c2gm](../../cube_datamove/asc_copy_l0c2gm/asc_copy_l0c2gm.md)、[asc_copy_l0c2l1](../../cube_datamove/asc_copy_l0c2l1/asc_copy_l0c2l1.md)或[asc_copy_l0c2ub](../../cube_datamove/asc_copy_l0c2ub.md)搬出结果。

## MX矩阵计算

MX矩阵计算使用[asc_copy_l12l0a_mx](../../cube_datamove/asc_copy_l12l0a_mx.md)和[asc_copy_l12l0b_mx](../../cube_datamove/asc_copy_l12l0b_mx.md)同时搬入矩阵与量化系数，再通过[asc_mmad_mx](../asc_mmad_mx.md)完成计算。产品支持和MX矩阵排布以单接口文档为准。

**图 2**  MX矩阵计算流程

![](../../../../figures/mx_matrix_computation_workflow.png)

## 4选2结构化稀疏矩阵计算

先使用[asc_copy_l12l0b_sparse](../../cube_datamove/asc_copy_l12l0b_sparse.md)将稠密化权重和索引搬入L0B Buffer及专用索引空间，再使用[asc_mmad_sparse](../asc_mmad_sparse.md)计算。

**图 3**  4选2结构化稀疏矩阵计算流程

![](../../../../figures/sparse_matrix_computation_workflow.png)

## Conv2D前向计算

Conv2D场景通过`asc_copy_l12l0a`的3D搬运重载完成Feature Map的img2col展开，相关属性由[asc_set_l13d_fmatrix](../../cube_datamove/asc_set_l13d_fmatrix.md)、[asc_set_l13d_size](../../cube_datamove/asc_set_l13d_size.md)、[asc_set_l13d_padding](../../cube_datamove/asc_set_l13d_padding.md)和[asc_set_l13d_rpt](../../cube_datamove/asc_set_l13d_rpt.md)配置。计算结果可通过`asc_copy_l0c2gm`完成支持的格式转换后写回GM。

**图 4**  Conv2D前向计算流程

![](../../../../figures/conv2d_forward.png)
