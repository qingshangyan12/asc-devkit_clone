# HF32

HF32用于在支持的产品上以更高吞吐完成`float`矩阵计算。使用前根据场景调用以下配置接口：

- [asc_enable_hf32](../asc_enable_hf32.md)：配置HF32计算模式。
- [asc_enable_hf32_trans](../asc_enable_hf32_trans.md)：配置HF32转置相关模式。
- [asc_set_hf32_round_mode](../asc_set_hf32_round_mode.md)：配置舍入模式。
- [asc_set_fp32_mode](../asc_set_fp32_mode.md)：恢复或配置FP32模式。

HF32模式、转置模式和舍入模式的产品支持范围并不完全相同，应分别核对单接口文档。调用[asc_mmad](../asc_mmad.md)时，还需要按目标架构区分`k_direction_align`与`disable_gemv`参数，不能使用一段未限定架构的调用覆盖两套原型。
