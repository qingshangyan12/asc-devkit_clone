# HF32<a name="ZH-CN_TOPIC_0000002538231188"></a>

**特性说明：**

HF32的核心功能体现为：用户在输入矩阵A、B矩阵都为fp32数据类型的场景下，当配置开启HF32开关后，fp32数据在执行矩阵乘法运算前会被转换并舍入为HF32（half-fp32）格式。这种做法可使`asc_mmad`（f322f32）的计算性能提升至原来的两倍，但会带来一定的精度损失。需要注意的是，尽管中间计算使用HF32格式，最终的运算结果仍以fp32格式输出，以保证后续处理的兼容性。

舍入模式说明：fp32至HF32转换过程中的舍入模式由[asc_enable_hf32_trans](../asc_enable_hf32_trans.md)配置。HF32模式开启后，`mode=1`时FP32以向零靠近的方式舍入为HF32；`mode=0`时FP32以最接近偶数的方式舍入为HF32。

**使用示例：**

示例中，`m`、`k`和`n`分别通过`asc_mmad`的`left_height`、`n_dim`和`right_width`参数传入，其余控制项也由独立参数显式传入，不使用参数对象。HF32模式只改变fp32输入参与矩阵计算时的内部精度，C矩阵仍为fp32输出。

```cpp
// 开启HF32模式，并设置为向零靠近的舍入方式。
asc_enable_hf32();
asc_enable_hf32_trans(1);
asc_mmad(c_matrix, a_matrix, b_matrix, m, k, n, unit_flag,
    k_direction_align, c_matrix_source, c_matrix_init_val);
// 恢复FP32模式和最接近偶数的舍入方式。
asc_set_fp32_mode();
asc_enable_hf32_trans(0);
```
