# 原子操作概述

C API提供两类原子操作：数据搬运随路原子配置和Scalar单点原子读改写。两类接口的作用范围不同。

## 数据搬运随路原子操作

以下配置接口设置后续支持原子模式的GM写操作：

| 操作 | 配置入口 |
| --- | --- |
| 原子加 | [asc_set_atomic_add](asc_set_atomic_add.md) |
| 原子最大值 | [asc_set_atomic_max](asc_set_atomic_max.md) |
| 原子最小值 | [asc_set_atomic_min](asc_set_atomic_min.md) |
| 关闭原子模式 | [asc_set_atomic_none](asc_set_atomic_none.md) |

`asc_set_atomic_add`、`asc_set_atomic_max`和`asc_set_atomic_min`是接口族文档标题，实际调用符号按数据类型区分，例如`asc_set_atomic_add_int8`、`asc_set_atomic_add_float16`和`asc_set_atomic_add_float`。应从对应文档的函数原型中选择真实符号，不能调用带`*`的通配名称。

## Scalar单点原子操作

Scalar接口直接对单个GM地址执行原子读改写，包括[asc_atomic_add](../scalar_compute/asc_atomic_add.md)、[asc_atomic_sub](../scalar_compute/asc_atomic_sub.md)、[asc_atomic_max](../scalar_compute/asc_atomic_max.md)、[asc_atomic_min](../scalar_compute/asc_atomic_min.md)、[asc_atomic_cas](../scalar_compute/asc_atomic_cas.md)和位运算原子接口等。完整入口参见[标量计算](../scalar_compute/标量计算.md)。

两类原子操作都只保证目标地址上的原子更新，不自动建立多核阶段同步，也不自动处理Scalar DCache中其他地址的数据可见性。
