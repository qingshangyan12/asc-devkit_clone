# 系统同步能力概述

Ascend C API的同步接口用于约束当前Core内的流水执行顺序，或在分离模式下传递Core间同步信号。不同层级的同步不能互相替代。

| 同步范围 | 接口 | 作用 |
| --- | --- | --- |
| 当前Core的全部流水 | [asc_sync](asc_sync.md) | 等待当前Core此前提交到所有流水的操作完成。该接口不是多核Barrier。 |
| 当前Core的单条流水 | [asc_sync_pipe](asc_sync_pipe.md) | 等待指定流水的前序操作完成。 |
| 当前Core的不同流水 | [asc_sync_notify](asc_sync_notify.md)、[asc_sync_wait](asc_sync_wait.md) | 通过事件ID建立源流水和目的流水之间的依赖。 |
| 分离模式下的Core间同步 | [同步控制](同步控制.md)中的block、subblock、intra和inter接口 | 在指定同步范围内发送或等待信号。 |
| 数据可见性屏障 | [asc_sync_data_barrier](asc_sync_data_barrier.md) | 按单接口文档约束建立数据访问屏障。 |

同步范围越大，可能引入的等待越多。优先选择能够覆盖真实依赖关系的最小同步范围。
