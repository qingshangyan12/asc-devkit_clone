# 核间同步能力概述

分离模式下，AIC和AIV按group组织，一个group包含一个block和若干subblock。C API按同步参与者提供不同接口族。

| 同步范围 | 到达接口 | 等待接口 |
| --- | --- | --- |
| 同一group内block与subblock | [asc_sync_block_arrive](../asc_sync_block_arrive.md) | [asc_sync_block_wait](../asc_sync_block_wait.md) |
| 同一group内不同subblock | [asc_sync_subblock_arrive](../asc_sync_subblock_arrive.md) | [asc_sync_subblock_wait](../asc_sync_subblock_wait.md) |
| 不同group之间 | [asc_sync_inter_arrive](../asc_sync_inter_arrive.md) | [asc_sync_inter_wait](../asc_sync_inter_wait.md) |
| 同一block内block与单个subblock | [asc_sync_intra_arrive](../asc_sync_intra_arrive.md) | [asc_sync_intra_wait](../asc_sync_intra_wait.md) |

`asc_sync_intra_arrive/wait`只在其单接口文档列出的产品上可用。各接口通过`flag_id`或`sync_id`关联到达和等待操作，支持的流水、ID范围、计数器上限和Kernel类型要求不同。

[asc_sync](../asc_sync.md)仅同步当前Core的流水，不属于核间同步接口。
