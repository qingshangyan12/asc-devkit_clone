# 比较与选择概述

Memory矢量计算提供矢量间比较、矢量与标量比较、条件选择及按掩码提取能力。

| 类别 | 接口 | 结果或用途 |
| --- | --- | --- |
| 矢量间比较 | [asc_eq](../asc_eq.md)、[asc_ne](../asc_ne.md)、[asc_lt](../asc_lt.md)、[asc_le](../asc_le.md)、[asc_gt](../asc_gt.md)、[asc_ge](../asc_ge.md) | 按元素比较，可根据重载将结果写入UB或比较掩码寄存器。 |
| 矢量与标量比较 | [asc_eq_scalar](../asc_eq_scalar.md)、[asc_ne_scalar](../asc_ne_scalar.md)、[asc_lt_scalar](../asc_lt_scalar.md)、[asc_le_scalar](../asc_le_scalar.md)、[asc_gt_scalar](../asc_gt_scalar.md)、[asc_ge_scalar](../asc_ge_scalar.md) | 按元素比较矢量数据和标量。 |
| 条件选择 | [asc_select](../asc_select.md) | 根据选择掩码从两个源操作数中选择元素。 |
| 比较掩码访问 | [asc_get_cmp_mask](../asc_get_cmp_mask.md)、[asc_set_cmp_mask](../asc_set_cmp_mask.md) | 读取或设置比较掩码寄存器。 |
| 掩码提取 | [asc_reduce](../asc_reduce.md) | 根据数据收集掩码提取有效元素。 |

比较掩码记录比较结果，供`asc_select`等后续接口使用；Vector Mask控制本次矢量指令中哪些元素参与计算。两者用途不同，不能混用。具体mask形式、结果存储位置和支持重载以单接口文档为准。
