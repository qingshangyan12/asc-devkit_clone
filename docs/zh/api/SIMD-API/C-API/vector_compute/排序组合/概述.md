# 排序组合概述

Region Proposal由候选框坐标、置信度和类别等字段组成。排序组合接口通常按置信度对`score`和`index`组合进行排序，再通过`index`访问完整候选框数据。

**图 1**  Region Proposal结构

![](../../../../figures/region_proposal.png)

- [asc_bitsort](../asc_bitsort.md)：在一次迭代内对32组`score`和`index`执行降序排列。
- [asc_mrgsort4](../asc_mrgsort4.md)：将最多4个已经有序的子队列归并为一个有序队列。

两个接口的产品支持、输入数据排布和支持数据类型应分别以单接口文档为准，不能由某一个产品示例推导完整支持范围。
