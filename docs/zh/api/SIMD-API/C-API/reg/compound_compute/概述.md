# 概述

复合计算支持以下接口：

**表 1**  复合计算接口

| 接口 | 描述 |
| :--- | :--- |
| [asc_abs_sub](asc_abs_sub.md) | $dstReg_i = \lvert srcReg0_i - srcReg1_i \rvert$ |
| [asc_axpy](asc_axpy.md) | $dstReg_i = scalarValue \times srcReg_i + dstReg_i$ |
| [asc_exp_sub（废弃）](asc_exp_sub_deprecated.md) | • srcReg数据类型为float时：<br>$dstReg_i = e^{srcReg0_i - srcReg1_i}$<br>• srcReg数据类型为half时：<br>$dstReg_i = e^{cast\_f16\_to\_f32(srcReg0_i) - cast\_f16\_to\_f32(srcReg1_i)}$ |
| [asc_madd](asc_madd.md) | $dstReg_i = dstReg_i \times srcReg0_i + srcReg1_i$ |
