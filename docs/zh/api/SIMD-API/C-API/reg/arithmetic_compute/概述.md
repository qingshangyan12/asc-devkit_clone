# 概述

**表 1**  单目运算

| 接口 | 描述 |
| --- | --- |
| [asc_abs](asc_abs.md) | 对srcReg中的有效元素逐个取绝对值，并将结果写入dstReg对应位置，计算公式如下：$dstReg_i = \lvert srcReg_i \rvert$ |
| [asc_exp](asc_exp.md) | $dstReg_i = e^{srcReg_i}$ |
| [asc_ln](asc_ln.md) | $dstReg_i = \ln(srcReg_i)$ |
| [asc_log](../../vector_compute/asc_log.md) | $dstReg_i = \log(srcReg_i)$ |
| [asc_neg](asc_neg.md) | $dstReg_i = -srcReg_i$ |
| [asc_relu](asc_relu.md) | $dstReg_i = \max(0, srcReg_i)$ |
| [asc_sqrt](asc_sqrt.md) | $dstReg_i = (srcReg_i)^{1/2}$ |

**表 2**  双目运算

| 接口 | 描述 |
| --- | --- |
| [asc_add](asc_add.md) | $dstReg_i = srcReg0_i + srcReg1_i$ <br>$\{carry_i, dstReg_i\} = srcReg0_i + srcReg1_i$ |
| [asc_addc](asc_addc.md) | $\{carry_i, dstReg_i\} = srcReg0_i + srcReg1_i + carrySrc_i$ |
| [asc_div](asc_div.md) | $dstReg_i = srcReg0_i / srcReg1_i$ |
| [asc_max](asc_max.md) | $dstReg_i = \max(srcReg0_i, srcReg1_i)$ |
| [asc_min](asc_min.md) | $dstReg_i = \min(srcReg0_i, srcReg1_i)$ |
| [asc_mul](asc_mul.md) | $dstReg_i = srcReg0_i \times srcReg1_i$ |
| [asc_mull](asc_mull.md) | $dstReg0_i = (srcReg0_i \times srcReg1_i) \bmod 2^{bit}$<br>$dstReg1_i = (srcReg0_i \times srcReg1_i) / 2^{bit}$<br>其中，bit表示操作数的位宽bit数。 |
| [asc_prelu](asc_prelu.md) | $dstReg_i = \begin{cases} srcReg0_i & srcReg0_i > 0 \\ srcReg0_i \times srcReg1_i & srcReg0_i \leq 0 \end{cases}$ |
| [asc_sub](asc_sub.md) | $dstReg_i = srcReg0_i - srcReg1_i$ <br>$\{carry_i, dstReg_i\} = \{1'b0, srcReg0_i\} + \{1'b0, ~srcReg1_i\} + 33'b1$ |
| [asc_subc](asc_subc.md) | $\{carry_i, dstReg_i\} = \{1'b0, srcReg0_i\} + \{1'b0, ~srcReg1_i\} + \{32'b0,carrySrc_i\}$ |

**表 3**  标量双目运算

| 接口 | 描述 |
| --- | --- |
| [asc_add_scalar](asc_add_scalar.md) | $dstReg_i = srcReg_i + scalarValue$ |
| [asc_leakyrelu](asc_leakyrelu.md) | $dstReg_i = \begin{cases} srcReg_i & srcReg_i > 0 \\ srcReg_i \times scalarValue & srcReg_i \leq 0 \end{cases}$ |
| [asc_max_scalar](asc_max_scalar.md) | $dstReg_i = \max(srcReg_i, scalarValue)$ |
| [asc_min_scalar](asc_min_scalar.md) | $dstReg_i = \min(srcReg_i, scalarValue)$ |
| [asc_mul_scalar](asc_mul_scalar.md) | $dstReg_i = srcReg_i \times scalarValue$ |
