# 概述

逻辑计算支持以下接口：

**表1**  逻辑计算接口

| 接口 | 描述 |
| :--- | :--- |
| [asc_not](asc_not.md) | • 对矢量数据寄存器操作：<br>根据mask对输入数据srcReg执行按位取反操作，将结果写入dstReg。<br>• 对vector_bool操作：<br>根据mask对输入数据src执行按位取反操作，将结果写入dst。 |
| [asc_and](asc_and.md) | • 对矢量数据寄存器操作：<br>根据mask对输入数据srcReg0、srcReg1执行按位与（&）操作，将结果写入dstReg。<br>• 对vector_bool操作：<br>根据mask对两个输入vector_bool数据src0、src1执行按位与（&）操作，将结果写入dst。 |
| [asc_or](asc_or.md) | • 对矢量数据寄存器操作：<br>根据mask对输入数据srcReg0、srcReg1按位求或（\|）操作，将结果写入dstReg。<br>• 对vector_bool操作：<br>根据mask对两个输入vector_bool数据src0、src1按位求或（\|）操作，将结果写入dst。 |
| [asc_xor](asc_xor.md) | • 对矢量数据寄存器操作：<br>根据mask对输入数据srcReg0、srcReg1按位异或（^）操作，将结果写入dstReg。<br>• 对vector_bool操作：<br>根据mask对两个输入vector_bool数据src0、src1按位异或（^）操作，将结果写入dst。 |
| [asc_shiftleft](asc_shiftleft.md) | $dstReg_i = srcReg0_i \ll srcReg1_i$ |
| [asc_shiftright](asc_shiftright.md) | $dstReg_i = srcReg0_i \gg srcReg1_i$ |
| [asc_shiftleft_scalar](asc_shiftleft_scalar.md) | $dstReg_i = srcReg_i \ll scalarValue$ |
| [asc_shiftright_scalar](asc_shiftright_scalar.md) | $dstReg_i = srcReg_i \gg scalarValue$ |
