# Reg矢量计算概述

Reg矢量计算API直接操作矢量数据寄存器和掩码寄存器。数据通常先通过Reg搬入接口从UB加载到寄存器，在寄存器中完成计算，再通过Reg搬出接口写回UB。与Memory矢量计算相比，Reg矢量计算将数据搬入、计算和搬出的组织方式交给开发者控制。

典型Vector Function包含以下步骤：

1. 使用`__simd_vf__`定义Vector Function。
2. 定义[Reg寄存器数据类型](reg_data_types/reg_data_types.md)中的矢量数据寄存器和mask。
3. 在[硬件循环](关键特性说明/关键特性说明.md#硬件循环hardwareloop)中通过[asc_update_mask](reg_data_types/asc_update_mask.md)更新有效元素。
4. 使用[asc_loadalign](reg_load/asc_loadalign.md)等接口从UB搬入一个VL的数据。
5. 调用[asc_add](arithmetic_compute/asc_add.md)等Reg计算接口。
6. 使用[asc_storealign](reg_store/asc_storealign.md)等接口将结果写回UB。

GM与UB之间的数据搬运应使用[GM与UB数据搬运](../vector_datamove/数据搬运导览/GM与UB数据搬运.md)中的接口。Vector Function内部的内存依赖按[asc_mem_bar](sync_control/asc_mem_bar.md)约束处理。

接口入口参见[Reg矢量计算](reg.md)。
