# L1 Buffer与L0 Buffer数据搬运

## 普通矩阵搬运

- [asc_copy_l12l0a](../asc_copy_l12l0a/asc_copy_l12l0a.md)：L1 Buffer->L0A Buffer。
- [asc_copy_l12l0b](../asc_copy_l12l0b/asc_copy_l12l0b.md)：L1 Buffer->L0B Buffer。

两组接口均包含架构相关重载，可覆盖2D或3D搬运、转置等场景。应根据对应架构文档选择公开重载及其标量参数。

## 专用搬运

| 场景 | 接口 |
| --- | --- |
| L0A Buffer转置搬入 | [asc_copy_l12l0a_trans](../asc_copy_l12l0a_trans.md) |
| L0B Buffer转置搬入 | [asc_copy_l12l0b_trans](../asc_copy_l12l0b_trans/asc_copy_l12l0b_trans.md) |
| L0A Buffer与MX量化系数搬入 | [asc_copy_l12l0a_mx](../asc_copy_l12l0a_mx.md) |
| L0B Buffer与MX量化系数搬入 | [asc_copy_l12l0b_mx](../asc_copy_l12l0b_mx.md) |
| 结构化稀疏权重搬入 | [asc_copy_l12l0b_sparse](../asc_copy_l12l0b_sparse.md) |
| L1 Buffer->L0C Buffer | [asc_copy_l12l0c](../asc_copy_l12l0c.md) |

结构化稀疏搬入的数据供[asc_mmad_sparse](../../cube_compute/asc_mmad_sparse.md)使用。MX搬运接口同时处理矩阵数据和对应量化系数，参数及存储排布以单接口文档为准。

## 辅助配置

3D搬运相关配置接口包括[asc_set_l13d_fmatrix](../asc_set_l13d_fmatrix.md)、[asc_set_l13d_size](../asc_set_l13d_size.md)、[asc_set_l13d_padding](../asc_set_l13d_padding.md)和[asc_set_l13d_rpt](../asc_set_l13d_rpt.md)。Padding值配置以当前公开的对应接口文档为准。
