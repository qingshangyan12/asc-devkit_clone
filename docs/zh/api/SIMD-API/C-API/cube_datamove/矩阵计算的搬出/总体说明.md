# 矩阵计算搬出总体说明

矩阵计算搬出将L0C Buffer中的结果搬运到GM、L1 Buffer或UB，并可在部分接口和产品上完成格式转换、量化或激活。

| 数据通路 | 接口 |
| --- | --- |
| L0C Buffer->GM | [asc_copy_l0c2gm](../asc_copy_l0c2gm/asc_copy_l0c2gm.md) |
| L0C Buffer->L1 Buffer | [asc_copy_l0c2l1](../asc_copy_l0c2l1/asc_copy_l0c2l1.md) |
| L0C Buffer->UB | [asc_copy_l0c2ub](../asc_copy_l0c2ub.md) |

`asc_copy_l0c2gm`在2201和3510架构上提供不同重载。3510架构重载可通过显式参数控制L2 Cache、Clip ReLU、unit flag、预量化、ReLU、Channel Split、NZ2ND、后量化及NZ2DN等能力；2201架构的参数和能力集合不同，不能混用原型。

随路量化或随路ReLU使用矢量参数时，通过[asc_set_l0c2gm_config](../../cube_compute/asc_set_l0c2gm_config.md)配置相关地址，并通过[asc_copy_l12fb](../asc_copy_l12fb/asc_copy_l12fb.md)将参数搬入Fixpipe Buffer。该配置接口用于设置预处理矢量地址和unit flag开关，不用于重置L0C Buffer搬出状态。
