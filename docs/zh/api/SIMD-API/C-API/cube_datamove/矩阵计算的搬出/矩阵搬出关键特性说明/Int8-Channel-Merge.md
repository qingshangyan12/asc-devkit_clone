# Int8 Channel Merge<a name="ZH-CN_TOPIC_0000002538071280"></a>

## 特性说明

矩阵计算的搬出过程中，当目标数据类型转换为`int8_t`或`uint8_t`并保持NZ输出时，该特性自动启用。硬件会将分形矩阵从16×16扩展为16×32。若输出通道数N是16的偶数倍，则在N方向上每两个相邻的16×16分形合并为一个16×32分形；若N是16的奇数倍，则最后16个通道保持为独立分形。

## 特性约束

硬件自动开启，不能配置。

## 使用示例

例如，当目标数据类型为`int8_t`、M为32、N为48时，硬件先将N方向上前两个16×16分形合并成一个16×32分形，再搬运剩余的16×16分形。
