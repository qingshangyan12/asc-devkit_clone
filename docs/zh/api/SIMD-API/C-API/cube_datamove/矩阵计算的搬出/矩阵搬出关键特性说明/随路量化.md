# 随路量化

矩阵结果从L0C Buffer搬出时，可在支持的产品和数据类型组合上完成类型转换或量化。主要入口为[asc_copy_l0c2gm](../../asc_copy_l0c2gm/asc_copy_l0c2gm.md)，其他目的存储位置的能力以相应搬出接口文档为准。

## 量化系数形式

- Scalar量化：整个矩阵使用一个量化参数，参数随`quant_pre`或目标架构对应参数传入。
- Vector量化：N方向的不同channel使用不同量化参数。通过[asc_set_l0c2gm_config](../../../cube_compute/asc_set_l0c2gm_config.md)设置矢量量化参数地址，并通过[asc_copy_l12fb](../../asc_copy_l12fb/asc_copy_l12fb.md)将参数搬入Fixpipe Buffer。

## 架构差异

2201和3510架构支持的量化模式、枚举值、参数位域和舍入行为不同。调用时应使用对应架构的`asc_copy_l0c2gm`文档，不应从某一架构的`QUANT_PRE`位域推导另一架构的参数编码。

数据类型名称应与函数原型一致，例如`int8_t`、`uint8_t`、half、`bfloat16_t`、`fp8_e4m3fn_t`和`hifloat8_t`。具体支持组合以单接口文档为准。

随路量化与ReLU同时启用时，参见[随路量化与随路ReLU场景组合](随路量化与随路ReLU场景组合.md)。
