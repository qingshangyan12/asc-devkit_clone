# NZ2NZ

NZ2NZ表示矩阵结果从L0C Buffer搬出后仍保持NZ排布。主要通过[asc_copy_l0c2gm](../../asc_copy_l0c2gm/asc_copy_l0c2gm.md)或对应目的存储位置的搬出接口实现。

## 参数含义

- M、N方向有效大小由对应架构函数原型中的矩阵尺寸参数描述。
- 源stride表示L0C Buffer中相邻分形或数据块之间的间隔。
- 目的stride表示目标NZ排布中相邻分形或数据块之间的间隔。

2201与3510架构的参数名称和stride单位不同。应以对应架构单接口文档为准，不能在两个架构间复用同一个单位说明。

## 约束

- 目标地址区域不能互相重叠。
- 数据类型、分形尺寸和地址对齐必须满足目标搬出接口约束。
- 与F32 Channel Split或Channel Merge组合时，小分形尺寸和N方向有效长度应满足组合能力要求。
- 当M方向有效元素不能填满分形时，应按接口定义处理搬入阶段产生的无效元素。
