# 卷积格式转换

在卷积运算中，L0C Buffer上存放的数据格式为NC1HWC0格式，`asc_copy_l0c2gm`通过[NZ2ND](NZ2ND.md)能力，支持将L0C Buffer上数据转为NHWC格式输出。转换示意图如下所示：

**图 1**  NC1HWC0转换为NHWC格式<a name="zh-cn_topic_0000002515830464_fig63620361414"></a>

![](../../../../../figures/fixpipe_nc1hwc0_nhwc.png)

在支持NZ2DN的产品上，`asc_copy_l0c2gm`还可通过[NZ2DN](NZ2DN.md)能力，将L0C Buffer上的数据转换为NCHW格式输出。转换示意图如下所示：
