# 矩阵计算输入搬运约束<a name="ZH-CN_TOPIC_0000002568950895"></a>

## 对齐约束

具体可见[表数据通路和存储层级](总体说明.md#zh-cn_topic_0000002543771563_table3523123518108)。

- 当源地址位于L1 Buffer时，该地址必须32Byte对齐；当源地址位于GM时，该地址必须1Byte对齐。
- 当目的地址位于L0A Buffer/L0B Buffer时，该地址必须512Byte对齐；当目的地址位于L1 Buffer时，该地址必须32Byte对齐。

## 带宽约束

- asc_copy_gm2l1 / asc_copy_l12l0a / asc_copy_l12l0b以大小为512Byte的分形为单位进行搬运。
- asc_copy_l12l0a / asc_copy_l12l0b以大小为512Byte的分形为单位进行搬运。
- asc_copy_l12l0b_sparse搬运以512Byte为单位存放的稠密权重矩阵到L0B Buffer里，同时搬运以128Byte为单位的索引矩阵到内置的专用buffer空间。

## 分形约束

asc_copy_gm2l1在不使能随路进行ND到NZ转换的时候，不会改变分形间和分形内排布，如Nz2Nz，在使能ND到NZ转换的情况下，一定会改变分形排布，如ND2Nz。

asc_copy_gm2l1 / asc_copy_l12l0a / asc_copy_l12l0b在不使能转置情况下，只能改变分形间的排布，如Nz2Zz；在使能转置情况下，既能改变分形内的排布，又能改变分形间的排布，如Nz2Zn。

asc_copy_l12l0a_transpose / asc_copy_l12l0b_transpose一定改变分形内的排布，可以按需改变分形间的排布，如Nz2Zn。

asc_copy_l12l0a_transpose / asc_copy_l12l0b_transpose在B32场景下，源操作数2个连续的16\*8分形将被合并为1个16\*16的方块矩阵，然后再基于该方块矩阵做转置，因此要求两个连续分形合并为方块矩阵，要求L1 Buffer上的矩阵满足Nz排布（当且仅当Row==16）或Zn排布（当且仅当Col==16）。

asc_copy_l12l0a / asc_copy_l12l0b主要用于对NC1HWC0格式的feature map完成image to column操作，并将展开后的二维矩阵搬入对应内存位置，因此对于asc_copy_l12l0a / asc_copy_l12l0b的源操作数中数据必须按照NC1HWC0格式排布，目的操作数数据必须按照目的地址L0A Buffer/L0B Buffer中支持的排布方式排布。

<!-- npu="A3,910b" id1 -->
asc_copy_l12l0b_sparse主要用于搬运以512Byte为单位存放的稠密权重矩阵到L0B Buffer里，同时搬运以128Byte为单位的索引矩阵到内置的专用buffer空间（用于后续asc_mmad_sparse接口进行读取），因此源操作稠密权重矩阵和索引矩阵都需要按照Zn格式排布，其中稠密权重矩阵排布方式为32\*16\*8bit=512Byte，索引矩阵排布方式为32\*16\*2bit=128Byte。
