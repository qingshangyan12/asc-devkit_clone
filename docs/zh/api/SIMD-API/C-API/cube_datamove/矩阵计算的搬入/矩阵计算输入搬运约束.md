# 矩阵计算输入搬运约束

## 地址和数据通路

- 源、目的地址必须满足对应单接口文档的地址空间和对齐要求。
- 部分产品不支持GM直接搬运到L0A Buffer或L0B Buffer，需要通过L1 Buffer中转。
- 512字节分形是部分矩阵搬运接口的数据单位，不是所有矩阵搬运C API的统一长度单位。

## 数据排布

- [asc_copy_gm2l1](../asc_copy_gm2l1/asc_copy_gm2l1.md)在普通搬运场景下保持数据内容和排布；格式转换应使用专用重载或专用接口。
- ND->NZ场景使用[asc_copy_gm2l1_nd2nz](../asc_copy_gm2l1_nd2nz/asc_copy_gm2l1_nd2nz.md)。
- DN->NZ场景使用[asc_copy_gm2l1_dn2nz](../asc_copy_gm2l1_dn2nz.md)。
- L1 Buffer->L0A Buffer或L0B Buffer的普通、3D、转置及MX场景应分别选择对应公开接口及重载。
- 结构化稀疏权重和索引的排布必须满足[asc_copy_l12l0b_sparse](../asc_copy_l12l0b_sparse.md)要求，搬入结果供[asc_mmad_sparse](../../cube_compute/asc_mmad_sparse.md)使用。

## 3D搬运配置

3D搬运可使用以下辅助接口配置Feature Map、尺寸、Padding和Repeat信息：

- [asc_set_l13d_fmatrix](../asc_set_l13d_fmatrix.md)
- [asc_set_l13d_fmatrix_b](../asc_set_l13d_fmatrix_b.md)
- [asc_set_l13d_size](../asc_set_l13d_size.md)
- [asc_set_l13d_padding](../asc_set_l13d_padding.md)
- [asc_set_l13d_rpt](../asc_set_l13d_rpt.md)

## 架构差异

2201与3510架构的搬运接口在参数列表、转置能力、支持数据类型和分形排布上存在差异。不得将一个架构文档中的参数顺序直接用于另一架构；应从接口汇总页进入对应架构文档核对。
