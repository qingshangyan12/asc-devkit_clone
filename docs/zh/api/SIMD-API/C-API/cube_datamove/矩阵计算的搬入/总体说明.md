# 矩阵计算搬入总体说明

矩阵计算搬入将左右矩阵、Bias和随路处理参数搬运到Cube计算所需的片上存储。C API通过不同公开符号区分数据通路和格式转换能力。

| 数据通路或场景 | 接口 |
| --- | --- |
| GM->L1 Buffer | [asc_copy_gm2l1](../asc_copy_gm2l1/asc_copy_gm2l1.md) |
| GM（ND）->L1 Buffer（NZ） | [asc_copy_gm2l1_nd2nz](../asc_copy_gm2l1_nd2nz/asc_copy_gm2l1_nd2nz.md) |
| GM（DN）->L1 Buffer（NZ） | [asc_copy_gm2l1_dn2nz](../asc_copy_gm2l1_dn2nz.md) |
| GM非对齐搬入L1 Buffer | [asc_copy_gm2l1_align](../asc_copy_gm2l1_align.md) |
| GM->L0A Buffer/L0B Buffer | [asc_copy_gm2l0a](../asc_copy_gm2l0a.md)、[asc_copy_gm2l0b](../asc_copy_gm2l0b.md) |
| L1 Buffer->L0A Buffer/L0B Buffer | [asc_copy_l12l0a](../asc_copy_l12l0a/asc_copy_l12l0a.md)、[asc_copy_l12l0b](../asc_copy_l12l0b/asc_copy_l12l0b.md) |
| 转置搬入 | [asc_copy_l12l0a_trans](../asc_copy_l12l0a_trans.md)、[asc_copy_l12l0b_trans](../asc_copy_l12l0b_trans/asc_copy_l12l0b_trans.md) |
| MX矩阵及量化系数搬入 | [asc_copy_l12l0a_mx](../asc_copy_l12l0a_mx.md)、[asc_copy_l12l0b_mx](../asc_copy_l12l0b_mx.md) |
| 结构化稀疏权重搬入 | [asc_copy_l12l0b_sparse](../asc_copy_l12l0b_sparse.md) |
| Bias搬入 | [asc_copy_l12bt](../asc_copy_l12bt/asc_copy_l12bt.md) |
| Fixpipe参数搬入 | [asc_copy_l12fb](../asc_copy_l12fb/asc_copy_l12fb.md) |

表中的接口名均为公开C API符号。带有`_arch_2201`或`_arch_3510`后缀的名称仅是文档文件名，不是可调用符号。

不同架构上的可用数据通路、完整重载和数据类型不同。调用前应进入对应单接口文档核对函数原型，并结合[矩阵计算输入搬运约束](矩阵计算输入搬运约束.md)选择数据排布。
