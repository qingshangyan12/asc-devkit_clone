## 功能说明

获取一个uint64_t类型数字的二进制表示中从最低有效位开始的第一个0出现的位置，如果没找到则返回-1。

## 函数原型

```c
__aicore__ inline int64_t asc_ffz(uint64_t value)
```

## 参数说明

**表1** 参数说明

|参数名|输入/输出|描述|
| :------ | :--- | :------------ |
|value   |输入   |输入数据，数据类型是uint64_t。|

## 返回值说明

value中第一个0出现的位置。

## 流水类型

PIPE_S

## 约束说明

- 本接口为标量单目位运算，操作数的dtype固定为`uint64_t`，其他dtype触发数据类型异常。
- 返回值取值范围为[0, 63]或−1（未找到时），调用方接收返回值后按`int64_t`解释即可，结果可能为负值（−1），不应假设非负。
- 本接口为纯位查找运算，不访问UB/GM/L1等存储单元，不涉及地址对齐与容量约束，也不产生浮点状态或异常上报。
- 本接口运行在标量流水上，与后续依赖该返回值的指令之间存在标量数据依赖，由标量流水本身的顺序执行保证，无需额外插入同步指令。

## 调用示例

```cpp
uint64_t value = 33;
// 输出数据count_first_zero为1
int64_t count_first_zero = asc_ffz(value);
```
