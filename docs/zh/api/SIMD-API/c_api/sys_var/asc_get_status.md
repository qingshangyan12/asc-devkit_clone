## 功能说明

获取状态信息。

## 函数原型

```cpp
__aicore__ inline int64_t asc_get_status()
```

## 参数说明

无

## 返回值说明

状态信息。各bit含义如下：
**表1** 状态寄存器比特位说明

| bit范围    | 含义 |
| ----------- |:----|
| 5 | 浮点运算溢出。SIMD指令int16_t和int32_t算术运算溢出也会上报到该位。 |
| 6 | 浮点运算下溢（结果浮点数小于非规格化数能表示的最小值，则结果为0）。 |
| 7 | 将任意浮点数转换为无符号整数时，输入为负数。 |
| 8 | 从L0C到UB的数据搬运过程中发生溢出（float->half、int32_t->half）。 |
| 9 | 从L0C到UB的数据搬运过程中发生下溢（float->half）。 |
| 10 | CUBE累加运算溢出（可能是float、half、int32_t）。 |
| 11 | CUBE累加运算下溢（可能是float、half）。 |
| 13 | 标量指令输入为NaN/INF。 |
| 14 | 向量指令输入为NaN/INF。 |
| 15 | CUBE指令输入为NaN/INF。 |
| 61 | 数据搬运类指令输入为NaN/INF |
| 其它bit位 | 保留位。 |

## 流水类型

PIPE_S

## 约束说明

### 通用约束

- 本接口为只读查询接口，仅读取状态寄存器当前值，可在AIC与AIV上下文中调用。
- 状态寄存器访问属性为读清除（RC）：本接口读取动作会清除状态寄存器的当前值，读取返回的是清除前的快照。调用方如需保留状态信息应在读取后自行存储，再次调用本接口在下次告警置位前将返回0。
- 状态寄存器在以下情形被清除：SC kickstart一个kernel、硬件/软件复位、本接口读取、SC经debug通道读取。kernel启动时STATUS被复位为0，运行期间随告警事件置位、随本接口读取清除。
- 返回值落在64bit范围内，按`int64_t`返回时高1位为符号位，调用方若需按无符号64bit整数解析应自行做位运算处理。
- 状态寄存器位域承载多类告警语义（Icache奇偶校验/多命中错误、各存储缓冲ECC单比特错误、整型/浮点溢出与下溢、NEG指令最小负数标志、浮点转无符号整型负数标志、float→half/int32_t→half转换溢出与下溢、CUBE累加溢出与下溢、AIPP/WAIPP FP16计算溢出或下溢、SCALAR/VECTOR/CUBE/MTE指令NaN/INF输入、最近一次告警PC片段、各类错误计数器等），调用方应按状态寄存器位域定义逐bit解析返回值，不可将整体值作为单一数值使用；其中STATUS[31:24]为保留位，读取时该段值不携带有效信息。
- 本接口读取的是核级STATUS状态寄存器，与其他特殊寄存器（控制、参数基址、系统时钟等）语义不同，不可混用。
- 本接口不支持纯SIMT编译模式，在该模式下包含`sys_var.h`头文件会触发编译错误。

## 调用示例

```cpp
int64_t status = asc_get_status();
printf("status is %x", status);// 需用%x将其打印成十六进制的数
```
