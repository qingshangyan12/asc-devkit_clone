## 功能说明

设置GM->L1 Buffer Nz格式搬运的目的侧分形步长参数。本接口将Nz格式搬运所需的ND维搬运块数、N维相邻元素目的步长、D维分块间目的步长、ND维块间目的步长等参数拼装到64 bit配置值后整体写入Nz格式搬运配置寄存器，供后续GM->L1 Buffer的Nz格式搬运指令读取。调用方须按各字段的位域定义自行拼装64 bit配置值后传入；写入后对后续所有GM->L1 Buffer Nz格式搬运指令立即生效，直至再次调用本接口覆盖配置。Nz格式搬运场景下，配置loop搬运次数与源/目步长需通过[asc_set_gm2l1_loop1_stride](asc_set_gm2l1_loop1_stride.md)、[asc_set_gm2l1_loop2_stride](asc_set_gm2l1_loop2_stride.md)、[asc_set_gm2l1_loop_size](asc_set_gm2l1_loop_size.md)预先配置；填充场景下，填充值需通过[asc_set_gm2l1_pad](asc_set_gm2l1_pad.md)预先配置。

本接口仅在AIC上执行有效，在AIV上调用为空操作。

## 函数原型

```cpp
__aicore__ inline void asc_set_gm2l1_nz_para(uint64_t config)
```

## 参数说明

**表1** 参数说明

| 参数名 | 输入/输出 | 描述 |
|---|---|---|
| `config` | 输入 | 待写入Nz格式搬运配置寄存器的64 bit配置值，调用方须按各字段的位域定义自行拼装后整体传入。取值范围 [0, 2^64−1]。参数位宽（64 bit）与寄存器位宽（64 bit）一致，整个值原样写入寄存器，无整体截断风险；但config内各字段位宽小于64 bit，用户拼装时需确保各字段值落在对应位宽范围内，超出部分会被截断（详见约束说明）。各字段位宽、含义与拼装位置见下表。 |

**表2** config字段拼装说明

| 字段名 | 含义 | 位宽 | 取值范围 |
|---|---|---|---|
| ND维搬运块数 | Nz格式搬运最外层（ND维）的迭代次数。占用config的第0~3位（低4位）。不可为0，否则后续搬运指令触发异常并退化为空操作。 | 4 bit | [0, 15] |
| N维相邻元素目的步长 | Nz格式搬运中N维相邻元素在L1 Buffer目的侧的步长，以分形字节大小为单位。占用config的第16~20位。 | 5 bit | [0, 31] |
| D维分块间目的步长 | Nz格式搬运中D维（通道方向）相邻分块在L1 Buffer目的侧的步长，以分形字节大小为单位。占用config的第32~36位。 | 5 bit | [0, 31] |
| ND维块间目的步长 | Nz格式搬运中ND维（最外层）相邻块在L1 Buffer目的侧的步长，以分形字节大小为单位。占用config的第48~52位。 | 5 bit | [0, 31] |

未列出的位（第4~15位、第21~31位、第37~47位、第53~63位）为保留位，写入时填0，避免影响后续扩展或导致非预期行为。

## 返回值说明

无

## 流水类型

PIPE_S

## 约束说明

### 通用约束

- 本接口仅在AIC上生效，非AIC调用直接返回。
- 本接口直接整体写入64bit Nz格式搬运配置寄存器，会覆盖寄存器全部位；调用方须按各字段的位域定义自行拼装完整64bit配置值后传入，避免误覆盖其他字段导致后续搬运指令按错误参数展开。
- 本接口写入的配置值对后续所有GM→L1 Buffer Nz格式搬运指令立即生效，直至再次调用本接口覆盖配置；不同任务间若需不同NZ参数，应在相关搬运指令发出前重新调用本接口设置。
- 若仅需修改个别字段，应整体重新拼装64bit配置值后调用本接口整体写回，避免直接写入导致其余字段被覆盖为传入值的对应位（包括保留位）。
- `config`参数位宽（64bit）与寄存器位宽（64bit）一致，整个值原样写入寄存器，无整体截断风险；但config内各字段位宽小于64bit，用户拼装时若某字段值超出对应位宽范围，超出部分会被截断（见各字段专属约束）。
- Nz格式搬运配置寄存器为WO类型，本接口仅写不读，调用方无法通过本接口确认写入是否生效。
- 须先调用本接口写配置，再调用配套搬运接口发起Nz格式搬运；未预先设置NZ参数直接调用搬运接口，搬运按复位值（全0）展开，ND维搬运块数为0会触发异常并退化为空操作。
- ND维搬运块数取值范围为[1, 15]，超出取值范围的值会被截断，导致后续搬运结果不符合预期。
- N维相邻元素目的步长取值范围为[0, 31]，超出取值范围的值会被截断，导致后续搬运结果不符合预期。
- D维分块间目的步长取值范围为[0, 31]，超出取值范围的值会被截断，导致后续搬运结果不符合预期。
- ND维块间目的步长取值范围为[0, 31]，超出取值范围的值会被截断，导致后续搬运结果不符合预期。

## 调用示例
```cpp
uint64_t nz_dst_stride = 16;
uint64_t config = nz_dst_stride << 48; //[63:48]
uint64_t c0_stride = 32;
config |= c0_stride << 32; //[47:32]
uint64_t n_dst_stride = 32;
config |= n_dst_stride << 16; //[31:16]
uint64_t nd_num = 64;
config |= nd_num; //[15:0]

asc_set_gm2l1_nz_para(config);
```
