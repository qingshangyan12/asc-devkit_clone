## 功能说明

对MTE2_NZ_PARA寄存器中的值进行设置，可以在调用[asc_copy_gm2l1_dn2nz](../cube_data_move/asc_copy_gm2l1_dn2nz.md)和[asc_copy_gm2l1_nd2nz](../cube_data_move/asc_copy_gm2l1_nd2nz/asc_copy_gm2l1_nd2nz_arch_3510.md)前设置相关参数。

MTE2_NZ_PARA是一个64bit的寄存器，其中各bit含义如下：

**表1** MTE2_NZ_PARA寄存器比特位说明

| bit范围 |        含义         |
|:------|:-----------------:|
| 15:0  |  需要搬运的ND/DN矩阵数量。  |
| 31:16 | N维度上相邻两个block块之间的间隔。 |
| 47:32 | 同一个NZ矩阵中2个C0列之间的间隔。 |
| 63:48 | 两个ND/DN矩阵中两个NZ矩阵之间的间隔。 |

## 函数原型

```cpp
__aicore__ inline void asc_set_gm2l1_nz_para(uint64_t config)
```

## 参数说明

**表2** 参数说明

|参数名|输入/输出| 描述        |
| :------ | :---  |:----------|
| config | 输入 | 待设置的寄存器值。 |

## 约束说明

### 通用约束

- 本接口仅在AIC上生效，非AIC调用直接返回。
- 本接口直接整体写入64bit NZ格式搬运配置寄存器，会覆盖寄存器全部位；调用方须按各字段的位域定义自行拼装完整64bit配置值后传入，避免误覆盖其他字段导致后续搬运指令按错误参数展开。
- 本接口写入的配置值对后续所有GM→L1 Buffer NZ格式搬运指令立即生效，直至再次调用本接口覆盖配置；不同任务间若需不同NZ参数，应在相关搬运指令发出前重新调用本接口设置。
- 若仅需修改个别字段，应整体重新拼装64bit配置值后调用本接口整体写回，避免直接写入导致其余字段被覆盖为传入值的对应位（包括保留位）。
- `config`参数位宽（64bit）与寄存器位宽（64bit）一致，整个值原样写入寄存器，无整体截断风险；但config内各字段位宽小于64bit，用户拼装时若某字段值超出对应位宽范围，超出部分会被截断（见各字段专属约束）。
- NZ格式搬运配置寄存器为WO类型，本接口仅写不读，调用方无法通过本接口确认写入是否生效。
- 须先调用本接口写配置，再调用配套搬运接口发起NZ格式搬运；未预先设置NZ参数直接调用搬运接口，搬运按复位值（全0）展开，ND维搬运块数为0会触发异常并退化为空操作。
- ND维搬运块数占用config的第0~3位（4bit），传入>15的值会被截断为低4位（如16→0、17→1），硬件不报错。截断后实际生效的ND维搬运块数偏小，导致后续搬运指令实际搬运的ND维块数小于预期，部分数据未被搬运；截断后若值为0会同时触发后续搬运指令的异常并退化为空操作。
- N维相邻元素目的步长占用config的第16~20位（5bit），传入>31的值会被截断为低5位（如32→0、33→1），硬件不报错。截断后实际生效值偏小，导致后续搬运指令中N维相邻元素的目的侧步长偏小，后一元素写到错误位置，与前一元素数据重叠或错位。
- D维分块间目的步长占用config的第32~36位（5bit），传入>31的值会被截断为低5位（如32→0、33→1），硬件不报错。截断后实际生效值偏小，导致后续搬运指令中D维相邻分块的目的侧步长偏小，后一分块写到错误位置，与前一分块数据重叠或错位。
- ND维块间目的步长占用config的第48~52位（5bit），传入>31的值会被截断为低5位（如32→0、33→1），硬件不报错。截断后实际生效值偏小，导致后续搬运指令中ND维相邻块的目的侧步长偏小，后一块写到错误位置，与前一数据块重叠或错位。

## 调用示例
```cpp
uint64_t nz_dst_stride = 16;
uint64_t config = nz_dst_stride << 48; //[63:48]
uint64_t c0_stride = 32;
config |= c0_stride << 32; //[47:32]
uint64_t n_dst_stride = 32;
config |= n_dst_stride << 16; //[31:16]
uint64_t nd_num = 64;
config |= nd_num; //[15:0]

asc_set_gm2l1_nz_para(config);
```
