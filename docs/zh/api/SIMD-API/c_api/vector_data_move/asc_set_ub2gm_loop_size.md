## 功能说明

头文件路径为：`"c_api/vector_datamove/vector_datamove.h"`。

设置UB->GM对齐搬运接口在循环搬运模式下的两层循环迭代次数。配置写入后供后续调用的UB->GM对齐搬运接口在循环搬运模式下取用：循环搬运模式按两层嵌套（loop1在内、loop2在外）展开搬运，每层迭代的次数分别由本接口设置的`loop1_size`、`loop2_size`决定；搬运时按两层循环迭代次数对源端数据块进行切分并按步长偏移写入目的端。本接口将两个循环次数参数按位拼装为一个64位配置值后写入硬件配置寄存器，`loop1_size`、`loop2_size`分别占据配置值的相应位段。

本接口仅在AIV上执行有效，在AIC上调用为空操作。

循环搬运模式下，本接口需与`asc_set_ub2gm_loop1_stride`、`asc_set_ub2gm_loop2_stride`配合使用，预先配置两层循环的迭代次数与搬运步长。

## 函数原型

```c
__aicore__ inline void asc_set_ub2gm_loop_size(uint32_t loop1_size,
                                               uint32_t loop2_size)
```

## 参数说明

**表 1**  参数说明

| 参数名 | 输入/输出 | 描述 |
|---|---|---|
| `loop1_size` | 输入 | 循环搬运模式下内层循环（loop1）的迭代次数，即loop1维度上要搬运的数据块组数。取值范围为[1，2^21−1]，不可为0。参数类型为`uint32_t`（0~2^32−1），传入>2^21−1的值会按位宽截断处理（如2^21→0、2^21+1→1），硬件不报错。截断后实际生效值偏小，导致内层循环实际迭代次数小于预期，循环提前结束，部分数据未被搬运。 |
| `loop2_size` | 输入 | 循环搬运模式下外层循环（loop2）的迭代次数，即loop2维度上要搬运的数据块组数。取值范围为[1，2^22−1]，不可为0。参数类型为`uint32_t`（0~2^32−1），传入>2^22−1的值会按位宽截断处理（如2^22→0、2^22+1→1），硬件不报错。截断后实际生效值偏小，导致外层循环实际迭代次数小于预期，循环提前结束，部分数据未被搬运。 |

无

## 约束说明

### 通用约束

- **本接口仅在AIV上生效，非AIV调用直接返回。**
- 本接口仅写入循环搬运模式的循环次数配置，实际搬运由后续调用的UB->GM对齐搬运接口在循环搬运模式下取用该配置完成，须先调用本接口写入配置，再调用对应搬运接口。
- 本接口与配套setter接口协同配置循环搬运模式的完整参数集（循环次数及两层循环步长），调用搬运接口前须完成全部相关配套setter的配置（配套setter名见功能说明章节）。
- 配置写入后对后续所有UB->GM对齐搬运接口调用生效，直至再次调用本接口覆盖配置；不同搬运任务间若需不同循环次数，应在调用搬运接口前重新调用本接口设置。
- 本接口配置仅在搬运接口选择循环搬运模式时被取用；若搬运接口未启用循环搬运模式（即两层循环均按默认值1×1单次迭代），本接口设置的循环次数不被取用，搬运按单次执行。

### loop1_size字段截断约束

- `loop1_size`，参数类型为`uint32_t`可表示0~2^32−1，传入>2^21−1的值会按位宽截断处理（如2^21→0、2^21+1→1），硬件不报错。截断后实际生效值偏小，导致内层循环实际迭代次数小于预期，循环提前结束，部分数据未被搬运。截断后若值为0会触发循环搬运接口将该层循环置为不操作（不搬运数据）。

### loop2_size字段截断约束

- `loop2_size`，参数类型为`uint32_t`可表示0~2^32−1，传入>2^22−1的值会按位宽截断处理（如2^22→0、2^22+1→1），硬件不报错。截断后实际生效值偏小，导致外层循环实际迭代次数小于预期，循环提前结束，部分数据未被搬运。截断后若值为0会触发循环搬运接口将该层循环置为不操作（不搬运数据）。

### 循环次数取值约束

- `loop1_size`不可为0，否则后续调用的循环搬运接口将该层循环置为不操作（不搬运数据，硬件不报错）。
- `loop2_size`不可为0，否则后续调用的循环搬运接口将该层循环置为不操作（不搬运数据，硬件不报错）。
- 完成当前循环搬运任务后，需再次调用本接口将`loop1_size`和`loop2_size`均设置为1，复位循环配置，否则可能影响下一次搬运。

## 调用示例

```cpp
uint32_t loop1_size = 2;
uint32_t loop2_size = 2;
uint64_t loop1_src_stride = 96;
uint64_t loop1_dst_stride = 128;
uint64_t loop2_src_stride = 192;
uint64_t loop2_dst_stride = 288;
asc_set_ub2gm_loop_size(loop1_size, loop2_size);
asc_set_ub2gm_loop1_stride(loop1_src_stride, loop1_dst_stride);
asc_set_ub2gm_loop2_stride(loop2_src_stride, loop2_dst_stride);
asc_copy_ub2gm_align(dst, src, 2, 48 * sizeof(int8_t), asc_store_l2_cache_mode::NORMAL_FIRST_VICTIM, 48, 48);
asc_set_ub2gm_loop_size(1, 1);
```
