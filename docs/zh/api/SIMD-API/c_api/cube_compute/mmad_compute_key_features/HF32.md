# HF32<a name="ZH-CN_TOPIC_0000002538231188"></a>

**特性说明：**

HF32的核心功能体现为：用户在输入矩阵A、B矩阵都为fp32数据类型的场景下，当配置开启HF32开关后，fp32数据在执行矩阵乘法运算前会被转换并舍入为HF32（half-fp32）格式。这会降低中间数值精度，并可能提升矩阵计算吞吐；实际收益依赖架构、形状和数据准备开销。需要注意的是，尽管中间计算使用HF32格式，最终的运算结果仍以fp32格式输出，以保证后续处理的兼容性。

舍入模式说明：fp32至HF32转换过程中的舍入模式由[asc_set_hf32_round_mode](../asc_set_hf32_round_mode.md)接口配置。当HF32模式开启且设置asc_hf32_round_mode为NEAREST_AWAY时，FP32将以向最接近的值舍入，平局时远离零的方式舍入为HF32；若设置asc_hf32_round_mode为NEAREST_EVEN时，FP32将以向最接近的值舍入，平局时向偶数舍入的方式舍入为HF32。

**使用示例：**

```cpp
// a、b为已就绪的float矩阵；c为__cc__ float*。
asc_enable_hf32();
asc_set_hf32_round_mode(asc_hf32_round_mode::NEAREST_AWAY);
asc_mmad(c, a, b, m, k, n, asc_unit_flag_mode::DISABLE,
         false /* 2201:k_direction_align；3510:disable_gemv */, false, true);
// 确认本轮矩阵计算结束，再切换后续任务的模式。
asc_sync_pipe(PIPE_M);
#if __NPU_ARCH__ == 3510
asc_disable_hf32();
#elif __NPU_ARCH__ == 2201
asc_set_fp32_mode();
#endif
asc_set_hf32_round_mode(asc_hf32_round_mode::NEAREST_EVEN);
```

上例显式恢复FP32和NEAREST_EVEN，若调用方原先使用其他舍入配置，应在后续任务前恢复对应配置。舍入设置会持续生效，关闭再开启HF32不会自动替你重新设定。
