# 基础知识<a name="ZH-CN_TOPIC_0000002532388147"></a>

本节内容为使用[Reg矢量计算API](https://gitcode.com/cann/asc-devkit/blob/master/docs/api/SIMD-API/基础API/Reg矢量计算/Reg矢量计算.md)和[SIMT API](https://gitcode.com/cann/asc-devkit/blob/master/docs/api/SIMT-API/SIMT-API.md)进行SIMD与SIMT混合编程的指导。

在[Vector Core](../../编程指南/高级编程/硬件实现/基本架构.md)中，SIMT单元和SIMD单元共享片上存储，因此可以利用片上存储Unified Buffer完成SIMD与SIMT混合编程，具体硬件架构的介绍请参考[NPU架构版本3510](../../编程指南/高级编程/硬件实现/架构规格/NPU架构版本3510.md)。在进行后续内容的学习前，请先了解SIMD与SIMT混合编程的编程模型：[SIMD与SIMT混合编程](../../编程指南/高级编程/高级AI-Core编程模型/SIMD与SIMT混合编程.md)。

[SIMD编程](../../编程指南/编程模型/AI-Core-SIMD编程/基于Tensor的CPP编程/Reg矢量计算编程.md)适合处理连续、规整的数据计算，[SIMT编程](../../编程指南/语言扩展层/SIMT-BuiltIn关键字.md)适合处理离散访问、索引映射和分支判断等逻辑。两种编程方式可以通过片上存储完成数据衔接，在同一个算子中配合使用。

后续章节将以具体算子为例，介绍如何根据计算逻辑组合使用SIMD和SIMT完成算子实现。
