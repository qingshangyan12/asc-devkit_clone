# 整数除法的快速算法

>[!NOTE]说明
>该性能优化建议适用于如下型号：
>-   Ascend 950PR/Ascend 950DT

【优先级】低

【描述】整数除法在 NPU 上是高延迟指令，相比乘法和移位操作执行开销显著更高。当除数固定时，可以预先在SIMD中由除数计算出魔数（magic）和移位量（shift），再在 SIMT 并行计算中用乘法和移位操作替代除法，从而显著降低每次除法的执行开销。

【样例介绍】以整数快速除法算子为例，算子功能为将输入 input 中每个 uint32_t 元素除以固定除数 divisor，结果写入 output。由于除数在运行期间保持不变，可以预先计算出对应的魔数和移位量，供 SIMT 并行计算使用。

【反例】

基于SIMT的整数快速除法算子实现：在 SIMT 核函数中对每个元素直接使用 `/` 运算符，每个线程独立触发一次硬件除法指令，执行开销高，代码如下。

```cpp
__simt_vf__ __launch_bounds__(THREAD_COUNT) inline void normal_div_vf(
    __ubuf__ uint32_t* input,
    __gm__ uint32_t* output,
    uint32_t divisor,
    uint32_t total_length)
{
    uint32_t idx = blockIdx.x * blockDim.x + threadIdx.x;
    if (idx >= total_length) return;
    output[idx] = input[idx] / divisor;
}
```

【正例】

基于SIMD与SIMT混合编程的整数快速除法算子实现：在调用 SIMT 前，由 SIMD 部分调用 `clz`、`bcnt1` 等标量计算接口预先计算出魔数 `magic` 和移位量 `shift`，SIMT 核函数中每个线程改用乘法和移位操作完成等价的除法计算，避免触发高延迟的硬件除法指令，代码如下。

魔数和移位量的计算方式如下：

```cpp
__aicore__ inline void calc_magic_shift(
    uint32_t& magic_out,
    uint32_t& shift_out,
    uint32_t divisor)
{
    int64_t pos = BIT_64_LEN - CountLeadingZero(divisor); // CountLeadingZero：调用 clz，计算除数的前导零个数
    int64_t cnt1 = GetBitCount1(divisor);                 // GetBitCount1：调用 bcnt1，计算除数二进制中 1 的个数
    uint32_t shift = (cnt1 == 1) ? (pos - 1) : pos;
    uint32_t magic = (1l << BIT_32_LEN) * ((1l << shift) - divisor) / divisor + 1;
    magic_out = magic;
    shift_out = shift;
}
```

SIMT 中用乘法和移位替代除法：根据除数预先计算出的魔数 `magic` 和移位量 `shift`，用 `__umulhi(value, magic)` 取 `value * magic` 乘积的高 32 位得到中间值 `q`，再对 `value + q` 右移 `shift` 位，得到与 `value / divisor` 等价的结果，从而用乘法和移位替代高延迟的除法指令。

```cpp
__simt_vf__ __launch_bounds__(THREAD_COUNT) inline void fast_div_vf(
    __ubuf__ uint32_t* input,
    __gm__ uint32_t* output,
    uint32_t magic,
    uint32_t shift,
    uint32_t total_length)
{
    uint32_t idx = blockIdx.x * blockDim.x + threadIdx.x;
    if (idx >= total_length) return;
    uint32_t value = input[idx];
    uint32_t q = __umulhi(value, magic);
    output[idx] = (value + q) >> shift;
}
```
