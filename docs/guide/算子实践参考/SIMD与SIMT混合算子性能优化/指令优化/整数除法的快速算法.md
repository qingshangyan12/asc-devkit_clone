# 整数除法的快速算法

>[!NOTE]说明
>该性能优化建议适用于如下型号：
>-   Ascend 950PR/Ascend 950DT

【优先级】低

【描述】整数除法指令在AI处理器上相比乘法和移位，执行开销显著更高。当除数固定时，可以使用基于乘法和移位的快速除法算法，在SIMD中根据除数预计算魔数`magic`和移位量`shift`，作为替代普通除法所需参数；在SIMT并行计算中使用乘法和移位操作，得到与普通整数除法一致的结果，从而降低每次除法的执行开销。

【样例介绍】以整数快速除法算子为例，算子功能为将输入input中每个uint32_t元素除以固定除数divisor，结果写入output。由于除数在运行期间保持不变，可以预先计算出对应的魔数和移位量，供SIMT并行计算使用。

【反例】基于SIMT的整数普通除法算子实现

对每个元素直接使用`/`运算符，每个线程独立触发一次硬件除法指令，执行开销高，代码如下。

```cpp
__simt_vf__ __launch_bounds__(THREAD_COUNT) inline void simt_normal_div(
    __ubuf__ uint32_t* input,
    __gm__ uint32_t* output,
    uint32_t divisor,
    uint32_t total_length)
{
    uint32_t idx = blockIdx.x * blockDim.x + threadIdx.x;
    if (idx >= total_length) return;
    output[idx] = input[idx] / divisor;
}
```

【正例】基于SIMD与SIMT混合编程的整数快速除法算子实现

对于uint32_t类型整数除法，可作如下变形，将除法计算转换为乘法和移位操作：

$$
\left\lfloor \frac{\text{input}}{\text{divisor}} \right\rfloor =
\left\lfloor \frac{\text{input}}{\text{divisor}} \times \frac{2^{\text{shift}}}{2^{\text{shift}}} \right\rfloor =
\left\lfloor \frac{2^{\text{shift}}}{\text{divisor}} \times \frac{\text{input}}{2^{\text{shift}}} \right\rfloor
$$

其中 $\dfrac{2^{\text{shift}}}{\text{divisor}}$ 是将除法运算转换为乘法运算所需的魔数`magic`，`shift`为移位量，二者可根据固定除数预先计算得到。
基于上述除法转换思路，在SIMD编程中预先获取快速除法所需的`magic`和`shift`，计算方式如下：

```cpp
__aicore__ inline void calc_magic_shift(
    uint32_t& magic_out,
    uint32_t& shift_out,
    uint32_t divisor)
{
    int64_t pos = BIT_64_LEN - CountLeadingZero(divisor); // CountLeadingZero：调用clz，计算除数的前导零个数
    int64_t cnt1 = GetBitCount1(divisor);                 // GetBitCount1：调用bcnt1，计算除数二进制中 1 的个数
    uint32_t shift = (cnt1 == 1) ? (pos - 1) : pos;
    uint32_t magic = (1l << BIT_32_LEN) * ((1l << shift) - divisor) / divisor + 1;
    magic_out = magic;
    shift_out = shift;
}
```

在SIMT编程中使用乘法和移位组合运算的方式替代普通除法：SIMD程序中预计算得到的`magic`和`shift`可被SIMT线程复用。对单个线程需要处理的被除数`value`，调用`__umulhi(value, magic)`接口，获取`value`与`magic`乘积的高 32 位结果`q`，再对`value + q`右移`shift`位，得到与`value / divisor`等价的结果，从而用乘法和移位替代高延迟的除法指令。

```cpp
__simt_vf__ __launch_bounds__(THREAD_COUNT) inline void simt_fast_div(
    __ubuf__ uint32_t* input,
    __gm__ uint32_t* output,
    uint32_t magic,
    uint32_t shift,
    uint32_t total_length)
{
    uint32_t idx = blockIdx.x * blockDim.x + threadIdx.x;
    if (idx >= total_length) return;
    uint32_t value = input[idx];
    uint32_t q = __umulhi(value, magic);
    output[idx] = (value + q) >> shift;
}
```

【性能对比】

本优化方法的收益主要体现在除法指令层面：将每次除法替代为乘法和移位操作，可有效降低计算部分的执行开销。

**单次除法操作cycle数对比**

使用NPU硬件时钟周期（clock cycle）统计每个线程执行除法操作的耗时，每个线程通过`clock()`记录除法操作前后的时间差，得到一次除法操作的cycle数。平均clock cycles为所有线程统计除法操作cycle数的平均值，数据量 32768，结果如下：

**表 2**  单次除法操作cycle数对比

| 数据量（N） | 线程块数 | 单核线程数 | 快速除法（cycles） | 普通除法（cycles） |
|:-----------:|:-------:|:---------:|:-----------------:|:-----------------:|
| 32,768      | 64      | 512       | 14.00             | 38.25             |

N=32768 时，快速除法平均clock cycles为 14.00，普通除法为 38.25。

**asc_vf_call整体耗时对比**

通过在核函数内使用`GetSystemCycle()`对`asc_vf_call`前后打点，采集SIMT VF函数的执行时间。以下数据为分别重复运行快速除法和普通除法样例各 10 次后，取第 0 号核测量结果统计得到，数据量 32768。结果如下：

**表 3**  asc_vf_call整体耗时对比

| 除法方式 | 各次结果（cycles） | 均值 |
|:--------:|:-----------------|:----:|
| 快速除法 | 880, 543, 526, 611, 527, 526, 558, 618, 570, 515 | 587.40 |
| 普通除法 | 867, 949, 1020, 941, 601, 1317, 1148, 756, 945, 858 | 940.20 |

快速除法均值（587.40 cycles）约为普通除法均值（940.20 cycles）的 62%，平均节省约 353 cycles。其中，快速除法核函数中执行`calc_magic_shift`预计算magic和shift，该接口耗时约 19 cycles，该开销与输入数据量无关，相比快速除法整体收益，计算开销较小。
