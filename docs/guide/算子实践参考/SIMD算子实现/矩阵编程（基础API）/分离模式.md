# 分离模式<a name="ZH-CN_TOPIC_0000002532228173"></a>

>[!NOTE]说明 
>本节内容为针对分离模式，使用基础API进行矩阵乘法的编程指导。
>如下章节内容暂不支持Ascend 950PR/Ascend 950DT。

针对[分离模式](../../../编程指南/高级编程/硬件实现/基本架构.md#section1574769433)，由于硬件架构差异，在使用基础API进行矩阵乘法算子的实现上存在差异：
- 分离模式中，Cube计算单元与Vector计算单元分离部署，每个核有自己的Scalar单元。在核函数编写时，可通过\_\_cube\_\_的函数类型限定符标识该核函数在设备端aicore上的Cube核执行。
- 分离模式中支持[Fixpipe](https://gitcode.com/cann/asc-devkit/blob/master/docs/api/SIMD-API/基础API/矩阵计算（ISASI）/数据搬运/Fixpipe.md)硬件加速，支持从L0C Buffer直接搬出数据到L1 Buffer/Global Memory的同时，完成量化反量化、数据格式转换等功能。
