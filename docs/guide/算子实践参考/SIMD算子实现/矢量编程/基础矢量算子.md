## 算子分析<a name="zh-cn_topic_0000002201157438_section4870456573"></a>

算子分析具体步骤如下：

1.  明确算子的数学表达式及计算逻辑。

    Add算子的数学表达式为：

    ```
    z = x + y
    ```

    计算逻辑是：Ascend C提供的[矢量计算接口](https://gitcode.com/cann/asc-devkit/blob/master/docs/api/SIMD-API/基础API/Memory矢量计算/基础算术/Add.md)的操作元素都为[LocalTensor](https://gitcode.com/cann/asc-devkit/blob/master/docs/api/SIMD-API/基础API/数据结构/LocalTensor和GlobalTensor定义/LocalTensor/LocalTensor.md)，输入数据需要先从外部存储（Global Memory）搬运进片上存储（Unified Buffer），然后使用计算接口完成两个输入参数相加，得到最终结果，再搬出到外部存储上。Ascend C  Add算子的计算逻辑如下图所示。

    **图2**  算子计算逻辑<a name="zh-cn_topic_0000002201157438_zh-cn_topic_0000001464091780_fig18937134755411"></a>
    ![](../../../figures/算子计算逻辑.png "算子计算逻辑")

2.  明确输入和输出。
    -   Add算子有两个输入：x与y；输出为z。
    -   本样例中算子的输入支持的数据类型为float（float32），算子输出的数据类型与输入的数据类型相同。
    -   算子输入支持的shape为（8，2048），输出shape与输入shape相同。
    -   算子输入支持的[format](../../../技术附录/概念原理和术语/神经网络和算子/数据排布格式.md)为：ND。

3.  确定核函数名称和参数。
    -   您可以自定义核函数名称，本样例中核函数命名为vector\_add\_custom。
    -   根据对算子输入输出的分析，确定核函数有4个参数x，y，z，totalLength；x，y为输入在Global Memory上的内存地址，z为输出在Global Memory上的内存地址，totalLength为输入数据的总长度。

4.  确定算子实现所需接口。
    -   实现涉及外部存储和内部存储间的数据搬运，查看Ascend C  API参考中的数据搬运接口，需要使用[DataCopy](https://gitcode.com/cann/asc-devkit/blob/master/docs/api/SIMD-API/基础API/数据搬运导览/概览/数据搬运概念.md)来实现数据搬运。
    -   本样例只涉及矢量计算的加法操作，查看Ascend C  API参考中的[矢量计算](https://gitcode.com/cann/asc-devkit/blob/master/docs/api/SIMD-API/基础API/Memory矢量计算/Memory矢量计算.md)接口，初步分析可使用基础算术Add接口[Add](https://gitcode.com/cann/asc-devkit/blob/master/docs/api/SIMD-API/基础API/Memory矢量计算/基础算术/Add.md)实现x+y。
    -   使用[Queue队列](https://gitcode.com/cann/asc-devkit/blob/master/docs/api/SIMD-API/基础API/资源管理/Pipe和Que框架/TQue/TQue简介.md)管理计算中使用的Tensor数据结构，具体使用[EnQue](https://gitcode.com/cann/asc-devkit/blob/master/docs/api/SIMD-API/基础API/资源管理/Pipe和Que框架/TQue/EnQue.md)、[DeQue](https://gitcode.com/cann/asc-devkit/blob/master/docs/api/SIMD-API/基础API/资源管理/Pipe和Que框架/TQue/DeQue.md)等接口。

## 核函数定义<a name="zh-cn_topic_0000002201157438_section58723515714"></a>

根据[核函数](../../../编程指南/编程模型/AI-Core-SIMD编程/核函数.md)中介绍的规则进行核函数的定义。

1.  函数原型定义

    本样例中，函数名为vector\_add\_custom（核函数名称可自定义），根据[算子分析](#zh-cn_topic_0000002201157438_section4870456573)中对算子输入输出的分析，确定有3个参数x，y，z，其中x，y为输入内存，z为输出内存。根据[核函数](../../../编程指南/编程模型/AI-Core-SIMD编程/核函数.md#zh-cn_topic_0000001447989210_section1915102519220)的规则介绍，函数原型定义如下所示：使用\_\_global\_\_函数类型限定符标识它是一个核函数，可以被<<<\>\>\>调用；使用\_\_vector\_\_函数类型限定符标识该核函数在设备端aicore的Vector Core上执行。

    ```
    __global__ __vector__ void vector_add_custom(__gm__ uint8_t* x, __gm__ uint8_t* y, __gm__ uint8_t* z, uint32_t totalLength)
    {
    }
    ```

2.  根据[核函数定义和调用](../../../编程指南/编程模型/AI-Core-SIMD编程/核函数.md#zh-cn_topic_0000001447989210_section1915102519220)章节，调用核函数时，除了需要传入参数x，y，z，还需要传入numBlocks（核函数执行的核数）、动态UB大小（无动态UB需求时设置为0）、stream（应用程序中维护异步操作执行顺序的stream）来规定核函数的执行配置。

    ```
    vector_add_custom<<<numBlocks, 0, stream>>>(xDevice, yDevice, zDevice, totalLength);
    ```

## 算子实现<a name="zh-cn_topic_0000002201157438_section10423482111"></a>

根据矢量编程范式对Add算子的实现流程进行设计的思路如下，矢量编程范式请参考[矢量编程范式](../../../编程指南/编程模型/AI-Core-SIMD编程/基于TPipe-TQue框架编程/TPipe-TQue框架编程范式.md#section116515238815)，设计完成后得到的Add算子实现流程图参见[图3 Add算子实现流程](#zh-cn_topic_0000002201157438_fig4134406304)：

-   Add算子的实现流程分为3个基本任务：CopyIn，Compute，CopyOut。CopyIn任务负责将Global Memory上的输入Tensor xGm和yGm搬运至Local Memory，分别存储在xLocal，yLocal，Compute任务负责对xLocal，yLocal执行加法操作，计算结果存储在zLocal中，CopyOut任务负责将输出数据从zLocal搬运至Global Memory上的输出Tensor zGm中。
-   CopyIn，Compute任务间通过VECIN队列inQueueX，inQueueY进行同步，Compute，CopyOut任务间通过VECOUT队列outQueueZ进行同步。
-   任务间交互使用到的内存、临时变量的内存统一使用[Pipe内存管理对象](https://gitcode.com/cann/asc-devkit/blob/master/docs/api/SIMD-API/基础API/资源管理/Pipe和Que框架/TPipe/TPipe.md)进行管理。

**图3**  Add算子实现流程<a name="zh-cn_topic_0000002201157438_fig4134406304"></a>
![](../../../figures/Add算子实现流程.png "Add算子实现流程")

核函数中主要实现上述流程，对上图中的三个基本任务进行调用；同时定义算子实现中会用到的变量，比如上图中的GlobalTensor（xGm、yGm、zGm）和VECIN、VECOUT队列等。完整的核函数如下：

```
__global__ __vector__ void vector_add_custom(__gm__ uint8_t* x, __gm__ uint8_t* y, __gm__ uint8_t* z, uint32_t totalLength)
{
    // Init阶段
    AscendC::TPipe pipe;
    AscendC::TQue<AscendC::TPosition::VECIN, 1> inQueueX;
    AscendC::TQue<AscendC::TPosition::VECIN, 1> inQueueY;
    AscendC::TQue<AscendC::TPosition::VECOUT, 1> outQueueZ;
    AscendC::GlobalTensor<float> xGm;
    AscendC::GlobalTensor<float> yGm;
    AscendC::GlobalTensor<float> zGm;

    // totalLength 表示全局输入长度；GetBlockNum() 返回本次启动的核数，
    // 这里按核数均分每个 block 的处理区间。
    uint32_t blockLength = totalLength / AscendC::GetBlockNum();
    // 根据 block_idx 计算当前核在 GM 中的起始地址，确保各核访问互不重叠的数据分片。
    xGm.SetGlobalBuffer((__gm__ float*)x + blockLength * AscendC::GetBlockIdx(), blockLength);
    yGm.SetGlobalBuffer((__gm__ float*)y + blockLength * AscendC::GetBlockIdx(), blockLength);
    zGm.SetGlobalBuffer((__gm__ float*)z + blockLength * AscendC::GetBlockIdx(), blockLength);
    // 为输入和输出队列申请与 blockLength 对应的 UB 缓冲，保持 TPipe/TQue 的编程范式。
    pipe.InitBuffer(inQueueX, 1, blockLength * sizeof(float));
    pipe.InitBuffer(inQueueY, 1, blockLength * sizeof(float));
    pipe.InitBuffer(outQueueZ, 1, blockLength * sizeof(float));

    // CopyIn阶段
    // 使用 DataCopy 将输入从 GM 搬运到 UB，并通过 EnQue 将 LocalTensor 入队，供后续计算阶段 DeQue 取用。
    AscendC::LocalTensor<float> xLocal = inQueueX.AllocTensor<float>();
    AscendC::LocalTensor<float> yLocal = inQueueY.AllocTensor<float>();
    AscendC::DataCopy(xLocal, xGm, blockLength);
    AscendC::DataCopy(yLocal, yGm, blockLength);
    inQueueX.EnQue(xLocal);
    inQueueY.EnQue(yLocal);

    // Compute阶段
    // DeQue 取出输入张量，在 UB 内执行 Add，并将结果 EnQue 到输出队列，供后续写回 GM。
    xLocal = inQueueX.DeQue<float>();
    yLocal = inQueueY.DeQue<float>();
    AscendC::LocalTensor<float> zLocal = outQueueZ.AllocTensor<float>();
    AscendC::Add(zLocal, xLocal, yLocal, blockLength);
    outQueueZ.EnQue<float>(zLocal);
    inQueueX.FreeTensor(xLocal);
    inQueueY.FreeTensor(yLocal);

    // CopyOut阶段
    // 从输出队列取出结果，并写回当前核负责的 GM 分片。
    zLocal = outQueueZ.DeQue<float>();
    AscendC::DataCopy(zGm, zLocal, blockLength);
    outQueueZ.FreeTensor(zLocal);
}
```

初始化阶段主要完成以下内容：

-   设置输入输出Global Tensor的Global Memory内存地址。

    本样例中的分配方案是：数据整体长度TOTAL\_LENGTH为8 \* 2048，分8个核计算，每个核计算的数据长度blockLength为2048，使用GlobalTensor类的[SetGlobalBuffer](https://gitcode.com/cann/asc-devkit/blob/master/docs/api/SIMD-API/基础API/数据结构/LocalTensor和GlobalTensor定义/GlobalTensor/SetGlobalBuffer.md)接口设定该核上Global Memory的起始地址以及长度。

    ```
    xGm.SetGlobalBuffer((__gm__ float*)x + blockLength * AscendC::GetBlockIdx(), blockLength);
    ```

-   通过[Pipe内存管理对象](https://gitcode.com/cann/asc-devkit/blob/master/docs/api/SIMD-API/基础API/资源管理/Pipe和Que框架/TPipe/TPipe.md)为输入输出Queue分配内存。

    比如，为输入x的Queue分配内存，可以通过如下代码段实现：

    ```
    pipe.InitBuffer(inQueueX, 1, blockLength * sizeof(float));
    ```

具体的初始化阶段代码如下：

```
// Init阶段
AscendC::TPipe pipe;
AscendC::TQue<AscendC::TPosition::VECIN, 1> inQueueX;
AscendC::TQue<AscendC::TPosition::VECIN, 1> inQueueY;
AscendC::TQue<AscendC::TPosition::VECOUT, 1> outQueueZ;
AscendC::GlobalTensor<float> xGm;
AscendC::GlobalTensor<float> yGm;
AscendC::GlobalTensor<float> zGm;

// totalLength 表示全局输入长度；GetBlockNum() 返回本次启动的核数，
// 这里按核数均分每个 block 的处理区间。
uint32_t blockLength = totalLength / AscendC::GetBlockNum();
// 根据 block_idx 计算当前核在 GM 中的起始地址，确保各核访问互不重叠的数据分片。
xGm.SetGlobalBuffer((__gm__ float*)x + blockLength * AscendC::GetBlockIdx(), blockLength);
yGm.SetGlobalBuffer((__gm__ float*)y + blockLength * AscendC::GetBlockIdx(), blockLength);
zGm.SetGlobalBuffer((__gm__ float*)z + blockLength * AscendC::GetBlockIdx(), blockLength);
// 为输入和输出队列申请与 blockLength 对应的 UB 缓冲，保持 TPipe/TQue 的编程范式。
pipe.InitBuffer(inQueueX, 1, blockLength * sizeof(float));
pipe.InitBuffer(inQueueY, 1, blockLength * sizeof(float));
pipe.InitBuffer(outQueueZ, 1, blockLength * sizeof(float));
```

根据编程范式上面的算法分析，将整个计算拆分成三个Stage，用户单独编写每个Stage的代码，三阶段流程示意图参见[图3](#zh-cn_topic_0000002201157438_fig4134406304)，具体流程如下：

<a id="copyin-implementation">
1.  Stage1：CopyIn实现。

    1.  使用[DataCopy](https://gitcode.com/cann/asc-devkit/blob/master/docs/api/SIMD-API/基础API/数据搬运导览/概览/数据搬运概念.md)接口将GlobalTensor数据拷贝到LocalTensor。
    2.  使用[EnQue](https://gitcode.com/cann/asc-devkit/blob/master/docs/api/SIMD-API/基础API/资源管理/Pipe和Que框架/TQue/EnQue.md)将LocalTensor放入VECIN的Queue中。

    ```
    // 使用 DataCopy 将输入从 GM 搬运到 UB，并通过 EnQue 将 LocalTensor 入队，供后续计算阶段 DeQue 取用。
    AscendC::LocalTensor<float> xLocal = inQueueX.AllocTensor<float>();
    AscendC::LocalTensor<float> yLocal = inQueueY.AllocTensor<float>();
    AscendC::DataCopy(xLocal, xGm, blockLength);
    AscendC::DataCopy(yLocal, yGm, blockLength);
    inQueueX.EnQue(xLocal);
    inQueueY.EnQue(yLocal);
    ```

2.  Stage2：Compute实现。

    1.  使用[DeQue](https://gitcode.com/cann/asc-devkit/blob/master/docs/api/SIMD-API/基础API/资源管理/Pipe和Que框架/TQue/DeQue.md)从VECIN中取出LocalTensor。
    2.  使用Ascend C接口[Add](https://gitcode.com/cann/asc-devkit/blob/master/docs/api/SIMD-API/基础API/Memory矢量计算/基础算术/Add.md)完成矢量计算。
    3.  使用[EnQue](https://gitcode.com/cann/asc-devkit/blob/master/docs/api/SIMD-API/基础API/资源管理/Pipe和Que框架/TQue/EnQue.md)将计算结果LocalTensor放入到VECOUT的Queue中。
    4.  使用[FreeTensor](https://gitcode.com/cann/asc-devkit/blob/master/docs/api/SIMD-API/基础API/资源管理/Pipe和Que框架/TQue/FreeTensor.md)释放不再使用的LocalTensor。

    ```
    // DeQue 取出输入张量，在 UB 内执行 Add，并将结果 EnQue 到输出队列，供后续写回 GM。
    xLocal = inQueueX.DeQue<float>();
    yLocal = inQueueY.DeQue<float>();
    AscendC::LocalTensor<float> zLocal = outQueueZ.AllocTensor<float>();
    AscendC::Add(zLocal, xLocal, yLocal, blockLength);
    outQueueZ.EnQue<float>(zLocal);
    inQueueX.FreeTensor(xLocal);
    inQueueY.FreeTensor(yLocal);
    ```
<a id="copyout-implementation">
3.  Stage3：CopyOut实现。

    1.  使用[DeQue](https://gitcode.com/cann/asc-devkit/blob/master/docs/api/SIMD-API/基础API/资源管理/Pipe和Que框架/TQue/DeQue.md)接口从VECOUT的Queue中取出LocalTensor。
    2.  使用[DataCopy](https://gitcode.com/cann/asc-devkit/blob/master/docs/api/SIMD-API/基础API/数据搬运导览/概览/数据搬运概念.md)接口将LocalTensor拷贝到GlobalTensor上。
    3.  使用[FreeTensor](https://gitcode.com/cann/asc-devkit/blob/master/docs/api/SIMD-API/基础API/资源管理/Pipe和Que框架/TQue/FreeTensor.md)将不再使用的LocalTensor进行回收。

    ```
    // 从输出队列取出结果，并写回当前核负责的 GM 分片。
    zLocal = outQueueZ.DeQue<float>();
    AscendC::DataCopy(zGm, zLocal, blockLength);
    outQueueZ.FreeTensor(zLocal);
    ```
