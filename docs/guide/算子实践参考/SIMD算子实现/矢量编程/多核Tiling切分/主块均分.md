# 主块均分

如图 1所示，该场景中输入数据可以按参与计算的核数和主块长度`mainTileLength`均匀切分，每个核都处理`tileNum`个主块长度的数据。完成主块分配后没有剩余数据，各核处理的数据量相同，且核内只包含主块。

本场景样例的完整代码请参考[场景0：主块均分](https://gitcode.com/cann/asc-devkit/blob/master/examples/01_simd_cpp_api/02_features/02_tiling_selector/vector_tiling_strategy/README.md#scenario0-main-tile-only)。样例中固定使用8个核，主块长度`mainTileLength`为3200个`half`元素，数据整体长度为256000个`half`元素。数据平均分配到8个核上运行，每个核计算32000个元素；每个核内共切分成10个主块，不涉及尾块和尾核处理。

## Tiling实现

基于本节的切分策略，Tiling需要定义如下参数：

- blockLength：每个核的计算数据长度，单位为元素。
- tileNum：每个核需要计算的主块个数。

根据确定的Tiling参数，使用C++语法定义`MainTileOnlyTiling`结构体，代码如下。

```cpp
struct MainTileOnlyTiling {
    uint32_t blockLength; // 每个核处理的元素数量
    uint32_t tileNum;     // 主块数量
};
```

接下来完成Tiling参数的计算。`numBlocks`表示参与计算的逻辑核数，`dataBlockSize`表示一个DataBlock的字节数，`halfSize`表示一个`half`元素的字节数，`alignNum`表示一个DataBlock包含的`half`元素数量，`mainTileLength`表示一个主块包含的`half`元素数量。步骤如下：

1. 根据`dataBlockSize`和`halfSize`计算`alignNum`，本样例中`alignNum`为16。`totalLength`表示输入数据的元素总数，将其按`alignNum`向上对齐后得到元素总数`totalLengthAligned`。

    ```cpp
    constexpr uint32_t dataBlockSize = 32;
    constexpr uint32_t halfSize = 2;
    constexpr uint32_t alignNum = dataBlockSize / halfSize;

    uint32_t totalLengthAligned = AlignUp(totalLength, alignNum);
    ```

2. 按`numBlocks`和`mainTileLength`计算每个核均分到的主块数量`mainTileNum`，以及主块均分后的剩余元素数量`mainTileRemainder`。`baseLength`表示每个核已分配的基础元素数量，`baseTileNum`表示对应的主块数量。

    ```cpp
    constexpr uint32_t numBlocks = 8;
    constexpr uint32_t mainTileLength = 3200;

    uint32_t mainTileNum = totalLengthAligned / (numBlocks * mainTileLength);
    uint32_t mainTileRemainder = totalLengthAligned % (numBlocks * mainTileLength);
    uint32_t baseLength = mainTileNum * mainTileLength;
    uint32_t baseTileNum = mainTileNum;
    ```

3. 当`mainTileRemainder`为0时，表示所有数据都能按主块均匀分配到各核，此时使用`MainTileOnlyTiling`。

    ```cpp
    if (mainTileRemainder == 0U) {
        MainTileOnlyTiling tiling{baseLength, baseTileNum};
        add_custom<MainTileOnlyTiling><<<numBlocks, 0, stream>>>(xDevice, yDevice, zDevice, tiling);
        return;
    }
    ```

    其中，`xDevice`、`yDevice`和`zDevice`分别为输入输出的Device侧地址，`stream`为执行核函数的Stream。

## 算子类实现

Kernel侧算子采用[静态Tensor编程](../../../../编程指南/编程模型/AI-Core-SIMD编程/基于Tensor的CPP编程/静态Tensor编程.md)方式实现，通过`LocalTensor`构造函数直接指定Local Memory地址。静态Tensor编程中的内存管理和同步管理请参考对应章节，本文重点说明Tiling结果如何传入Kernel侧，并指导GM地址计算和循环处理主块数据。

- Kernel入口通过模板参数接收Host侧传入的Tiling结构体，并将`tiling`传入算子类`Init`函数。主块均分场景中，传入的结构体类型为`MainTileOnlyTiling`。

    ```cpp
    template <typename TilingData>
    __vector__ __global__ void add_custom(__gm__ uint8_t* x, __gm__ uint8_t* y, __gm__ uint8_t* z, TilingData tiling)
    {
        AscendC::InitSocState();
        KernelAdd op;
        op.Init(x, y, z, tiling);
        op.Process();
        AscendC::PipeBarrier<PIPE_ALL>();
    }
    ```

- 由于本样例中将数据分配到多个核上处理，每个核访问的Global Memory地址不同。`Init`函数通过`tiling.blockLength`获取每个核处理的元素数量，并结合[GetBlockIdx](https://gitcode.com/cann/asc-devkit/blob/master/docs/api/SIMD-API/基础API/工具接口/系统资源与变量/GetBlockIdx.md)计算当前核的Global Memory偏移。以输入x为例，`x + tiling.blockLength * GetBlockIdx()`即为当前核处理的x在Global Memory上的起始地址。`offset`和`length`分别表示以`half`元素为单位的Global Memory偏移和数据长度。获取偏移后，`InitGm`函数通过[SetGlobalBuffer](https://gitcode.com/cann/asc-devkit/blob/master/docs/api/SIMD-API/基础API/数据结构/LocalTensor和GlobalTensor定义/GlobalTensor/SetGlobalBuffer.md)设置输入输出`GlobalTensor`。

    ```cpp
    __aicore__ inline void Init(__gm__ uint8_t* x, __gm__ uint8_t* y, __gm__ uint8_t* z,
                                MainTileOnlyTiling tiling)
    {
        uint32_t offset = AscendC::GetBlockIdx() * tiling.blockLength;
        InitGm(x, y, z, offset, tiling.blockLength);
        this->tileNum = tiling.tileNum;
        this->lastTileLength = 0U;
    }

    __aicore__ inline void InitGm(
        __gm__ uint8_t* x, __gm__ uint8_t* y, __gm__ uint8_t* z, uint32_t offset, uint32_t length)
    {
        xGm.SetGlobalBuffer((__gm__ half*)x + offset, length);
        yGm.SetGlobalBuffer((__gm__ half*)y + offset, length);
        zGm.SetGlobalBuffer((__gm__ half*)z + offset, length);
    }
    ```

- `Process`函数基于`tiling.tileNum`保存的主块数量循环处理数据。主块均分场景下，每个核只包含主块，此循环次数为`tileNum`。`xAddr`、`yAddr`和`zAddr`表示Local Memory中的字节偏移；每轮循环使用`mainTileLength`作为当前主块的元素数量，通过`loopIdx * mainTileLength`计算核内元素偏移，依次完成输入搬入、Add计算和输出搬出。

    ```cpp
    __aicore__ inline void Process()
    {
        AscendC::LocalTensor<half> xLocal(AscendC::TPosition::VECCALC, xAddr, mainTileLength);
        AscendC::LocalTensor<half> yLocal(AscendC::TPosition::VECCALC, yAddr, mainTileLength);
        AscendC::LocalTensor<half> zLocal(AscendC::TPosition::VECCALC, zAddr, mainTileLength);

        uint32_t totalLoop = this->tileNum + (this->lastTileLength > 0U ? 1U : 0U);
        for (uint32_t loopIdx = 0; loopIdx < totalLoop; loopIdx++) {
            uint32_t curLen = (loopIdx < this->tileNum) ? mainTileLength : this->lastTileLength;
            uint32_t startElement = loopIdx * mainTileLength;
            AscendC::DataCopy(xLocal, xGm[startElement], curLen);
            AscendC::DataCopy(yLocal, yGm[startElement], curLen);
            AscendC::Add(zLocal, xLocal, yLocal, curLen);
            AscendC::DataCopy(zGm[startElement], zLocal, curLen);
        }
    }
    ```
