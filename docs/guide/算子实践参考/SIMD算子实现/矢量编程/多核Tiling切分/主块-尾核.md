# 主块-尾核

在实际算子开发中，受输入数据总量与切分单位的制约，并非所有场景都能将计算完全均匀地分配到每个核上。该场景中，主块均分后存在剩余数据，但剩余数据无法以DataBlock为最小单位均匀分配到每个核，只能分配给部分核。获得额外DataBlock的核为整核，其余为尾核，此时存在核间负载不均衡，需要分别处理整核和尾核。

本场景样例的完整代码请参考[场景2：主块-尾核](https://gitcode.com/cann/asc-devkit/blob/master/examples/01_simd_cpp_api/02_features/02_tiling_selector/vector_tiling_strategy/README.md#scenario2-main-tile-tail-core)。样例中固定使用8个核，主块长度`mainTileLength`为3200个`half`元素，数据整体长度为256064个`half`元素。数据按DataBlock对齐后，前4个核各处理32016个元素，后4个核各处理32000个元素；整核包含10个主块和16个元素的尾块，尾核只包含10个主块。数据切分示意如图 1所示：

本场景中，整核和尾核处理的元素数量、主块数量及尾块情况不同，无法继续使用一组`blockLength`、`tileNum`和`lastTileLength`描述所有核。因此，在Tiling参数中增加`formerNum`，用于记录整核数量，并分别使用`former*`和`tail*`参数描述整核和尾核。由于尾核内只包含主块，无需定义`tailLastTileLength`。Tiling结构体包含以下成员：

- formerNum：分配到数据量较多的核数，即整核的核数。
- formerLength：整核计算的元素数量。
- formerTileNum：整核中主块的数量。
- formerLastTileLength：整核中尾块的元素数量。
- tailLength：尾核计算的元素数量。
- tailTileNum：尾核中主块的数量。

## Tiling实现

Tiling结构体定义如下：

```cpp
struct MainTileWithTailCoreTiling {
    uint32_t formerNum;            // 整核数量
    uint32_t formerLength;         // 整核处理的元素数量
    uint32_t formerTileNum;        // 整核中主块的数量
    uint32_t formerLastTileLength; // 整核中尾块的元素数量
    uint32_t tailLength;           // 尾核处理的元素数量
    uint32_t tailTileNum;          // 尾核中主块的数量
};
```

Host侧Tiling沿用[主块-尾块](主块-尾块.md)中的逻辑核数`numBlocks`、主块元素数量`mainTileLength`、每个DataBlock包含的元素数量`alignNum`、DataBlock对齐、主块分配和基础尾块计算，得到`remainingTailLength`、`tailBlockNumEachCore`、`baseLength`和`baseTileNum`。当`remainingTailLength`不为0时，继续执行以下步骤：

1. 最后剩余的DataBlock无法均匀分配到每个核，只能分配给前`formerNum`个整核。`formerNum`表示整核数量，`formerLength`和`tailLength`分别表示每个整核和每个尾核处理的元素数量；整核比尾核多处理一个DataBlock的数据。

    ```cpp
    if (remainingTailLength != 0U) {
        uint32_t formerNum = remainingTailLength / alignNum;
        uint32_t formerLength = baseLength + alignNum;
        uint32_t tailLength = baseLength;
    }
    ```

2. 分别计算整核和尾核的主块数量。`formerTileNum`和`tailTileNum`分别表示整核和尾核的主块数量。

    ```cpp
    uint32_t formerTileNum = baseTileNum;
    uint32_t tailTileNum = baseTileNum;
    ```

3. 在`remainingTailLength`不为0的前提下，继续判断`tailBlockNumEachCore`是否为0。等于0表示各核未分配到基础尾块，尾核内只包含主块；整核比尾核多处理一个DataBlock，因此整核尾块长度`formerLastTileLength`直接设置为`alignNum`。此时进入主块-尾核场景，使用`MainTileWithTailCoreTiling`。

    ```cpp
    if (tailBlockNumEachCore == 0U) {
        uint32_t formerLastTileLength = alignNum;
        MainTileWithTailCoreTiling tiling{
            formerNum, formerLength, formerTileNum, formerLastTileLength, tailLength, tailTileNum};
        add_custom<MainTileWithTailCoreTiling><<<numBlocks, 0, stream>>>(xDevice, yDevice, zDevice, tiling);
    }
    ```

（1，256064）形状的输入数据计算后，Tiling结构体内各个变量的值如下：

```cpp
MainTileWithTailCoreTiling tiling{
    4,     // formerNum：前4个核为整核
    32016, // formerLength：整核计算32016个half
    10,    // formerTileNum：整核包含10个主块
    16,    // formerLastTileLength：整核包含16个half的尾块
    32000, // tailLength：尾核计算32000个half
    10     // tailTileNum：尾核包含10个主块
};
```

## 算子类实现

Kernel侧算子仍采用[静态Tensor编程](../../../../编程指南/编程模型/AI-Core-SIMD编程/基于Tensor的CPP编程/静态Tensor编程.md)方式实现。与[主块均分](主块均分.md)相比，本场景中不同核处理的数据长度不同，因此`Init`函数需要根据`GetBlockIdx()`判断当前核是整核还是尾核，并分别设置Global Memory偏移和循环参数。`blockIdx`表示当前逻辑核的索引。

整核使用`formerLength`、`formerTileNum`和`formerLastTileLength`。其中，`offset`表示以`half`元素为单位的Global Memory偏移。整核输入的Global Memory偏移计算如下：

```cpp
uint32_t offset = tiling.formerLength * blockIdx;
InitGm(x, y, z, offset, tiling.formerLength);
```

尾核使用`tailLength`和`tailTileNum`，且尾核内只包含主块，因此`lastTileLength`设置为0。尾核输入的Global Memory偏移需要在全部整核数据之后继续计算，代码如下：

```cpp
uint32_t offset = tiling.formerLength * tiling.formerNum + tiling.tailLength * (blockIdx - tiling.formerNum);
InitGm(x, y, z, offset, tiling.tailLength);
```

完整的`Init`函数实现代码如下：

```cpp
__aicore__ inline void Init(__gm__ uint8_t* x, __gm__ uint8_t* y, __gm__ uint8_t* z,
                            MainTileWithTailCoreTiling tiling)
{
    uint32_t blockIdx = AscendC::GetBlockIdx();
    if (blockIdx < tiling.formerNum) {
        uint32_t offset = tiling.formerLength * blockIdx;
        InitGm(x, y, z, offset, tiling.formerLength);
        this->tileNum = tiling.formerTileNum;
        this->lastTileLength = tiling.formerLastTileLength;
    } else {
        uint32_t offset =
            tiling.formerLength * tiling.formerNum + tiling.tailLength * (blockIdx - tiling.formerNum);
        InitGm(x, y, z, offset, tiling.tailLength);
        this->tileNum = tiling.tailTileNum;
        this->lastTileLength = 0U;
    }
}
```

完成`Init`后，`Process`函数仍按照`tileNum`和`lastTileLength`进行循环处理。整核需要处理主块和尾块，尾核只处理主块；循环逻辑与[主块均分](主块均分.md)中的`Process`函数一致，这里不重复展开。
