# 入门功能落地<a name="ZH-CN_TOPIC_000000_ADD_ENTRY"></a>

本节使用基础API进行矩阵乘法的编程指导。数据搬运和计算流水线通过事件同步进行协调，简化了编程复杂度。

## 算子概述

  Matmul计算公式：
  $$
  C = A * B
  $$
  - A、B为源操作数，A为左矩阵，形状为[M, K]；B为右矩阵，形状为[K, N]
  - C为目的操作数，存放矩阵乘结果的矩阵，形状为[M, N]

## 算子实现

-   算子分析：分析算子的数学表达式、输入、输出以及计算逻辑的实现，明确需要调用的Ascend C接口。
-   核函数定义：定义Ascend C算子入口函数。
-   算子实现：完成核函数的内部实现，调用私有成员函数CopyInA、CopyInB、DataLoadA、DataLoadB、Compute、CopyOut完成矩阵算子的四级流水操作。

算子实现的流程具体任务之间的交互流程如下。

1.  Stage1：CopyIn任务（GM --> L1）  
    使用[DataCopy](https://gitcode.com/cann/asc-devkit/blob/master/docs/api/context/DataCopy.md)接口将Global Memory 中的数据搬运到L1 Buffer（A1/B1），同时利用[随路格式转换](https://gitcode.com/cann/asc-devkit/blob/master/docs/api/context/随路转换ND2NZ搬运.md)功能将ND格式转换为NZ格式。

2.  Stage2：Split任务（L1 --> L0）    
    使用[LoadData](https://gitcode.com/cann/asc-devkit/blob/master/docs/api/context/LoadData.md)接口将数据从A1/B1中搬运到A2/B2（L0A/L0B），同时完成NZ到ZZ/ZN的格式转换。

3.  Stage3：Compute任务（L0上计算）    
    使用[Mmad](https://gitcode.com/cann/asc-devkit/blob/master/docs/api/context/Mmad.md)接口在L0上完成矩阵乘计算，结果存放在CO1（L0C Buffer）。

4.  Stage4：CopyOut任务（L0C --> GM）    
    使用[Fixpipe](https://gitcode.com/cann/asc-devkit/blob/master/docs/api/context/Fixpipe.md)接口将结果从CO1直接搬运到Global Memory，同时利用Fixpipe的随路格式转换功能将NZ格式转回ND格式。

下文将以Matmul算子为例对上述步骤进行详细介绍，Matmul算子的代码框架如下，完整代码请参见[Mmad样例](https://gitee.com/ascend/samples/tree/master/operator/ascendc/0_introduction/20_mmad_kernellaunch/MmadInvocation)。

public:

    {
        // ...
    }
    __aicore__ inline void Process()
    {
        // 创建静态LocalTensor
        // 三重循环：m方向 * n方向 * k方向
        // 每次循环执行 CopyIn --> Sync --> Sync --> Compute --> Sync --> CopyOut
    }
private:
    __aicore__ inline void CopyInA(...)
    __aicore__ inline void CopyInB(..)
    __aicore__ inline void DataLoadA(...)
    __aicore__ inline void DataLoadB(...)
    __aicore__ inline void Compute(...)
    __aicore__ inline void CopyOut(...)

### 核函数定义<a name="zh-cn_topic_0000002135641293_section434251315304"></a>

根据[核函数](../../../编程指南/编程模型/AI-Core-SIMD编程/核函数.md)中介绍的规则进行核函数的定义。

1.  函数原型定义。

    本样例中，函数名为matmul\_custom（核函数名称可自定义）；根据[算子分析](#zh-cn_topic_0000002135641293_section11569817102912)中对算子输入输出的分析，确定有3个参数a，b，c，其中a，b都为输入内存，c为输出内存。使用\_\_global\_\_函数类型限定符来标识它是一个核函数，可以被<<<\>\>\>调用；使用\_\_aicore\_\_函数类型限定符来标识该核函数在设备端aicore上执行；为方便起见，统一使用GM\_ADDR宏修饰入参。

    ```
    template <
    uint32_t M, uint32_t K, uint32_t N, uint32_t singleCoreM, uint32_t singleCoreK, uint32_t singleCoreN,
    uint32_t baseM, uint32_t baseK, uint32_t baseN>
    __global__ __cube__ void mmad_custom(GM_ADDR a, GM_ADDR b, GM_ADDR c)
    {
        // ...
    }
    ```
    > [!NOTE]说明
    > 核函数使用模板参数传入矩阵的分块信息，这样可以在编译期确定循环次数，有利于编译器优化。其中M/K/N为总矩阵维度，singleCoreM/singleCoreK/singleCoreN为单核处理的分块大小，baseM/baseK/baseN为Cube单元单次计算的Tile大小。

2.  调用算子类的Init和Process函数。

    算子类的Init函数，完成内存初始化相关工作，Process函数完成算子实现的核心逻辑，具体介绍参见[算子类实现](#zh-cn_topic_0000002135641293_section1882915463510)。核函数在开始时调用`AscendC::InitSocState()`初始化硬件状态，结束时调用`AscendC::PipeBarrier<PIPE_ALL>()`等待所有流水线完成。

    ```
    extern "C" __global__ __aicore__ void matmul_custom(GM_ADDR a, GM_ADDR b, GM_ADDR c)
    {
        AscendC::InitSocState();
        KernelMatmul op;
        op.Init(a, b, c);
        op.Process();
        AscendC::PipeBarrier<PIPE_ALL>();
    }
    ```

### 算子类实现<a name="zh-cn_topic_0000002135641293_section1882915463510"></a>

根据上一章节介绍，核函数中会调用算子类的Init和Process函数，本章具体讲解基于编程范式实现算子类。

算子类中主要包含对外开放的初始化Init函数和核心处理函数Process以及一些实现中会用到的私有成员。

#### 算子类实现

KernelMatmul算子类的定义如下：

```
class KernelMatmul {
public:
    __aicore__ inline KernelMatmul() {}
    __aicore__ inline void Init(GM_ADDR a, GM_ADDR b, GM_ADDR c)
    {
        aGM.SetGlobalBuffer((__gm__ half*)a);
        bGM.SetGlobalBuffer((__gm__ half*)b);
        cGM.SetGlobalBuffer((__gm__ half*)c);
        InitGMOffsets();
    }

    __aicore__ inline void Process()
    {
        AscendC::LocalTensor<half> a1Local(AscendC::TPosition::A1, a1Addr, baseM * baseK);
        AscendC::LocalTensor<half> a2Local(AscendC::TPosition::A2, a2Addr, baseM * baseK);
        AscendC::LocalTensor<half> b1Local(AscendC::TPosition::B1, b1Addr, baseK * baseN);
        AscendC::LocalTensor<half> b2Local(AscendC::TPosition::B2, b2Addr, baseK * baseN);
        AscendC::LocalTensor<float> cLocal(AscendC::TPosition::CO1, cAddr, baseM * baseN);

        constexpr uint32_t kLoopCount = singleCoreK / baseK;
        constexpr uint32_t mLoopCount = singleCoreM / baseM;
        constexpr uint32_t nLoopCount = singleCoreN / baseN;
        for (uint32_t mIndex = 0; mIndex < mLoopCount; mIndex++) {
            for (uint32_t nIndex = 0; nIndex < nLoopCount; nIndex++) {
                for (uint32_t kIndex = 0; kIndex < kLoopCount; kIndex++) {
                    CopyInA(a1Local, kIndex, mIndex);
                    CopyInB(b1Local, kIndex, nIndex);

                    AscendC::SetFlag<AscendC::HardEvent::MTE2_MTE1>(EVENT_ID0);
                    AscendC::WaitFlag<AscendC::HardEvent::MTE2_MTE1>(EVENT_ID0);

                    DataLoadA(a1Local, a2Local, mIndex);
                    DataLoadB(b1Local, b2Local, nIndex);

                    AscendC::SetFlag<AscendC::HardEvent::MTE1_M>(EVENT_ID0);
                    AscendC::WaitFlag<AscendC::HardEvent::MTE1_M>(EVENT_ID0);

                    Compute(cLocal, a2Local, b2Local, kIndex, mIndex, nIndex);

                    AscendC::SetFlag<AscendC::HardEvent::M_MTE2>(EVENT_ID0);
                    AscendC::WaitFlag<AscendC::HardEvent::M_MTE2>(EVENT_ID0);
                }
                AscendC::SetFlag<AscendC::HardEvent::M_FIX>(EVENT_ID0);
                AscendC::WaitFlag<AscendC::HardEvent::M_FIX>(EVENT_ID0);
                CopyOut(cLocal, mIndex, nIndex);
            }
        }
    }

private:
    // ...
};
```

下面逐个函数详细说明实现细节。

#### InitGMOffsets函数实现

InitGMOffsets函数负责根据当前核的编号（GetBlockIdx）计算出该核在全局矩阵中负责的数据偏移量。在多核并行计算中，每个核处理矩阵的一个子块。

```cpp
__aicore__ inline void InitGMOffsets()
{
    constexpr uint32_t mIter = M / singleCoreM;
    uint32_t mIterIdx = AscendC::GetBlockIdx() % mIter;
    uint32_t nIterIdx = AscendC::GetBlockIdx() / mIter;

    uint64_t gmOffsetA = mIterIdx * singleCoreM * K;
    uint64_t gmOffsetB = nIterIdx * singleCoreN;
    uint64_t gmOffsetC = mIterIdx * singleCoreM * N + nIterIdx * singleCoreN;
    aGM = aGM[gmOffsetA];
    bGM = bGM[gmOffsetB];
    cGM = cGM[gmOffsetC];
}
```

以本样例为例：M=512，K=512，N=1024，singleCoreM=256，singleCoreN=512，共4个核（numBlocks=4）。
- mIter = 512/256 = 2，即 M 方向上分为 2 个核。
- 核 0（mIterIdx=0， nIterIdx=0）：处理 a 的 \[0:256, :\]和b的\[:, 0:512\]。
- 核 1（mIterIdx=1， nIterIdx=0）：处理 a 的 \[256:512, :\]和b的\[:, 0:512\]。
- 核 2（mIterIdx=0， nIterIdx=1）：处理 a 的 \[0:256, :\]和b的\[:, 512:1024\]。
- 核 3（mIterIdx=1， nIterIdx=1）：处理 a 的 \[256:512, :\]和b的\[:, 512:1024\]。

#### CopyInA / CopyInB函数实现（Stage1：GM --> L1）

CopyInA和CopyInB负责将矩阵数据从GM搬运到L1 Buffer，同时通过DataCopy接口的 Nd2NzParams 参数自动完成ND格式到NZ格式的转换。


**CopyInA函数** ———— 搬运矩阵a的一个Tile（大小为baseM \* baseK）：

```cpp
__aicore__ inline void CopyInA(AscendC::LocalTensor<half> a1Local, uint32_t kIndex, uint32_t mIndex)
{
    AscendC::Nd2NzParams nd2nzA1Params;
    nd2nzA1Params.ndNum = 1;
    nd2nzA1Params.nValue = baseM;
    nd2nzA1Params.dValue = baseK;
    nd2nzA1Params.srcNdMatrixStride = 0;
    nd2nzA1Params.srcDValue = K;
    nd2nzA1Params.dstNzC0Stride = baseM;
    nd2nzA1Params.dstNzNStride = 1;
    nd2nzA1Params.dstNzMatrixStride = 0;
    AscendC::DataCopy(a1Local, aGM[kIndex * baseK + mIndex * K * baseM], nd2nzA1Params);
}
```

**CopyInB函数** ———— 搬运矩阵b的一个Tile（大小为baseK \* baseN）：

```cpp
__aicore__ inline void CopyInB(AscendC::LocalTensor<half> b1Local, uint32_t kIndex, uint32_t nIndex)
{
    AscendC::Nd2NzParams nd2nzB1Params;
    nd2nzB1Params.ndNum = 1;
    nd2nzB1Params.nValue = baseK;
    nd2nzB1Params.dValue = baseN;
    nd2nzB1Params.srcNdMatrixStride = 0;
    nd2nzB1Params.srcDValue = N;
    nd2nzB1Params.dstNzC0Stride = baseK;
    nd2nzB1Params.dstNzNStride = 1;
    nd2nzB1Params.dstNzMatrixStride = 0;
    AscendC::DataCopy(b1Local, bGM[kIndex * baseK * N + nIndex * baseN], nd2nzB1Params);
}
```

Nd2NzParams参数说明：
- **ndNum**：ND矩阵的个数，本样例只搬运1个矩阵，设为1。
- **nValue**：ND矩阵的行数，搬运a时为baseM，搬运b时为baseK。
- **dValue**：ND矩阵的列数，搬运a时为baseK，搬运b时为baseN。
- **srcNdMatrixStride**：源ND矩阵间的步长，ndNum为1时设为0。
- **srcDValue**：源ND矩阵每行的实际长度（即原始矩阵的总列数），用于计算源地址偏移。矩阵a的原始列数为K，矩阵b的原始列数为N。
- **dstNzC0Stride**：目的NZ矩阵中C0方向（即分形内的高度方向）的步长。
- **dstNzNStride**：目的NZ矩阵中N方向的步长，设为1表示连续存储。
- **dstNzMatrixStride**：目的NZ矩阵间的步长，ndNum为1时设为0。

#### 流水同步机制说明

数据搬运、矩阵计算（M）、结果搬出（FIX）等操作通过不同流水线并行执行。为确保数据依赖正确，需要在各阶段之间插入同步点。

本样例使用`AscendC::PipeBarrier<PIPE_ALL>()`进行全局流水同步：等待所有流水线上的操作全部完成后，再继续执行后续指令。

```cpp
// CopyIn后同步：等待数据搬运到L1完成
AscendC::PipeBarrier<PIPE_ALL>();
// DataLoad后同步：等待数据搬运到L0完成
AscendC::PipeBarrier<PIPE_ALL>();
// Compute后同步：等待矩阵计算完成
AscendC::PipeBarrier<PIPE_ALL>();
// k方向循环结束后同步：等待所有k分片计算累加完成，准备CopyOut
AscendC::PipeBarrier<PIPE_ALL>();
```

#### DataLoadA / DataLoadB函数实现（Stage2: L1 --> L0）

DataLoadA和DataLoadB负责将数据从L1 Buffer（A1/B1）搬运到L0（A2/B2），同时通过LoadData接口完成格式转换：
- 矩阵a：NZ格式 --> ZZ格式（ifTranspose = false）
- 矩阵b：NZ格式 --> ZN格式（ifTranspose = true）

**DataLoadA函数** —— 将矩阵a从A1搬运到A2，NZ --> ZZ：

```cpp
__aicore__ inline void DataLoadA(
    AscendC::LocalTensor<half> a1Local, AscendC::LocalTensor<half> a2Local, uint32_t mIndex)
{
#if defined(__NPU_ARCH__) && (__NPU_ARCH__ == 2201)
    constexpr uint32_t dstOffset = baseK * CUBE_BLOCK;
    // 单个分型的大小为512B，对于half类型小分型大小为16*16=256
    constexpr uint32_t srcOffset = 512 / sizeof(half);
    AscendC::LoadData2DParams loadDataParamsA;
    loadDataParamsA.repeatTimes = baseK / CUBE_BLOCK;
    loadDataParamsA.srcStride = baseM / CUBE_BLOCK;
    loadDataParamsA.dstGap = 0;
    loadDataParamsA.ifTranspose = false;
    for (int i = 0; i < baseM / CUBE_BLOCK; ++i) {
        AscendC::LoadData(a2Local[i * dstOffset], a1Local[i * srcOffset], loadDataParamsA);
    }
#elif defined(__NPU_ARCH__) && (__NPU_ARCH__ == 3510)
    AscendC::LoadData2DParamsV2 loadDataParamsA;
    loadDataParamsA.mStartPosition = 0;
    loadDataParamsA.kStartPosition = 0;
    loadDataParamsA.mStep = AscendC::DivCeil(baseM, CUBE_BLOCK);
    loadDataParamsA.kStep = AscendC::DivCeil(baseK * sizeof(half), 32);
    loadDataParamsA.srcStride = AscendC::DivCeil(baseM, CUBE_BLOCK);
    loadDataParamsA.dstStride = AscendC::DivCeil(baseM, CUBE_BLOCK);
    loadDataParamsA.ifTranspose = false;
    AscendC::LoadData(a2Local, a1Local, loadDataParamsA);
#endif
}
```

**DataLoadB函数** —— 将矩阵b从B1搬运到B2，NZ --> ZN：

```cpp
__aicore__ inline void DataLoadB(
    AscendC::LocalTensor<half> b1Local, AscendC::LocalTensor<half> b2Local, uint32_t nIndex)
{
#if defined(__NPU_ARCH__) && (__NPU_ARCH__ == 2201)
    constexpr uint32_t dstOffset = baseN * CUBE_BLOCK;
    // 单个分型的大小为512B，对于half类型小分型大小为16*16=256
    constexpr uint32_t srcOffset = 512 / sizeof(half);
    AscendC::LoadData2DParams loadDataParamsB;
    loadDataParamsB.repeatTimes = baseN / CUBE_BLOCK;
    loadDataParamsB.srcStride = baseK / CUBE_BLOCK;
    loadDataParamsB.dstGap = 0;
    loadDataParamsB.ifTranspose = true;
    for (int i = 0; i < baseK / CUBE_BLOCK; ++i) {
        AscendC::LoadData(b2Local[i * dstOffset], b1Local[i * srcOffset], loadDataParamsB);
    }
#elif defined(__NPU_ARCH__) && (__NPU_ARCH__ == 3510)
    AscendC::LoadData2DParamsV2 loadDataParamsB;
    loadDataParamsB.mStartPosition = 0;
    loadDataParamsB.kStartPosition = 0;
    loadDataParamsB.mStep = AscendC::DivCeil(baseK, CUBE_BLOCK);
    loadDataParamsB.kStep = AscendC::DivCeil(baseN * sizeof(half), 32);
    loadDataParamsB.srcStride = AscendC::DivCeil(baseK, CUBE_BLOCK);
    loadDataParamsB.dstStride = AscendC::DivCeil(baseN, CUBE_BLOCK);
    loadDataParamsB.ifTranspose = true;
    AscendC::LoadData(b2Local, b1Local, loadDataParamsB);
#endif
}
```

> [!NOTE]说明
> 代码中使用 `__NPU_ARCH__` 宏区分不同硬件架构。其中 `__NPU_ARCH__ == 2201` 使用 LoadData2DParams 参数结构体，通过循环分批搬运各方向分形；`__NPU_ARCH__ == 3510` 使用 LoadData2DParamsV2 参数结构体，增加了 mStartPosition、kStartPosition、mStep、kStep 等参数支持更灵活的步长配置，一次调用即可完成全部搬运。开发者根据目标硬件选择合适的参数配置即可。

LoadData2DParams参数说明（以矩阵a为例，baseM=128， baseK=64，CUBE_BLOCK=16）：
- **repeatTimes = baseK / CUBE_BLOCK**：每次LoadData调用搬运K方向的4个分形。
- **srcStride = baseM / CUBE_BLOCK**：源矩阵（NZ格式）中，相邻两个分形起始地址之间的间隔为8个分形单位。
- **dstGap = 0**：目的矩阵中分形连续存储。
- **ifTranspose**：矩阵a设为false（不转置，保持Z格式），矩阵b设为true（转置，Z --> N格式）。

外层循环将m方向（矩阵a）或K方向（矩阵b）的分形分批搬运。以矩阵a为例：baseM/CUBE_BLOCK = 8次循环，每次搬运4个分形（K方向），共搬运32个16 \* 16的分形，覆盖128 \* 64的Tile。

> [!NOTE]说明
>矩阵乘法要求：左矩阵a为ZZ格式（行优先的Z格式），右矩阵b为ZN格式（列优先的N格式，即转置后）。LoadData接口的ifTranspose参数控制是否在搬运过程中进行转置操作，从而一步完成“搬运 + 格式转换”。

### Compute函数实现（Stage3：矩阵乘计算）
Compute函数调用Mmad接口在L0上执行矩阵乘法计算，结果存放在CO1（L0C Buffer）中。

```cpp
__aicore__ inline void Compute(
    AscendC::LocalTensor<float> cLocal, AscendC::LocalTensor<half> a2Local, AscendC::LocalTensor<half> b2Local,
    uint32_t kIndex, uint32_t mIndex, uint32_t nIndex)
{
    AscendC::MmadParams mmadParams;
    mmadParams.m = baseM;
    mmadParams.n = baseN;
    mmadParams.k = baseK;
    mmadParams.cmatrixInitVal = (kIndex == 0 ? true : false);
    AscendC::Mmad(cLocal, a2Local, b2Local, mmadParams);
}
```

MmadParams参数说明：
- **m**：左矩阵A的行数。
- **n**：右矩阵B的列数。
- **k**：左矩阵A的列数/右矩阵B的行数。
- **cmatrixInitVal**：K方向第一次计算时设为true，将结果矩阵初始化为0；后续累加计算时设为false，防止覆盖已有结果。

#### CopyOut函数实现（Stage4：L0C --> GM）

CopyOut函数通过Fixpipe接口将计算结果从CO1（L0C Buffer）直接搬运到Global Memory，同时完成NZ到ND的格式转换和精度转换（float32 -> float16）。

```cpp
__aicore__ inline void CopyOut(AscendC::LocalTensor<float> cLocal, uint32_t mIndex, uint32_t nIndex)
{
    AscendC::FixpipeParamsV220 fixpipeParams;
    fixpipeParams.nSize = baseN;
    fixpipeParams.mSize = baseM;
    fixpipeParams.srcStride = baseM;
    fixpipeParams.dstStride = N;
    fixpipeParams.quantPre = QuantMode_t::F322F16;
    fixpipeParams.ndNum = 1;
    fixpipeParams.srcNdStride = 0;
    fixpipeParams.dstNdStride = 0;
    AscendC::Fixpipe(cGM[mIndex * baseM * N + nIndex * baseN], cLocal, fixpipeParams);
}
```

FixpipeParamsV220参数说明：
- **nSize / mSize**：输出矩阵的列数/行数。
- **srcStride**：源矩阵（NZ格式）中相邻行在内存中的步长。
- **dstStride**：目的矩阵（ND格式）中相邻行在内存中的步长，即原始矩阵的总列数N。
- **quantPre**：精度转换模式，F322F16表示将float32转为float16；设为QuantMode_t::NONE则不转换。
- **ndNum**：ND矩阵个数，设为1。
- **srcNdStride / dstNdStride**：多矩阵场景下的矩阵间步长，单矩阵场景设为0。

## 功能调试

### printf

该接口提供CPU域/NPU域调试场景下的格式化输出功能。

在算子kernel侧实现代码中需要输出日志信息的地方调用printf接口打印相关内容。

示例如下：

```
AscendC::printf("matmul blockIdx=%d\n", AscendC::GetBlockIdx());
```

> [!CAUTION]注意 
>printf（PRINTF）接口打印功能会对算子实际运行的性能带来一定影响，通常在调测阶段使用。开发者可以按需通过设置ASCENDC\_DUMP=0的方式关闭打印功能。

### DumpTensor

基于算子工程开发的算子，可以使用该接口Dump指定Tensor的内容。同时支持打印自定义的附加信息（仅支持uint32\_t数据类型的信息），比如打印当前行号等。

在算子kernel侧实现代码中需要打印Tensor数据的地方调用DumpTensor接口打印相关内容。样例如下：

```
AscendC::DumpTensor(cLocal, baseM * baseN);
```

> [!CAUTION]注意 
>DumpTensor接口打印功能会对算子实际运行的性能带来一定影响，通常在调测阶段使用。开发者可以按需通过设置ASCENDC\_DUMP=0来关闭打印功能。

## 性能调试

### msProf工具介绍
msProf工具是单算子性能分析工具。包含msprof op和msprof op simulator两种使用方式。该工具协助用户定位算子内存、算子代码以及算子指令的异常，实现全方位的算子调优。当前支持基于不同运行模式（上板或仿真）和不同文件形式（可执行文件或算子二进制.o文件）进行性能数据的采集和自动解析。

- 上板性能采集

    通过上板性能采集，可以直接测定算子昇腾AI处理器上的运行时间。该方式适合在板环境中快速定位算子性能问题。

    基于可执行文件demo通过msprof op执行算子调优：
    ```
    msprof op ./demo
    ```

    - 性能数据说明  
      命令完成后，会在默认目录下生成以“OPPROF_{timestamp}_XXX”命名的文件夹,性能数据文件夹结构示例如下：

      ```bash
      ├──dump                       # 原始的性能数据，用户无需关注
      ├──ArithmeticUtilization.csv  # cube/vector指令cycle占比
      ├──L2Cache.csv                # L2 Cache命中率，影响MTE2，建议合理规划数据搬运逻辑，增加命中率
      ├──Memory.csv                 # UB，L1和主存储器读写带宽速率
      ├──MemoryL0.csv               # L0A，L0B，和L0C读写带宽速率
      ├──MemoryUB.csv               # Vector和Scalar到UB的读写带宽速率
      ├──OpBasicInfo.csv            # 算子基础信息
      ├──PipeUtilization.csv        # 采集计算单元和搬运单元耗时和占比
      ├──ResourceConflictRatio.csv  # UB上的 bank group、bank conflict和资源冲突率在所有指令中的占比
      └──visualize_data.bin         # MindStudio Insight呈现文件
      ```

更多msProf工具使用方式请参考[MindStudio工具](https://www.hiascend.com/document/redirect/CannCommercialToolOpDev)算子调优（msProf）中的内容。
