# 概述<a name="ZH-CN_TOPIC_0000001846719812"></a>

## 需要具备的知识<a name="section9155515143412"></a>

本文档旨在引导开发者基于Ascend C编程语言，在昇腾 AI 处理器上构建从“功能跑通”到“性能极致”的高性能算子。在阅读此文档前，建议您具备以下基础：

-   编程基础：熟练掌握C++编程语言。
-   理论基础：建议先完成Ascend C[入门教程](../入门教程/Ascend-C概述与学习路径.md)的学习，了解异构系统和编程模型的基本概念，搭建好Ascend C开发与调试环境。

关于Ascend C编程更详细的教学内容，您可以通过[LINK](../编程指南/本文档组织结构.md)获取。

## 本文档的目的<a name="section235444416411"></a>

本文档的核心目的在于引导不同阶段（初级、中级、高级）的开发者，不仅学会**编写算子**，更学会如何编写出具有**极致性能**的算子。通过阅读本文档，您将学会：

1.  **算子实现与性能优化**：掌握从零实现一个算子到极致优化的全过程——从多种编程方式的典型实践案例入手，逐步完成入门功能落地、中级性能优化、高级极限打磨三个阶段的进阶，最终通过真实案例融会贯通。
2.  **性能瓶颈识别与诊断**：学会如何利用Profiling工具和仿真流水图，识别算子的性能瓶颈（搬运瓶颈、计算瓶颈、同步断流等），从而有针对性地调优。
3.  **深度优化技巧**：掌握针对SIMD编程、SIMT编程及SIMD+SIMT混合编程的深度优化手段，涵盖Tiling策略、Double Buffer、内存访问对齐、Bank冲突消除、VF自动融合与手写VF融合、指令双发等。

算子性能优化是一个“分析-优化-验证”的持续迭代流程，本文档将指导您在不同阶段采用最合适的策略，最终达成性能目标。

## 文档组织与章节介绍<a name="section_doc_org"></a>

本文档按照**"典型实践案例 → 功能调试 → 性能分析 → 性能优化"**的递进关系组织，各章的内容以及目标如下：

-   **[典型算子实践案例](典型算子实践案例/概述.md)**：通过具体的案例展示不同编程方式下的算子实现逻辑，每个案例均通过“入门、中级、高阶”三个梯度，指导开发者实现从基本功能实现到极致性能优化的跨越。
-   **[功能调试](功能调试/)**：介绍部分比较常见的影响算子功能的场景。目的是让开发者可以快速解决功能问题，便于进行性能优化，以及快速解决在性能优化过程中可能出现的功能问题。
-   **[性能分析](性能分析/)**：介绍了算子性能数据分析的方向。目的是让开发者能够通过分析性能数据，识别性能的优化方向。算子性能数据的测试方法，以及性能工具使用方式的详细说明请参考《性能调优工具用户指南》，本章不做赘述。
-   **[SIMD算子性能优化](SIMD算子性能优化/)**：介绍性能优化的手段。目的是让开发者结合算子性能瓶颈点，开展性能优化工作。将主要的优化建议分成搬运优化、内存优化、API使用优化、流水优化以及Tiling优化。有一些优化建议是对上述分类的综合体现，则写在了相关性比较大的章节。这些建议按优先级进行分类，优先级是综合考虑性能效果及其范围来设定：为大多数Ascend C算子带来性能收益的建议具有最高优先级，而仅影响特定情况的手段被给予较低优先级。开发者不必熟悉所有优化手段，可以根据分析得到的算子性能瓶颈，获取对应的优化手段，逐渐了解优化策略全貌。
-   **[SIMD与SIMT混合算子性能优化](SIMD与SIMT混合算子性能优化/)**：介绍SIMD与SIMT混合编程场景的性能优化建议。包括内存访问优化、计算优化等。
