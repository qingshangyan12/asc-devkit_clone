# 入门功能落地<a name="ZH-CN_TOPIC_000000_MATMUL_LEAKYRELU_ENTRY"></a>

本节以Matmul+LeakyRelu融合算子为例，介绍基于Ascend C编程模型实现Cube单元与Vector单元协同计算的基本方法，重点说明Cube/Vector分核策略、核间同步机制以及矩阵乘与向量计算的融合编程模式，帮助开发者快速入门融合算子开发。

## 算子概述

Matmul+LeakyRelu融合算子的计算过程分为两步：

**Matmul计算**：

$$
C = A \times B
$$

**LeakyRelu计算**：

$$
C_{out}[i][j] = \begin{cases}
C[i][j] & \text{if } C[i][j] \geq 0 \\
C[i][j] \times 0.001 & \text{if } C[i][j] < 0
\end{cases}
$$

其中，A为左矩阵，形状为[M, K]；B为右矩阵，形状为[K, N]；C为输出矩阵，形状为[M, N]。

- A：输入左矩阵，形状[512, 512]，数据类型half；
- B：输入右矩阵，形状[512, 1024]，数据类型half；
- C：输出矩阵，形状[512, 1024]，数据类型half；

Matmul+LeakyRelu融合算子的计算逻辑遵循"Cube计算→核间同步→Vector计算"三段式流水结构：

1. Cube核将A、B矩阵从Global Memory搬运到L1，再加载到L0A/L0B，执行矩阵乘累加，结果通过Fixpipe写回Global Memory；
2. Cube核通过CrossCoreSetFlag通知Vector核，Vector核通过CrossCoreWaitFlag等待；
3. Vector核将Matmul结果从Global Memory搬运到UB，执行LeakyRelu激活计算，结果写回Global Memory。

## 计算步骤分析

融合算子的核心在于Cube和Vector两种计算单元的协同工作。下面分析各阶段的计算步骤。

### Cube核：Matmul矩阵乘计算

矩阵乘计算的数据流路径为：

```
GM(A:ND,half) -> L1(A:Nz,half) -> L0A(A:Nz,half) -
             │                  │                 │
          DataCopy            LoadData            │
          ND->Nz              Nz->Nz              │
                                                  │--->L0C(Nz,float) -> GM(C:ND,half)
                                                  │  │                  │
                                                  │ Mmad             Fixpipe
                                                  │ C=A×B       Nz->ND, float32->half
                                                  │
GM(B:ND,half) -> L1(B:Nz,half) -> L0B(B:Zn,half) -
             │                  │
          DataCopy            LoadData
          ND->Nz              Nz->Zn(转置)
```

| 步骤 | 计算内容 | 接口 | 内存层级 |
|:---:|:---|:---|:---|
| 1 | GM→L1：搬运A矩阵，ND格式转Nz格式 | DataCopy (Nd2Nz) | GM → L1 |
| 2 | GM→L1：搬运B矩阵，ND格式转Nz格式 | DataCopy (Nd2Nz) | GM → L1 |
| 3 | L1→L0A：加载A矩阵数据 | LoadData | L1 → L0A |
| 4 | L1→L0B：加载B矩阵数据（需转置） | LoadData | L1 → L0B |
| 5 | L0A×L0B→L0C：矩阵乘累加 | Mmad | L0A, L0B → L0C |
| 6 | L0C→GM：结果搬出，Nz转ND，float32转half | Fixpipe | L0C → GM |

其中步骤1~5沿K方向循环累加，K方向循环完毕后执行步骤6写出结果。

### 核间同步

| 步骤 | Cube核 | Vector核 |
|:---:|:---|:---|
| 同步 | CrossCoreSetFlag\<0x2, PIPE_FIX\> | CrossCoreWaitFlag(0) |
| 含义 | 通知Vector核"一块baseM×baseN的结果已就绪" | 等待Cube核完成当前块的计算 |

### Vector核：LeakyRelu激活计算

```
GM(C:ND,half) → UB(VECCALC,half) → UB(VECCALC,half) → GM(C:ND,half)
```

| 步骤 | 计算内容 | 接口 | 内存层级 |
|:---:|:---|:---|:---|
| 1 | GM→UB：搬运Matmul结果 | DataCopyPad | GM → UB |
| 2 | UB计算：LeakyRelu激活 | LeakyRelu | UB |
| 3 | UB→GM：写出激活结果 | DataCopyPad | UB → GM |

### 分核策略

输出矩阵C沿M和N方向分块，共分为4个分块，每个分块由1个Cube核完成Matmul计算，每个Cube核的计算结果由2个Vector核协同完成LeakyRelu计算。

分核参数说明：

- M方向分块数：M / singleCoreM = 512 / 256 = 2
- N方向分块数：N / singleCoreN = 1024 / 512 = 2
- 总Cube核数：2 × 2 = 4
- 总Vector核数：4 × 2 = 8（Cube:Vector = 1:2）
- 每个Cube核负责singleCoreM × singleCoreN的Matmul计算，每次计算产生baseM × baseN的结果
- 每个Vector核负责singleCoreM/2 × singleCoreN的计算，每次计算产生baseM/2 × baseN的结果

```
           N方向 (1024)
         ┌────────┬────────┐
  M方向  │Block0  │Block1  │  每块 256×512
 (512)   ├────────┼────────┤
         │Block2  │Block3  │  每块 256×512
         └────────┴────────┘

Block0: Cube核0 → Vec核0(上半128行) + Vec核1(下半128行)
Block1: Cube核2 → Vec核4(上半128行) + Vec核5(下半128行)
Block2: Cube核1 → Vec核2(上半128行) + Vec核3(下半128行)
Block3: Cube核3 → Vec核6(上半128行) + Vec核7(下半128行)
```

**约束条件**：

1. baseM/baseK/baseN满足16对齐
2. baseM/baseK/baseN能被singleCoreM/singleCoreK/singleCoreN整除
3. singleCoreM/singleCoreK/singleCoreN能被M/K/N整除，不支持非整切场景
4. Vector核数是Cube核数的2倍

## 算子实现

Matmul+LeakyRelu融合算子基于静态Tensor编程模式实现，核心逻辑封装在`KernelMatmul`类中，通过`__mix__(1, 2)`核调用符实现Cube和Vector核的协同调用：

```cpp
constexpr uint32_t CUBE_BLOCK = 16;  // half类型，Cube分型大小

template <
    uint32_t M, uint32_t K, uint32_t N,
    uint32_t singleCoreM, uint32_t singleCoreK, uint32_t singleCoreN,
    uint32_t baseM, uint32_t baseK, uint32_t baseN>
class KernelMatmul {
public:
    __aicore__ inline KernelMatmul() {}

    __aicore__ inline void Init(GM_ADDR a, GM_ADDR b, GM_ADDR c)
    {
        aGM.SetGlobalBuffer((__gm__ half*)a);
        bGM.SetGlobalBuffer((__gm__ half*)b);
        cGM.SetGlobalBuffer((__gm__ half*)c);
        if ASCEND_IS_AIC {
            InitGMOffsetsMatrix();
        }
        if ASCEND_IS_AIV {
            InitGMOffsetsVector();
        }
    }

    __aicore__ inline void Process()
    {
        // Cube核内存分配
        AscendC::LocalTensor<half> a1Local(AscendC::TPosition::A1, 0, baseM * baseK);
        AscendC::LocalTensor<half> a2Local(AscendC::TPosition::A2, 0, baseM * baseK);
        AscendC::LocalTensor<half> b1Local(AscendC::TPosition::B1, 256 * 1024, baseK * baseN);
        AscendC::LocalTensor<half> b2Local(AscendC::TPosition::B2, 0, baseK * baseN);
        AscendC::LocalTensor<float> cLocal(AscendC::TPosition::CO1, 0, baseM * baseN);

        // Vector核内存分配
        AscendC::LocalTensor<half> vecLocal(AscendC::TPosition::VECCALC, 0, baseM / 2 * baseN);

        constexpr uint32_t kLoopCount = singleCoreK / baseK;
        constexpr uint32_t mLoopCount = singleCoreM / baseM;
        constexpr uint32_t nLoopCount = singleCoreN / baseN;

        for (uint32_t mIndex = 0; mIndex < mLoopCount; mIndex++) {
            for (uint32_t nIndex = 0; nIndex < nLoopCount; nIndex++) {
                if ASCEND_IS_AIC {
                    // Cube核：沿K方向循环累加
                    for (uint32_t kIndex = 0; kIndex < kLoopCount; kIndex++) {
                        CopyInA(a1Local, kIndex, mIndex);
                        CopyInB(b1Local, kIndex, nIndex);
                        AscendC::SetFlag<AscendC::HardEvent::MTE2_MTE1>(EVENT_ID0);
                        AscendC::WaitFlag<AscendC::HardEvent::MTE2_MTE1>(EVENT_ID0);

                        DataLoadA(a1Local, a2Local, mIndex);
                        DataLoadB(b1Local, b2Local, nIndex);
                        AscendC::SetFlag<AscendC::HardEvent::MTE1_M>(EVENT_ID0);
                        AscendC::WaitFlag<AscendC::HardEvent::MTE1_M>(EVENT_ID0);

                        Compute(cLocal, a2Local, b2Local, kIndex, mIndex, nIndex);
                        AscendC::SetFlag<AscendC::HardEvent::M_MTE2>(EVENT_ID0);
                        AscendC::WaitFlag<AscendC::HardEvent::M_MTE2>(EVENT_ID0);
                    }
                    AscendC::SetFlag<AscendC::HardEvent::M_FIX>(EVENT_ID0);
                    AscendC::WaitFlag<AscendC::HardEvent::M_FIX>(EVENT_ID0);
                    CopyOut(cLocal, mIndex, nIndex);
                    // 核间同步：通知Vector核
                    AscendC::CrossCoreSetFlag<0x2, PIPE_FIX>(0);
                }
                if ASCEND_IS_AIV {
                    // Vector核：等待Cube核完成
                    AscendC::CrossCoreWaitFlag(0);
                    // LeakyRelu计算
                    LeaklyGeluCompute(vecLocal, mIndex, nIndex, baseM / 2 * baseN);
                }
            }
        }
    }

private:
    // Cube核分核：根据blockIdx计算M/N方向的偏移
    __aicore__ inline void InitGMOffsetsMatrix()
    {
        constexpr uint32_t mIter = M / singleCoreM;
        uint32_t mIterIdx = AscendC::GetBlockIdx() % mIter;
        uint32_t nIterIdx = AscendC::GetBlockIdx() / mIter;

        uint64_t gmOffsetA = mIterIdx * singleCoreM * K;
        uint64_t gmOffsetB = nIterIdx * singleCoreN;
        uint64_t gmOffsetC = mIterIdx * singleCoreM * N + nIterIdx * singleCoreN;
        aGM = aGM[gmOffsetA];
        bGM = bGM[gmOffsetB];
        cGM = cGM[gmOffsetC];
    }

    // Vector核分核：blockIdx/2映射到对应Cube核，%2区分上半/下半
    __aicore__ inline void InitGMOffsetsVector()
    {
        constexpr uint32_t mIter = M / singleCoreM;
        uint32_t mIterIdx = AscendC::GetBlockIdx() / 2 % mIter;
        uint32_t nIterIdx = AscendC::GetBlockIdx() / 2 / mIter;
        uint64_t gmOffsetC = mIterIdx * singleCoreM * N + nIterIdx * singleCoreN;
        cGM = cGM[gmOffsetC];
    }

    // GM→L1：搬运A矩阵，ND格式转Nz格式
    __aicore__ inline void CopyInA(AscendC::LocalTensor<half> a1Local, uint32_t kIndex, uint32_t mIndex)
    {
        AscendC::Nd2NzParams nd2nzA1Params;
        nd2nzA1Params.ndNum = 1;
        nd2nzA1Params.nValue = baseM;
        nd2nzA1Params.dValue = baseK;
        nd2nzA1Params.srcNdMatrixStride = 0;
        nd2nzA1Params.srcDValue = K;
        nd2nzA1Params.dstNzC0Stride = baseM;
        nd2nzA1Params.dstNzNStride = 1;
        nd2nzA1Params.dstNzMatrixStride = 0;
        AscendC::DataCopy(a1Local, aGM[kIndex * baseK + mIndex * K * baseM], nd2nzA1Params);
    }

    // GM→L1：搬运B矩阵，ND格式转Nz格式
    __aicore__ inline void CopyInB(AscendC::LocalTensor<half> b1Local, uint32_t kIndex, uint32_t nIndex)
    {
        AscendC::Nd2NzParams nd2nzB1Params;
        nd2nzB1Params.ndNum = 1;
        nd2nzB1Params.nValue = baseK;
        nd2nzB1Params.dValue = baseN;
        nd2nzB1Params.srcNdMatrixStride = 0;
        nd2nzB1Params.srcDValue = N;
        nd2nzB1Params.dstNzC0Stride = baseK;
        nd2nzB1Params.dstNzNStride = 1;
        nd2nzB1Params.dstNzMatrixStride = 0;
        AscendC::DataCopy(b1Local, bGM[kIndex * baseK * N + nIndex * baseN], nd2nzB1Params);
    }

    // L0A/L0B→L0C：矩阵乘累加
    __aicore__ inline void Compute(
        AscendC::LocalTensor<float> cLocal, AscendC::LocalTensor<half> a2Local,
        AscendC::LocalTensor<half> b2Local, uint32_t kIndex, uint32_t mIndex, uint32_t nIndex)
    {
        AscendC::MmadParams mmadParams;
        mmadParams.m = baseM;
        mmadParams.n = baseN;
        mmadParams.k = baseK;
        mmadParams.cmatrixInitVal = (kIndex == 0 ? true : false);  // K方向首次初始化，后续累加
        AscendC::Mmad(cLocal, a2Local, b2Local, mmadParams);
    }

    // L0C→GM：结果搬出，Nz转ND，float32转half
    __aicore__ inline void CopyOut(AscendC::LocalTensor<float> cLocal, uint32_t mIndex, uint32_t nIndex)
    {
        AscendC::FixpipeParamsV220 fixpipeParams;
        fixpipeParams.nSize = baseN;
        fixpipeParams.mSize = baseM;
        fixpipeParams.srcStride = baseM;
        fixpipeParams.dstStride = N;
        fixpipeParams.quantPre = QuantMode_t::F322F16;
        fixpipeParams.ndNum = 1;
        fixpipeParams.srcNdStride = 0;
        fixpipeParams.dstNdStride = 0;
        AscendC::Fixpipe(cGM[mIndex * baseM * N + nIndex * baseN], cLocal, fixpipeParams);
    }

    // Vector核：LeakyRelu激活计算
    __aicore__ inline void LeaklyGeluCompute(
        const AscendC::LocalTensor<half>& vecLocal, uint32_t mIndex, uint32_t nIndex, uint32_t tileLen)
    {
        uint32_t blockLen = baseN * sizeof(half);
        uint32_t srcStride = (N - baseN) * sizeof(half);
        uint32_t dstStride = 0;
        AscendC::DataCopyExtParams copyParams = {static_cast<uint16_t>(baseM / 2), blockLen, srcStride, dstStride, 0};
        AscendC::DataCopyPadExtParams<half> padParams = {true, 0, 0, 0};

        // blockIdx%2区分上半/下半
        uint32_t gmOffset = (mIndex * baseM * N + nIndex * baseN)
                            + AscendC::GetBlockIdx() % 2 * (baseM / 2 * N);

        // GM → UB
        AscendC::DataCopyPad<half>(vecLocal, cGM[gmOffset], copyParams, padParams);
        AscendC::SetFlag<AscendC::HardEvent::MTE2_V>(EVENT_ID0);
        AscendC::WaitFlag<AscendC::HardEvent::MTE2_V>(EVENT_ID0);

        // LeakyRelu计算
        AscendC::LeakyRelu(vecLocal, vecLocal, (half)0.001, tileLen);
        AscendC::SetFlag<AscendC::HardEvent::V_MTE3>(EVENT_ID0);
        AscendC::WaitFlag<AscendC::HardEvent::V_MTE3>(EVENT_ID0);

        // UB → GM
        copyParams.srcStride = 0;
        copyParams.dstStride = srcStride;
        AscendC::DataCopyPad<half>(cGM[gmOffset], vecLocal, copyParams);
    }

private:
    AscendC::GlobalTensor<half> aGM;
    AscendC::GlobalTensor<half> bGM;
    AscendC::GlobalTensor<half> cGM;
};

template <
    uint32_t M, uint32_t K, uint32_t N,
    uint32_t singleCoreM, uint32_t singleCoreK, uint32_t singleCoreN,
    uint32_t baseM, uint32_t baseK, uint32_t baseN>
__global__ __mix__(1, 2) void mmad_vec_custom(GM_ADDR a, GM_ADDR b, GM_ADDR c)
{
    AscendC::InitSocState();
    KernelMatmul<M, K, N, singleCoreM, singleCoreK, singleCoreN, baseM, baseK, baseN> op;
    op.Init(a, b, c);
    op.Process();
    AscendC::PipeBarrier<PIPE_ALL>();
}
```

核函数调用（Host端）：

```cpp
constexpr uint32_t M = 512, K = 512, N = 1024;
constexpr uint32_t singleCoreM = 256, singleCoreK = 512, singleCoreN = 512;
constexpr uint32_t baseM = 128, baseK = 64, baseN = 256;

uint32_t numBlocks = (M / singleCoreM) * (N / singleCoreN);  // 4个Cube核 + 8个Vector核

mmad_vec_custom<M, K, N, singleCoreM, singleCoreK, singleCoreN, baseM, baseK, baseN>
    <<<numBlocks, nullptr, stream>>>(aDevice, bDevice, cDevice);
```

关键实现要点：

- **核调用符**：`__mix__(1, 2)` 表示Cube:Vector核数比例为1:2，硬件自动分配4个Cube核和8个Vector核
- **核类型判断**：`ASCEND_IS_AIC` / `ASCEND_IS_AIV` 区分Cube核和Vector核的执行路径
- **分核策略**：M-N二维切分，Cube核用`blockIdx % mIter`和`blockIdx / mIter`确定M/N方向编号；Vector核用`blockIdx / 2`映射到对应Cube核，`blockIdx % 2`区分上半/下半
- **核间同步**：Cube核通过`CrossCoreSetFlag`通知、Vector核通过`CrossCoreWaitFlag`等待，确保Matmul结果就绪后才开始LeakyRelu计算
- **K方向累加**：`Mmad`的`cmatrixInitVal`参数在K方向首次迭代时为true（初始化C矩阵），后续为false（累加到C矩阵）
- **格式转换**：`DataCopy`的Nd2Nz参数完成ND到Nz格式转换，`Fixpipe`完成Nz到ND格式转换及float32到half类型转换

### printf

该接口提供CPU域/NPU域调试场景下的格式化输出功能。

在算子kernel侧实现代码中需要输出日志信息的地方调用printf接口打印相关内容。

示例如下：

```
#include "kernel_operator.h"
AscendC::printf("fmt string %d\n", 0x123);
AscendC::PRINTF("fmt string %d\n", 0x123);
```

### DumpTensor

基于算子工程开发的算子，可以使用该接口Dump指定Tensor的内容。同时支持打印自定义的附加信息（仅支持uint32\_t数据类型的信息），比如打印当前行号等。

在算子kernel侧实现代码中需要打印Tensor数据的地方调用DumpTensor接口打印相关内容。样例如下：

```
// Mmad计算完成后，打印L0C上的结果
AscendC::Mmad(cLocal, a2Local, b2Local, mmadParams);
AscendC::DumpTensor(cLocal, 1, 16);
```

打印示例如下：


## 性能调试

### msProf工具介绍

msProf工具是单算子性能分析工具。包含msprof op和msprof op simulator两种使用方式。该工具协助用户定位算子内存、算子代码以及算子指令的异常，实现全方位的算子调优。当前支持基于不同运行模式（上板或仿真）和不同文件形式（可执行文件或算子二进制.o文件）进行性能数据的采集和自动解析。

- 上板性能采集

    通过上板性能采集，可以直接测定算子昇腾AI处理器上的运行时间。该方式适合在板环境中快速定位算子性能问题。

    基于可执行文件demo通过msprof op执行算子调优：
    ```
    msprof op ./demo
    ```

    - 性能数据说明  
      命令完成后，会在默认目录下生成以"OPPROF_{timestamp}_XXX"命名的文件夹,性能数据文件夹结构示例如下：

      ```bash
      ├──dump                       # 原始的性能数据，用户无需关注
      ├──ArithmeticUtilization.csv  # cube/vector指令cycle占比
      ├──L2Cache.csv                # L2 Cache命中率，影响MTE2，建议合理规划数据搬运逻辑，增加命中率
      ├──Memory.csv                 # UB，L1和主存储器读写带宽速率
      ├──MemoryL0.csv               # L0A，L0B，和L0C读写带宽速率
      ├──MemoryUB.csv               # Vector和Scalar到UB的读写带宽速率
      ├──OpBasicInfo.csv            # 算子基础信息
      ├──PipeUtilization.csv        # 采集计算单元和搬运单元耗时和占比
      ├──ResourceConflictRatio.csv  # UB上的 bank group、bank conflict和资源冲突率在所有指令中的占比
      └──visualize_data.bin         # MindStudio Insight呈现文件
      ```

更多msProf工具使用方式请参考[MindStudio工具](https://www.hiascend.com/document/redirect/CannCommercialToolOpDev)算子调优（msProf）中的内容。
