# 中级性能优化

本节介绍Add矢量算子的性能调优方法，通过7个渐进式优化步骤（标量→向量→多核→大块搬运→双缓冲→L2 Cache bypass→Bank Conflict优化），展示从基准程序到近理论峰值的完整调优路径。

详细内容请参考 [Add性能调优样例](../../../../../examples/01_simd_cpp_api/04_best_practices/00_vector_compute_practices/add_high_performance/README.md)，该样例涵盖：

- 7个优化Case的逐步讲解与性能对比（Atlas A2与Ascend 950双平台数据）
- 每步优化的原理说明、硬件引擎与数据流向（MTE2/MTE3/Vector）、硬件约束
- 功能调试（printf、DumpTensor）与性能调试（msProf）方法
- 最终优化效果：相比基准Case 0性能提升6711倍
