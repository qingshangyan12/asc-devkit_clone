# 入门功能落地<a name="ZH-CN_TOPIC_000000_ADD_ENTRY"></a>

本节以Add（向量加法）算子为例，介绍基于Ascend C静态Tensor编程模型实现单核向量算子的基本方法，帮助开发者快速入门SIMD算子开发。

## 算子概述

Add算子实现两个向量的逐元素加法运算，计算公式为：

$$
z = x + y
$$

- x：输入，形状为[8192, 8192]，数据类型为half；
- y：输入，形状为[8192, 8192]，数据类型为half；
- z：输出，形状为[8192, 8192]，数据类型为half；

Add算子的计算逻辑遵循"搬入-计算-搬出"三段式流水结构：

1. 将输入数据x和y从Global Memory搬运到Unified Buffer；
2. 在Unified Buffer上对x和y执行向量加法操作；
3. 将计算结果从Unified Buffer搬运到Global Memory。

```
Global Memory               Unified Buffer (UB)           Global Memory
┌──────────┐               ┌──────────────┐             ┌──────────┐
│  x (GM)  │───DataCopy───▶│  xLocal (UB) │             │          │
└──────────┘               └──────────────┘             │  z (GM)  │
┌──────────┐               ┌──────────────┐             │          │
│  y (GM)  │───DataCopy───▶│  yLocal (UB) │             └──────────┘
└──────────┘               └──────────────┘                  ▲
                                  │                     DataCopy
                          Add(z, x, y)                        │
                           ┌──────────────┐                   │
                           │  zLocal (UB) │───────────────────┘
                           └──────────────┘
```

## 算子分析

### 明确分核与分块策略

本样例中输入数据shape为[8192, 8192]，总数据量为8192 × 8192 = 67108864个half元素。采用单核处理，`dataCopyLen = 4096`，每次搬运4096个half元素，循环次数为67108864 / 4096 = 16384次。

样例配置：
- 核数：1（splitM=1, splitN=1）
- `dataCopyLen = 4096`，单次搬运数据量为 4096 × 2B = 8192 Byte
- 单次`Add`处理两个输入Tensor，处理的总数据量为 16384 Byte

### Kernel类定义

定义`KernelAdd`模板类，模板参数包括`totalM`（矩阵行数）、`totalN`（矩阵列数）、`splitM`（行方向切分数）、`splitN`（列方向切分数）和`dataCopyLen`（单次搬运数据量）：

```cpp
template <uint32_t totalM, uint32_t totalN, uint32_t splitM, uint32_t splitN, uint32_t dataCopyLen>
class KernelAdd {
public:
    __aicore__ inline KernelAdd() = default;
    __aicore__ inline void Init(GM_ADDR x, GM_ADDR y, GM_ADDR z);
    __aicore__ inline void ProcessSingle();
private:
    __aicore__ inline uint32_t GetTotalBlocks() const { return AscendC::DivCeil(totalElementsPerCore, dataCopyLen); }

    // 单缓冲地址布局
    static constexpr uint32_t xAddr = 0;
    static constexpr uint32_t yAddr = MAX_DATA_COPY_LEN * sizeof(half);
    static constexpr uint32_t zAddr = yAddr + MAX_DATA_COPY_LEN * sizeof(half);

    AscendC::GlobalTensor<half> xGm;
    AscendC::GlobalTensor<half> yGm;
    AscendC::GlobalTensor<half> zGm;
    uint32_t singleCoreM;
    uint32_t singleCoreN;
    uint32_t totalElementsPerCore;
};
```

UB地址布局如下（单缓冲，仅需3块）：

```
UB内存分配（单缓冲）：
┌──────────────┐
│  xLocal      │  0x00000
│  16384*2B    │
├──────────────┤
│  yLocal      │  0x08000 (32768)
│  16384*2B    │
├──────────────┤
│  zLocal      │  0x10000 (65536)
│  16384*2B    │
└──────────────┘
```

### Init函数实现

Init函数完成Global Memory地址初始化，根据核ID和切分策略计算当前核应处理的数据偏移：

```cpp
__aicore__ inline void Init(GM_ADDR x, GM_ADDR y, GM_ADDR z)
{
    uint32_t blockIdx = AscendC::GetBlockIdx();
    uint32_t blockIdxM = blockIdx;
    constexpr uint32_t baseCoreM = totalM / splitM;
    constexpr uint32_t remainderM = totalM % splitM;
    uint32_t actualCoreM;
    uint32_t startM;
    if (blockIdxM < remainderM) {
        actualCoreM = baseCoreM + 1;
        startM = blockIdxM * actualCoreM;
    } else {
        actualCoreM = baseCoreM;
        startM = remainderM * (baseCoreM + 1) + (blockIdxM - remainderM) * baseCoreM;
    }
    this->singleCoreM = actualCoreM;
    this->singleCoreN = totalN;
    this->totalElementsPerCore = this->singleCoreM * this->singleCoreN;
    xGm.SetGlobalBuffer((__gm__ half*)x + startM * totalN, this->totalElementsPerCore);
    yGm.SetGlobalBuffer((__gm__ half*)y + startM * totalN, this->totalElementsPerCore);
    zGm.SetGlobalBuffer((__gm__ half*)z + startM * totalN, this->totalElementsPerCore);
}
```

单核场景下（splitM=1, splitN=1），`actualCoreM = totalM = 8192`，`totalElementsPerCore = 8192 × 8192 = 67108864`。

### 核函数定义与调用

```cpp
template <uint32_t totalM, uint32_t totalN, uint32_t splitM, uint32_t splitN, uint32_t dataCopyLen>
__vector__ __global__ void add_custom(GM_ADDR x, GM_ADDR y, GM_ADDR z)
{
    AscendC::InitSocState();
    KernelAdd<totalM, totalN, splitM, splitN, dataCopyLen> op;
    op.Init(x, y, z);
    op.ProcessSingle();
    AscendC::PipeBarrier<PIPE_ALL>();
}
```

在Host侧使用内核调用符`<<<>>>`调用核函数：

```cpp
constexpr uint32_t totalM = 8192;
constexpr uint32_t totalN = 8192;
constexpr uint32_t splitM = 1;
constexpr uint32_t splitN = 1;
constexpr uint32_t dataCopyLen = 4096;
constexpr uint32_t numBlocks = splitM * splitN;

add_custom<totalM, totalN, splitM, splitN, dataCopyLen>
    <<<numBlocks, nullptr, stream>>>(inputDevice[0], inputDevice[1], outputDevice[0]);
```

## 数据搬入

数据搬入阶段将输入数据从Global Memory搬运到Unified Buffer。本样例通过静态地址分配UB空间，并使用`DataCopy`接口完成GM到UB的数据搬运。

### UB内存初始化

使用静态地址创建LocalTensor，指定位置为`VECCALC`：

```cpp
AscendC::LocalTensor<half> xLocal(AscendC::TPosition::VECCALC, xAddr, MAX_DATA_COPY_LEN);
AscendC::LocalTensor<half> yLocal(AscendC::TPosition::VECCALC, yAddr, MAX_DATA_COPY_LEN);
AscendC::LocalTensor<half> zLocal(AscendC::TPosition::VECCALC, zAddr, MAX_DATA_COPY_LEN);
```

### DataCopy搬入

在每个循环迭代中，计算当前轮次应搬运的数据偏移和长度，使用`DataCopy`将输入数据从Global Memory搬运到Unified Buffer：

```cpp
uint32_t totalLoop = GetTotalBlocks();

for (uint32_t loopIdx = 0; loopIdx < totalLoop; loopIdx++) {
    uint32_t startElement = loopIdx * dataCopyLen;
    uint32_t remainElements = totalElementsPerCore - startElement;
    uint32_t curLen = remainElements > dataCopyLen ? dataCopyLen : remainElements;

    // 等待上一轮计算读完成，确保UB缓冲区可安全写入
    if (loopIdx != 0) {
        AscendC::WaitFlag<AscendC::HardEvent::V_MTE2>(EVENT_ID0);
    }

    // 将数据从Global Memory搬入Unified Buffer
    AscendC::DataCopy(xLocal, xGm[startElement], curLen);
    AscendC::DataCopy(yLocal, yGm[startElement], curLen);
```

其中`WaitFlag<AscendC::HardEvent::V_MTE2>`确保上一轮Vector计算已读完UB数据，避免搬运覆盖尚未消费的数据。`curLen`处理了最后一轮数据量不足`dataCopyLen`的情况。

## 数据计算

数据计算阶段在Unified Buffer上执行向量加法运算。本样例使用`AscendC::Add`向量指令，单次处理`curLen`个half元素，充分利用AI Core的向量计算单元。

```cpp
    // 等待搬入完成，确保数据已就绪
    AscendC::SetFlag<AscendC::HardEvent::MTE2_V>(EVENT_ID0);
    AscendC::WaitFlag<AscendC::HardEvent::MTE2_V>(EVENT_ID0);

    // 等待上一轮写出完成，避免读写UB冲突
    if (loopIdx != 0) {
        AscendC::WaitFlag<AscendC::HardEvent::MTE3_V>(EVENT_ID0);
    }

    // 执行向量加法
    AscendC::Add(zLocal, xLocal, yLocal, curLen);
```

关键点：
- `SetFlag<AscendC::HardEvent::MTE2_V>`与`WaitFlag<AscendC::HardEvent::MTE2_V>`：确保数据搬入完成后再开始计算，避免读到未就绪的数据。
- `AscendC::Add(zLocal, xLocal, yLocal, curLen)`：向量加法指令，一次完成`curLen`个half元素的加法运算。
- `WaitFlag<AscendC::HardEvent::MTE3_V>`：确保上一轮写出已完成，避免UB读写冲突。

### 事件同步机制

单缓冲模式下，搬入、计算、搬出三个阶段串行执行，使用单个Event ID（EVENT_ID0）进行同步，确保各阶段按序执行：

- `V_MTE2`：Vector计算完成后，通知可以开始搬入下一块数据
- `MTE2_V`：数据搬入完成后，通知可以开始Vector计算
- `V_MTE3`：Vector计算完成后，通知可以开始写出数据
- `MTE3_V`：数据写出完成后，通知Vector可以开始下一轮计算

```
循环迭代 i:
  [搬入] ──MTE2_V──▶ [计算] ──V_MTE3──▶ [搬出]
                            ──V_MTE2──▶ (下一轮搬入)
                            ◀──MTE3_V── (上一轮写出完成)
```

## 数据搬出

数据搬出阶段将计算结果从Unified Buffer写回Global Memory：

```cpp
    // 计算完成，通知下一轮可以开始搬入
    if (loopIdx != (totalLoop - 1)) {
        AscendC::SetFlag<AscendC::HardEvent::V_MTE2>(EVENT_ID0);
    }
    // 通知写出就绪
    AscendC::SetFlag<AscendC::HardEvent::V_MTE3>(EVENT_ID0);
    AscendC::WaitFlag<AscendC::HardEvent::V_MTE3>(EVENT_ID0);

    // 将计算结果从Unified Buffer搬出到Global Memory
    AscendC::DataCopy(zGm[startElement], zLocal, curLen);

    // 写出完成，通知下一轮Vector计算可以开始
    if (loopIdx != (totalLoop - 1)) {
        AscendC::SetFlag<AscendC::HardEvent::MTE3_V>(EVENT_ID0);
    }
}
```

其中`SetFlag<AscendC::HardEvent::V_MTE3>`与`WaitFlag<AscendC::HardEvent::V_MTE3>`确保Vector计算完成后再写出，避免写出未完成的数据。`SetFlag<AscendC::HardEvent::MTE3_V>`在写出完成后通知下一轮的Vector计算可以安全进行。

### ProcessSingle函数完整实现

将数据搬入、数据计算、数据搬出三个阶段组合起来，`ProcessSingle`函数的完整实现如下：

```cpp
__aicore__ inline void ProcessSingle()
{
    AscendC::LocalTensor<half> xLocal(AscendC::TPosition::VECCALC, xAddr, MAX_DATA_COPY_LEN);
    AscendC::LocalTensor<half> yLocal(AscendC::TPosition::VECCALC, yAddr, MAX_DATA_COPY_LEN);
    AscendC::LocalTensor<half> zLocal(AscendC::TPosition::VECCALC, zAddr, MAX_DATA_COPY_LEN);

    uint32_t totalLoop = GetTotalBlocks();

    for (uint32_t loopIdx = 0; loopIdx < totalLoop; loopIdx++) {
        uint32_t startElement = loopIdx * dataCopyLen;
        uint32_t remainElements = totalElementsPerCore - startElement;
        uint32_t curLen = remainElements > dataCopyLen ? dataCopyLen : remainElements;

        // === 数据搬入 ===
        if (loopIdx != 0) {
            AscendC::WaitFlag<AscendC::HardEvent::V_MTE2>(EVENT_ID0);
        }
        AscendC::DataCopy(xLocal, xGm[startElement], curLen);
        AscendC::DataCopy(yLocal, yGm[startElement], curLen);
        AscendC::SetFlag<AscendC::HardEvent::MTE2_V>(EVENT_ID0);
        AscendC::WaitFlag<AscendC::HardEvent::MTE2_V>(EVENT_ID0);

        // === 数据计算 ===
        if (loopIdx != 0) {
            AscendC::WaitFlag<AscendC::HardEvent::MTE3_V>(EVENT_ID0);
        }
        AscendC::Add(zLocal, xLocal, yLocal, curLen);

        // === 数据搬出 ===
        if (loopIdx != (totalLoop - 1)) {
            AscendC::SetFlag<AscendC::HardEvent::V_MTE2>(EVENT_ID0);
        }
        AscendC::SetFlag<AscendC::HardEvent::V_MTE3>(EVENT_ID0);
        AscendC::WaitFlag<AscendC::HardEvent::V_MTE3>(EVENT_ID0);
        AscendC::DataCopy(zGm[startElement], zLocal, curLen);
        if (loopIdx != (totalLoop - 1)) {
            AscendC::SetFlag<AscendC::HardEvent::MTE3_V>(EVENT_ID0);
        }
    }
}
```
