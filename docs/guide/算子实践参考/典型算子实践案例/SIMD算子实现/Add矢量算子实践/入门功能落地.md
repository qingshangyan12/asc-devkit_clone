# 入门功能落地

本节介绍Add矢量算子的入门实现，包括基于Ascend C编程模型的"搬入-计算-搬出"三段式流水结构、功能调试（printf、DumpTensor）和性能调试（msProf）方法。

详细内容请参考 [Add入门样例](../../../../../examples/01_simd_cpp_api/00_introduction/01_vector/add/README.md)，该样例涵盖：

- 算子实现：Global Tensor与Local Tensor的使用、DataCopy数据搬运、Add向量计算
- 功能调试：printf格式化输出、DumpTensor张量数据打印
- 编译运行：bisheng编译与执行
- 性能调试：msProf工具上板与仿真性能采集
