## 从入门到优化

[入门功能落地](./入门功能落地.md)实现了 Matmul 算子的基本功能：A/B 矩阵经 MTE2 的 `DataCopy` 从 GM 搬入 L1（ND→NZ 转换），经 MTE1 的 `LoadData` 搬入 L0A/L0B（NZ→ZZ/ZN 转换），Cube 单元执行 `Mmad`，结果经 `Fixpipe` 从 L0C 写回 GM。

入门实现存在以下**性能瓶颈**——这也是中级优化的起点：

| 瓶颈 | 入门实现的问题 | 对应的中级优化 |
|------|---------------|---------------|
| **L1/L0 单缓冲区** | A、B 矩阵在 L1 和 L0 中各只有一份缓冲区，下一轮数据必须等上一轮消费完才能搬入 | 改为 Ping-Pong 双缓冲，让数据搬运和计算重叠执行 |
| **流水线串行执行** | 当前实现中使用PipeBarrier和SetFlag/WaitFlag进行流水线同步，但未采用双缓冲机制，MTE2、MTE1、M、FIX各硬件单元无法充分流水并行 | 通过双缓冲和硬件事件同步，使四个单元流水并行，显著提升吞吐 |
| **多核切分固定** | 硬编码 `M / singleCoreM` 计算核数分配，仅适用于固定矩阵规模和核数场景 | 通用切分策略，支撑任意核数和矩阵规模的自动分配 |
| **B 矩阵搬运等待** | A 和 B 依次搬运，B 数据到位晚导致 L1 缓冲区欠载 | 优先搬 B → 先 B 后 A 调度 |
| MTE2单条搬运指令粒度小 | DataCopyIn 每次搬入一个 `baseM×baseK` 块，MTE2 指令发射次数多 | 大包搬运 → 一次搬入 `stepKa` 个 block |
| MTE1 指令队列压力大 | LoadData2D 一次只能搬一个 16×K 切片，需 for 循环多次发射 | LoadData3D → 单条指令完成搬运 |
| Tiling 参数运行时计算 | 所有参数在 kernel 内用 Scalar 计算，增加流水线停顿 | 常量 Tiling → 编译期确定 |
| L0C 写回阻塞 | `Fixpipe` 与 Mmad 串行，Cube 等待写回完成再计算 | UnitFlag → 512B 粒度 MMAD-FIXPIPE 重叠 |
| L2Cache 未充分利用 | 当前实现中B矩阵每次均从GM读取，多核反复访问GM导致MTE2带宽压力大；L2Cache纯读带宽约3~4倍于GM，但当前实现未能利用这一特性 | 沿M方向切分A矩阵，使B矩阵跨轮驻留L2Cache，减少GM访问次数，有效降低MTE2耗时 |

## 详细内容

详细内容请参考 [Matmul 基础API最佳实践样例](https://gitcode.com/cann/asc-devkit/tree/master/examples/01_simd_cpp_api/05_best_practices/01_matrix_compute/matmul_basic_api_high_performance)，其中中级性能优化涵盖4个核心步骤：

- 1、**[L1/L0 双缓冲 Ping-Pong 布局](https://gitcode.com/cann/asc-devkit/blob/master/examples/01_simd_cpp_api/05_best_practices/01_matrix_compute/matmul_basic_api_high_performance/README.md#1-l1l0-双缓冲-ping-pong-布局)**：DataCopyIn（GM→L1）、DataLoad（L1→L0）与 Compute 三个阶段形成三级流水
- 2、**[细粒度流水同步](https://gitcode.com/cann/asc-devkit/blob/master/examples/01_simd_cpp_api/05_best_practices/01_matrix_compute/matmul_basic_api_high_performance/README.md#2-细粒度流水同步)**：四类硬件事件（MTE2_MTE1、MTE1_MTE2、MTE1_M、M_MTE1）精确控制流水线
- 3、**[多核并行切分](https://gitcode.com/cann/asc-devkit/blob/master/examples/01_simd_cpp_api/05_best_practices/01_matrix_compute/matmul_basic_api_high_performance/README.md#3-多核并行切分)**：M/N 方向均匀切分，支撑任意核数和矩阵规模的自动分配
- 4、**[DataCopyIn 优先搬运 B 矩阵](https://gitcode.com/cann/asc-devkit/blob/master/examples/01_simd_cpp_api/05_best_practices/01_matrix_compute/matmul_basic_api_high_performance/README.md#4-datacopyin-优先搬运-b-矩阵)**：先 B 后 A 调度，缓解 L1 缓冲区欠载

每步优化均包含原理说明与数据流向说明，并附有功能调试（printf、DumpTensor）与性能调试（msProf）方法说明。
