# 入门功能落地<a name="ZH-CN_TOPIC_000000_ADD_ENTRY"></a>

本节以Matmul（矩阵乘法）算子为例，介绍基于Ascend C编程模型和Cube计算单元实现矩阵算子的基本方法。

## 算子概述

Matmul计算公式：
$$
C_{M, N} = A_{M, K} \times B_{K, N}
$$

- A：左矩阵，形状[M, K]，数据类型half
- B：右矩阵，形状[K, N]，数据类型half
- C：结果矩阵，形状[M, N]，数据类型half

本样例中 M=128, K=128, N=128，使用2个核并行计算。

## 算子实现

矩阵乘算子的计算逻辑遵循"搬入-格式转换-计算-搬出"的四级流水结构：

1. 将输入数据从Global Memory搬入L1 Buffer，同步完成ND→NZ格式转换；
2. 将数据从L1 Buffer搬入L0 Buffer，同步完成NZ→ZZ/ZN格式转换；
3. 在L0上执行矩阵乘计算，结果暂存于L0C；
4. 将计算结果从L0C搬出到Global Memory，同步完成NZ→ND格式转换和FP32→FP16精度转换。

完整代码实现如下：

```cpp
constexpr uint32_t CUBE_BLOCK = 16;
constexpr uint32_t M = 128;
constexpr uint32_t K = 128;
constexpr uint32_t N = 128;

__global__ __cube__ void matmul_custom(__gm__ uint8_t* a, __gm__ uint8_t* b, __gm__ uint8_t* c)
{
    AscendC::InitSocState();

    // Global Tensor定义
    AscendC::GlobalTensor<half> aGm, bGm, cGm;
    aGm.SetGlobalBuffer((__gm__ half*)a, M * K);
    bGm.SetGlobalBuffer((__gm__ half*)b, K * N);
    cGm.SetGlobalBuffer((__gm__ half*)c, M * N);

    // 分核：获取当前核编号，计算该核在M方向的起始偏移
    uint32_t blockIdx = AscendC::GetBlockIdx();
    uint32_t localM = M / 2;

    // Local Tensor定义
    AscendC::LocalTensor<half> l1aLocal(AscendC::TPosition::A1, 0, localM * K);
    AscendC::LocalTensor<half> l1bLocal(AscendC::TPosition::B1, 256 * 1024, K * N);
    AscendC::LocalTensor<half> l0aLocal(AscendC::TPosition::A2, 0, localM * K);
    AscendC::LocalTensor<half> l0bLocal(AscendC::TPosition::B2, 0, K * N);
    AscendC::LocalTensor<float> l0cLocal(AscendC::TPosition::CO1, 0, localM * N);

    // Stage1: GM -> L1，同步ND→NZ格式转换
    AscendC::DataCopy(l1aLocal, aGm[blockIdx * localM * K],
        AscendC::Nd2NzParams{1, static_cast<uint16_t>(localM), K, 0, K, static_cast<uint16_t>(localM), 1, 0});
    AscendC::DataCopy(l1bLocal, bGm,
        AscendC::Nd2NzParams{1, K, N, 0, N, K, 1, 0});
    AscendC::PipeBarrier<PIPE_ALL>();

    // Stage2: L1 -> L0，同步NZ→ZZ（A矩阵）/ NZ→ZN（B矩阵）格式转换
#if defined(__NPU_ARCH__) && (__NPU_ARCH__ == 2201)
    for (int i = 0; i < localM / CUBE_BLOCK; ++i) {
        AscendC::LoadData(l0aLocal[i * K * CUBE_BLOCK], l1aLocal[i * 512 / sizeof(half)],
            AscendC::LoadData2DParams{0, K / CUBE_BLOCK, static_cast<uint16_t>(localM / CUBE_BLOCK), 0, 0, false, 0});
    }
    for (int i = 0; i < K / CUBE_BLOCK; ++i) {
        AscendC::LoadData(l0bLocal[i * N * CUBE_BLOCK], l1bLocal[i * 512 / sizeof(half)],
            AscendC::LoadData2DParams{0, N / CUBE_BLOCK, K / CUBE_BLOCK, 0, 0, true, 0});
    }
#elif defined(__NPU_ARCH__) && (__NPU_ARCH__ == 3510)
    AscendC::LoadData(l0aLocal, l1aLocal,
        AscendC::LoadData2DParamsV2{0, 0, static_cast<uint16_t>(AscendC::DivCeil(localM, CUBE_BLOCK)),
            AscendC::DivCeil(K * sizeof(half), 32), static_cast<int32_t>(AscendC::DivCeil(localM, CUBE_BLOCK)),
            static_cast<uint16_t>(AscendC::DivCeil(localM, CUBE_BLOCK)), false, 0});
    AscendC::LoadData(l0bLocal, l1bLocal,
        AscendC::LoadData2DParamsV2{0, 0, AscendC::DivCeil(K, CUBE_BLOCK), AscendC::DivCeil(N * sizeof(half), 32),
            AscendC::DivCeil(K, CUBE_BLOCK), AscendC::DivCeil(N, CUBE_BLOCK), true, 0});
#endif
    AscendC::PipeBarrier<PIPE_ALL>();

    // Stage3: L0上执行矩阵乘计算
    AscendC::Mmad(l0cLocal, l0aLocal, l0bLocal,
        AscendC::MmadParams{static_cast<uint16_t>(localM), static_cast<uint16_t>(N), static_cast<uint16_t>(K),
            static_cast<uint16_t>(0), false, true});
    AscendC::PipeBarrier<PIPE_ALL>();

    // Stage4: L0C -> GM，同步NZ→ND格式转换和FP32→FP16精度转换
    AscendC::Fixpipe(cGm[blockIdx * localM * N], l0cLocal,
        AscendC::FixpipeParamsV220{N, static_cast<uint16_t>(localM), static_cast<uint16_t>(localM), N, false,
            QuantMode_t::F322F16, 0, 1, 0, 0, 0});
    AscendC::PipeBarrier<PIPE_ALL>();
}
```

下面按步骤说明各环节的做法和原因。

1. **分核处理**：
    
    通过`GetBlockIdx()`获取当前核编号，计算出M方向起始偏移 `blockIdx * localM`，每个核负责 localM = M/2 = 64 行。A矩阵按行切分，B矩阵每个核使用完整数据。将矩阵沿M方向切分到多核并行，各核独立计算、各自写回GM的不同区域，无需跨核通信，可实现算力的线性扩展。

2. **stage 1：数据搬运（GM→L1，同步ND→NZ）**：
    
    调用`DataCopy`将A矩阵当前核负责的部分和完整B矩阵从GM搬运到L1，通过`Nd2NzParams`配置随路完成ND→NZ格式转换。Cube计算单元要求数据以NZ分形格式（16×16分形、列优先）组织，可直接读取完整分形送入计算，而Host传入数据为ND行优先格式，因此首次搬运时同步完成转换。

3. **stage 2：数据搬运（L1→L0，同步NZ→ZZ/ZN）**：
    
    调用`LoadData`将数据从L1搬运到L0A/L0B，通过`LoadData2DParams`（2201架构循环逐分形搬运，`ifTranspose`控制转置）或`LoadData2DParamsV2`（3510架构一次性搬运）完成格式转换。Mmad要求左矩阵为ZZ格式（分形内行优先）、右矩阵为ZN格式（分形内列优先且整体转置），与L1中的NZ格式不同，因此搬运时同步转换。

4. **stage 3：执行矩阵乘计算**：
    
    调用`Mmad`在L0上执行 `C[localM, N] += A[localM, K] × B[K, N]`，结果以float32存入L0C。当K维度分多次计算时，通过`MmadParams::cmatrixInitVal`控制——首次true清零累加器，后续false累加。本样例K=128不分块，单次Mmad即可完成。

5. **stage 4：计算结果搬出（L0C→GM，同步NZ→ND + FP32→FP16）**：
    
    调用`Fixpipe`将结果搬运到`cGm[blockIdx * localM * N]`，同步完成NZ→ND格式转换和FP32→FP16精度转换。Mmad输出为NZ分形格式且精度float32，而最终输出需要ND行优先格式和half精度，Fixpipe在搬出时同步完成这两个变换。

6. **流水同步**：

    DataCopy、LoadData、Mmad和Fixpipe分别由MTE2、MTE1、Cube、Fix等不同硬件流水线执行，各阶段之间存在数据依赖。代码中使用`PipeBarrier<PIPE_ALL>()`在各阶段之间插入全局同步，确保所有流水线操作完成后才进入下一步。

## 功能调试

### printf

该接口提供CPU域或NPU域调试场景下的格式化输出功能。

在算子kernel侧实现代码中需要输出日志信息的地方调用printf接口打印相关内容。

示例如下：

```cpp
AscendC::printf("matmul blockIdx=%d\n", AscendC::GetBlockIdx());
```

> [!CAUTION]注意 
>printf（PRINTF）接口打印功能会对算子实际运行的性能带来一定影响，通常在调测阶段使用。开发者可以按需通过设置ASCENDC\_DUMP=0的方式关闭打印功能。

### DumpTensor

基于算子工程开发的算子，可以使用该接口Dump指定Tensor的内容。同时支持打印自定义的附加信息（仅支持uint32\_t数据类型的信息），比如打印当前行号等。

在算子kernel侧实现代码中需要打印Tensor数据的地方调用DumpTensor接口打印相关内容。样例如下：

```cpp
AscendC::DumpTensor(cLocal, baseM * baseN);
```

> [!CAUTION]注意 
>DumpTensor接口打印功能会对算子实际运行的性能带来一定影响，通常在调测阶段使用。开发者可以按需通过设置ASCENDC\_DUMP=0来关闭打印功能。

## 性能调试

### msProf工具介绍
msProf工具是单算子性能分析工具。包含msprof op和msprof op simulator两种使用方式。该工具协助用户定位算子内存、算子代码以及算子指令的异常，实现全方位的算子调优。当前支持基于不同运行模式（上板或仿真）和不同文件形式（可执行文件或算子二进制.o文件）进行性能数据的采集和自动解析。

- 上板性能采集

    通过上板性能采集，可以直接测定算子在昇腾AI处理器上的运行时间。该方式适合在板环境中快速定位算子性能问题。

    基于可执行文件demo通过msprof op执行算子调优：
    ```
    msprof op ./demo
    ```

- 性能数据说明  
    命令完成后，会在默认目录下生成以“OPPROF_{timestamp}_XXX”命名的文件夹,性能数据文件夹结构示例如下：

    ```bash
    ├──dump                       # 原始的性能数据，用户无需关注
    ├──ArithmeticUtilization.csv  # cube/vector指令cycle占比
    ├──L2Cache.csv                # L2 Cache命中率，影响MTE2，建议合理规划数据搬运逻辑，增加命中率
    ├──Memory.csv                 # UB，L1和主存储器读写带宽速率
    ├──MemoryL0.csv               # L0A，L0B，和L0C读写带宽速率
    ├──MemoryUB.csv               # Vector和Scalar到UB的读写带宽速率
    ├──OpBasicInfo.csv            # 算子基础信息
    ├──PipeUtilization.csv        # 采集计算单元和搬运单元耗时和占比
    ├──ResourceConflictRatio.csv  # UB上的 bank group、bank conflict和资源冲突率在所有指令中的占比
    └──visualize_data.bin         # MindStudio Insight呈现文件
    ```

更多msProf工具使用方式请参考[MindStudio工具](https://www.hiascend.com/document/redirect/CannCommercialToolOpDev)算子调优（msProf）中的内容。

完整样例代码请参见[matmul样例](https://gitcode.com/cann/asc-devkit/tree/master/examples/01_simd_cpp_api/00_introduction/02_matrix/matmul)。
