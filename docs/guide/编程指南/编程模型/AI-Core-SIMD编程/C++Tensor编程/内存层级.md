## 引言

AscendC采用LocalTensor/GlobalTensor抽象管理内存，LocalTensor对应片上存储（UB、L1、L0A、L0B、L0C等），GlobalTensor对应全局存储（GM）。Tensor携带数据类型、形状信息、内存位置等属性，开发者通过Tensor进行数据搬运、计算操作。

本章旨在帮助开发者建立对AscendC内存管理体系的系统化认知，掌握Tensor创建、内存分配、形状管理的方法。全文遵循「物理架构—基础能力内存管理—扩展能力Layout抽象—实践案例」的递进逻辑展开。

## 硬件底层支撑：三级存储架构

AscendC沿用AI Core三级存储架构，通过Tensor抽象隐藏内存位置细节：

**表 1**  AI Core存储层级

| 存储层级 | 存储类型 | 名称 | 用途 |
|----------|----------|------|------|
| **外部存储** | Global Memory | Global Memory | 存放算子输入/输出数据 |
| **片上存储** | Local Memory | UB | Vector输入/输出 |
| | | L1 | Cube数据中转 |
| | | L0A/L0B | Cube矩阵输入 |
| | | L0C | Cube矩阵输出 |
| **计算单元内部** | 寄存器 | 矢量寄存器 | Vector计算工作存储 |

**数据流转路径**：

- **Vector算子数据流**：`GM → UB → Vector计算 → UB → GM`
- **Cube算子数据流**：`GM → L1 → L0A/L0B → Cube计算 → L0C → GM`

> 📌 **提示**：AscendC通过Tensor抽象内存，基础能力用TPosition枚举表达内存位置，扩展能力用Engine抽象隐藏位置细节。

## basic_api内存管理：TPosition与ShapeInfo

### LocalTensor定义

basic_api的LocalTensor通过TPosition枚举表达内存位置：

```cpp
template <typename T>
class LocalTensor {
public:
    using PrimType = PrimT<T>;
    
    // 构造方式：显式指定位置和地址
    __aicore__ inline LocalTensor<T>(TPosition pos, uint32_t addr);
    __aicore__ inline LocalTensor<T>(uint32_t addr);
    
    // 形状信息设置（运行期）
    __aicore__ inline void SetShapeInfo(const ShapeInfo& shapeInfo);
    __aicore__ inline ShapeInfo GetShapeInfo() const;
    
    // 内存位置信息
    __aicore__ inline int32_t GetPosition() const;
    
private:
    TPosition position_;  // 内存位置枚举
    uint32_t address_;    // 内存地址
    ShapeInfo shapeInfo_; // 形状信息（运行期）
};
```

### TPosition内存位置枚举

TPosition定义片上存储的位置类型：

```cpp
enum TPosition {
    VECIN,    // Vector输入缓冲区
    VECOUT,   // Vector输出缓冲区
    VECCALC,  // Vector计算缓冲区
    A1,       // L1缓冲区A（Cube输入）
    B1,       // L1缓冲区B（Cube输入）
    C1,       // L1缓冲区C（Cube输出）
    L0A,      // L0A缓冲区（Cube内部）
    L0B,      // L0B缓冲区（Cube内部）
    L0C,      // L0C缓冲区（Cube输出）
    UB,       // Unified Buffer（Vector主缓冲区）
    GM,       // Global Memory
};
```

### ShapeInfo形状信息

ShapeInfo携带Tensor的形状信息，运行期设置：

```cpp
struct ShapeInfo {
    uint32_t shape[MAX_DIM_NUM];      // 当前形状
    uint32_t originalShape[MAX_DIM_NUM]; // 原始形状
    DataFormat dataFormat;            // 数据格式
};
```

### LocalTensor创建与使用

**创建LocalTensor**：

```cpp
// 方式1：TPipe队列管理
TPipe pipe;
TQue<UB, 1> que;
pipe.InitBuffer(que, 1, 256 * sizeof(half));
LocalTensor<half> ubTensor = que.AllocTensor<half>();

// 方式2：TBuf缓冲区管理
TBuf<UB> ubBuf;
pipe.InitBuffer(ubBuf, 256 * sizeof(half));
LocalTensor<half> ubTensor = ubBuf.Get<half>();

// 方式3：显式地址构造
LocalTensor<half> ubTensor(UB, ubAddress);
ubTensor.SetShapeInfo({128, 64});  // 运行期设置形状
```

**使用LocalTensor**：

```cpp
// 获取形状信息
ShapeInfo shapeInfo = ubTensor.GetShapeInfo();

// 获取内存位置
int32_t pos = ubTensor.GetPosition();  // 返回UB

// 数据搬运
GlobalTensor<half> gmTensor;
gmTensor.SetGlobalBuffer((__gm__ half*)gmBuffer, bufferSize);
DataCopy(ubTensor, gmTensor, 256);
```

### GlobalTensor定义

GlobalTensor对应全局内存，通过SetGlobalBuffer设置地址：

```cpp
template <typename T>
class GlobalTensor {
public:
    using PrimType = PrimT<T>;
    
    // 设置全局缓冲区
    __aicore__ inline void SetGlobalBuffer(__gm__ PrimType* buffer, uint64_t bufferSize);
    
    // 缓存模式设置
    __aicore__ inline void SetL2CacheHint(CacheMode mode);
    
private:
    __gm__ PrimType* buffer_;  // GM指针
    uint64_t bufferSize_;      // 缓冲区大小
    ShapeInfo shapeInfo_;      // 形状信息
};
```

**创建GlobalTensor**：

```cpp
GlobalTensor<half> gmTensor;
gmTensor.SetGlobalBuffer((__gm__ half*)gmBuffer, 256 * sizeof(half));
gmTensor.SetShapeInfo({128, 64});

// 配置L2缓存
gmTensor.SetL2CacheHint(CacheMode::READ_ONLY);
```

### TPipe内存管理

TPipe提供内存分配与队列管理能力：

```cpp
class TPipe {
public:
    // 初始化队列缓冲区
    template <class T>
    __aicore__ inline bool InitBuffer(T& que, uint8_t num, uint32_t len);
    
    // 初始化缓冲区
    template <TPosition pos>
    __aicore__ inline bool InitBuffer(TBuf<pos>& buf, uint32_t len);
    
    // SPM缓冲区管理（溢出缓冲区）
    template <typename T>
    __aicore__ inline void InitSpmBuffer(const GlobalTensor<T>& workspace, const int32_t bufferSize);
};
```

**TQue队列管理**：

```cpp
template <TPosition pos, int32_t depth>
class TQue {
public:
    // 分配Tensor
    template <typename T>
    __aicore__ inline LocalTensor<T> AllocTensor();
    
    // 释放Tensor
    template <typename T>
    __aicore__ inline void FreeTensor(LocalTensor<T>& tensor);
    
    // 入队
    template <typename T>
    __aicore__ inline bool EnQue(const LocalTensor<T>& tensor);
    
    // 出队
    template <typename T>
    __aicore__ inline void DeQue(LocalTensor<T>& tensor);
};
```

**使用示例**：

```cpp
TPipe pipe;
TQue<UB, 2> queIn, queOut;

// 初始化队列
pipe.InitBuffer(queIn, 2, 256 * sizeof(half));
pipe.InitBuffer(queOut, 1, 256 * sizeof(half));

// 分配Tensor
LocalTensor<half> ubIn = queIn.AllocTensor<half>();
queIn.EnQue(ubIn);

// 从队列获取Tensor
queIn.DeQue(ubIn);

// 使用完毕后释放
queIn.FreeTensor(ubIn);
```

## 扩展能力：Engine-Layout分离

在基础能力基础上，对LocalTensor进行扩展，引入Layout概念，将数据布局抽象为类型：

- **Shape**：描述张量形状（维度），编译期确定
- **Stride**：描述内存步长（排列方式），编译期确定
- **Info**：携带LayoutPattern和TraitType信息

**Layout优势**：
- 编译期确定Shape和Stride，减少运行期错误
- LayoutPattern支持ND、NZ、ZN、ZZ等标准布局
- Slice/Tile操作零开销，只改变Layout不拷贝数据

### Layout定义

```cpp
template <typename T, typename U, typename Info = DefaultInfo>
struct Layout {
    static constexpr auto rank = Std::tuple_size_v<T>;  // 维度数（编译期）
    static constexpr auto size = StaticLayoutSize<T, U>::size;  // 总大小
    
    // Shape/Stride获取
    __aicore__ inline constexpr decltype(auto) Shape();
    __aicore__ inline constexpr decltype(auto) Stride();
    
    // 坐标到索引映射
    template <typename S>
    __aicore__ inline constexpr auto operator()(const S& coord) const;
};
```

### Shape与Stride创建

Shape和Stride编译期确定，通过工厂函数创建：

```cpp
// 创建Shape（编译期）
auto shape = MakeShape(128, 64);  // 128行×64列

// 创建Stride（编译期）
auto stride = MakeStride(64, 1);  // 行主序：每行64元素，元素间步长1

// 从Shape自动推导Stride（连续布局）
auto layout = MakeLayout(MakeShape(128, 64));  // 自动计算stride=(64, 1)
```

### Engine抽象

Engine持有数据指针，抽象内存位置：

```cpp
template <typename Iterator>
struct ViewEngine {
```

### LocalTensor扩展

扩展LocalTensor，采用Engine-Layout分离设计：

```cpp
template <typename EngineType, typename LayoutType>
struct LocalTensor<TensorAttribute<EngineType, LayoutType>> {
    using engineType = EngineType;
    using layoutType = LayoutType;
    static constexpr int rank = LayoutType::rank;  // 编译期常量
    
    // 分离访问
    __aicore__ inline constexpr decltype(auto) Engine() const;
    __aicore__ inline constexpr decltype(auto) Layout() const;
    __aicore__ inline constexpr decltype(auto) Data() const;
    
    // 坐标访问（通过Layout计算偏移）
    template <typename Coord>
    __aicore__ inline constexpr decltype(auto) operator[](const Coord& coord);
};
```

### LayoutPattern布局模式

LayoutPattern定义标准内存布局格式，用于Cube计算场景：

**表 2**  LayoutPattern分类

| Pattern | 描述 | 适用场景 |
|---------|------|----------|
| `NDLayoutPtn` | 行主序连续布局 | Vector计算 |
| `NZLayoutPtn` | 列分块，行连续 | Cube矩阵乘输入 |
| `ZNLayoutPtn` | 行分块，列连续 | RNN算子 |
| `ZZLayoutPtn` | 行分块，列分块 | Cube特殊场景 |


## 布局变换：零开销切片与分块

提供Slice、Tile等布局变换操作，零数据拷贝：

### Slice切片操作

```cpp
// 创建Tensor
auto tensor = MakeTensor(ubPointer, MakeShape(128, 64));

// 切片：只改变Layout，Engine偏移，无数据拷贝
auto sliceTensor = tensor.Slice(MakeCoord(10, 20), MakeShape(32, 16));

// 切片访问：指向ubPointer + 10×64 + 20
sliceTensor[MakeCoord(0, 0)];
```

### Tile分块操作

```cpp
// 分块：按(16, 16)块大小分块
auto tiledTensor = tensor.Tile(MakeTile(16, 16));

// 分块后的Tensor可进一步切片
auto blockTensor = tiledTensor.Slice(MakeCoord(2, 3), MakeShape(1, 1));
```

### 与basic_api对比

basic_api无内置切片支持，需手动计算偏移：

```cpp
// basic_api：手动计算偏移
LocalTensor<half> ubTensor;
ubTensor.SetShapeInfo({128, 64});
uint32_t offset = 10 * 64 + 20;
LocalTensor<half> sliceTensor = ubTensor[offset];  // 需手动计算

// 扩展能力：Slice零开销
auto sliceTensor = tensor.Slice(MakeCoord(10, 20), MakeShape(32, 16));
```

## 实践案例：Vector与Cube算子内存管理

### Vector算子内存管理（basic_api）

```cpp
// ===== TPipe队列管理 =====
TPipe pipe;
TQue<UB, 2> queIn, queOut;

pipe.InitBuffer(queIn, 2, 256 * sizeof(half));
pipe.InitBuffer(queOut, 1, 256 * sizeof(half));

// ===== 分配Tensor =====
LocalTensor<half> ubIn0 = queIn.AllocTensor<half>();
LocalTensor<half> ubIn1 = queIn.AllocTensor<half>();
LocalTensor<half> ubOut = queOut.AllocTensor<half>();

ubIn0.SetShapeInfo({128, 64});
ubIn1.SetShapeInfo({128, 64});
ubOut.SetShapeInfo({128, 64});

// ===== GlobalTensor =====
GlobalTensor<half> gmIn0, gmIn1, gmOut;
gmIn0.SetGlobalBuffer((__gm__ half*)gmIn0Buffer, 128 * 64);
gmIn1.SetGlobalBuffer((__gm__ half*)gmIn1Buffer, 128 * 64);
gmOut.SetGlobalBuffer((__gm__ half*)gmOutBuffer, 128 * 64);

// ===== 数据搬运与计算 =====
DataCopy(ubIn0, gmIn0, 128 * 64);
DataCopy(ubIn1, gmIn1, 128 * 64);
Add(ubOut, ubIn0, ubIn1, 128 * 64);
DataCopy(gmOut, ubOut, 128 * 64);

// ===== 释放Tensor =====
queIn.FreeTensor(ubIn0);
queIn.FreeTensor(ubIn1);
queOut.FreeTensor(ubOut);
```

### Cube算子内存管理（扩展能力）

```cpp
// ===== 创建Tensor（NZ布局）=====
constexpr uint32_t M = 128;
constexpr uint32_t K = 32;
constexpr uint32_t N = 64;

// L1 Tensor（NZ布局）
auto l1TensorA = MakeTensor(l1PointerA, MakeFrameLayout<NZLayoutPtn>(M, K));
auto l1TensorB = MakeTensor(l1PointerB, MakeFrameLayout<NZLayoutPtn>(K, N));

// L0 Tensor
auto l0aTensor = MakeTensor(l0aPointer, MakeShape(M, K));
auto l0bTensor = MakeTensor(l0bPointer, MakeShape(K, N));
auto l0cTensor = MakeTensor(l0cPointer, MakeShape(M, N));

// ===== 切片分块 =====
auto blockA = l1TensorA.Slice(MakeCoord(0, 0), MakeShape(16, 16));
auto blockB = l1TensorB.Slice(MakeCoord(0, 0), MakeShape(16, 16));

// ===== Copy Atom搬运 =====
auto copyL12L0A = MakeCopy<CopyL12L0A>();
auto copyL12L0B = MakeCopy<CopyL12L0B>();
Copy(copyL12L0A, blockA, l0aTensor);
Copy(copyL12L0B, blockB, l0bTensor);

// ===== Mmad =====
auto mmadAtom = MakeMmad<MmadOperation>();
Mmad(mmadAtom, l0aTensor, l0bTensor, l0cTensor);
```
