# 内存层级

内存层级是C++ Tensor编程的基础支撑，Tensor抽象将物理内存封装为对象，合理的内存布局与数据流转策略是实现高性能算子的核心前提。本章系统阐述Tensor体系架构、基础Tensor与扩展Tensor定义方式、寄存器Tensor体系，帮助开发者建立对Tensor内存管理的完整认知，掌握内存资源管控与数据搬运优化的核心方法论。

AI Core采用分级存储架构，不同计算单元的编程视角有所差异：**Vector矢量计算**传统架构采用「Global Memory → UB」两级层级，Ascend 950PR/Ascend 950DT引入寄存器后构建「Global Memory → UB → Register」三级层级，**Global Memory**存放输入输出数据，**UB**作为矢量计算数据枢纽，**Register**位于Vector计算单元最内层，具备最低访存延迟与最高带宽；**Cube矩阵计算**采用「Global Memory → L1/L0系列Buffer」两级层级，L1 Buffer、L0A/L0B Buffer、L0C Buffer服务矩阵计算。

C++ Tensor编程将物理内存抽象为Tensor对象，开发者无需直接操作指针，Tensor作为编程接口的载体承载内存操作，携带数据类型、形状、内存位置等属性，搬运计算接口直接操作Tensor对象即可完成数据流转：**GlobalTensor**用于存储Global Memory数据，作为算子与外部数据交互的门户；**LocalTensor**用于存储UB Buffer、L1 Buffer、L0A/L0B/L0C Buffer等片上内存数据，承载计算过程中的输入、输出和中间数据；**RegTensor**用于存储寄存器变量，是矢量计算的基本存储单元，配合Load-Compute-Store模式与UB协作完成计算。

> 📌 寄存器可编程能力从**Ascend 950PR/Ascend 950DT**引入，构建三级内存架构，可获得接近峰值的计算性能。

## Tensor抽象内存定义

C++ Tensor通过Tensor抽象封装物理内存，开发者无需直接操作地址限定符。Tensor携带类型、形状、位置属性，API自动推断操作参数。

### 基础Tensor(不带Layout)定义

- **GlobalTensor**直接通过构造函数定义Tensor对象，并通过`SetGlobalBuffer`函数指定Tensor所绑定的指针和大小。
```cpp
GlobalTensor<half> gmTensor;
gmTensor.SetGlobalBuffer((__gm__ half*)gmBuffer, bufferSize);
gmTensor.SetL2CacheHint(CacheMode::READ_ONLY);  // Configure L2 cache
```

- **LocalTensor**通过`LocalMemAllocator`内存分配器创建，用户可指定物理存储位置和内存大小。以下代码示例在UB上分配一块TILE_LENGTH大小的内存块，返回的LocalTensor可直接用于数据搬运和计算操作。
```cpp
// Specify TILE_LENGTH size, use LocalMemAllocator to allocate TILE_LENGTH size memory and return LocalTensor
AscendC::LocalMemAllocator<AscendC::Hardware::UB> ubAllocator;
AscendC::LocalTensor<float> xLocalPing = ubAllocator.Alloc<float, TILE_LENGTH>();
AscendC::LocalTensor<float> yLocalPing = ubAllocator.Alloc<float, TILE_LENGTH>();
AscendC::LocalTensor<float> zLocalPing = ubAllocator.Alloc<float, TILE_LENGTH>();

// If user provides a compiler-unknown Size, can use Alloc parameter to allocate
AscendC::LocalMemAllocator<AscendC::Hardware::UB> ubAllocator;
AscendC::LocalTensor<float> xLocalPing = ubAllocator.Alloc<float>(tileLength);
AscendC::LocalTensor<float> yLocalPing = ubAllocator.Alloc<float>(tileLength);
AscendC::LocalTensor<float> zLocalPing = ubAllocator.Alloc<float>(tileLength);
```

### 扩展Tensor(带有Layout)定义

Ascend 950PR/950DT在Tensor基础上引入Layout布局概念，将Shape和Stride移到编译期确定，实现类型安全和分形布局自动生成。开发者只需定义Tensor的Layout，搬运和计算接口自动推断底层参数，大幅降低矩阵算子开发难度。

> 📌 扩展Tensor(带有layout)能力从**Ascend 950PR/Ascend 950DT**开始支持。

#### Layout表述

使用Shape和Stride表达Layout排布格式：

| 排布方式 | Shape | Stride | 说明 |
|---------|-------|--------|------|
| 行优先 | (2, 4) | (4, 1) | 行内元素连续，行间跳转 |
| 列优先 | (2, 4) | (1, 2) | 列内元素连续，列间跳转 |

![行优先排布](../../../../figures/行优先排布.png)
![列优先排布](../../../../figures/列优先排布.png)

#### Layout层次化表达

复杂内存排布采用层次化表述法，Shape和Stride元素可以是元组：

```
Shape: ((2, 3), (2, 4))
Stride: ((1, 4), (2, 12))
```

![层次化Layout表达](../../../../figures/层次化Layout表达.png)

图中展示两层矩阵：内层矩阵为灰色线包裹的矩阵，外层矩阵为黑色线包裹的矩阵。Shape的第一个元素`(2, 3)`表示内层和外层行数分别为2和3；第二个元素`(2, 4)`表示内层和外层列数分别为2和4。

#### Tensor定义方式

扩展能力Tensor通过`MakeTensor`函数创建，Shape和Stride编译期确定：

**1. 定义连续内存块Tensor**
```cpp
// Dynamic Shape
auto dynTensor = MakeTensor(pointer, MakeShape(m, n));
// Static Shape
auto staticTensor = MakeTensor(pointer, MakeShape(Std::Int<128>{}, Std::Int<64>{}));
```

**2. 指定Stride定义任意排布Tensor**
```cpp
// Row-major
auto rowMajorTensor = MakeTensor(pointer, MakeLayout(MakeShape(m, n), MakeStride(n, Std::Int<1>{})));
// Column-major
auto colMajorTensor = MakeTensor(pointer, MakeLayout(MakeShape(m, n), MakeStride(Std::Int<1>{}, n)));
```

**3. 层次化布局定义矩阵分形Tensor**
```cpp
// (128, 64) matrix, internal 16x16 fractal
auto nzTensor = MakeTensor(pointer, MakeLayout(MakeShape((8, 16), (4, 16))));
```

**4. 分形布局简化定义**（Cube矩阵乘专用，自动生成Shape/Stride）
```cpp
auto tensor = MakeTensor(l0aPointer, MakeFrameLayout<NZLayoutPtn>(128, 64));
```

#### Tensor使用方式

扩展能力Tensor是"自描述数据容器"，支持编译期自动推导、类型安全校验、零开销切片：

**切片操作**
```cpp
auto tensor = MakeTensor(pointer, MakeShape(1024, 512));
// Fixed slice
auto slice = tensor.Slice(MakeCoord(0, 0), MakeShape(128, 64));
// Dynamic slice
auto slice = tensor.Slice(MakeCoord(i * 64, j * 32), MakeShape(64, 32));
```

**搬运接口**（无需复杂参数计算）
```cpp
auto gmTensor = MakeTensor(gmPtr, MakeShape(128, 64));
auto ubTensor = MakeTensor(ubPtr, MakeShape(128, 64));

// System built-in copy
Copy(gmTensor, ubTensor);
// Custom copy Op
auto copyAtom = MakeCopy<CopyGM2UB>();
Copy(copyAtom, gmTensor, ubTensor);
```

**CUBE计算**（简化Mmad接口）
```cpp
Mmad(l0c, l0a, l0b, {m, n, k, false, iterK == 0});
```

#### 使用示例

```cpp
using namespace AscendC::Reg;
MaskReg mask;                        // Mask register
RegTensor<half> srcReg;              // Data register
LoadAlign(srcReg, ubAddr);           // Load: UB->Register
Add(dstReg, srcReg0, srcReg1, mask); // Compute: Register computation
StoreAlign(ubDstAddr, dstReg, mask); // Store: Register->UB
```

本章阐述了C++ Tensor编程的内存层级管理体系。Tensor体系按能力演进分为两类：**基础Tensor**(不带Layout)携带数据类型、形状、内存位置属性，接口调用需手动传递操作参数；**扩展Tensor**(带有Layout)引入Layout概念，通过Shape和Stride在编译期确定数据布局，实现类型安全校验和自动参数推断，支持零开销切片和简化搬运计算接口，大幅降低矩阵算子开发复杂度。
