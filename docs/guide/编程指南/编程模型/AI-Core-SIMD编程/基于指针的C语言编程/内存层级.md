# 内存层级

内存层级是C语言指针编程的底层基石，直接映射AI Core硬件存储结构。合理的内存布局与数据流转策略，是实现高性能算子的核心前提。本章系统阐述存储架构定位、内存申请方式、寄存器体系，帮助开发者建立对硬件存储资源的完整认知，掌握内存资源管控与数据搬运优化的核心方法论。

AI Core采用分级存储架构，不同计算单元的编程视角有所差异：**Vector矢量计算**采用「Global Memory → UB → Register」三级层级，**Global Memory**存放输入输出数据，**UB**作为矢量计算数据枢纽，**Register**（Ascend 950PR/Ascend 950DT引入）位于Vector计算单元最内层，具备最低访存延迟与最高带宽；**Cube矩阵计算**采用「Global Memory → L1/L0系列Buffer」两级层级，L1 Buffer、L0A/L0B Buffer、L0C Buffer服务矩阵计算。

### 地址空间限定符

### 静态数组申请

数组长度需编译期常量，编译器自动分配地址空间、自动对齐。适用于内存大小在编译期可确定的静态场景，语法简洁、不易出错。
```cpp
constexpr uint32_t ub_size = 256;
__ubuf__ half ub_buffer[ub_size];  // 申请UB，编译器自动32字节对齐

constexpr uint32_t l1_size = 4096;
__cbuf__ half l1_buffer[l1_size];  // 申请L1

constexpr uint32_t l0a_size = 128;
__ca__ half l0a_buffer[l0a_size];  // 申请L0A，编译器自动512字节对齐
```
> 📌 **约束**：不支持动态数组、多维数组、嵌套数组。

### 动态内存申请

当内存大小在编译期无法确定时，可通过静态数组分配一块大内存，再通过偏移获取物理地址，手动管理地址分配和对齐，实现动态内存需求。
```cpp
constexpr uint32_t ub_size = 1024;
__ubuf__ half ub_buffer[ub_size];  // 申请UB，编译器自动32字节对齐

// 基于通过数组申请出来的ub_buffer地址进行offset偏移获取tmp_ub_buffer地址，需要确保offset满足32字节对齐
__ubuf__ half* tmp_ub_buffer = (__ubuf__ half*)ub_buffer + offset;
```

---

内存层级构建「Global Memory → 片上存储（UB服务矢量计算，L1/L0A/L0B/L0C服务矩阵计算）→ 寄存器」的存储架构，各层级通过__gm__/__ubuf__/__cbuf__等地址限定符精准映射并遵循严格对齐约束。Vector计算单元仅访问寄存器，数据需经GM搬运至UB再加载至寄存器参与计算，开发者需掌握静态数组与偏移量两种内存申请方式，合理利用掩码寄存器、地址寄存器处理尾部数据与循环迭代。
后续章节详述数据搬运接口、计算接口、同步机制。
