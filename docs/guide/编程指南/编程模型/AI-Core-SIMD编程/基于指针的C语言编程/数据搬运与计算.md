# 数据搬运与计算

数据搬运与计算是AI Core算子开发的两大核心操作，共同构成算子执行的数据流转与计算处理闭环。数据搬运解决「数据从哪里来、到哪里去」的问题，计算解决「数据如何处理」的问题，二者协同配合完成算子功能实现。本章旨在帮助开发者建立对C语言指针编程搬运与计算接口的系统化认知，重点阐述C语言指针编程的特点与优势，以及接口的分类体系与使用方法。全文遵循「编程特点—主要接口分类」的递进逻辑展开。

## C语言指针编程数据搬运与计算接口

C语言指针编程开放芯片完备编程能力，支持以数组形式分配内存，主要通过指针操作进行编程。提供与业界一致的C语言编程体验。包含asc_simd.h文件来调用C API相应接口。如无特殊说明，包含该头文件即可满足接口调用需求。若API文档中有特殊说明，则应遵循API的具体说明。
```c
#include "c_api/asc_simd.h" 
```
C语言指针编程接口分为搬运类和计算类两大类：搬运类包括**矢量搬运**和**矩阵搬运**接口，计算类包括矢量计算和**矩阵计算**接口；其中矢量计算接口因Ascend 950PR/Ascend 950DT引入寄存器，进一步分为**Memory矢量计算**接口和**Reg矢量计算**接口。

### 矢量搬运接口

Vector搬运接口支撑GM与UB之间的数据流转，是Vector算子开发的基础。接口命名遵循「源→目标」格式（如`asc_copy_gm2ub`表示GM到UB搬运），参数简洁直观（dst、src、size），主要包含如下接口定义：
- **GM2UB搬运**: `asc_copy_gm2ub`加载输入数据到UB
- **UB2GM搬运**: `asc_copy_ub2gm`输出计算结果到GM
- **GM2UB多维搬运**: `asc_ndim_copy_gm2ub`进行多维度带填充搬运

同时对于同一类接口，提供了不同的接口形式来应对不同的应用场景：
- **常规接口**：`asc_copy_gm2ub(dst, src, size)`，异步执行，需配合同步接口
- **高维切分接口**：`asc_copy_gm2ub(dst, src, n_burst, len_burst, src_gap, dst_gap)`，支持复杂搬运模式
- **同步接口**：`asc_copy_gm2ub_sync(dst, src, size)`，内部自动等待搬运完成

```c
__vector__ __global__ __aicore__ void add_custom(__gm__ float* x, __gm__ float* y, __gm__ float* z)
{
    // Load input data from GM to UB using asc_copy_gm2ub
    asc_copy_gm2ub(xLocal, xGm + i * tileLength, 1, burst_len, 0, 0);
    // ... vector computation
    // Store computation result from UB to GM using asc_copy_ub2gm
    asc_copy_ub2gm(zGm + i * tileLength, zLocal, 1, burst_len, 0, 0);
}
```
**详细说明**：参见 [Vector搬运接口](../../../../../api/context/c_api/vector_datamove/)

### 矩阵搬运接口

Cube搬运接口支撑矩阵乘法的数据供给，涵盖GM→L1、L1→L0A/L0B、L0C→GM的完整路径。接口支持2D格式搬运、转置搬运、3D格式搬运等多种模式, 主要包含如下接口定义:
- **GM2L1搬运** : `asc_copy_gm2l1_nd2nz`加载矩阵数据到L1并进行ND2NZ转换
- **L12L0A搬运**: `asc_copy_l12l0a`加载左矩阵到L0A
- **L12L0B搬运**: `asc_copy_l12l0b`加载右矩阵到L0B
- **L0C2GM搬运**: `asc_copy_l0c2gm`输出矩阵乘结果到GM

```c
__cube__ __global__ __aicore__ void matmul_custom(__gm__ float* c, __gm__ float* a, __gm__ float* b)
{
    // Load A, B matrices from GM to L1 with ND2NZ conversion using asc_copy_gm2l1
    asc_copy_gm2l1_nd2nz(l1a, gma, nd_num, n_value, d_value, src_nd_matrix_stride, src_d_value, dst_nz_c0_stride, dst_nz_n_stride, dst_nz_matrix_stride);
    asc_copy_gm2l1_nd2nz(l1b, gmb, nd_num, n_value, d_value, src_nd_matrix_stride, src_d_value, dst_nz_c0_stride, dst_nz_n_stride, dst_nz_matrix_stride);
    // Load A, B matrices from L1 to L0 using asc_copy_l12l0
    asc_copy_l12l0a(l0a, l1a, a_start_index, repeat, src_stride, dst_gap);
    asc_copy_l12l0b(l0b, l1b, b_start_index, repeat, src_stride, dst_gap);
    // ... matrix computation

    // Store computation result to GM using asc_copy_l0c2gm
    asc_copy_l0c2gm_sync(gmc, l0c, n_size, m_size, dst_stride_dst_d, src_stride, unit_flag_mode, quant_pre, relu_pre, channel_split, nz2nd_en);
}
```
**详细说明**：参见 [Cube搬运接口](../../../../../api/context/c_api/cube_datamove/)

### Memory矢量计算接口
Memory矢量计算接口覆盖算术运算、比较运算、类型转换、规约运算、激活函数等场景，是算子开发的核心工具集。接口命名直观（`asc_add`表示向量加法），参数简洁（dst、src、count），主要接口包括算术运算、比较运算、类型转换等矢量常用计算接口。

Memory矢量计算接口入参均为指针形式，直接在UB内存执行矢量计算。
```c
// Interface definition
// Compute first n elements, mainly for continuous computation scenarios
__aicore__ inline void asc_add(__ubuf__ int16_t* dst, __ubuf__ int16_t* src0, __ubuf__ int16_t* src1, uint32_t count)
// High-dimensional segmented computation, mainly for scenarios requiring interval sampling
__aicore__ inline void asc_add(__ubuf__ int16_t* dst, __ubuf__ int16_t* src0, __ubuf__ int16_t* src1, uint8_t repeat, 
    uint8_t dst_block_stride, uint8_t src0_block_stride, uint8_t src1_block_stride, uint8_t dst_repeat_stride, 
    uint8_t src0_repeat_stride, uint8_t src1_repeat_stride)
// Synchronous compute interface, uses a serial Add method, suitable for simplified operator development with low performance requirements
__aicore__ inline void asc_add_sync(__ubuf__ int16_t* dst, __ubuf__ int16_t* src0, __ubuf__ int16_t* src1, uint32_t count)

// Interface usage
__vector__ __global__ __aicore__ void add_custom(__gm__ float* x, __gm__ float* y, __gm__ float* z)
{
    __ubuf__ float xLocal[C_API_TILE_LENGTH];
    __ubuf__ float yLocal[C_API_TILE_LENGTH];
    __ubuf__ float zLocal[C_API_TILE_LENGTH];
    // ... load data to UB
    // Direct vector computation using __ubuf__
    asc_add(zLocal, xLocal, yLocal, tileLength * sizeof(float) / C_API_ONE_REPEAT_BYTE_SIZE, 1, 1, 1, 8, 8, 8);
    // ... store computation result to GM
}
```

**详细说明**：参见 [Vector计算接口](../../../../../api/context/c_api/vector_compute/)

### Reg矢量计算接口

> 📌 寄存器可编程能力从**Ascend 950PR/Ascend 950DT**引入。

Ascend 950PR/Ascend 950DT新一代架构在传统UB缓存体系的基础上，开放寄存器（Register）可编程能力，构建出「Global Memory → UB → Register」的三级内存层级。
- **Reg矢量计算调用层次**: 如下图所示，核函数（__global__ __aicore__）是Device侧入口函数，可调用__aicore__函数；__simd_vf__函数可被核函数调用，内部只能调用__simd_callee__子函数和constexpr aicore函数。
![Reg矢量计算调用层次](../../../../figures/Reg矢量计算调用层次.png)
  - **Reg矢量计算接口**：这类接口为C语言指针编程提供的矢量计算接口，接口定义都使用__simd_callee__作为限定符，依托寄存器低延迟、高带宽的硬件优势，专为极致性能优化场景设计了一套直接操作寄存器变量的矢量计算接口， 主要接口包括加载&存储、算术运算、比较运算、类型转换等矢量常用计算接口。
  ```c
  // Load function: load data from UB to vector compute register variable
  __simd_callee__ inline void asc_load(vector_int8_t& dst, __ubuf__  int8_t* src);
  // Compute function: use vector compute register for vector computation, mainly provides arithmetic, comparison, type conversion and other common vector compute interfaces
  __simd_callee__ inline void asc_add(vector_uint8_t& dst, vector_uint8_t src0, vector_uint8_t src1, vector_bool mask);
  // Store function: store Reg vector compute result to UB
  __simd_callee__ inline void asc_store(__ubuf__  int8_t* dst, vector_int8_t src);
  ```  

  - **simd vf函数**：上述矢量计算接口只能在simd vf函数中调用， 并且该函数只能通过`asc_vf_call`的方式被核函数/__aicore__函数调用
  ```c
  __simd_vf__ inline void add_custom(__ubuf__ half* dst, __ubuf__ half* src0, __ubuf__ half* src1) {
    // Internal call to Reg vector compute interface for vector computation
    vector_half dst_reg, src0_reg, src1_reg;
    asc_load(src0_reg, src0);
    // ...
  }
  ```

  - **核函数/__aicore__**: 核函数(使用__global__ __aicore__标识的为核函数)或者普通Device侧函数(使用__aicore__函数)通过`asc_vf_call`函数调用`simd vf`完成最终的计算
  ```c
  __vector__ __global__ __aicore__ void add_custom(__gm__ float* x, __gm__ float* y, __gm__ float* z)
  {
    __ubuf__ float x_local[TILE_LENGTH];
    __ubuf__ float y_local[TILE_LENGTH];
    __ubuf__ float z_local[TILE_LENGTH];
    // Load GM data to UB
    asc_copy_gm2ub_align((__ubuf__ float*)x_local, x, BLK_NUM, burst_length, 0, 0, true, cache_mode, src_stride, dst_stride);
    asc_copy_gm2ub_align((__ubuf__ float*)y_local, y, BLK_NUM, burst_length, 0, 0, true, cache_mode, src_stride, dst_stride);
    // ...
    // Call simd vf function through asc_vf_call
    asc_vf_call<add_custom>(z_local, x_local, y_local);

    // Store computation result to result GM
    asc_copy_ub2gm_align(z, (__ubuf__ float*)z_local, BLK_NUM, burst_length, cache_mode, src_stride, dst_stride);
  }
  ```
  **详细说明**：参见 [Vector计算接口](../../../../../api/context/c_api/vector_compute/)、 [编程示例](./编程示例.md)

### 矩阵计算接口

矩阵计算接口以`asc_mmad`为核心，支持多种数据类型与计算模式。接口参数直观（c_matrix、a_matrix、b_matrix、M、K、N），开发者可精细控制矩阵计算过程，主要包含如下接口定义：

- **标准矩阵乘加**：`asc_mmad`，输入half/bf16/float/int8，输出float/int32
- **4-bit量化矩阵乘**：`asc_mmad_s4`，输入int4b_t，输出int32
- **MX格式矩阵乘**：`asc_mmad_mx`，输入fp8/fp4，输出float（950PR/950DT专用）

```c
// Interface definition
// Standard matrix multiplication
__aicore__ inline void asc_mmad(__cc__ int32_t* c_matrix, __ca__ int8_t* a_matrix, __cb__ int8_t* b_matrix, uint16_t left_height, uint16_t n_dim, uint16_t right_width, uint8_t unit_flag, bool k_direction_align, bool c_matrix_source, bool c_matrix_init_val);
// MX format matrix multiplication
__aicore__ inline void asc_mmad_mx(__cc__ float* c_matrix, __ca__ fp4x2_e1m2_t* a_matrix, __cb__ fp4x2_e1m2_t* b_matrix, uint16_t left_height, uint16_t n_dim, uint16_t right_width, uint8_t unit_flag, bool disable_gemv, bool c_matrix_source, bool c_matrix_init_val)

// Interface invocation
asc_mmad_sync(c_matrix, a_matrix, b_matrix, left_height, n_dim, right_width, unit_flag, disable_gemv, c_matrix_source, c_matrix_init_val);
```

**详细说明**：参见 [矩阵计算接口](../../../../../api/context/c_api/cube_compute/)、 [编程示例](./编程示例.md)

本章系统阐述了C语言指针编程数据搬运与计算接口。C语言指针编程提供指令级透明可控的底层编程能力，函数与硬件指令一一对应、调用即执行，参数简洁直观。同步位置、内存分配、分块策略完全由开发者控制。数据搬运接口分为Vector搬运与Cube搬运两类，分别支撑向量算子与矩阵算子的数据流转。计算接口分为向量计算与矩阵计算两类，覆盖算术、比较、转换、规约、激活、矩阵乘等主流场景。Vector算子遵循「加载→计算→存储」三阶段模式，Cube算子遵循四阶段模式，开发者可按需选择同步接口简化同步控制。
