本文档针对AscendC C++类库开发人员，详细介绍类库中三种核心Tensor编程API（静态Tensor、带Layout Tensor、RegTensor）的定义、核心特性、编程流程、代码示例及适用场景，帮助开发人员根据实际需求（开发效率、性能要求、硬件适配）选择合适的编程模式，高效开发昇腾NPU算子及相关应用。

### Tensor编程API核心定位总览
AscendC C++类库的三种Tensor编程API，层级从高到低、封装度从高到低、灵活性从低到高、性能可控性从弱到强，核心定位差异明确，适配不同开发场景，具体如下：

-   静态 Tensor编程：用户直接申请Tensor并调用封装好的API进行操作，无需关注底层硬件细节，优先保障开发效率，适合快速迭代、常规场景开发。
    
-   Layout Tensor编程：Tensor定义语义类似CUTE，支持用户直接传入Tensor进行编程，兼顾灵活性与易用性，支持自定义Tensor布局，适配复杂算子开发。
    
-   Reg Tensor编程：直接操作寄存器级Tensor，灵活性与性能可控性最强，需开发人员熟悉昇腾硬件寄存器架构，适合对性能极致追求的场景。
