## 引言

本章通过完整的编程示例，帮助开发者掌握AscendC算子开发的实践方法。示例覆盖Vector算子、Cube算子、Double Buffer流水线、RegTensor精细控制等典型场景，分别展示基础能力与扩展能力的实现方式。

## Vector算子示例：Add算子

Add算子是最基础的Vector算子，实现两个输入向量的逐元素相加，数据流路径为「GM→UB→Vector计算→UB→GM」。

### 基础能力实现

```cpp
extern "C" __global__ __aicore__ void add_kernel(
    __gm__ half* gmIn0, __gm__ half* gmIn1, __gm__ half* gmOut,
    const uint32_t totalLength) {
    
    // ===== 第一步：初始化队列 =====
    TPipe pipe;
    TQue<UB, 1> queIn, queOut;
    
    constexpr uint32_t TILE_LENGTH = 256;
    pipe.InitBuffer(queIn, 1, TILE_LENGTH * sizeof(half));
    pipe.InitBuffer(queOut, 1, TILE_LENGTH * sizeof(half));
    
    // ===== 第二步：定义GlobalTensor =====
    GlobalTensor<half> gmTensorIn0, gmTensorIn1, gmTensorOut;
    gmTensorIn0.SetGlobalBuffer(gmIn0, totalLength);
    gmTensorIn1.SetGlobalBuffer(gmIn1, totalLength);
    gmTensorOut.SetGlobalBuffer(gmOut, totalLength);
    
    // ===== 第三步：分块处理循环 =====
    constexpr uint32_t eventID = 0;
    uint32_t offset = 0;
    
    while (offset < totalLength) {
        uint32_t curLength = min(TILE_LENGTH, totalLength - offset);
        
        // 分配LocalTensor
        LocalTensor<half> ubIn0 = queIn.AllocTensor<half>();
        LocalTensor<half> ubIn1 = queIn.AllocTensor<half>();
        LocalTensor<half> ubOut = queOut.AllocTensor<half>();
        
        // 数据搬入：GM→UB
        DataCopy(ubIn0, gmTensorIn0[offset], curLength);
        DataCopy(ubIn1, gmTensorIn1[offset], curLength);
        
        // 同步：等待MTE2完成
        SetFlag<HardEvent::MTE2_V>(eventID);
        WaitFlag<HardEvent::MTE2_V>(eventID);
        
        // 计算：Add
        Add(ubOut, ubIn0, ubIn1, curLength);
        
        // 同步：等待Vector完成
        SetFlag<HardEvent::V_MTE3>(eventID);
        WaitFlag<HardEvent::V_MTE3>(eventID);
        
        // 数据搬出：UB→GM
        DataCopy(gmTensorOut[offset], ubOut, curLength);
        
        // 释放LocalTensor
        queIn.FreeTensor(ubIn0);
        queIn.FreeTensor(ubIn1);
        queOut.FreeTensor(ubOut);
        
        offset += TILE_LENGTH;
    }
}
```

```cpp
extern "C" __global__ __aicore__ void add_kernel(

    auto ubInTensor0 = ubAllocator.Alloc<half, M * N>();
    auto ubInTensor1 = ubAllocator.Alloc<half, M * N>();
    auto ubOutTensor = ubAllocator.Alloc<half, M * N>();
    
    // ===== 第二步：创建Copy Atom =====
    auto copyGM2UB = MakeCopy<CopyGM2UB>();
    auto copyUB2GM = MakeCopy<CopyUB2GM>();
    
    // ===== 第三步：数据搬入（隐式同步）=====
    Copy(copyGM2UB, gmInTensor0, ubInTensor0);
    Copy(copyGM2UB, gmInTensor1, ubInTensor1);
    
    // ===== 第四步：计算执行 =====
    Add(ubOutTensor, ubInTensor0, ubInTensor1);
    
    // ===== 第五步：数据搬出（隐式同步）=====
    Copy(copyUB2GM, ubOutTensor, gmOutTensor);
}
```

## Cube算子示例：MatMul算子

MatMul算子实现矩阵乘法，数据流路径为「GM→L1→L0A/L0B→Cube计算→L0C→GM」。

### 基础能力实现

```cpp
extern "C" __global__ __aicore__ void matmul_kernel(
    __gm__ half* gmA, __gm__ half* gmB, __gm__ float* gmC,
    const uint32_t M, const uint32_t K, const uint32_t N) {
    
    // ===== 第一步：初始化队列 =====
    TPipe pipe;
    TQue<L1, 2> queL1A, queL1B;
    TQue<L0A, 1> queL0A;
    TQue<L0B, 1> queL0B;
    TQue<L0C, 1> queL0C;
    
    constexpr uint32_t BLOCK_M = 16;
    constexpr uint32_t BLOCK_K = 16;
    constexpr uint32_t BLOCK_N = 16;
    
    pipe.InitBuffer(queL1A, 2, BLOCK_M * BLOCK_K * sizeof(half));
    pipe.InitBuffer(queL1B, 2, BLOCK_K * BLOCK_N * sizeof(half));
    pipe.InitBuffer(queL0A, 1, BLOCK_M * BLOCK_K * sizeof(half));
    pipe.InitBuffer(queL0B, 1, BLOCK_K * BLOCK_N * sizeof(half));
    pipe.InitBuffer(queL0C, 1, BLOCK_M * BLOCK_N * sizeof(float));
    
    // ===== 第二步：定义GlobalTensor =====
    GlobalTensor<half> gmTensorA, gmTensorB;
    GlobalTensor<float> gmTensorC;
    gmTensorA.SetGlobalBuffer(gmA, M * K);
    gmTensorB.SetGlobalBuffer(gmB, K * N);
    gmTensorC.SetGlobalBuffer(gmC, M * N);
    
    // ===== 第三步：分块矩阵乘法 =====
    constexpr uint32_t eventID0 = 0;
    constexpr uint32_t eventID1 = 1;
    constexpr uint32_t eventID2 = 2;
    
    for (uint32_t i = 0; i < M / BLOCK_M; i++) {
        for (uint32_t j = 0; j < N / BLOCK_N; j++) {
            // 分配L0C并初始化
            LocalTensor<float> l0c = queL0C.AllocTensor<float>();
            
            for (uint32_t k = 0; k < K / BLOCK_K; k++) {
                // 分配L1/L0A/L0B
                LocalTensor<half> l1a = queL1A.AllocTensor<half>();
                LocalTensor<half> l1b = queL1B.AllocTensor<half>();
                LocalTensor<half> l0a = queL0A.AllocTensor<half>();
                LocalTensor<half> l0b = queL0B.AllocTensor<half>();
                
                // GM→L1
                uint32_t offsetA = (i * BLOCK_M * K + k * BLOCK_K);
                uint32_t offsetB = (k * BLOCK_K * N + j * BLOCK_N);
                DataCopy(l1a, gmTensorA[offsetA], BLOCK_M * BLOCK_K);
                DataCopy(l1b, gmTensorB[offsetB], BLOCK_K * BLOCK_N);
                
                SetFlag<HardEvent::MTE2_MTE1>(eventID0);
                WaitFlag<HardEvent::MTE2_MTE1>(eventID0);
                
                // L1→L0A/L0B
                LoadData2DParams loadParams;
                loadParams.repeatTimes = 1;
                LoadData(l0a, l1a, loadParams);
                LoadData(l0b, l1b, loadParams);
                
                SetFlag<HardEvent::MTE1_C>(eventID1);
                WaitFlag<HardEvent::MTE1_C>(eventID1);
                
                // Mmad
                MmadParams mmadParams;
                mmadParams.m = BLOCK_M;
                mmadParams.n = BLOCK_N;
                mmadParams.k = BLOCK_K;
                mmadParams.cmatrixInitVal = (k == 0);  // 首次初始化为0
                Mmad(l0c, l0a, l0b, mmadParams);
                
                // 释放
                queL1A.FreeTensor(l1a);
                queL1B.FreeTensor(l1b);
                queL0A.FreeTensor(l0a);
                queL0B.FreeTensor(l0b);
            }
            
            // L0C→GM
            SetFlag<HardEvent::C_MTE3>(eventID2);
            WaitFlag<HardEvent::C_MTE3>(eventID2);
            
            uint32_t offsetC = (i * BLOCK_M * N + j * BLOCK_N);
            DataCopy(gmTensorC[offsetC], l0c, BLOCK_M * BLOCK_N);
            
            queL0C.FreeTensor(l0c);
        }
    }
}
```

### 扩展能力实现

```cpp
extern "C" __global__ __aicore__ void matmul_kernel(
    __gm__ half* gmA, __gm__ half* gmB, __gm__ float* gmC,
    const uint32_t M, const uint32_t K, const uint32_t N) {
    
    // ===== 第一步：创建Tensor（NZ布局）=====
    constexpr uint32_t BLOCK_M = 16;
    constexpr uint32_t BLOCK_K = 16;
    constexpr uint32_t BLOCK_N = 16;
    
    auto gmTensorA = MakeTensor(gmA, MakeShape(M, K));
    auto gmTensorB = MakeTensor(gmB, MakeShape(K, N));
    auto gmTensorC = MakeTensor(gmC, MakeShape(M, N));
    
    AscendC::LocalMemAllocator<AscendC::Hardware::L1> l1Allocator;
    auto l1TensorA = l1Allocator.Alloc<half, BLOCK_M * BLOCK_K>();
    auto l1TensorB = l1Allocator.Alloc<half, BLOCK_K * BLOCK_N>();
    
    AscendC::LocalMemAllocator<AscendC::Hardware::L0A> l0aAllocator;
    AscendC::LocalMemAllocator<AscendC::Hardware::L0B> l0bAllocator;
    AscendC::LocalMemAllocator<AscendC::Hardware::L0C> l0cAllocator;
    
    auto l0aTensor = l0aAllocator.Alloc<half, BLOCK_M * BLOCK_K>();
    auto l0bTensor = l0bAllocator.Alloc<half, BLOCK_K * BLOCK_N>();
    auto l0cTensor = l0cAllocator.Alloc<float, BLOCK_M * BLOCK_N>();
    
    // ===== 第二步：创建Copy/Mmad Atom =====
    auto copyGM2L1 = MakeCopy<CopyGM2L1>();
    auto copyL12L0A = MakeCopy<CopyL12L0A>();
    auto copyL12L0B = MakeCopy<CopyL12L0B>();
    auto copyL0C2GM = MakeCopy<CopyL0C2GM>();
    auto mmadAtom = MakeMmad<MmadOperation>();
    
    // ===== 第三步：分块矩阵乘法 =====
    for (uint32_t i = 0; i < M / BLOCK_M; i++) {
        for (uint32_t j = 0; j < N / BLOCK_N; j++) {
            for (uint32_t k = 0; k < K / BLOCK_K; k++) {
                // 切片
                auto gmBlockA = gmTensorA.Slice(
                    MakeCoord(i * BLOCK_M, k * BLOCK_K),
                    MakeShape(BLOCK_M, BLOCK_K));
                auto gmBlockB = gmTensorB.Slice(
                    MakeCoord(k * BLOCK_K, j * BLOCK_N),
                    MakeShape(BLOCK_K, BLOCK_N));
                
                // GM→L1（隐式同步）
                Copy(copyGM2L1, gmBlockA, l1TensorA);
                Copy(copyGM2L1, gmBlockB, l1TensorB);
                
                // L1→L0A/L0B（隐式同步）
                Copy(copyL12L0A, l1TensorA, l0aTensor);
                Copy(copyL12L0B, l1TensorB, l0bTensor);
                
                // Mmad
                Mmad(mmadAtom, l0aTensor, l0bTensor, l0cTensor);
            }
            
            // L0C→GM（隐式同步）
            auto gmBlockC = gmTensorC.Slice(
                MakeCoord(i * BLOCK_M, j * BLOCK_N),
                MakeShape(BLOCK_M, BLOCK_N));
            Copy(copyL0C2GM, l0cTensor, gmBlockC);
        }
    }
}
```

## Double Buffer示例：流水线并行

Double Buffer技术通过Ping-Pong交替机制实现数据搬运与计算的并行，提升流水线效率。

### 基础能力实现

```cpp
extern "C" __global__ __aicore__ void add_double_buffer_kernel(
    __gm__ half* gmIn0, __gm__ half* gmIn1, __gm__ half* gmOut,
    const uint32_t totalLength) {
    
    // ===== 第一步：初始化Double Buffer队列 =====
    TPipe pipe;
    TQue<UB, 2> queIn0, queIn1;  // depth=2支持Ping-Pong
    TQue<UB, 1> queOut;
    
    constexpr uint32_t TILE_LENGTH = 256;
    pipe.InitBuffer(queIn0, 2, TILE_LENGTH * sizeof(half));
    pipe.InitBuffer(queIn1, 2, TILE_LENGTH * sizeof(half));
    pipe.InitBuffer(queOut, 1, TILE_LENGTH * sizeof(half));
    
    // ===== 第二步：定义GlobalTensor =====
    GlobalTensor<half> gmTensorIn0, gmTensorIn1, gmTensorOut;
    gmTensorIn0.SetGlobalBuffer(gmIn0, totalLength);
    gmTensorIn1.SetGlobalBuffer(gmIn1, totalLength);
    gmTensorOut.SetGlobalBuffer(gmOut, totalLength);
    
    // ===== 第三步：Double Buffer流水线 =====
    constexpr uint32_t eventID = 0;
    uint32_t tileNum = (totalLength + TILE_LENGTH - 1) / TILE_LENGTH;
    
    // 预加载第一个Tile
    LocalTensor<half> ubIn0Ping = queIn0.AllocTensor<half>();
    LocalTensor<half> ubIn1Ping = queIn1.AllocTensor<half>();
    DataCopy(ubIn0Ping, gmTensorIn0[0], TILE_LENGTH);
    DataCopy(ubIn1Ping, gmTensorIn1[0], TILE_LENGTH);
    
    for (uint32_t i = 0; i < tileNum; i++) {
        // 当前Tile索引
        uint32_t curOffset = i * TILE_LENGTH;
        uint32_t curLength = min(TILE_LENGTH, totalLength - curOffset);
        
        // Ping-Pong切换
        LocalTensor<half> ubIn0 = ubIn0Ping;
        LocalTensor<half> ubIn1 = ubIn1Ping;
        
        // 预加载下一个Tile
        if (i + 1 < tileNum) {
            ubIn0Ping = queIn0.AllocTensor<half>();
            ubIn1Ping = queIn1.AllocTensor<half>();
            DataCopy(ubIn0Ping, gmTensorIn0[(i + 1) * TILE_LENGTH], TILE_LENGTH);
            DataCopy(ubIn1Ping, gmTensorIn1[(i + 1) * TILE_LENGTH], TILE_LENGTH);
        }
        
        // 同步：等待当前Tile数据就绪
        SetFlag<HardEvent::MTE2_V>(eventID);
        WaitFlag<HardEvent::MTE2_V>(eventID);
        
        // 计算
        LocalTensor<half> ubOut = queOut.AllocTensor<half>();
        Add(ubOut, ubIn0, ubIn1, curLength);
        
        // 同步：等待计算完成
        SetFlag<HardEvent::V_MTE3>(eventID);
        WaitFlag<HardEvent::V_MTE3>(eventID);
        
        // 输出
        DataCopy(gmTensorOut[curOffset], ubOut, curLength);
        
        // 释放
        queIn0.FreeTensor(ubIn0);
        queIn1.FreeTensor(ubIn1);
        queOut.FreeTensor(ubOut);
    }
}
```

## RegTensor示例：寄存器精细控制

> 📌 **提示**：RegTensor从**Ascend 950RT**开始支持，用于寄存器级精细控制与极致性能场景。

RegTensor提供对Vector计算单元内部寄存器的直接操作能力，适用于需要精细控制计算过程的场景。

### RegTensor Add示例

```cpp
#include "kernel_operator.h"

using namespace AscendC;
using namespace AscendC::Reg;

extern "C" __global__ __aicore__ void regtensor_add_kernel(
    __gm__ half* gmIn0, __gm__ half* gmIn1, __gm__ half* gmOut,
    const uint32_t totalLength) {
    
    // ===== 第一步：定义GlobalTensor =====
    GlobalTensor<half> gmTensorIn0, gmTensorIn1, gmTensorOut;
    gmTensorIn0.SetGlobalBuffer(gmIn0, totalLength);
    gmTensorIn1.SetGlobalBuffer(gmIn1, totalLength);
    gmTensorOut.SetGlobalBuffer(gmOut, totalLength);
    
    // ===== 第二步：分配UB空间 =====
    AscendC::LocalMemAllocator<AscendC::Hardware::UB> ubAllocator;
    LocalTensor<half> ubIn0 = ubAllocator.Alloc<half, 256>();
    LocalTensor<half> ubIn1 = ubAllocator.Alloc<half, 256>();
    LocalTensor<half> ubOut = ubAllocator.Alloc<half, 256>();
    
    // ===== 第三步：计算循环 =====
    constexpr uint32_t TILE_LENGTH = 256;
    uint32_t offset = 0;
    
    while (offset < totalLength) {
        uint32_t curLength = min(TILE_LENGTH, totalLength - offset);
        
        // Load：GM→UB
        DataCopy(ubIn0, gmTensorIn0[offset], curLength);
        DataCopy(ubIn1, gmTensorIn1[offset], curLength);
        
        // 同步
        SetFlag<HardEvent::MTE2_V>(0);
        WaitFlag<HardEvent::MTE2_V>(0);
        
        // ===== RegTensor计算 =====
        // 获取UB地址
        auto ubAddr0 = ubIn0.GetAddress();
        auto ubAddr1 = ubIn1.GetAddress();
        auto ubDstAddr = ubOut.GetAddress();
        
        // 创建寄存器
        vector_half srcReg0, srcReg1, dstReg;
        MaskReg mask;  // 全1掩码
        
        // Load：UB→寄存器
        LoadAlign(srcReg0, ubAddr0);
        LoadAlign(srcReg1, ubAddr1);
        
        // Compute：寄存器计算
        Add(dstReg, srcReg0, srcReg1, mask);
        
        // Store：寄存器→UB
        StoreAlign(ubDstAddr, dstReg, mask);
        
        // 同步
        SetFlag<HardEvent::V_MTE3>(0);
        WaitFlag<HardEvent::V_MTE3>(0);
        
        // Store：UB→GM
        DataCopy(gmTensorOut[offset], ubOut, curLength);
        
        offset += TILE_LENGTH;
    }
}
```

### RegTensor Mask示例

MaskReg掩码寄存器控制参与计算的元素，实现条件计算。

```cpp
// Mask条件计算示例
using namespace AscendC::Reg;

// 创建全1掩码
MaskReg maskAll;
maskAll.Set();  // 所有元素参与计算

// 创建条件掩码
vector_half compareResult;
MaskReg maskConditional;
compareResult[0] = 0.5;  // 比较值

// 条件掩码：大于0.5的元素参与计算
Compare(maskConditional, srcReg, compareResult, CMPMODE::GT);

// 条件计算：只有maskConditional为1的元素参与
Add(dstReg, srcReg0, srcReg1, maskConditional);
```

## Layout示例：多维数据布局

扩展能力通过Layout抽象多维数据的内存排列，支持平铺布局、层次化布局、分形布局等多种模式。

### 平铺布局示例

```cpp
// 平铺布局：128×64矩阵
auto shape = MakeShape(128, 64);
auto stride = MakeStride(64, 1);  // 行主序

auto layout = MakeLayout(shape, stride);
auto tensor = MakeTensor(ubPointer, layout);

// 访问元素：编译期自动计算索引
auto element = tensor[MakeCoord(32, 16)];  // 访问第32行第16列
```

### 层次化布局示例

```cpp
// 层次化布局：128×64矩阵分为8×4个16×16的块
// 外层：(8, 4) 个块
// 内层：每个块 (16, 16) 个元素
auto outerShape = MakeShape(8, 4);
auto innerShape = MakeShape(16, 16);
auto hierarchicalShape = MakeShape(outerShape, innerShape);

auto outerStride = MakeStride(256, 16);  // 块间步长
auto innerStride = MakeStride(16, 1);     // 块内步长
auto hierarchicalStride = MakeStride(outerStride, innerStride);

auto layout = MakeLayout(hierarchicalShape, hierarchicalStride);
auto tensor = MakeTensor(ubPointer, layout);

// 访问块
auto block = tensor.Slice(MakeCoord(2, 3), MakeShape(16, 16));
```

## 小结

本章通过Vector算子、Cube算子、Double Buffer、RegTensor、Layout等编程示例，展示了AscendC算子开发的实践方法：Vector算子遵循「加载→同步→计算→同步→存储」流程；Cube算子遵循「GM→L1→L0A/L0B→Mmad→L0C→GM」数据流；Double Buffer通过Ping-Pong机制实现搬运与计算并行；RegTensor提供寄存器级精细控制能力；Layout抽象简化多维数据布局处理。

开发者可根据算子特性选择基础能力或扩展能力，简单场景优先使用扩展能力的隐式同步，复杂场景可配合基础能力显式同步接口。
