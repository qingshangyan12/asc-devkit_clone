## Regbase矢量计算

**RegBase**架构芯片为开放了**基于寄存器**进行计算的指令。Ascend C提供Reg矢量计算API面向RegBase架构设计的矢量计算编程接口，供用户在开发矢量计算算子时调用。其操作对象为矢量寄存器（Register），用户通过主动调用Reg矢量计算搬运类API，完成本地内存（UB：Unified Buffer）与寄存器之间的数据交互；Reg矢量计算类API的计算参数均为寄存器，中间计算结果可暂存于寄存器中，无需频繁与本地内存交互，从而实现更高的计算效率与更大的开发灵活性。

Reg矢量计算API均以 `__simd_callee__` 修饰，只能在以 `__simd_vf__` 修饰的向量函数（VF:Vector Function）中调用。

**接口风格：**

Reg矢量计算接口采用C++类库形式，所有接口均位于 `AscendC::Reg` 命名空间中，矢量寄存器抽象为 `RegTensor` 数据结构。

```
namespace AscendC {
namespace Reg {
// 搬运接口举例
template <typename T = DefaultType, typename U>
__simd_callee__ inline void Load(U& dstReg, __ubuf__ T* srcAddr);

template <typename T = DefaultType, typename U>
__simd_callee__ inline void Store(__ubuf__ T* dstAddr, U& srcReg);

// 计算接口举例
template <typename T = DefaultType, MaskMergeMode mode = MaskMergeMode::ZEROING, typename U>
__simd_callee__ inline void Add(U& dstReg, U& srcReg0, U& srcReg1, MaskReg& mask);

}
}
```

**适用场景：**

- **高性能计算场景：** 当计算逻辑涉及多步骤中间结果时，Reg矢量计算可将中间结果保留在寄存器中，避免反复的Load/Store操作，从而显著降低延迟、提升整体性能。
- **精细化寄存器控制场景：** 当用户需要直接控制数据搬运与计算过程时（如设置掩码MaskReg、管理地址偏移AddrReg、处理非对齐访存UnalignReg等），Reg矢量计算API提供了比基础Tensor API更底层的操作能力。
- **SIMD VF函数编程场景：** 在以 `__simd_vf__` 标记的向量函数内部，计算操作须通过Reg矢量计算API实现；此类函数由核函数经 `asc_vf_call` 调用，并由硬件向量运算单元负责执行。
