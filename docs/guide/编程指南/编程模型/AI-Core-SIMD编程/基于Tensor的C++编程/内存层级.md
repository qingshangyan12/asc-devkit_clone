## 引言

AI Core采用三级存储架构，数据搬运遵循层级流转原则。Ascend C将物理内存抽象为Tensor对象，Tensor携带数据类型、形状、内存位置属性，接口调用时自动推断操作参数。本章阐述存储层级定位、Tensor抽象方式、接口定义方式。
> 📌 寄存器可编程能力从**Ascend 950PR/Ascend 950DT**引入，构建三级内存架构，可获得接近峰值的计算性能。
---

## 三级存储架构

AI Core采用「外部存储—片上存储—寄存器」三级架构，各层级分工明确、协同联动。数据流转遵循「就近计算」原则，数据需搬运到距离计算单元最近的存储层级。
**数据流转路径**：
- **Vector算子**：Global Memory → UB → 寄存器 → 计算 → UB → Global Memory
- **Cube算子**：Global Memory → L1 → L0A/L0B → 计算 → L0C → Global Memory

### 存储层级功能定位

- **外部存储（Global Memory）**：存放算子输入/输出数据。容量大但延迟高，需通过MTE2/MTE3流水线搬运到片上存储后才能参与计算。
- **片上存储（Local Memory）**：包括L1 Buffer、L0系列Buffer和Unified Buffer（UB）。L1承接GM数据供给L0，L0A/L0B直接供给Cube计算单元，L0C存储计算结果。UB是Vector算子的数据枢纽。容量有限但延迟低，采用分块迭代策略完成全域计算。
- **寄存器（Ascend 950PR/950DT引入）**：计算单元内部高速存储，延迟最低、带宽最高。Vector计算单元只能访问寄存器，不直接读取UB。

### 存储层级与地址限定符

**表 1** 存储层级与地址限定符对应关系
| 存储层级 | 地址限定符 | Tensor对应类型 | 用途 |
|----------|-----------|---------------|------|
| Global Memory | `__gm__` | GlobalTensor | 全局输入/输出 |
| UB | `__ubuf__` | LocalTensor\<Location::UB\> | Vector数据枢纽 |
| L1 | `__cbuf__` | LocalTensor\<Location::L1\> | Cube数据中转 |
| L0A | `__ca__` | LocalTensor\<Location::L0A\> | 左矩阵输入 |
| L0B | `__cb__` | LocalTensor\<Location::L0B\> | 右矩阵输入 |
| L0C | `__cc__` | LocalTensor\<Location::L0C\> | 矩阵乘结果 |

> 📌 片内存储有限，采用「分块搬运、迭代计算、结果累加」策略。UB容量约数十KB~数百KB，L1约数百KB~1MB，需据此规划分块大小。

## Tensor抽象内存定义
### 基础Tensor内存定义
- **Global Tensor**通过SetGlobalBuffer设置地址和大小
```cpp
GlobalTensor<half> gmTensor;
gmTensor.SetGlobalBuffer((__gm__ half*)gmBuffer, bufferSize);
gmTensor.SetL2CacheHint(CacheMode::READ_ONLY);  // 配置L2缓存
```

- **Local Tensor**提供了通过LocalMemAllocator指定硬件位置进行Tensor分配及通过LocalTensor构造函数创建Tensor(极致性能场景推荐使用此方式)
```cpp
// 方式1：使用LocalMemAllocator进行内存分配
AscendC::LocalMemAllocator<AscendC::Hardware::UB> ubAllocator;
AscendC::LocalTensor<float> xLocalPing = ubAllocator.Alloc<float, TILE_LENGTH>();
AscendC::LocalTensor<float> yLocalPing = ubAllocator.Alloc<float, TILE_LENGTH>();
AscendC::LocalTensor<float> zLocalPing = ubAllocator.Alloc<float, TILE_LENGTH>();

// 方式2：直接使用LocalTensor构造函数构造Tensor
AscendC::LocalTensor<float> xLocalPing(AscendC::TPosition::VECCALC, xAddrPing, TILE_LENGTH);
AscendC::LocalTensor<float> yLocalPing(AscendC::TPosition::VECCALC, yAddrPing, TILE_LENGTH);
AscendC::LocalTensor<float> zLocalPing(AscendC::TPosition::VECCALC, zAddrPing, TILE_LENGTH);
```

### 扩展Layout Tensor内存定义

### LocalTensor定义
- **Global Tensor & Local Tensor**都通过数组的方式申请内存，然后通过MakeTensor的方式进行Tensor创建
```cpp
// 1. Global Tensor的创建: 指定GM地址x, 创建Global Tensor
auto gmATensor = MakeTensor(MakeMemPtr(x), MakeFrameLayout<NDExtLayoutPtn>(m, k));

// 2. Local Tensor的创建: 通过数组的方式申请内存，并通过MakeTensor的方式创建对应的Local Tensor
constexpr uint32_t baseM = 128;
constexpr uint32_t baseN = 128;
constexpr uint32_t baseK = 256;
__cbuf__ half l1ABuf[baseM * baseK]; // 申请L1A的内存
__cbuf__ half l1BBuf[baseN * baseK]; // 申请L1B的内存
__ca__ half l0ABuf[baseM * baseK];   // 申请L0A的内存
__cb__ half l0BBuf[baseN * baseK];   // 申请L0B的内存
__cc__ float l0CBuf[baseM * baseN];  // 申请L0C的内存

auto l1ATensor = MakeTensor(MakeMemPtr(l1ABuf),  MakeFrameLayout<NZLayoutPtn, half>(baseM, baseK));
auto l1BTensor = MakeTensor(MakeMemPtr(l1BBuf),  MakeFrameLayout<NZLayoutPtn, half>(baseN, baseK));
auto l0ATensor = MakeTensor(MakeMemPtr(l0ABuf),  MakeFrameLayout<NZLayoutPtn, half>(baseM, baseK));
auto l0BTensor = MakeTensor(MakeMemPtr(l0BBuf),  MakeFrameLayout<ZNLayoutPtn, half>(baseN, baseK));
auto l0CTensor = MakeTensor(MakeMemPtr(l0CBuf),  MakeFrameLayout<NZLayoutPtn, half>(baseM, baseN));
```

### 寄存器Tensor定义（Ascend 950PR/950DT引入）

寄存器是计算单元工作存储，Vector只能访问寄存器，通过Load-Compute-Store与UB协作：

**寄存器Tensor类型**：
- **MaskReg**（vector_bool）：掩码寄存器，控制参与计算的元素
- **AddrReg**（vector_address）：地址寄存器，存储地址偏移量
- **RegTensor\<T\>**（RegTensor\<half\>、RegTensor\<float\>等）：矢量数据寄存器，存储计算数据

```cpp
using namespace AscendC::Reg;
MaskReg mask;                   // 掩码寄存器
RegTensor<half> srcReg;         // 数据寄存器
LoadAlign(srcReg, ubAddr);      // Load：UB→寄存器
Add(dstReg, srcReg0, srcReg1, mask);  // Compute：寄存器计算
StoreAlign(ubDstAddr, dstReg, mask);  // Store：寄存器→UB
```

## 小结
三级存储架构支撑数据流转，各层级有明确分工和对齐约束；物理存储抽象为GlobalTensor、LocalTensor、RegTensor三类；基础能力Tensor携带类型和位置属性，扩展能力引入Layout实现编译期类型安全和自动参数推断；寄存器是计算单元工作存储，通过Load-Compute-Store与片上存储协作。
