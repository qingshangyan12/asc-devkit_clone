AI Core采用三级存储架构，数据搬运遵循层级流转原则。Ascend C将物理内存抽象为Tensor对象，Tensor携带数据类型、形状、内存位置属性，接口调用时自动推断操作参数。本章阐述存储层级定位、Tensor抽象方式、接口定义方式。
> 📌 寄存器可编程能力从**Ascend 950PR/Ascend 950DT**引入，构建三级内存架构，可获得接近峰值的计算性能。

## 存储结构

Ascend 950PR/Ascend 950DT新一代架构在传统UB缓存体系的基础上，开放寄存器（Register）可编程能力，构建出「Global Memory → UB → Register」的三级内存层级，衍生出两套适配不同性能诉求的矢量计算模式，实现通用场景与极致性能场景的全覆盖。其内存层级结构如下图所示：

![AI Core存储层次结构](<../../../../figures/AI Core存储层次结构.png>)

### 存储层级功能定位

**外部存储（Global Memory）**：存放算子输入/输出数据。容量大但延迟高，需通过MTE2流水线搬运到片上存储后参与计算并通过MTE3流水搬出。
**片上存储（Local Memory）**：包括L1 Buffer、L0系列Buffer和Unified Buffer（UB）。UB是Vector算子的数据枢纽，数据需从Global Memory搬运至UB后才能参与矢量计算。L1 Buffer、L0A/L0B Buffer、L0C Buffer服务于矩阵计算：输入数据从GM搬运至L1 Buffer，再分发至L0A/L0B Buffer供Cube单元计算，结果暂存于L0C Buffer。
**寄存器（Ascend 950PR/950DT引入）**：位于Vector计算单元最内层，具备最低访存延迟与最高带宽。开放寄存器可编程能力，可充分释放硬件峰值性能。Vector计算单元仅访问寄存器，数据需从UB加载至寄存器后方可参与计算。

### 地址限定符

每种存储层级通过**地址限定符**标识，编译器据此将数据分配到对应物理存储空间。地址限定符是C指针编程的核心语法要素，明确告知编译器数据的存储位置，确保数据访问与硬件存储层级精准映射。使用方式包括：声明变量时指定限定符，或对指针进行强制类型转换。

## Tensor抽象内存定义
### 基础Tensor内存定义
- **Global Tensor**通过SetGlobalBuffer设置地址和大小
```cpp
GlobalTensor<half> gmTensor;
gmTensor.SetGlobalBuffer((__gm__ half*)gmBuffer, bufferSize);
gmTensor.SetL2CacheHint(CacheMode::READ_ONLY);  // 配置L2缓存
```

- **Local Tensor**提供两种定义方式：通过LocalMemAllocator指定硬件位置进行Tensor分配，或通过LocalTensor构造函数创建Tensor（极致性能场景推荐使用此方式）。
```cpp
// 方式1：使用LocalMemAllocator进行内存分配
AscendC::LocalMemAllocator<AscendC::Hardware::UB> ubAllocator;
AscendC::LocalTensor<float> xLocalPing = ubAllocator.Alloc<float, TILE_LENGTH>();
AscendC::LocalTensor<float> yLocalPing = ubAllocator.Alloc<float, TILE_LENGTH>();
AscendC::LocalTensor<float> zLocalPing = ubAllocator.Alloc<float, TILE_LENGTH>();

// 方式2：直接使用LocalTensor构造函数构造Tensor
AscendC::LocalTensor<float> xLocalPing(AscendC::TPosition::VECCALC, xAddrPing, TILE_LENGTH);
AscendC::LocalTensor<float> yLocalPing(AscendC::TPosition::VECCALC, yAddrPing, TILE_LENGTH);
AscendC::LocalTensor<float> zLocalPing(AscendC::TPosition::VECCALC, zAddrPing, TILE_LENGTH);
```

### 扩展Layout Tensor内存定义（Ascend 950PR/950DT引入）

Ascend 950PR/950DT在Tensor基础上引入Layout布局概念，将Shape和Stride移到编译期确定，实现类型安全和分形布局自动生成，开发者只需定义Tensor的Layout，搬运和计算接口自动推断底层参数，大幅降低矩阵算子开发难度。

#### Layout表述
我们使用Shape和Stride来表达Layout排布格式，比如下图中的行优先和列优先排布：
Shape用于表达Tensor形状，Stride则用于区分不同的排布：
- 行优先: Shape (2, 4) Stride (4, 1)
- 列优先: Shape (2, 4) Stride (1, 2)
图中每个方格中的数字表示该位置元素在内存中按顺序排列时的下标。对于相同的矩阵位置，排布方式不同时，其在内存中的顺序可能是不同的，例如，矩阵坐标 (1, 0) 在行优先和列优先的情况下，对应元素在内存中的顺序分别是4和1。

![行优先排布](../../../../figures/行优先排布.png)
![列优先排布](../../../../figures/列优先排布.png)

### Layout层次化表达
通常Shape或者Stride中的元素是一个单独的整数（如上文的示例），但是遇到一些复杂的内存排布情况可能无法表达，所以采用层次化表述法，该方式中，元素也可以是一个元组。元组的第一个元素用于描述不同层次中矩阵的行数，元组的第二个元素用于描述不同层次中矩阵的列数。
例如在下图中，Layout的Shape和Stride分别为：
- Shape((2, 3), (2, 4))
- Stride((1, 4), (2, 12))

![层次化Layout表达](../../../../figures/层次化Layout表达.png)

图中展示了两层矩阵：内层矩阵为内部用灰色线包裹的矩阵，外层矩阵为将内层矩阵视为一个元素时黑色线包裹的矩阵。
Shape的第一个元素描述行方向的形状，(2, 3)表示内层矩阵和外层矩阵的行数分别为2和3；Shape的第二个元素描述的是列方向上的形状，(2, 4)表示内层矩阵和外层矩阵的列数分别为2和4。
Stride中的每个元素与Shape中的元素对应，表示该对应维度下，相邻元素首地址在内存地址上的间隔，图片中用箭头表示了每个维度相邻元素的首地址间隔。

### Tensor定义方式
扩展能力的Tensor是通过对基础Tensor的特化扩展实现，它通过MakeTensor函数创建，Shape和Stride可以在编译期确定。针对不同的应用场景提供多种定义方式：
- **1. 定义连续的内存块的Tensor**
```cpp
// 1.1 定义动态Shape Tensor
auto dynTensor = MakeTensor(pointer, MakeShape(m, n));
// 1.2 定义静态Shape Tensor
auto staticTensor = MakeTensor(pointer, MakeShape(Std::Int<128>{}, Std::Int<64>{}));
```

- **2. 指定Stride定义任意排布的Tensor**
```cpp
// 2.1 行优先排布的Tensor定义
auto rowMajorTensor = MakeTensor(pointer, MakeLayout(MakeShape(m, n), MakeStride(n, Std::Int<1>{})));
// 2.2 列优先排布的Tensor定义
auto colMajorTensor = MakeTensor(pointer, MakeLayout(MakeShape(m, n), MakeStride(Std::Int<1>{}, n)));
```

- **3. 通过层次化布局形式定义矩阵分形Tensor**
```cpp
// 3.1 针对(128, 64)的矩阵，内部为16 * 16的分形，可以通过层次化布局来定义对应的4维Tensor
auto nzTensor = MakeTensor(pointer, MakeLayout(MakeShape((8, 16), (4, 16))));
```

- **4. 通过特定的分形布局进行简化的定义** - Cube矩阵乘专用，自动生成Shape和Stride
```cpp
// 4.1 通过MakeFrameLayout，指定NZ Pattern直接指定NZ分形, 接口内部自动推导成4维分形
auto tensor = MakeTensor(l0aPointer, MakeFrameLayout<NZLayoutPtn>(128, 64));
```

### Tensor使用方式
扩展能力Tensor引入Layout抽象成为"自描述数据容器"，实现编译期自动推导操作参数、类型安全校验和零开销切片，开发者只需定义Tensor即可自动推断后续搬运、计算参数，无需手动传递。

- **进行切片操作**
```cpp
auto tensor = MakeTensor(pointer, MakeShape(1024, 512));
// 切片：从(0,0)位置取128×64块
auto slice = tensor.Slice(MakeCoord(0, 0), MakeShape(128, 64));
// 动态切片：分块处理场景
auto slice = tensor.Slice(MakeCoord(i * 64, j * 32), MakeShape(64, 32));
```

- **提供简化的搬运接口，无需复杂的参数计算**
```cpp
auto gmTensor = MakeTensor(gmPtr, MakeShape(128, 64));
auto ubTensor = MakeTensor(ubPtr, MakeShape(128, 64));

// 3.1 搬运：利用系统内置搬运直接搬运，无需设置Size等
Copy(gmTensor, ubTensor);

// 3.2 搬运: 通过自定义搬运Op，进行定制化的搬运处理
auto copyAtom = MakeCopy<CopyGM2UB>();
Copy(copyAtom, gmTensor, ubTensor);
```

- **CUBE计算：提供了简化的Mmad接口，方便用户直接进行矩阵乘计算**
```cpp
Mmad(l0c, l0a, l0b, {m, n, k, false, iterK == 0});
```

### 寄存器Tensor定义（Ascend 950PR/950DT引入）

寄存器是计算单元工作存储，Vector只能访问寄存器，通过Load-Compute-Store与UB协作：

**寄存器Tensor类型**：
- **MaskReg**（vector_bool）：掩码寄存器，控制参与计算的元素
- **AddrReg**（vector_address）：地址寄存器，存储地址偏移量
- **RegTensor\<T\>**（RegTensor\<half\>、RegTensor\<float\>等）：矢量数据寄存器，存储计算数据

```cpp
using namespace AscendC::Reg;
MaskReg mask;                   // 掩码寄存器
RegTensor<half> srcReg;         // 数据寄存器
LoadAlign(srcReg, ubAddr);      // Load：UB→寄存器
Add(dstReg, srcReg0, srcReg1, mask);  // Compute：寄存器计算
StoreAlign(ubDstAddr, dstReg, mask);  // Store：寄存器→UB
```

三级存储架构支撑数据流转，各层级有明确分工和对齐约束；物理存储抽象为GlobalTensor、LocalTensor、RegTensor三类；基础能力Tensor携带类型和位置属性，扩展能力引入Layout实现编译期类型安全和自动参数推断；
