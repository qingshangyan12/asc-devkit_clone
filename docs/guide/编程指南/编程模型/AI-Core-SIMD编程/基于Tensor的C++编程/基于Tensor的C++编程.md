# 基于Tensor的C++编程

基于Tensor的C++编程是Ascend C提供的一种面向极致性能的编程方式，开发者通过直接构造指定地址和存储位置的LocalTensor，并将其传递给搬运、计算等基础API完成算子开发。相比基于Pipe（TPipe）的编程方式，该方式省去了TPipe内存管理初始化等运行时开销，赋予开发者对内存分配、DoubleBuffer流水和同步事件的完全控制权，从而实现更优性能。但开发复杂度也相应提高，需要开发者自行管理内存复用、流水线同步等细节。

基于Tensor的C++编程包含以下两种编程模式：

- **[静态Tensor编程](./静态Tensor编程.md)**：通过LocalMemAllocator或直接构造LocalTensor管理内存，开发者自主插入同步事件协调各指令流水，适用于矢量算子和矩阵算子的精细化调优。
- **[Reg矢量计算编程](./Reg矢量计算编程.md)**：面向RegBase架构，直接对Vector计算寄存器进行操作，中间结果暂存于寄存器而非Local Memory，减少不必要的UB读写开销，适用于计算链较长的激活函数等场景。
