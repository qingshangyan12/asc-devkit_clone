## 引言
数据搬运与计算是Ascend C算子开发的核心操作，数据搬运实现Global Memory与Local Memory之间的数据流转，计算操作实现Vector单元的向量运算和Cube单元的矩阵乘法。两者紧密协作，共同支撑算子的完整执行流程。
本章旨在帮助开发者建立对Ascend C数据搬运与计算接口的系统化认知，掌握基础能力与扩展能力的接口使用方法。全文遵循「数据搬运接口—计算接口—协作模式」的递进逻辑展开，完整覆盖数据搬运与计算全链路核心内容：阐述数据搬运的通路与功能、拆解计算接口的分类与使用、并逐层讲解数据搬运与计算的协作模式。

## 数据搬运接口：通路与功能定位
DataCopy系列接口提供全面的数据搬运功能，支持多种数据搬运场景，并可在搬运过程中实现随路格式转换和量化激活等操作。

### 数据搬运通路
**表 1**  DataCopy数据搬运通路
| 搬运通路 | 方向 | 描述 | 使用场景 |
|----------|------|------|----------|
| **GM→UB** | Global Memory → Unified Buffer | 全局内存到Vector缓冲区 | Vector算子输入数据加载 |
| **UB→GM** | Unified Buffer → Global Memory | Vector缓冲区到全局内存 | Vector算子结果输出 |
| **GM→L1** | Global Memory → L1 Buffer | 全局内存到Cube中转站 | Cube算子矩阵数据加载 |
| **L1→L0A/L0B** | L1 → L0A/L0B | Cube中转站到输入缓冲区 | Cube算子分块加载 |
| **L0C→GM** | L0C → Global Memory | Cube结果缓冲区到全局内存 | Cube算子结果输出 |
| **UB→UB** | UB → UB | UB内部数据搬运 | Vector算子内部数据重组 |
| **L0C→UB** | L0C → UB | Cube结果到Vector缓冲区 | Cube+Vector协作场景 |

> 📌 **提示**：数据搬运通路的选择取决于算子类型：Vector算子使用GM↔UB通路，Cube算子使用GM→L1→L0A/L0B→L0C→GM通路，Cube+Vector协作场景使用L0C→UB通路。

### DataCopy功能分类
DataCopy系列接口按功能分为基础数据搬运、增强数据搬运、切片数据搬运、随路转换搬运、随路量化激活搬运、多维数据搬运六大类。
**表 2**  DataCopy功能分类
| 功能 | 描述 | GM→Local | Local→GM | Local→Local | 典型场景 |
|------|------|----------|----------|-------------|----------|
| **基础数据搬运** | 数据保持原始格式和内容不变，支持连续和非连续搬运 | ✓ | ✓ | ✓ | 基础算子数据加载/输出 |
| **增强数据搬运** | 增加随路计算能力 | ✓ | ✓ | ✓ | 搬运过程中执行简单计算 |
| **切片数据搬运** | 提取多维Tensor数据的子集搬运 | ✓ | ✓ | ✗ | 分块处理场景 |
| **随路转换ND2NZ** | 搬运时进行ND到NZ格式转换 | ✗ | ✓ | ✓ | Cube矩阵乘数据准备 |
| **随路转换NZ2ND** | 搬运时进行NZ到ND格式转换 | ✓ | ✗ | ✗ | Cube结果格式恢复 |
| **随路量化激活** | 搬运过程中进行量化/Relu激活 | ✓ | ✗ | ✓ | 量化/激活算子 |
| **多维数据搬运** | 自由配置搬入维度和Stride | ✗ | ✓ | ✗ | 复杂布局场景 |

### 基础数据搬运接口
基础数据搬运接口提供Local Memory与Global Memory之间的基础搬运能力，数据在传输过程中保持原始格式和内容不变。
**表 3**  基础DataCopy接口参数说明
| 参数名 | 类型 | 描述 | 必选 |
|--------|------|------|------|
| **dst** | LocalTensor\<T\> / GlobalTensor\<T\> | 目标Tensor，数据搬入的位置 | 是 |
| **src** | LocalTensor\<T\> / GlobalTensor\<T\> | 源Tensor，数据搬出的位置 | 是 |
| **size** | uint32_t | 搬运数据个数（元素数） | 是 |

**函数原型**：
```cpp
// Local Memory → Global Memory
template <typename T>
__aicore__ inline void DataCopy(GlobalTensor<T>& dst, const LocalTensor<T>& src, const uint32_t size)
// Global Memory → Local Memory
template <typename T>
__aicore__ inline void DataCopy(LocalTensor<T>& dst, const GlobalTensor<T>& src, const uint32_t size)
// Local Memory → Local Memory
template <typename T>
__aicore__ inline void DataCopy(LocalTensor<T>& dst, const LocalTensor<T>& src, const uint32_t size)
```
**使用示例**：
```cpp
// ===== GM→UB：Vector算子输入加载 =====
GlobalTensor<half> gmInput;
LocalTensor<half> ubBuffer;
DataCopy(ubBuffer, gmInput, 256);  // 搬运256个half元素
// ===== UB→GM：Vector算子结果输出 =====
GlobalTensor<half> gmOutput;
LocalTensor<half> ubResult;
DataCopy(gmOutput, ubResult, 256);  // 输出256个half元素
```

> 📌 **提示**：基础DataCopy接口的size参数是元素个数，不是字节数。搬运half类型256个元素，实际搬运256×sizeof(half)=512字节。

### 切片数据搬运接口
切片数据搬运接口支持提取多维Tensor数据的子集进行搬运，适用于分块处理场景。
**表 4**  切片DataCopy接口参数说明
| 参数名 | 类型 | 描述 | 必选 |
|--------|------|------|------|
| **dst** | LocalTensor\<T\> / GlobalTensor\<T\> | 目标Tensor切片 | 是 |
| **src** | LocalTensor\<T\> / GlobalTensor\<T\> | 源Tensor切片 | 是 |

**使用示例**：
```cpp
// ===== 切片搬运：GM→UB =====
GlobalTensor<half> gmTensor = MakeTensor(gmPtr, MakeShape(1024, 512));
LocalTensor<half> ubTensor = MakeTensor(ubPtr, MakeShape(128, 64));
// 切片：取GM中(0,0)位置的128×64块
auto gmSlice = gmTensor.Slice(MakeCoord(0, 0), MakeShape(128, 64));
DataCopy(ubTensor, gmSlice);  // 搬运切片数据
```

### 扩展能力Copy接口
扩展能力通过Copy Atom实现数据搬运，Copy Atom显式表达内存路径，简化参数配置，并支持隐式同步。
**表 5**  Copy Atom接口参数说明
| 参数名 | 类型 | 描述 | 必选 |
|--------|------|------|------|
| **copyAtom** | Copy\<Operation\> | Copy Atom对象，显式表达内存路径 | 是 |
| **src** | Tensor | 源Tensor | 是 |
| **dst** | Tensor | 目标Tensor | 是 |

**Copy Atom类型**：
- **CopyGM2UB**：GM→UB搬运Atom
- **CopyUB2GM**：UB→GM搬运Atom
- **CopyGM2L1**：GM→L1搬运Atom
- **CopyL12L0A**：L1→L0A搬运Atom
- **CopyL12L0B**：L1→L0B搬运Atom
- **CopyL0C2GM**：L0C→GM搬运Atom

**使用示例**：
```cpp
// ===== 创建Copy Atom =====
auto copyGM2UB = MakeCopy<CopyGM2UB>();  // GM→UB Atom
auto copyUB2GM = MakeCopy<CopyUB2GM>();  // UB→GM Atom
// ===== 使用Copy Atom搬运（隐式同步）=====
Copy(copyGM2UB, gmTensor, ubTensor);  // GM→UB，隐式同步
Copy(copyUB2GM, ubTensor, gmTensor);  // UB→GM，隐式同步
```

> 📌 **提示**：扩展能力的Copy接口采用Operation驱动隐式同步，减少手动同步调用，简化开发流程。

## 计算接口：Vector与Cube分类
Ascend C计算接口分为Vector计算接口（向量运算）和Cube计算接口（矩阵乘法），分别对应Vector计算单元和Cube计算单元。

### Vector计算接口分类
Vector计算接口按功能分为逐元素运算、逐元素比较、归约运算、数据类型转换四大类。
**表 6**  Vector计算接口分类
| 接口类型 | 功能描述 | 典型接口 | 使用场景 |
|----------|----------|----------|----------|
| **逐元素运算** | 对Tensor中每个元素执行相同运算 | Add、Sub、Mul、Div、Abs、Sqrt | 激活函数、归一化、逐元素操作 |
| **逐元素比较** | 对Tensor中每个元素进行比较 | Compare、Greater、Less、Equal | 条件判断、阈值处理 |
| **归约运算** | 对Tensor中元素进行聚合计算 | ReduceSum、ReduceMax、ReduceMin | 求和、最大值、最小值 |
| **数据类型转换** | 转换Tensor数据类型 | Cast、CastTranspose | 精度转换、格式转换 |

### Add接口参数说明
Add接口实现逐元素求和，是最基础的Vector计算接口。
**表 7**  Add接口参数说明
| 参数名 | 类型 | 描述 | 必选 |
|--------|------|------|------|
| **dst** | LocalTensor\<T\> | 目标Tensor，存储计算结果 | 是 |
| **src0** | LocalTensor\<T\> | 源Tensor0，第一个输入 | 是 |
| **src1** | LocalTensor\<T\> | 源Tensor1，第二个输入 | 是 |
| **count** | int32_t | 参与计算的元素个数 | 是（前n模式） |

**函数原型**：
```cpp
// 整个tensor参与计算
dst = src0 + src1;
// tensor前n个数据计算
template <typename T>
__aicore__ inline void Add(const LocalTensor<T>& dst, const LocalTensor<T>& src0, const LocalTensor<T>& src1, const int32_t& count)
```
**支持数据类型**：
- Ascend 950PR/Ascend 950DT：int8_t、uint8_t、int16_t、uint16_t、half、bfloat16_t、int32_t、uint32_t、float、complex32、int64_t、uint64_t、complex64
- Atlas A2/A3系列：half、int16_t、int32_t、float

**使用示例**：
```cpp
// ===== Add计算：UB上两个Tensor相加 =====
LocalTensor<half> ubSrc0, ubSrc1, ubDst;
Add(ubDst, ubSrc0, ubSrc1, 256);  // 256个half元素相加
// ===== 整个Tensor参与计算 =====
ubDst = ubSrc0 + ubSrc1;  // 整个Tensor相加
```

### Cube计算接口：Mmad
Mmad接口实现矩阵乘法，是Cube计算单元的核心接口。
**表 8**  Mmad接口参数说明
| 参数名 | 类型 | 描述 | 必选 |
|--------|------|------|------|
| **dst** | LocalTensor\<T\> | 目标Tensor（L0C），存储矩阵乘结果 | 是 |
| **src0** | LocalTensor\<T\> | 源Tensor0（L0A），左矩阵 | 是 |
| **src1** | LocalTensor\<T\> | 源Tensor1（L0B），右矩阵 | 是 |
| **mmadParams** | MmadParams | Mmad参数结构体 | 是 |

**MmadParams参数说明**：
| 参数名 | 类型 | 描述 | 必选 |
|--------|------|------|------|
| **m** | uint32_t | 左矩阵行数 | 是 |
| **n** | uint32_t | 右矩阵列数 | 是 |
| **k** | uint32_t | 矩阵乘累加维度 | 是 |
| **cmatrixInitVal** | bool | L0C初始化值，true初始化为0 | 是 |

**使用示例**：
```cpp
// ===== Mmad计算：矩阵乘 =====
LocalTensor<half> l0a, l0b;
LocalTensor<float> l0c;
MmadParams mmadParams;
mmadParams.m = 16;
mmadParams.n = 16;
mmadParams.k = 16;
mmadParams.cmatrixInitVal = true;  // L0C初始化为0
Mmad(l0c, l0a, l0b, mmadParams);  // 16×16 × 16×16矩阵乘
```

> 📌 **提示**：Mmad接口的cmatrixInitVal参数控制L0C初始化值。首次矩阵乘时设置为true初始化为0，累加计算时设置为false保留上次结果。

### 扩展能力Mmad接口
扩展能力通过Mmad Atom实现矩阵乘，Mmad Atom简化参数配置，并支持隐式同步。
**表 9**  Mmad Atom接口参数说明
| 参数名 | 类型 | 描述 | 必选 |
|--------|------|------|------|
| **mmadAtom** | Mmad\<Operation\> | Mmad Atom对象 | 是 |
| **src0** | Tensor | 源Tensor0（L0A） | 是 |
| **src1** | Tensor | 源Tensor1（L0B） | 是 |
| **dst** | Tensor | 目标Tensor（L0C） | 是 |

**使用示例**：
```cpp
// ===== 创建Mmad Atom =====
auto mmadAtom = MakeMmad<MmadOperation>();
// ===== 使用Mmad Atom计算（隐式同步）=====
Mmad(mmadAtom, l0aTensor, l0bTensor, l0cTensor);
```

## 数据搬运与计算协作模式
数据搬运与计算紧密协作，形成完整的算子执行流程。Vector算子和Cube算子遵循不同的协作模式。

### Vector算子协作模式
Vector算子遵循「GM→UB→计算→UB→GM」协作模式，数据从Global Memory搬运到UB，在UB上执行Vector计算，结果写回Global Memory。
**表 10**  Vector算子协作模式流程
| 步骤 | 操作 | 接口 | 同步时机 |
|------|------|------|----------|
| **1. 数据搬入** | GM→UB | DataCopy | MTE2→V同步 |
| **2. 计算** | Vector计算 | Add/Sub/Mul等 | V→MTE3同步 |
| **3. 数据搬出** | UB→GM | DataCopy | 无 |

**标准流程示例**：
```cpp
// ===== Vector算子标准流程 =====
// 1. 数据搬入：GM→UB
DataCopy(ubIn0, gmInput0, size);
DataCopy(ubIn1, gmInput1, size);
// 2. 同步：等待MTE2完成
SetFlag<HardEvent::MTE2_V>(eventID);
WaitFlag<HardEvent::MTE2_V>(eventID);
// 3. 计算：Add
Add(ubOut, ubIn0, ubIn1, size);
// 4. 同步：等待Vector完成
SetFlag<HardEvent::V_MTE3>(eventID);
WaitFlag<HardEvent::V_MTE3>(eventID);
// 5. 数据搬出：UB→GM
DataCopy(gmOutput, ubOut, size);
```

> 📌 **提示**：Vector算子需要在数据搬运和计算之间添加同步，确保数据就绪后再执行计算，计算完成后再输出数据。

### Cube算子协作模式
Cube算子遵循「GM→L1→L0A/L0B→Mmad→L0C→GM」协作模式，数据经过多级搬运到达L0A/L0B，执行矩阵乘法，结果存储在L0C后写回Global Memory。
**表 11**  Cube算子协作模式流程
| 步骤 | 操作 | 接口 | 同步时机 |
|------|------|------|----------|
| **1. 数据搬入** | GM→L1 | DataCopy | MTE2→MTE1同步 |
| **2. 分块加载** | L1→L0A/L0B | LoadData | MTE1→C同步 |
| **3. 矩阵乘** | Mmad | Mmad | C→MTE3同步 |
| **4. 结果输出** | L0C→GM | DataCopy | 无 |

**标准流程示例**：
```cpp
// ===== Cube算子标准流程 =====
for (uint32_t i = 0; i < M / BLOCK_M; i++) {
    for (uint32_t j = 0; j < N / BLOCK_N; j++) {
        // 分配L0C并初始化
        LocalTensor<float> l0c = queL0C.AllocTensor<float>();
        for (uint32_t k = 0; k < K / BLOCK_K; k++) {
            // 1. 数据搬入：GM→L1
            DataCopy(l1a, gmTensorA[offsetA], BLOCK_M * BLOCK_K);
            DataCopy(l1b, gmTensorB[offsetB], BLOCK_K * BLOCK_N);
            SetFlag<HardEvent::MTE2_MTE1>(eventID0);
            WaitFlag<HardEvent::MTE2_MTE1>(eventID0);
            // 2. 分块加载：L1→L0A/L0B
            LoadData(l0a, l1a, loadParams);
            LoadData(l0b, l1b, loadParams);
            SetFlag<HardEvent::MTE1_C>(eventID1);
            WaitFlag<HardEvent::MTE1_C>(eventID1);
            // 3. 矩阵乘：Mmad
            Mmad(l0c, l0a, l0b, mmadParams);
        }
        // 4. 结果输出：L0C→GM
        SetFlag<HardEvent::C_MTE3>(eventID2);
        WaitFlag<HardEvent::C_MTE3>(eventID2);
        DataCopy(gmTensorC[offsetC], l0c, BLOCK_M * BLOCK_N);
        queL0C.FreeTensor(l0c);
    }
}
```

> 📌 **提示**：Cube算子需要多级同步：MTE2→MTE1（GM→L1完成后才能L1→L0）、MTE1→C（L1→L0完成后才能Mmad）、C→MTE3（Mmad完成后才能L0C→GM）。

### 扩展能力隐式同步模式
扩展能力通过Atom驱动隐式同步，减少手动同步调用，简化协作流程。
**隐式同步原理**：Atom内部自动插入同步，开发者无需显式调用SetFlag/WaitFlag。
**对比示例**：
```cpp
// ===== 基础能力：显式同步 =====
DataCopy(ubBuffer, gmInput, size);
SetFlag<HardEvent::MTE2_V>(eventID);   // 显式同步
WaitFlag<HardEvent::MTE2_V>(eventID);
Add(ubOut, ubIn0, ubIn1, size);
// ===== 扩展能力：隐式同步 =====
Copy(copyGM2UB, gmTensor, ubTensor);   // 隐式同步，无需手动SetFlag/WaitFlag
Add(ubOutTensor, ubIn0Tensor, ubIn1Tensor);
```

> 📌 **提示**：扩展能力的隐式同步适用于简单场景，复杂场景（如Double Buffer、多算子协作）仍需使用基础能力的显式同步接口。

## 小结
本章系统梳理了Ascend C数据搬运与计算接口的全链路技术体系：数据搬运接口按通路分为GM↔UB、GM↔L1、L1↔L0A/L0B、L0C↔GM等，按功能分为基础搬运、切片搬运、随路转换、随路量化激活等；计算接口分为Vector计算（逐元素运算、归约运算、数据转换）和Cube计算（Mmad矩阵乘）；数据搬运与计算协作模式分为Vector算子模式（GM→UB→计算→UB→GM）和Cube算子模式（GM→L1→L0A/L0B→Mmad→L0C→GM），扩展能力通过Atom驱动隐式同步简化流程。
后续章节将逐层深入、循序渐进地详解同步机制、编程示例，帮助开发者熟练掌握Ascend C数据搬运与计算的核心能力。
