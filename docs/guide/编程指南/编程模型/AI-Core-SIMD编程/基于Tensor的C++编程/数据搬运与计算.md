## 引言

数据搬运与计算是AI Core算子开发的两大核心操作，共同构成算子执行的数据流转与计算处理闭环。数据搬运解决「数据从哪里来、到哪里去」的问题，计算解决「数据如何处理」的问题，二者协同配合完成算子功能实现。本章旨在帮助开发者建立对C++ Tensor编程搬运与计算接口的系统化认知，重点阐述C++ Tensor编程的特点与优势，以及接口的分类体系与使用方法。全文遵循「编程特点—硬件架构—接口分类—标准流程」的递进逻辑展开。

## C++ Tensor编程：特点与核心优势

C++ Tensor编程是面向NPU硬件的C++模板库API，提供类型安全、编译期推断的高抽象编程能力。相比C指针编程的「指令级透明可控」，C++ Tensor编程的核心优势是提供模板编程体验。
### C++编程体验：模板与重载机制
C++ Tensor编程充分利用C++语言特性，提供现代化的编程体验：
- **函数重载简化调用**：同一接口名支持多种参数形式。`DataCopy`接口重载支持GM→UB、UB→GM、UB→UB三种通路；`Add`接口重载支持整个Tensor计算和前N个元素计算两种模式。开发者无需记忆不同函数名，一个接口名覆盖多种场景。
- **运算符重载直观表达**：支持C++运算符直接操作Tensor。`dst = src0 + src1`替代`Add(dst, src0, src1, count)`，`dst = src0 * src1`替代`Mul(dst, src0, src1, count)`。代码更简洁，表达更直观，符合数学运算直觉。
- **模板参数自动推导**：函数模板自动推导数据类型，无需显式指定。调用`Add(ubDst, ubSrc0, ubSrc1)`时，编译器从Tensor模板参数推导`T = half`，减少冗余类型声明。

### 扩展能力抽象：Layout与Shape机制
扩展能力引入Layout和Shape抽象，简化复杂场景开发：
- **Layout抽象布局处理**：`Layout<Shape, Stride>`描述多维张量的内存布局，支持ND（连续）、NZ（分形）、ZN（转置分形）、ZZ/NN（Scale布局）等多种格式。开发者定义Layout后，搬运接口自动处理布局转换（如ND→NZ），无需手动计算分形参数。
- **Shape定义张量维度**：`Shape<M, N, K>`定义张量的逻辑维度，编译期携带维度信息。配合Layout，编译器从Shape自动推断搬运长度、计算元素数，无需手动传入size/count参数。
- **Stride描述物理排布**：`Stride`定义各维度的物理步长，描述行主序、列主序或自定义布局。编译器根据Stride计算元素物理地址，支持非连续访问、矩阵转置等复杂场景。
- **编译器推断简化配置**：扩展能力Tensor携带Shape和Layout，搬运/计算接口从Tensor属性自动推断参数。对比：基础能力需手动传入`DataCopy(dst, src, size)`，扩展能力只需`Copy(atom, dstTensor, srcTensor)`，编译器从Tensor的Shape推断搬运长度。

## 硬件底层支撑：流水线与存储架构

AI Core采用多流水线并行架构与多层级存储架构，数据搬运与计算指令由不同流水线承载，协同完成数据处理。

**流水线分工**：
- **MTE2**：数据搬入（GM→Local Memory），承载DataCopy（GM→UB/L1）搬运指令
- **MTE3**：数据搬出（Local Memory→GM），承载DataCopy（UB/L0C→GM）搬运指令
- **MTE1**：L1搬运（L1→L0A/L0B），承载LoadData搬运指令
- **FIX**：L0C搬运（L0C→GM/UB），承载Fixpipe搬运指令
- **Vector**：向量计算，承载Add、Mul等计算指令
- **Cube**：矩阵计算，承载Mmad矩阵乘指令

**数据流转路径**：
- **Vector算子数据流**：`GM → UB → Vector计算 → UB → GM`
- **Cube算子数据流**：`GM → L1 → L0A/L0B → Cube计算 → L0C → GM`

> 📌 数据搬运遵循「就近计算」原则，将数据搬运到距离计算单元最近的存储层级，最大限度减少搬运开销。

## 数据搬运接口：分类体系

数据搬运接口按能力层次分为**基础搬运接口**与**扩展搬运接口**两类，按计算单元分为**Vector搬运**与**Cube搬运**两类。

### 基础搬运接口（Vector搬运）

基础搬运接口使用LocalTensor/GlobalTensor承载数据，接口定义形式包含连续搬运和非连续搬运形式。
- **接口原型**：
```cpp
// 连续搬运
template <typename T>
__aicore__ inline void DataCopy(const LocalTensor<T>& dst, const GlobalTensor<T>& src, const uint32_t count)

// 同时支持非连续搬运和连续搬运
template <typename T>
__aicore__ inline void DataCopy(const LocalTensor<T>& dst, const GlobalTensor<T>& src, const DataCopyParams& repeatParams)
```
- **使用场景**
```cpp
// srcLocal为half类型的LocalTensor，srcGlobal为half类型的GlobalTensor
// 使用传入count参数的搬运接口，完成连续搬运
AscendC::DataCopy(srcLocal, srcGlobal, 512);
// 使用传入DataCopyParams参数的搬运接口，支持连续和非连续搬运
DataCopyParams intriParams;
intriParams.blockCount = 1; // 连续数据块个数为1
intriParams.blockLen = 512 * sizeof(half) / 32; // 连续数据块长度，单位为DataBlock，此处长度为512个half元素
intriParams.srcGap = 0; // 源操作数做连续搬运
intriParams.dstGap = 0; // 目的操作数连续排布
AscendC::DataCopy(srcLocal, srcGlobal, intriParams);
```
---

### Cube搬运接口

Cube搬运接口支撑矩阵乘法的数据供给，涵盖GM→L1、L1→L0A/L0B、L0C→GM/UB的完整路径。

**DataCopy（GM→L1）**：加载矩阵数据到L1 Buffer，支持随路格式转换（ND→NZ、DN→NZ、NZ→NZ等），开发者定义源Tensor和目的Tensor的Layout，接口自动处理格式转换。
**LoadData（L1→L0A/L0B）**：从L1分块加载到L0A/L0B，根据源Tensor和目的Tensor的Layout自动推导是否转置。源Tensor为NZ、目的Tensor为NZ时不转置；源Tensor为ZN、目的Tensor为NZ时自动转置。
**Fixpipe（L0C→GM/UB）**：矩阵计算结果搬出，支持随路量化（float→int8/half等）、随路ReLU激活、通道拆分等特性。
---

### 基于扩展Tensor的Cube搬运接口

基础搬运接口需要开发者手动传入`count`或`DataCopyParams`参数指定搬运长度和搬运模式。扩展能力Tensor携带Shape、Stride和存储位置，编译器自动推断搬运参数和物理通路，进一步简化接口调用。同时提供**Atom定制接口**，开发者可基于CopyTraits自定义搬运行为（如自定义搬运模式、随路处理等），满足特殊场景定制需求。

**使用示例**：
```cpp
// 直接指定Global Tensor和 Local Tensor进行同等大小搬运，由接口自动推导搬运参数
Copy(l1Tensor, globalBias);

// 指定Global Tensor的偏移，实现从Global Tensor上Slice一块数据进行搬运
Copy(l1Tensor, globalBias.Slice(MakeCoord(0, j * baseN), MakeShape(1, curN)));

// 可根据OP创建Copy自定义CopyAtom，CopyGM2L1中实现GM→L1的自定义拷贝能力
auto atomCopy = MakeCopy(CopyGM2L1{}, DataCopyTraitDefault{});
Copy(atomCopy, dstTensor, srcTensor);

// Fixpipe随路量化示例
Copy(CopyAtom<CopyTraits<CopyL0C2GM, FixpipeTraitDefault>>{}, globalC, l0CTensor, quantScalar);
```

## 计算接口：向量与矩阵计算

计算接口分为向量计算和矩阵计算两类，分别由Vector流水线和Cube流水线执行。

### 向量计算接口

向量计算接口覆盖算术运算、比较运算、类型转换、规约运算、激活函数等场景，是算子开发的核心工具集。

**接口原型**：
```cpp
// 整个Tensor参与计算
dst = src0 + src1;  // 运算符形式

// tensor前n个数据计算
template <typename T>
__aicore__ inline void Add(const LocalTensor<T>& dst, const LocalTensor<T>& src0, const LocalTensor<T>& src1, const int32_t& count)

// tensor高维切分计算
template <typename T, bool isSetMask = true>
__aicore__ inline void Add(const LocalTensor<T>& dst, const LocalTensor<T>& src0, const LocalTensor<T>& src1, uint64_t mask[], const uint8_t repeatTime, const BinaryRepeatParams& repeatParams)
```

**使用示例**：
```cpp
// tensor前n个数据计算
AscendC::Add(dstLocal, src0Local, src1Local, 512);

// tensor高维切分计算样例-mask连续模式
uint64_t mask = 128;
// repeatTime = 4，一次迭代计算128个数，共计算512个数
// dstBlkStride, src0BlkStride, src1BlkStride = 1，单次迭代内数据连续读取和写入
// dstRepStride, src0RepStride, src1RepStride = 8，相邻迭代间数据连续读取和写入
AscendC::Add(dstLocal, src0Local, src1Local, mask, 4, { 1, 1, 1, 8, 8, 8 });
```
向量计算接口按功能分为以下类别：
- **算术运算**：逐元素算术运算，包括Add、Sub、Mul、Div、Abs、Sqrt等
- **比较运算**：逐元素比较运算，包括Compare、Greater、Less、Equal等
- **类型转换**：类型转换，包括Cast等
- **规约运算**：规约计算，包括ReduceSum、ReduceMax、ReduceMin等
- **激活函数**：激活函数，包括Relu、LeakyRelu、Exp、Ln等
---

### 矩阵计算接口

矩阵计算接口以Mmad为核心，实现矩阵乘加运算（C = A × B 或 C += A × B），由Cube流水线执行。

**接口原型**：
```cpp
// 基础接口：手动传入MmadParams
template <typename T>
__aicore__ inline void Mmad(const LocalTensor<T>& cMatrix, const LocalTensor<T>& aMatrix, const LocalTensor<T>& bMatrix, const MmadParams& mmadParams)

// 扩展接口：MmadAtom驱动，Shape自动推断
template <typename T>
__aicore__ inline void Mmad(const MmadAtom<T>& atomMmad, const LocalTensor<T>& cMatrix, const LocalTensor<T>& aMatrix, const LocalTensor<T>& bMatrix)

// 扩展接口：带Bias
template <typename T>
__aicore__ inline void Mmad(const MmadAtom<T>& atomMmad, const LocalTensor<T>& cMatrix, const LocalTensor<T>& aMatrix, const LocalTensor<T>& bMatrix, const LocalTensor<T>& biasMatrix)
```

**使用示例**：
```cpp
// 基础接口：手动配置MmadParams
MmadParams mmadParams;
mmadParams.m = 16;    // 左矩阵行数
mmadParams.n = 16;    // 右矩阵列数
mmadParams.k = 16;    // 累加维度
mmadParams.cmatrixInitVal = true;  // C初始化为0
Mmad(l0c, l0a, l0b, mmadParams);
```

## 小结

本章系统阐述了C++ Tensor编程数据搬运与计算接口：C++ Tensor编程提供类型安全、编译期检查的高抽象层次编程能力，Tensor模板携带数据类型、逻辑位置、内存布局，编译器自动推断参数；扩展能力引入Atom驱动隐式同步，减少手动同步调用。数据搬运接口分为基础搬运与扩展搬运两类，基础搬运使用LocalTensor/GlobalTensor、手动传参、显式同步，扩展搬运使用Tensor+Atom、Layout推断、隐式同步。计算接口分为向量计算与矩阵计算两类，覆盖算术、比较、转换、规约、激活、矩阵乘等主流场景。标准流程遵循「加载→计算→存储」三阶段模式（Vector算子）或四阶段模式（Cube算子），基础能力需手动同步。
