数据搬运与计算是AI Core算子开发的两大核心操作，共同构成算子执行的数据流转与计算处理闭环。数据搬运解决「数据从哪里来、到哪里去」的问题，计算解决「数据如何处理」的问题，二者协同配合完成算子功能实现。本章旨在帮助开发者建立对C++ Tensor编程搬运与计算接口的系统化认知，重点阐述C++ Tensor编程的特点与优势，以及接口的分类体系与使用方法。全文遵循「编程特点—硬件架构—接口分类—标准流程」的递进逻辑展开。

## C++ Tensor编程数据搬运与计算接口

C++ Tensor编程接口分为搬运类和计算类两大类：搬运类包括矢量搬运和矩阵搬运接口，计算类包括矢量计算和矩阵计算接口；其中针对扩展Tensor实现，新增了一系列简化使用的搬运接口。此外矢量计算接口因Ascend 950PR/Ascend 950DT引入寄存器，进一步分为Memory矢量计算接口和Reg矢量计算接口。

### 矢量搬运接口

Vector搬运接口支撑GM与UB之间的数据流转，是Vector算子开发的基础。接口都通过DataCopy进行描述，通过Local Tensor中的物理位置来确定具体的搬运通路；
- **GM2UB连续搬运**: `DataCopy(dst, src, count)`实现GM2UB的连续搬运加载
- **GM2UB非连续搬运**: `DataCopy(dst, src, datacopyParams)`实现GM2UB的非连续搬运加载
```cpp
// srcLocal为half类型的LocalTensor，srcGlobal为half类型的GlobalTensor
// 使用传入count参数的搬运接口，完成连续搬运
AscendC::DataCopy(srcLocal, srcGlobal, 512);
// 使用传入DataCopyParams参数的搬运接口，支持连续和非连续搬运
DataCopyParams intriParams;
intriParams.blockCount = 1; // 连续数据块个数为1
intriParams.blockLen = 512 * sizeof(half) / 32; // 连续数据块长度，单位为DataBlock，此处长度为512个half元素
intriParams.srcGap = 0; // 源操作数做连续搬运
intriParams.dstGap = 0; // 目的操作数连续排布
AscendC::DataCopy(srcLocal, srcGlobal, intriParams);
```
**详细说明**：参见 [Vector数据搬运](../../../../../api/SIMD-API/基础API/Memory数据搬运/)、 [编程示例](./编程示例.md)

### 矩阵搬运接口

Cube搬运接口支撑矩阵乘法的数据供给，涵盖GM→L1、L1→L0A/L0B、L0C→GM的完整路径。接口支持2D格式搬运、转置搬运、3D格式搬运等多种模式, 主要包含如下接口定义:

- **GM2L1搬运**：`DataCopy(dst, src, nd2nzParams)`搬运矩阵数据到L1 Buffer，支持随路格式转换（ND2NZ、DN2NZ、NZ2NZ等），开发者定义源Tensor和目的Tensor的Layout，接口自动处理格式转换。
- **L12L0A & L12L0B搬运**: 从L1分块加载到L0A/L0B，根据源Tensor和目的Tensor的Layout自动推导是否转置。源Tensor为NZ、目的Tensor为NZ时不转置；源Tensor为ZN、目的Tensor为NZ时自动转置。
- **L0C2GM & L0C2UB**：矩阵计算结果搬出，支持随路量化（float→int8/half等）、随路ReLU激活、通道拆分等特性。
```cpp
// srcLocal为half类型的L1 Buffer空间上的LocalTensor，workLocal为half类型的UB空间上的LocalTensor，srcGlobal为half类型的GlobalTensor
AscendC::Nd2NzParams intriParams{1, 32, 32, 0, 32, 32, 1, 0};
// Global Memory -> Local Memory
AscendC::DataCopy(srcLocal, srcGlobal, intriParams);
// Local Memory -> Local Memory
AscendC::DataCopy(srcLocal, workLocal, intriParams);
```
**详细说明**：参见 [Cube数据搬运](../../../../../api/SIMD-API/基础API/矩阵计算（ISASI）/数据搬运/)、 [编程示例](./编程示例.md)

### 基于扩展Tensor的矩阵搬运接口

基础搬运接口需要开发者手动传入`count`或`DataCopyParams`参数指定搬运长度和搬运模式。扩展能力Tensor携带Shape、Stride和存储位置，编译器自动推断搬运参数和物理通路，进一步简化接口调用。同时提供**Atom定制接口**，开发者可基于CopyTraits自定义搬运行为（如自定义搬运模式、随路处理等），满足特殊场景定制需求。

- **GM2L1搬运**: `Copy(dst, src)`搬运矩阵数据到L1 Buffer，支持随路格式转换（ND2NZ、DN2NZ、NZ2NZ等），开发者定义源Tensor和目的Tensor的Layout，接口自动处理格式转换。
```cpp
// 直接指定Global Tensor和 Local Tensor进行同等大小搬运，由接口自动推导搬运参数
Copy(l1Tensor, globalBias);

// 指定Global Tensor的偏移，实现从Global Tensor上Slice一块数据进行搬运
Copy(l1Tensor, globalBias.Slice(MakeCoord(0, j * baseN), MakeShape(1, curN)));

// 可根据OP创建Copy自定义CopyAtom，CopyGM2L1中实现GM→L1的自定义拷贝能力
auto atomCopy = MakeCopy(CopyGM2L1{}, DataCopyTraitDefault{});
Copy(atomCopy, dstTensor, srcTensor);

// Fixpipe随路量化示例
Copy(CopyAtom<CopyTraits<CopyL0C2GM, FixpipeTraitDefault>>{}, globalC, l0CTensor, quantScalar);
```

## 计算接口：矢量与矩阵计算

计算接口分为矢量计算和矩阵计算两类，分别由Vector流水线和Cube流水线执行。此外，针对扩展Tensor实现，新增了一系列简化使用的矩阵计算接口。

### Memory矢量计算接口

矢量计算接口覆盖算术运算、比较运算、类型转换、规约运算、激活函数等场景，是算子开发的核心工具集。
- **算术运算**：`Add`、`Sub`、`Mul`、`Div`等逐元素算术运算接口
- **比较运算**：`Compare`逐元素比较运算接口
- **类型转换**：`Cast`类型转换（支持舍入模式）接口

同时对于同一类接口，提供了不同的接口形式来应对不同的应用场景：
- **常规接口**：`Add(dst, src0, src1, count)`，异步执行
- **高维切分接口**：`Add(dst, src0, src1, mask, repeatTime, repeatParams)`支持repeat、block_stride、repeat_stride参数，适用于复杂数据布局

```cpp
// tensor前n个数据计算
AscendC::Add(dstLocal, src0Local, src1Local, 512);

// tensor高维切分计算样例-mask连续模式
uint64_t mask = 128;
// repeatTime = 4，一次迭代计算128个数，共计算512个数
// dstBlkStride, src0BlkStride, src1BlkStride = 1，单次迭代内数据连续读取和写入
// dstRepStride, src0RepStride, src1RepStride = 8，相邻迭代间数据连续读取和写入
AscendC::Add(dstLocal, src0Local, src1Local, mask, 4, { 1, 1, 1, 8, 8, 8 });
```
**详细说明**：参见 [Memory矢量计算接口](../../../../../api/SIMD-API/基础API/Memory矢量计算/)、 [编程示例](./编程示例.md)

### Reg矢量计算接口

Ascend 950PR/Ascend 950DT新一代架构在传统UB缓存体系的基础上，开放寄存器（Register）可编程能力，构建出「Global Memory → UB → Register」的三级内存层级。
- **Reg矢量计算调用层次**: 如下图所示，核函数（__global__ __aicore__）是Device侧入口函数，可调用__aicore__函数；__simd_vf__函数可被核函数调用，内部只能调用__simd_callee__子函数和constexpr aicore函数。
![Reg矢量计算调用层次](../../../../figures/Reg矢量计算调用层次.png)
  - **Reg矢量计算接口**：这类接口为C++ Tensor编程提供的矢量计算接口，接口定义都使用__simd_callee__作为限定符，利用了C++模板能力减少函数重载定义，另依托寄存器低延迟、高带宽的硬件优势，专为极致性能优化场景设计了一套直接操作寄存器变量的矢量计算接口， 主要接口包括加载&存储、算术运算、比较运算、类型转换等矢量常用计算接口。
  ```cpp
  // 加载函数，将数据从UB中加载到矢量计算寄存器变量中
  template <typename T = DefaultType, LoadDist dist = LoadDist::DIST_NORM, typename U>
  __simd_callee__ inline void LoadAlign(U& dstReg, __ubuf__ T* srcAddr);

  // 计算函数，使用矢量计算寄存器进行矢量计算，主要提供算术运算、比较运算、类型转换等矢量常用计算接口。
  template <typename T = DefaultType, MaskMergeMode mode = MaskMergeMode::ZEROING, typename U>
  __simd_callee__ inline void Add(U& dstReg, U& srcReg0, U& srcReg1, MaskReg& mask)

  // 存储函数，将Reg矢量计算的结果存储到UB中
  template <typename T = DefaultType, StoreDist dist = StoreDist::DIST_NORM, typename U>
  __simd_callee__ inline void StoreAlign(__ubuf__ T* dstAddr, U& srcReg, MaskReg& mask);
  ```  

  - **simd vf函数**：上述矢量计算接口只能在simd vf函数中调用， 并且该函数只能通过`asc_vf_call`的方式被核函数/__aicore__函数调用
  ```c
  __simd_vf__ inline void AddCustom(__ubuf__ half* dst, __ubuf__ half* src0, __ubuf__ half* src1) {
    // 内部调用Reg矢量计算接口完成矢量计算
    AscendC::Reg::RegTensor<half> dstReg, src0Reg, src1Reg;
    AscendC::Reg::LoadAlign(src0Reg, src0);
    // ...
  }
  ```

  - **核函数/__aicore__**: 核函数(使用__global__ __aicore__标识的为核函数)或者普通Device侧函数(使用__aicore__函数)通过`asc_vf_call`函数调用`simd vf`完成最终的计算
  ```c
  __vector__ __global__ __aicore__ void add_custom(__gm__ float* x, __gm__ float* y, __gm__ float* z)
  {
    __ubuf__ float x_local[TILE_LENGTH];
    __ubuf__ float y_local[TILE_LENGTH];
    __ubuf__ float z_local[TILE_LENGTH];
    // 将GM数据搬入到UB中
    asc_copy_gm2ub_align((__ubuf__ float*)x_local, x, BLK_NUM, burst_length, 0, 0, true, cache_mode, src_strice, dst_stride);
    asc_copy_gm2ub_align((__ubuf__ float*)y_local, y, BLK_NUM, burst_length, 0, 0, true, cache_mode, src_stride, dst_stride);
    // ...
    // 通过asc_vf_call调用simd vf函数
    asc_vf_call<AddCustom>(z_local, x_local, y_local);

    // 将计算结果搬出到结果GM中
    asc_copy_ub2gm_align(z, (__ubuf__ float*)zLocal, BLK_NUM, burstLength, cacheMode2, srcStride, dstStride);
  }
  ```
  **详细说明**：参见 [Reg矢量计算接口](../../../../../api/SIMD-API/基础API/Reg矢量计算/)、 [编程示例](./编程示例.md)

### 矩阵计算接口

矩阵计算接口以Mmad为核心，实现矩阵乘加运算（C = A × B 或 C += A × B），由Cube流水线执行。
- **标准矩阵乘加**：`Mmad(cMatrix, aMatrix, bMatrix, mmadParams)`，完成矩阵乘加（C += A * B）操作。矩阵ABC分别为A2/B2/CO1中的数据。
- **包含Bias的矩阵乘加**：`Mmad(cMatrix, aMatrix, bMatrix, bias, mmadParams)`，完成矩阵乘加（C = A * B + Bias）操作。矩阵ABC分别为A2/B2/CO1中的数据。

```cpp
// 基础接口：手动配置MmadParams
AscendC::MmadParams mmadParams;
mmadParams.m = m;
mmadParams.n = n / 2;
mmadParams.k = k;
AscendC::Mmad(c1Local, a2Local, b2Local, mmadParams);
```
  **详细说明**：参见 [矩阵计算接口](../../../../../api/SIMD-API/基础API/矩阵计算（ISASI）/矩阵计算/)、 [编程示例](./编程示例.md)


本章系统阐述了C++ Tensor编程数据搬运与计算接口。C++ Tensor编程提供类型安全、编译期检查的高抽象层次编程能力，Tensor模板携带数据类型、逻辑位置、内存布局，编译器自动推断参数。扩展能力引入Atom驱动隐式同步，减少手动同步调用。数据搬运接口分为基础搬运与扩展搬运两类，基础搬运使用LocalTensor/GlobalTensor、手动传参、显式同步，扩展搬运使用Tensor+Atom、Layout推断、隐式同步。计算接口分为矢量计算与矩阵计算两类，覆盖算术、比较、转换、规约、激活、矩阵乘等主流场景。
