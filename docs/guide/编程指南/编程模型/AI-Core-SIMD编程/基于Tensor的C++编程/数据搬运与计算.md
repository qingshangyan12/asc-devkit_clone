## 引言

数据搬运与计算是AscendC算子开发的两大核心操作，共同构成算子执行的数据流转与计算处理闭环。基础能力提供DataCopy、Add、Mmad等接口，通过参数结构体配置操作；扩展能力引入Copy Atom、Mmad Atom，通过Operation类型显式表达内存路径，Traits模板参数配置行为。

本章旨在帮助开发者建立对AscendC数据搬运与计算接口的系统化认知，掌握两套接口的使用方法与标准流程。全文遵循「硬件架构—基础能力接口体系—扩展能力Atom设计—标准流程实践」的递进逻辑展开。

## 硬件底层支撑：流水线与存储架构

AscendC沿用AI Core多流水线并行架构与多层级存储架构，数据搬运与计算由不同流水线承载：

**表 1**  AI Core流水线与存储层级

| 流水线 | 功能 | 源存储 | 目标存储 |
|--------|------|--------|---------|
| **MTE2** | 数据搬入 | GM | UB、L1 |
| **MTE3** | 数据搬出 | UB、L0C | GM |
| **MTE1** | L1→L0搬运 | L1 | L0A、L0B |
| **Vector** | 向量计算 | UB | UB |
| **Cube** | 矩阵计算 | L0A、L0B | L0C |

**数据流转路径**：

- **Vector算子数据流**：`GM → UB → Vector计算 → UB → GM`
- **Cube算子数据流**：`GM → L1 → L0A/L0B → Cube计算 → L0C → GM`

> 📌 **提示**：数据搬运遵循「就近计算」原则，将数据搬运到距离计算单元最近的存储层级。

## 基础能力接口体系：参数结构体传递

### 数据搬运接口

**接口层次**：

基础能力数据搬运接口分为三个层次：

```
Level 0: 基础模式（参数结构体 + repeatTime）
Level 1: 切片模式（SliceInfo数组）
Level 2: 简化模式（count计数）
```

**Level 0：基础模式**

```cpp
template <typename T>
__aicore__ inline void DataCopy(const LocalTensor<T>& dst, const GlobalTensor<T>& src, 
                                 const DataCopyParams& repeatParams);

// 参数结构体
struct DataCopyParams {
    uint16_t blockCount;    // 块数量
    uint16_t blockLen;      // 块长度
    uint16_t srcGap;        // 源块间隙
    uint16_t dstGap;        // 目标块间隙
};

// 使用示例
DataCopyParams params = {8, 256, 0, 0};
DataCopy(ubTensor, gmTensor, params);
```

**Level 1：切片模式**

```cpp
template <typename T>
__aicore__ inline void DataCopy(const LocalTensor<T>& dst, const GlobalTensor<T>& src, 
                                 const SliceInfo dstSliceInfo[], const SliceInfo srcSliceInfo[], 
                                 const uint32_t dimValue);

// SliceInfo结构体
struct SliceInfo {
    uint64_t startAddr;     // 起始地址偏移
    uint32_t burstLen;      // 传输长度
    uint64_t srcStride;     // 源步长
    uint64_t dstStride;     // 目标步长
};
```

**Level 2：简化模式**

```cpp
template <typename T>
__aicore__ inline void DataCopy(const LocalTensor<T>& dst, const GlobalTensor<T>& src, 
                                 const uint32_t count);

// 使用示例
DataCopy(ubTensor, gmTensor, 256);  // 搬运256个元素
```

**数据搬运接口分类**：

| 接口 | 源 | 目标 | 用途 |
|------|-----|------|------|
| `DataCopy` | GlobalTensor | LocalTensor | GM → UB/L1 |
| `DataCopy` | LocalTensor | GlobalTensor | UB/L0C → GM |
| `Copy` | LocalTensor | LocalTensor | UB内部拷贝 |
| `DataCopyPad` | GlobalTensor | LocalTensor | 带填充搬运 |

**ND2NZ格式转换**：

```cpp
template <typename T>
__aicore__ inline void DataCopy(const LocalTensor<T>& dst, const GlobalTensor<T>& src, 
                                 const Nd2NzParams& intriParams);

// Nd2NzParams结构体
struct Nd2NzParams {
    uint16_t ndNum;         // ND矩阵数量
    uint16_t nValue;        // N值
    uint16_t dValue;        // D值
    uint16_t srcNdMatrixStride;
    uint16_t dstNzC0Stride;
    uint16_t dstNzNStride;
};
```

### 向量计算接口

**接口层次**：

向量计算接口同样分为三个层次：

```
Level 0: 基础模式（mask + repeatTime + repeatParams）
Level 2: 简化模式（count计数）
```

**Level 0：基础模式**

```cpp
template <typename T>
__aicore__ inline void Add(const LocalTensor<T>& dst, const LocalTensor<T>& src0, 
                            const LocalTensor<T>& src1, uint64_t mask[], const uint8_t repeatTime,
                            const BinaryRepeatParams& repeatParams);

// BinaryRepeatParams结构体
struct BinaryRepeatParams {
    uint8_t dstBlkStride;    // 目标块步长
    uint8_t src0BlkStride;   // 源0块步长
    uint8_t src1BlkStride;   // 源1块步长
    uint8_t dstRepStride;    // 目标重复步长
    uint8_t src0RepStride;   // 源0重复步长
    uint8_t src1RepStride;   // 源1重复步长
};
```

**Level 2：简化模式**

```cpp
template <typename T>
__aicore__ inline void Add(const LocalTensor<T>& dst, const LocalTensor<T>& src0, 
                            const LocalTensor<T>& src1, const int32_t& count);

// 使用示例
Add(dstTensor, src0Tensor, src1Tensor, 256);  // 256个元素加法
```

**向量计算接口分类**：

| 接口类别 | 核心接口 | 支持类型 |
|----------|----------|----------|
| 算术运算 | Add、Sub、Mul、Div | half/float/int16/int32 |
| 比较运算 | Eq、Lt、Gt、Le、Ge | half/float/int系列 |
| 类型转换 | Float2Half、Half2Float | float/half/int系列 |
| 规约运算 | ReduceMax、ReduceMin、ReduceSum | half/float |
| 其他运算 | Duplicate、Relu、Abs、Sqrt | half/float/int32 |

## 扩展能力：Atom-Traits设计

### Copy Atom核心概念

引入Copy Atom，通过CopyOperation显式表达内存路径：

```cpp
template <typename CopyOperation>
struct CopyAtom<CopyOperation> : CopyAtom<CopyTraits<CopyOperation>> {
    using CopyTraitType = CopyTraits<CopyOperation>;
    using TraitType = typename CopyTraitType::TraitType;
    
    // 执行搬运
    template <const TraitType& traits, typename... Params>
    __aicore__ inline void Call(const Params& ...params) const;
    
    // 配置参数（with方法）
    template <typename... TraitsArgs>
    __aicore__ inline auto with(TraitsArgs&&... args) const;
};
```

### CopyOperation类型

CopyOperation定义内存搬运路径，显式表达源和目标层级：

**Vector CopyOperation**：

| Operation | 内存路径 | 用途 |
|----------|---------|------|
| `CopyGM2UB` | GM → UB | 加载Vector输入数据 |
| `CopyUB2GM` | UB → GM | 输出Vector计算结果 |
| `CopyUB2L1` | UB → L1 | 为Cube准备数据 |

**Cube CopyOperation**：

| Operation | 内存路径 | 用途 |
|----------|---------|------|
| `CopyGM2L1` | GM → L1 | 加载矩阵数据 |
| `CopyL12L0A` | L1 → L0A | 加载左矩阵到Cube输入 |
| `CopyL12L0B` | L1 → L0B | 加载右矩阵到Cube输入 |
| `CopyL0C2GM` | L0C → GM | 输出矩阵乘结果 |
| `CopyL0C2UB` | L0C → UB | 输出到UB供后续Vector处理 |

### Copy Atom创建与使用

**创建Copy Atom**：

```cpp
// 创建Copy Atom
auto copyGM2UB = MakeCopy<CopyGM2UB>();
auto copyUB2GM = MakeCopy<CopyUB2GM>();
auto copyGM2L1 = MakeCopy<CopyGM2L1>();
auto copyL12L0A = MakeCopy<CopyL12L0A>();
```

**执行Copy操作**：

```cpp
// 基础调用
Copy(copyAtom, srcTensor, dstTensor);

// 带参数配置调用（with方法）
auto copyAtomWithParams = copyAtom.with(/*运行期参数*/);
Copy(copyAtomWithParams, srcTensor, dstTensor);
```

### Mmad Atom核心概念

引入Mmad Atom，通过MmadOperation配置计算参数：

```cpp
template <typename MmadOperation>
struct MmadAtom<MmadOperation> : MmadAtom<MmadTraits<MmadOperation>> {
    using MmadTraitType = MmadTraits<MmadOperation>;
    using TraitType = typename MmadTraitType::TraitType;
    
    // 执行矩阵乘
    template <const TraitType& traits, typename... Params>
    __aicore__ inline void Call(const Params& ...params) const;
    
    // 配置参数（with方法）
    template <typename... TraitsArgs>
    __aicore__ inline auto with(TraitsArgs&&... args) const;
};
```

### Mmad Atom创建与使用

```cpp
// 创建Mmad Atom
auto mmadAtom = MakeMmad<MmadOperation>();

// 执行矩阵乘
Mmad(mmadAtom, l0aTensor, l0bTensor, l0cTensor);

// 带参数配置调用（with方法）
auto mmadAtomWithParams = mmadAtom.with(/*运行期参数*/);
Mmad(mmadAtomWithParams, l0aTensor, l0bTensor, l0cTensor);
```

### Atom-Traits设计优势

**编译期+运行期混合配置**：

```cpp
// 编译期确定Operation类型
auto copyAtom = MakeCopy<CopyGM2UB>();  // CopyOperation编译期绑定

// 运行期配置参数（with方法）
auto copyAtomWithParams = copyAtom.with(
    /*blockCount*/ 8,
    /*blockLen*/ 256
);
```

**类型安全**：

- CopyOperation显式表达内存路径，编译期校验
- 不同Operation类型的Atom无法混用
- Tensor的Layout类型编译期检查

**隐式同步**：

- Operation携带流水线信息，编译器自动推断同步
- 减少手动SetFlag/WaitFlag调用

### 与基础能力对比

| 对比维度 | 基础能力 | 扩展能力 |
|---------|---------|------------|
| 参数传递 | 参数结构体 | Traits模板参数 + with方法 |
| 内存路径 | 通过Tensor类型推断 | CopyOperation显式表达 |
| 配置方式 | 运行期设置 | 编译期+运行期混合 |
| 同步机制 | 显式SetFlag/WaitFlag | Operation隐式推断 |
| 切片操作 | 无内置支持 | Slice零开销 |
| 布局处理 | 手动计算步长 | LayoutPattern自动 |

## 标准流程实践：Vector与Cube算子

### Vector算子标准流程（基础能力）

```cpp
// ===== 第一步：创建Tensor =====
TPipe pipe;
TQue<UB, 2> queIn, queOut;

pipe.InitBuffer(queIn, 2, 256 * sizeof(half));
pipe.InitBuffer(queOut, 1, 256 * sizeof(half));

LocalTensor<half> ubIn0 = queIn.AllocTensor<half>();
LocalTensor<half> ubIn1 = queIn.AllocTensor<half>();
LocalTensor<half> ubOut = queOut.AllocTensor<half>();

GlobalTensor<half> gmIn0, gmIn1, gmOut;
gmIn0.SetGlobalBuffer((__gm__ half*)gmIn0Buffer, 256);
gmIn1.SetGlobalBuffer((__gm__ half*)gmIn1Buffer, 256);
gmOut.SetGlobalBuffer((__gm__ half*)gmOutBuffer, 256);

// ===== 第二步：加载输入 =====
DataCopy(ubIn0, gmIn0, 256);
DataCopy(ubIn1, gmIn1, 256);

// ===== 第三步：同步 =====
SetFlag<HardEvent::MTE2_V>(eventID);
WaitFlag<HardEvent::MTE2_V>(eventID);

// ===== 第四步：执行计算 =====
Add(ubOut, ubIn0, ubIn1, 256);

// ===== 第五步：同步 =====
SetFlag<HardEvent::V_MTE3>(eventID);
WaitFlag<HardEvent::V_MTE3>(eventID);

// ===== 第六步：存储结果 =====
DataCopy(gmOut, ubOut, 256);

// ===== 第七步：释放Tensor =====
queIn.FreeTensor(ubIn0);
queIn.FreeTensor(ubIn1);
queOut.FreeTensor(ubOut);
```

### Vector算子标准流程（扩展能力）

```cpp
// ===== 第一步：创建Tensor =====

// ===== 第四步：执行计算 =====

// ===== 第五步：存储结果（隐式同步）=====
Copy(copyUB2GM, ubOutTensor, gmOutTensor);
```

### Cube算子标准流程（基础能力）

```cpp
// ===== 第一步：创建Tensor =====
TPipe pipe;
TQue<L1, 2> queL1;
TQue<L0A, 1> queL0A;
TQue<L0B, 1> queL0B;
TQue<L0C, 1> queL0C;

pipe.InitBuffer(queL1, 2, 4096 * sizeof(half));
pipe.InitBuffer(queL0A, 1, 512 * sizeof(half));
pipe.InitBuffer(queL0B, 1, 512 * sizeof(half));
pipe.InitBuffer(queL0C, 1, 1024 * sizeof(float));

LocalTensor<half> l1A = queL1.AllocTensor<half>();
LocalTensor<half> l1B = queL1.AllocTensor<half>();
LocalTensor<half> l0a = queL0A.AllocTensor<half>();
LocalTensor<half> l0b = queL0B.AllocTensor<half>();
LocalTensor<float> l0c = queL0C.AllocTensor<float>();

GlobalTensor<half> gmA, gmB;
GlobalTensor<float> gmC;
gmA.SetGlobalBuffer((__gm__ half*)gmABuffer, 4096);
gmB.SetGlobalBuffer((__gm__ half*)gmBBuffer, 4096);
gmC.SetGlobalBuffer((__gm__ float*)gmCBuffer, 1024);

// ===== 第二步：加载矩阵到L1 =====
DataCopy(l1A, gmA, 4096);
DataCopy(l1B, gmB, 4096);

// ===== 第三步：同步 =====
SetFlag<HardEvent::MTE2_MTE1>(eventID0);
WaitFlag<HardEvent::MTE2_MTE1>(eventID0);

// ===== 第四步：搬运到L0A/L0B =====
LoadData2DParams loadParams = {/*配置参数*/};
LoadData(l0a, l1A, loadParams);
LoadData(l0b, l1B, loadParams);

// ===== 第五步：同步 =====
SetFlag<HardEvent::MTE1_C>(eventID1);
WaitFlag<HardEvent::MTE1_C>(eventID1);

// ===== 第六步：执行矩阵乘 =====
MmadParams mmadParams = {128, 64, 32, 0, true};
Mmad(l0c, l0a, l0b, mmadParams);

// ===== 第七步：同步 =====
SetFlag<HardEvent::C_MTE3>(eventID2);
WaitFlag<HardEvent::C_MTE3>(eventID2);

// ===== 第八步：输出结果 =====
DataCopy(gmC, l0c, 1024);

// ===== 第九步：释放Tensor =====
queL1.FreeTensor(l1A);
queL1.FreeTensor(l1B);
queL0A.FreeTensor(l0a);
queL0B.FreeTensor(l0b);
queL0C.FreeTensor(l0c);
```

### 切片分块流程（扩展能力）

扩展能力支持零开销切片，实现分块计算：

```cpp
// ===== 创建大Tensor =====

auto ubTensor = MakeTensor(ubPointer, MakeShape(1024, 512));

// ===== 分块处理 =====

constexpr uint32_t BLOCK_N = 32;

auto copyGM2UB = MakeCopy<CopyGM2UB>();

for (uint32_t i = 0; i < 1024 / BLOCK_M; i++) {
    for (uint32_t j = 0; j < 512 / BLOCK_N; j++) {

            MakeShape(BLOCK_M, BLOCK_N)

        Copy(copyGM2UB, gmBlock, ubBlock);
        // ... 计算 ...
    }
}
```

## 接口选择建议

### 基础能力适用场景

- **运行期参数配置**：参数需要运行期计算或动态调整
- **细粒度同步控制**：需要显式PipeBarrier、SetFlag/WaitFlag控制
- **快速原型开发**：接口直观，学习曲线平缓
- **简单Vector算子**：简化模式接口调用简洁

### 扩展能力适用场景

- **编译期类型安全**：Shape和Stride编译期确定
- **多种布局格式**：NZ、ZN、ZZ等分形布局自动处理
- **切片分块操作**：需要零开销切片/分块
- **Cube算子开发**：LayoutPattern简化分形布局处理

### 混合使用

扩展能力可配合基础能力同步接口使用：

```cpp
// 扩展能力搬运
auto copyAtom = MakeCopy<CopyGM2UB>();
Copy(copyAtom, gmTensor, ubTensor);

// 基础能力显式同步（复杂场景）
SetFlag<HardEvent::MTE2_V>(eventID);
WaitFlag<HardEvent::MTE2_V>(eventID);
```

本章系统梳理了AscendC数据搬运与计算接口：基础能力提供DataCopy、Add、Mmad等接口，通过参数结构体（DataCopyParams、MmadParams等）配置操作，接口分为基础模式、切片模式、简化模式三个层次；扩展能力引入Copy Atom、Mmad Atom，通过CopyOperation/MmadOperation显式表达内存路径，Traits模板参数配置行为，实现编译期+运行期混合配置；标准流程遵循「加载→同步→计算→同步→存储」模式，扩展能力通过隐式同步简化流程。
