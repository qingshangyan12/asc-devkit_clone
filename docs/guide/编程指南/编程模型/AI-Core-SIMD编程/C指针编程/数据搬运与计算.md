# 数据搬运与计算接口编程指南

## 引言

数据搬运与计算是AI Core算子开发的两大核心操作，共同构成算子执行的数据流转与计算处理闭环。本章以**数据流转与计算处理**为主线，遵循「存储架构—搬运接口—计算接口」递进逻辑，系统讲解存储层级架构、数据搬运接口和计算处理接口。

## 存储层级架构：多层级存储与数据流转

AI Core采用多层级存储架构，各层级在容量、带宽、延迟上差异显著，数据搬运的核心目标是在各层级间高效传输数据。

**表1**  AI Core存储层级分类
| 存储层级 | 容量 | 主要用途 |
|----------|------|----------|
| GM（全局内存） | GB级 | 存放输入输出、模型参数 |
| UB（统一缓冲区） | KB级 | Vector计算数据缓存 |
| L1（L1缓冲区） | KB级 | Cube计算数据缓存 |
| L0A/L0B/L0C | KB级 | 矩阵乘法输入/输出 |

**数据流转路径**：

Vector计算：`GM → UB → Vector计算 → UB → GM`

Cube计算：`GM → L1 → L0A/L0B → MMAD → L0C → GM`

> 📌 **提示**：数据搬运遵循「就近计算」原则，将数据搬运到距离计算单元最近的存储层级。

## 数据搬运接口：分层分类与核心接口

数据搬运接口按目标存储分为Vector搬运和Cube搬运两类。

### Vector搬运接口

**表2**  Vector搬运接口分类
| 接口类别 | 核心接口 | 用途 |
|----------|----------|------|
| GM→UB | `asc_copy_gm2ub`、`asc_copy_gm2ub_align` | 加载输入数据 |
| UB→GM | `asc_copy_ub2gm`、`asc_copy_ub2gm_align` | 输出计算结果 |
| UB→UB | `asc_copy_ub2ub` | UB内部拷贝 |
| UB→L1 | `asc_copy_ub2l1` | 为Cube准备数据 |
| 多维搬运 | `asc_ndim_copy_gm2ub` | 多维度带填充搬运 |

**核心接口参数**：

`asc_copy_gm2ub(dst, src, size)` — 从GM搬运size字节到UB

`asc_copy_gm2ub_align(dst, src, n_burst, len_burst, left_pad, right_pad, src_gap, dst_gap)` — 带填充对齐搬运

### Cube搬运接口

**表3**  Cube搬运接口分类
| 接口类别 | 核心接口 | 用途 |
|----------|----------|------|
| GM→L1 | `asc_copy_gm2l1`、`asc_copy_gm2l1_nd2nz` | 加载矩阵数据 |
| L1→L0A | `asc_copy_l12l0a`、`asc_copy_l12l0a_trans` | 加载左矩阵 |
| L1→L0B | `asc_copy_l12l0b`、`asc_copy_l12l0b_trans` | 加载右矩阵 |
| 填充 | `asc_fill_l0a`、`asc_fill_l0b`、`asc_fill_l1` | 常量填充 |

### 寄存器搬运接口

**表4**  寄存器搬运接口分类
| 接口类别 | 核心接口 | 用途 |
|----------|----------|------|
| 加载 | `asc_loadalign`、`asc_gather` | UB→寄存器 |
| 存储 | `asc_storealign`、`asc_storeunalign` | 寄存器→UB |
| 地址更新 | `asc_loadalign_postupdate` | 流式处理 |

> 📌 **提示**：同步接口（`_sync`后缀）搬运完成后阻塞等待，确保数据就绪后再执行后续计算。

## 计算接口：向量与矩阵计算

计算接口分为向量计算和矩阵计算两类。

### 向量计算接口

**表5**  向量计算接口分类
| 接口类别 | 核心接口 | 支持类型 |
|----------|----------|----------|
| 算术运算 | `asc_add`、`asc_sub`、`asc_mul`、`asc_div` | half/float/int16/int32 |
| 比较运算 | `asc_eq`、`asc_lt`、`asc_gt`、`asc_le`、`asc_ge` | half/float/int系列 |
| 类型转换 | `asc_float2half`、`asc_half2float`、`asc_float2int32` | float/half/bf16/int系列 |
| 规约运算 | `asc_reduce_max`、`asc_reduce_min`、`asc_reduce_sum` | half/float |
| 其他运算 | `asc_duplicate`、`asc_relu`、`asc_abs`、`asc_sqrt` | half/float/int32 |

**类型转换舍入模式**：`_rd`(向下)、`_ru`(向上)、`_rz`(向零)、`_rn`(最近)、`_rna`(交替)、`_sat`(饱和)

**接口形式示例**：
```c
asc_add(dst, src0, src1, count);              // 逐元素加法
asc_add_scalar(dst, src, value, count);       // 向量+标量
asc_float2half_rn(dst, src, count);           // float转half(最近舍入)
asc_datablock_reduce_sum(dst, src, count);    // 数据块规约求和
```

### 矩阵计算接口

**表6**  矩阵计算接口
| 接口 | 输入类型 | 输出类型 | 用途 |
|------|----------|----------|------|
| `asc_mmad` | half/bf16/float/int8 | float/int32 | 标准矩阵乘法 |
| `asc_mmad_s4` | int4b_t | int32 | 4-bit量化矩阵乘 |
| `asc_mmad_mx` | fp8/fp4 | float | MX格式矩阵乘 |
| `asc_mmad_sparse` | int8_t | int32 | 稀疏矩阵乘 |

**`asc_mmad`核心参数**：`c_matrix`(输出)、`a_matrix`(左矩阵)、`b_matrix`(右矩阵)、`left_height`(M)、`n_dim`(K)、`right_width`(N)

> 📌 **提示**：`c_matrix_init_val`为true时执行C=C+A×B，为false时执行C=A×B。

### 寄存器计算接口

寄存器计算接口使用`vector_`类型和`vector_bool mask`参数控制参与计算的元素：

```c
asc_add(vector_half& dst, vector_half src0, vector_half src1, vector_bool mask);
asc_mul(vector_float& dst, vector_float src0, vector_float src1, vector_bool mask);
asc_float2half_rd(vector_half& dst, vector_float src, vector_bool mask);
```

## 标准流程：数据搬运与计算实践

### Vector算子流程

```
GM→UB: asc_copy_gm2ub_sync → Vector计算: asc_add/asc_mul → UB→GM: asc_copy_ub2gm_sync
```

```c
// 加载输入
asc_copy_gm2ub_sync(ub_in0, gm_in0, size);
asc_copy_gm2ub_sync(ub_in1, gm_in1, size);
// 执行计算
asc_add(ub_out, ub_in0, ub_in1, size);
// 存储结果
asc_copy_ub2gm_sync(gm_out, ub_out, size);
```

### Cube算子流程

```
GM→L1: asc_copy_gm2l1 → L1→L0A/L0B: asc_copy_l12l0a/asc_copy_l12l0b → MMAD: asc_mmad → L0C→GM
```

```c
// 加载矩阵到L1
asc_copy_gm2l1_sync(l1_a, gm_a, size_a);
asc_copy_gm2l1_sync(l1_b, gm_b, size_b);
// 搬运到L0A/L0B
asc_copy_l12l0a_sync(l0a, l1_a, idx, rpt, stride, gap);
asc_copy_l12l0b_sync(l0b, l1_b, idx, rpt, stride, gap);
// 执行矩阵乘
asc_mmad_sync(l0c, l0a, l0b, m, k, n, flag, align, source, init);
// 输出结果
asc_copy_l0c2gm_sync(gm_c, l0c, size_c);
```

### 寄存器计算流程

```c
// 加载到寄存器
asc_loadalign(src0_reg, ub_src0);
asc_loadalign(src1_reg, ub_src1);
// 寄存器计算
vector_bool mask = asc_create_mask_b16(PAT_ALL);
asc_add(dst_reg, src0_reg, src1_reg, mask);
// 存储到UB
asc_storealign(ub_dst, dst_reg, mask);
```

## 小结

本章系统梳理了数据搬运与计算接口：AI Core采用GM→UB→L1→L0多级存储架构；Vector搬运接口支撑GM/UB间数据流转，Cube搬运接口支撑矩阵乘法数据供给；向量计算接口涵盖算术、比较、转换、规约运算，矩阵计算接口以asc_mmad为核心；标准流程遵循「加载→计算→存储」三阶段模式。
