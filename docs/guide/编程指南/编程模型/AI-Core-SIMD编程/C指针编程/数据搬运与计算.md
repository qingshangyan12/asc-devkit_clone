## 引言

数据搬运与计算是AI Core算子开发的两大核心操作，共同构成算子执行的数据流转与计算处理闭环。数据搬运解决「数据从哪里来、到哪里去」的问题，计算解决「数据如何处理」的问题，二者协同配合完成算子功能实现。

本章旨在帮助开发者建立对数据搬运与计算接口的系统化认知，掌握搬运接口与计算接口的分类体系与使用方法。全文遵循「物理架构—搬运接口—计算接口—标准流程」的递进逻辑展开。

## 硬件底层支撑：流水线与存储架构

AI Core采用多流水线并行架构与多层级存储架构，数据搬运与计算指令由不同流水线承载，协同完成数据处理。

**表 1**  AI Core流水线分工

| 流水线 | 功能 | 典型指令 |
|--------|------|----------|
| **MTE2** | 数据搬入（GM→Local Memory） | `asc_copy_gm2ub`、`asc_copy_gm2l1` |
| **MTE3** | 数据搬出（Local Memory→GM） | `asc_copy_ub2gm`、`asc_copy_l0c2gm` |
| **Vector** | 向量计算 | `asc_add`、`asc_mul` |
| **Cube** | 矩阵计算 | `asc_mmad` |

**数据流转路径**：

- **Vector算子数据流**：`GM → UB → Vector计算 → UB → GM`
- **Cube算子数据流**：`GM → L1 → L0A/L0B → Cube计算 → L0C → GM`

> 📌 **提示**：数据搬运遵循「就近计算」原则，将数据搬运到距离计算单元最近的存储层级，最大限度减少搬运开销。

## 数据搬运接口：分层分类体系

数据搬运接口按目标存储层级分为Vector搬运、Cube搬运、寄存器搬运三类，每类接口覆盖特定数据流转场景。

### Vector搬运接口

Vector搬运接口支撑GM与UB之间的数据流转，是Vector算子开发的基础。

**表 2**  Vector搬运接口分类

| 接口类别 | 核心接口 | 用途 |
|----------|----------|------|
| GM→UB | `asc_copy_gm2ub`、`asc_copy_gm2ub_align` | 加载输入数据 |
| UB→GM | `asc_copy_ub2gm`、`asc_copy_ub2gm_align` | 输出计算结果 |
| UB→UB | `asc_copy_ub2ub` | UB内部拷贝 |
| UB→L1 | `asc_copy_ub2l1` | 为Cube准备数据 |
| 多维搬运 | `asc_ndim_copy_gm2ub` | 多维度带填充搬运 |

**核心接口参数**：

```cpp
// 基础搬运：从GM搬运size字节到UB
asc_copy_gm2ub(dst, src, size);

// 带填充对齐搬运：支持左右填充、步长控制
asc_copy_gm2ub_align(dst, src, n_burst, len_burst, left_pad, right_pad, src_gap, dst_gap);
```

### Cube搬运接口

Cube搬运接口支撑矩阵乘法的数据供给，涵盖GM→L1、L1→L0A/L0B的完整路径。

**表 3**  Cube搬运接口分类

| 接口类别 | 核心接口 | 用途 |
|----------|----------|------|
| GM→L1 | `asc_copy_gm2l1`、`asc_copy_gm2l1_nd2nz` | 加载矩阵数据 |
| L1→L0A | `asc_copy_l12l0a`、`asc_copy_l12l0a_trans` | 加载左矩阵 |
| L1→L0B | `asc_copy_l12l0b`、`asc_copy_l12l0b_trans` | 加载右矩阵 |
| 填充 | `asc_fill_l0a`、`asc_fill_l0b`、`asc_fill_l1` | 常量填充 |

### 寄存器搬运接口

寄存器搬运接口支撑UB与寄存器之间的数据流转，是寄存器级计算的基础。

**表 4**  寄存器搬运接口分类

| 接口类别 | 核心接口 | 用途 |
|----------|----------|------|
| 加载 | `asc_loadalign`、`asc_gather` | UB→寄存器 |
| 存储 | `asc_storealign`、`asc_storeunalign` | 寄存器→UB |
| 地址更新 | `asc_loadalign_postupdate` | 流式处理 |

> 📌 **提示**：同步接口（`_sync`后缀）在搬运完成后阻塞等待，确保数据就绪后再执行后续计算；非同步接口需配合`asc_sync_notify`/`asc_sync_wait`使用。

## 计算接口：向量与矩阵计算

计算接口分为向量计算和矩阵计算两类，分别由Vector流水线和Cube流水线执行。

### 向量计算接口

向量计算接口覆盖算术运算、比较运算、类型转换、规约运算等场景，是算子开发的核心工具集。

**表 5**  向量计算接口分类

| 接口类别 | 核心接口 | 支持类型 |
|----------|----------|----------|
| 算术运算 | `asc_add`、`asc_sub`、`asc_mul`、`asc_div` | half/float/int16/int32 |
| 比较运算 | `asc_eq`、`asc_lt`、`asc_gt`、`asc_le`、`asc_ge` | half/float/int系列 |
| 类型转换 | `asc_float2half`、`asc_half2float`、`asc_float2int32` | float/half/bf16/int系列 |
| 规约运算 | `asc_reduce_max`、`asc_reduce_min`、`asc_reduce_sum` | half/float |
| 其他运算 | `asc_duplicate`、`asc_relu`、`asc_abs`、`asc_sqrt` | half/float/int32 |

**类型转换舍入模式**：`_rd`(向下)、`_ru`(向上)、`_rz`(向零)、`_rn`(最近)、`_rna`(交替)、`_sat`(饱和)

**接口形式示例**：

```cpp
asc_add(dst, src0, src1, count);              // 逐元素加法
asc_add_scalar(dst, src, value, count);       // 向量+标量
asc_float2half_rn(dst, src, count);           // float转half(最近舍入)
asc_datablock_reduce_sum(dst, src, count);    // 数据块规约求和
```

### 矩阵计算接口

矩阵计算接口以`asc_mmad`为核心，支持多种数据类型与计算模式。

**表 6**  矩阵计算接口

| 接口 | 输入类型 | 输出类型 | 用途 |
|------|----------|----------|------|
| `asc_mmad` | half/bf16/float/int8 | float/int32 | 标准矩阵乘法 |
| `asc_mmad_s4` | int4b_t | int32 | 4-bit量化矩阵乘 |
| `asc_mmad_mx` | fp8/fp4 | float | MX格式矩阵乘 |
| `asc_mmad_sparse` | int8_t | int32 | 稀疏矩阵乘 |

**`asc_mmad`核心参数**：`c_matrix`(输出)、`a_matrix`(左矩阵)、`b_matrix`(右矩阵)、`left_height`(M)、`n_dim`(K)、`right_width`(N)

> 📌 **提示**：`c_matrix_init_val`为true时执行C=C+A×B，为false时执行C=A×B。

### 寄存器计算接口

寄存器计算接口使用`vector_`类型和`vector_bool mask`参数控制参与计算的元素：

```cpp
asc_add(vector_half& dst, vector_half src0, vector_half src1, vector_bool mask);
asc_mul(vector_float& dst, vector_float src0, vector_float src1, vector_bool mask);
asc_float2half_rd(vector_half& dst, vector_float src, vector_bool mask);
```

## 标准流程：数据搬运与计算实践

### Vector算子标准流程

Vector算子遵循「加载→计算→存储」三阶段模式：

```cpp
// ===== 第一步：加载输入 =====
asc_copy_gm2ub_sync(ub_in0, gm_in0, size);  // 搬入输入数据1
asc_copy_gm2ub_sync(ub_in1, gm_in1, size);  // 搬入输入数据2

// ===== 第二步：执行计算 =====
asc_add(ub_out, ub_in0, ub_in1, size);  // 向量加法

// ===== 第三步：存储结果 =====
asc_copy_ub2gm_sync(gm_out, ub_out, size);  // 搬出结果数据
```

### Cube算子标准流程

Cube算子遵循「加载矩阵→搬运到L0→执行矩阵乘→输出结果」四阶段模式：

```cpp
// ===== 第一步：加载矩阵到L1 =====
asc_copy_gm2l1_sync(l1_a, gm_a, size_a);  // 搬入矩阵A
asc_copy_gm2l1_sync(l1_b, gm_b, size_b);  // 搬入矩阵B

// ===== 第二步：搬运到L0A/L0B =====
asc_copy_l12l0a_sync(l0a, l1_a, idx, rpt, stride, gap);  // L1→L0A
asc_copy_l12l0b_sync(l0b, l1_b, idx, rpt, stride, gap);  // L1→L0B

// ===== 第三步：执行矩阵乘 =====
asc_mmad_sync(l0c, l0a, l0b, m, k, n, flag, align, source, init);

// ===== 第四步：输出结果 =====
asc_copy_l0c2gm_sync(gm_c, l0c, size_c);  // L0C→GM
```

### 寄存器计算标准流程

寄存器级计算遵循「Load→Compute→Store」三阶段数据流：

```cpp
// ===== 第一步：Load：UB→寄存器 =====
asc_loadalign(src0_reg, ub_src0);  // UB→寄存器
asc_loadalign(src1_reg, ub_src1);

// ===== 第二步：Compute：寄存器计算 =====
vector_bool mask = asc_create_mask_b16(PAT_ALL);  // 创建掩码
asc_add(dst_reg, src0_reg, src1_reg, mask);       // 寄存器加法

// ===== 第三步：Store：寄存器→UB =====
asc_storealign(ub_dst, dst_reg, mask);  // 寄存器→UB
```

## 小结

本章系统梳理了数据搬运与计算接口：数据搬运接口分为Vector搬运、Cube搬运、寄存器搬运三类，分别支撑不同计算单元的数据供给；计算接口分为向量计算和矩阵计算两类，覆盖算术、比较、转换、规约、矩阵乘等场景；标准流程遵循「加载→计算→存储」三阶段模式，Cube算子增加L1→L0搬运阶段。
