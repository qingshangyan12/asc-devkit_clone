# C指针编程概述

本章介绍 AscendC 中直接使用 C 语言进行编码的方式——C API，聚焦「硬件架构适配 + 实操落地 + 性能优化」，帮助开发者掌握基于 C 语言的 Ascend 芯片底层算子开发、资源管控与调试技巧，实现高效、高可控性的算子开发。

---

## 1. 什么是 AscendC C API

AscendC C API 是一套面向 Ascend 芯片硬件架构、完全基于标准 C 语言语法设计的底层编程接口，为开发者提供无冗余封装、可直接操作芯片硬件资源（寄存器、UB、PE 等）的编程方式，核心是通过原生 C 语言，实现软件代码与芯片硬件的联动。

与 AscendC 基础 API（封装度高、易用性优先）不同，C API 完全遵循 C 语言原生特性，以指针操作为核心，无需依赖高层封装，直接打通"C 代码 → 芯片硬件"的执行链路。专注于底层高性能算子开发场景，实现对硬件资源的精细化管控与性能最大化利用。

---

## 2. 两类编程风格

C API 提供两种编程风格：

| 特性 | Membase API | Regbase API |
|-----|-------------|-------------|
| **数据表示** | `__ubuf__ half*` 指针 | `vector_half` 寄存器 |
| **数据加载** | 计算时自动读取 | 显式 `asc_loadalign` |
| **数据存储** | 计算后自动写入 | 显式 `asc_storealign` |
| **掩码控制** | 全局 Mask 寄存器 | 参数传递局部掩码 |
| **计算粒度** | 支持高维切分迭代 | 单次 VL 长度计算 |
| **非对齐支持** | 有专门接口 | 完整非对齐流程 |
| **交织操作** | 不支持 | 支持 DEINTLV/INTLV |
| **适用产品** | Atlas A3/A2 系列 | Ascend 950 系列 |

## 3. 核心定位与适用场景

### 3.1 核心定位

为开发者提供 Ascend 芯片底层硬件资源的直接操控能力，实现算子性能最大化，同时保障开发灵活性与硬件兼容性，兼顾底层可控性与实操性。

### 3.2 适用场景

| 场景 | 说明 | 推荐程度 |
|-----|------|---------|
| 高性能算子开发 | 需精准控制寄存器分配、数据搬运路径、计算时序，规避高层封装带来的性能损耗 | **强烈推荐** |
| 硬件资源精细化管控 | 需手动管理片上存储（UB）、寄存器、PE 计算单元，适配复杂算子的资源需求 | **强烈推荐** |
| C 语言原生开发 | 开发者熟悉 C 语言底层编程，需将传统 C 语言算子迁移至 Ascend 平台 | **推荐** |
| 性能优化 | 需针对特定算子极致性能调优，手动优化内存布局、数据复用、计算并行 | **推荐** |

## 6. 关键概念速览

### 6.1 存储层次

```
Global Memory (GM)        ← 外部大容量存储，DDR/HBM
    ↓ ↑
L1 Buffer                 ← 中间缓存，矩阵计算数据暂存
    ↓ ↑
L0A/L0B Buffer            ← 矩阵计算单元输入缓冲区
    ↓ ↑
L0C Buffer                ← 矩阵计算结果缓冲区
    ↓ ↑
Unified Buffer (UB)       ← 向量计算单元缓冲区
```

### 6.2 流水线类型

| 流水线 | 功能 |
|-------|------|
| PIPE_MTE2 | GM → UB/L1/L0A/L0B 搬运 |
| PIPE_MTE1 | L1 → L0A/L0B 搬运 |
| PIPE_MTE3 | UB/L0C → GM 搬运 |
| PIPE_V | 矢量计算 |
| PIPE_M | 矩阵计算 |

### 6.3 核心关键字

| 关键字 | 说明 |
|-------|------|
| `__gm__` | Global Memory 地址空间 |
| `__ubuf__` | Unified Buffer 地址空间 |
| `__cbuf__` | L1 Buffer 地址空间 |
| `__aicore__` | AI Core 执行空间限定符 |

## 7. 最简示例预览

### 7.1 Membase 示例

```cpp
#include "c_api/asc_simd.h"

__aicore__ void simple_add()
{
    __ubuf__ half src[128];
    __ubuf__ half dst[128];
    
    asc_copy_gm2ub(src, src_gm, 128 * sizeof(half));
    asc_sync_pipe(PIPE_MTE2);
    
    asc_add(dst, src, src, 128);
    asc_sync_pipe(PIPE_V);
    
    asc_copy_ub2gm(dst_gm, dst, 128 * sizeof(half));
    asc_sync_pipe(PIPE_MTE3);
}
```

### 7.2 Regbase 示例

```cpp
#include "c_api/asc_simd.h"

__simd_vf__ inline void simple_add()
{
    vector_half src, dst;
    vector_bool mask = asc_create_mask_b16(PAT_ALL);
    
    asc_loadalign(src, src_addr);
    asc_add(dst, src, src, mask);
    asc_storealign(dst_addr, dst, mask);
}
```
