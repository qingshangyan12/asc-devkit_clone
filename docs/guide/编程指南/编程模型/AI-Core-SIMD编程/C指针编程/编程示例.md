## Vector算子示例：向量加法完整实现

向量加法是最基础的Vector算子，完整展示C指针编程四步法的标准实现流程。

### 算子功能描述

输入两个向量x和y，计算输出向量z = x + y。

### 完整代码实现

```cpp
extern "C" __global__ __aicore__ void add_kernel(__gm__ float* x_gm, __gm__ float* y_gm, __gm__ float* z_gm, uint32_t totalLength)
{
    // ===== 第一步：内存规划与地址分配 =====
    constexpr uint32_t TILE_LENGTH = 256;  // 每次处理的元素个数
    __ubuf__ float x_local[TILE_LENGTH];   // 输入1 UB地址
    __ubuf__ float y_local[TILE_LENGTH];   // 输入2 UB地址
    __ubuf__ float z_local[TILE_LENGTH];   // 输出UB地址
    
    uint32_t tileNum = totalLength / TILE_LENGTH;  // 分块数量
    
    // ===== 第二步：循环处理每个数据块 =====
    for (uint32_t i = 0; i < tileNum; i++) {
        // ===== 数据搬入 =====
        asc_copy_gm2ub(x_local, x_gm + i * TILE_LENGTH, TILE_LENGTH);  // 搬入x
        asc_copy_gm2ub(y_local, y_gm + i * TILE_LENGTH, TILE_LENGTH);  // 搬入y
        
        // ===== 流水线同步：确保数据就绪 =====
        asc_sync_notify(PIPE_MTE2, PIPE_V, EVENT_ID0);  // MTE2通知V
        asc_sync_wait(PIPE_MTE2, PIPE_V, EVENT_ID0);    // V等待MTE2
        
        // ===== 第三步：计算执行 =====
        asc_add(z_local, x_local, y_local, TILE_LENGTH);  // 向量加法
        
        // ===== 流水线同步：确保计算完成 =====
        asc_sync_notify(PIPE_V, PIPE_MTE3, EVENT_ID0);  // V通知MTE3
        asc_sync_wait(PIPE_V, PIPE_MTE3, EVENT_ID0);    // MTE3等待V
        
        // ===== 第四步：结果搬出 =====
        asc_copy_ub2gm(z_gm + i * TILE_LENGTH, z_local, TILE_LENGTH);  // 搬出z
    }
}
```

### 代码解析

**表 1**  向量加法算子代码解析

| 步骤 | 关键代码 | 技术要点 |
|------|----------|----------|
| 内存规划 | `__ubuf__ float x_local[256]` | 使用静态数组方式申请UB内存，编译期自动分配地址 |
| 数据搬入 | `asc_copy_gm2ub(x_local, x_gm, 256)` | 从GM搬运数据到UB，每次处理256个元素 |
| 流水线同步 | `asc_sync_notify/wait` | 搬入完成后通知计算流水线，确保数据就绪 |
| 计算执行 | `asc_add(z_local, x_local, y_local)` | 调用向量加法接口，完成核心计算逻辑 |
| 结果搬出 | `asc_copy_ub2gm(z_gm, z_local)` | 将计算结果从UB搬回GM |

> 📌 **提示**：循环处理时，每个分块独立搬运、计算、搬出，流水线同步确保每个分块的数据依赖关系正确。

## Cube算子示例：矩阵乘法完整实现

矩阵乘法是典型的Cube算子，展示L1/L0内存层级与矩阵计算接口的使用方式。

### 算子功能描述

输入矩阵A（M×K）和矩阵B（K×N），计算输出矩阵C = A × B。

### 完整代码实现

```cpp
extern "C" __global__ __aicore__ void matmul_kernel(__gm__ half* a_gm, __gm__ half* b_gm, __gm__ float* c_gm, uint32_t M, uint32_t K, uint32_t N)
{
    // ===== 第一步：内存规划与地址分配 =====
    constexpr uint32_t BLOCK_M = 128;  // 分块M维度
    constexpr uint32_t BLOCK_K = 64;   // 分块K维度
    constexpr uint32_t BLOCK_N = 64;   // 分块N维度
    
    __cbuf__ half a_l1[BLOCK_M * BLOCK_K];   // L1中转区
    __cbuf__ half b_l1[BLOCK_K * BLOCK_N];   // L1中转区
    __ca__ half a_l0a[BLOCK_M * BLOCK_K];    // L0A输入
    __cb__ half b_l0b[BLOCK_K * BLOCK_N];    // L0B输入
    __cc__ float c_l0c[BLOCK_M * BLOCK_N];   // L0C输出
    
    // ===== 第二步：数据搬入 =====
    asc_copy_gm2l1(a_l1, a_gm, BLOCK_M * BLOCK_K);  // GM→L1
    asc_copy_gm2l1(b_l1, b_gm, BLOCK_K * BLOCK_N);  // GM→L1
    asc_sync_notify(PIPE_MTE2, PIPE_MTE1, EVENT_ID0);  // MTE2通知MTE1
    asc_sync_wait(PIPE_MTE2, PIPE_MTE1, EVENT_ID0);    // MTE1等待MTE2
    
    // ===== L1→L0A/L0B =====
    asc_copy_l12l0a(a_l0a, a_l1, 0, 1, 1, 0);  // L1→L0A
    asc_copy_l12l0b(b_l0b, b_l1, 0, 1, 1, 0);  // L1→L0B
    asc_sync_notify(PIPE_MTE1, PIPE_CUBE, EVENT_ID0);  // MTE1通知Cube
    asc_sync_wait(PIPE_MTE1, PIPE_CUBE, EVENT_ID0);    // Cube等待MTE1
    
    // ===== 第三步：计算执行 =====
    asc_mmad(c_l0c, a_l0a, b_l0b, BLOCK_M, BLOCK_K, BLOCK_N, 0, false, false, false);  // 矩阵乘
    asc_sync_notify(PIPE_CUBE, PIPE_MTE3, EVENT_ID0);  // Cube通知MTE3
    asc_sync_wait(PIPE_CUBE, PIPE_MTE3, EVENT_ID0);    // MTE3等待Cube
    
    // ===== 第四步：结果搬出 =====
    asc_copy_l0c2gm(c_gm, c_l0c, BLOCK_M * BLOCK_N);  // L0C→GM
}
```

### 代码解析

**表 2**  矩阵乘法算子代码解析

| 步骤 | 关键代码 | 技术要点 |
|------|----------|----------|
| 内存规划 | `__cbuf__`、`__ca__`、`__cb__`、`__cc__` | 分别申请L1、L0A、L0B、L0C内存，地址限定符标识存储层级 |
| GM→L1 | `asc_copy_gm2l1(a_l1, a_gm)` | 将矩阵数据从GM搬运到L1中转区 |
| L1→L0 | `asc_copy_l12l0a/asc_copy_l12l0b` | 将矩阵数据从L1搬运到L0A/L0B输入存储 |
| 计算执行 | `asc_mmad(c_l0c, a_l0a, b_l0b)` | 执行矩阵乘法，结果存储到L0C |
| 结果搬出 | `asc_copy_l0c2gm(c_gm, c_l0c)` | 将计算结果从L0C搬回GM |

> 📌 **提示**：Cube算子数据流遵循「GM→L1→L0A/L0B→MMAD→L0C→GM」路径，多级搬运需要多次同步确保数据依赖关系。

## 寄存器计算示例：Load-Compute-Store完整实现

寄存器计算示例展示UB与寄存器之间的Load-Compute-Store数据流。

### 算子功能描述

将输入向量数据加载到寄存器，执行向量乘法，结果写回UB。

### 完整代码实现

```cpp
extern "C" __global__ __aicore__ void reg_mul_kernel(__gm__ half* x_gm, __gm__ half* y_gm, __gm__ half* z_gm)
{
    // ===== 第一步：内存规划与地址分配 =====
    constexpr uint32_t LENGTH = 128;  // 处理元素个数
    __ubuf__ half x_ub[LENGTH];       // 输入1 UB地址
    __ubuf__ half y_ub[LENGTH];       // 输入2 UB地址
    __ubuf__ half z_ub[LENGTH];       // 输出UB地址
    
    // ===== 第二步：数据搬入 =====
    asc_copy_gm2ub(x_ub, x_gm, LENGTH);  // GM→UB
    asc_copy_gm2ub(y_ub, y_gm, LENGTH);  // GM→UB
    asc_sync_notify(PIPE_MTE2, PIPE_V, EVENT_ID0);  // MTE2通知V
    asc_sync_wait(PIPE_MTE2, PIPE_V, EVENT_ID0);    // V等待MTE2
    
    // ===== 第三步：寄存器计算（Load-Compute-Store） =====
    // ===== Load：UB→寄存器 =====
    vector_half x_reg;
    vector_half y_reg;
    asc_loadalign(x_reg, x_ub);  // 加载x到寄存器
    asc_loadalign(y_reg, y_ub);  // 加载y到寄存器
    
    // ===== Compute：寄存器计算 =====
    vector_half z_reg;
    vector_bool mask = asc_create_mask_b16(PAT_ALL);  // 创建全True掩码
    asc_mul(z_reg, x_reg, y_reg, mask);  // 寄存器乘法
    
    // ===== Store：寄存器→UB =====
    asc_storealign(z_ub, z_reg, mask);  // 存储结果到UB
    
    // ===== 第四步：结果搬出 =====
    asc_sync_notify(PIPE_V, PIPE_MTE3, EVENT_ID0);  // V通知MTE3
    asc_sync_wait(PIPE_V, PIPE_MTE3, EVENT_ID0);    // MTE3等待V
    asc_copy_ub2gm(z_gm, z_ub, LENGTH);  // UB→GM
}
```

### 代码解析

**表 3**  寄存器计算代码解析

| 步骤 | 关键代码 | 技术要点 |
|------|----------|----------|
| 内存规划 | `__ubuf__ half x_ub[128]` | 申请UB内存，作为寄存器加载的数据源 |
| Load | `asc_loadalign(x_reg, x_ub)` | 将UB数据加载到矢量寄存器，位宽为VL（256B） |
| Compute | `asc_mul(z_reg, x_reg, y_reg, mask)` | 寄存器间执行向量乘法，使用掩码控制计算范围 |
| Store | `asc_storealign(z_ub, z_reg, mask)` | 将寄存器结果写回UB，完成数据输出 |
| 同步控制 | `asc_sync_notify/wait` | 确保数据搬运与计算的数据依赖关系 |

> 📌 **提示**：寄存器计算遵循Load-Compute-Store三阶段流程，Vector计算单元只能访问寄存器，不能直接操作UB数据。
