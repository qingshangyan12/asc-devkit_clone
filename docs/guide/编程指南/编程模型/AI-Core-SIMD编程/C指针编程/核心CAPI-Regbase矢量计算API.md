本章介绍 AscendC 中直接使用 C 语言进行编码的方式——C API，聚焦「硬件架构适配+底层实操落地+性能优化」，帮助开发者掌握基于 C 语言的 Ascend 芯片底层算子开发、资源管控与调试技巧，实现高性能、高可控性的算子开发。
#### 什么是 AscendC C API
AscendC C API 是一套面向 Ascend 芯片硬件架构（如 RegBase 架构）、完全基于标准 C 语言语法设计的底层编程接口，为开发者提供无冗余封装、可直接操作芯片硬件资源（寄存器、UB、PE 等）的编程方式，核心是通过原生 C 语言特性，实现软件代码与芯片硬件的直接联动。

与 AscendC 基础 API（封装度高、易用性优先）不同，C API 完全遵循 C 语言原生特性，以指针操作为核心，无需依赖高层封装，直接打通“C 代码-芯片硬件”的执行链路，专注于底层高性能算子开发场景，实现对硬件资源的精细化管控与性能最大化利用。
#### 核心定位与适用场景
AscendC C API 的核心定位是：为开发者提供 Ascend 芯片底层硬件资源的直接操控能力，实现算子性能最大化，同时保障开发灵活性与硬件兼容性，兼顾底层可控性与实操性。

适用场景（贴合实际开发需求，聚焦底层开发核心需求）：

-   高性能算子开发：需要精准控制寄存器分配、数据搬运路径、计算时序，规避高层封装带来的性能损耗，如深度学习核心算子（卷积、矩阵乘）的底层实现。
    
-   硬件资源精细化管控：需手动管理片上存储（UB）、寄存器、PE 计算单元，适配复杂算子的资源调度需求，实现对芯片硬件资源的精准分配与高效利用。
    
-   C 语言原生开发适配：开发者熟悉 C 语言底层编程，需将传统 C 语言算子代码迁移至 Ascend 平台，或需与 C 语言原生项目无缝兼容，依托 C 语言的通用性降低开发与迁移成本。
    
-   性能优化场景：需针对特定算子进行极致性能调优，手动优化内存访问、数据复用、计算并行度，挖掘芯片硬件的最大计算潜力。
