# Regbase API 寄存器类型

本章详细介绍 Regbase API 的寄存器类型体系，包括矢量数据寄存器、掩码寄存器、地址寄存器、非对齐寄存器的定义、特点及使用方法。

---

## 1. 矢量数据寄存器

### 1.1 寄存器概述

矢量数据寄存器是 Regbase API 的核心数据载体，用于存储参与矢量计算的输入数据和输出结果。所有矢量数据寄存器位宽固定为 VL（Vector Length）= 256 字节。

### 1.2 寄存器类型分类

**按位宽分类**：

| 位宽 | 数据类型 | 元素数量 | 说明 |
|-----|---------|---------|------|
| b8 | `vector_int8_t` | 256 | 8 位整数 |
| b8 | `vector_uint8_t` | 256 | 8 位无符号整数 |
| b8 | `vector_fp8_e4m3fn_t` | 256 | FP8 E4M3 格式 |
| b8 | `vector_fp8_e5m2_t` | 256 | FP8 E5M2 格式 |
| b8 | `vector_hifloat8_t` | 256 | HiFloat8 格式 |
| b8 | `vector_int4x2_t` | 256 | INT4 打包类型 |
| b16 | `vector_int16_t` | 128 | 16 位整数 |
| b16 | `vector_uint16_t` | 128 | 16 位无符号整数 |
| b16 | `vector_half` | 128 | FP16 浮点数 |
| b16 | `vector_bfloat16_t` | 128 | BF16 浮点数 |
| b32 | `vector_int32_t` | 64 | 32 位整数 |
| b32 | `vector_uint32_t` | 64 | 32 位无符号整数 |
| b32 | `vector_float` | 64 | FP32 浮点数 |
| b64 | `vector_int64_t` | 32 | 64 位整数 |
| b64 | `vector_uint64_t` | 32 | 64 位无符号整数 |

### 1.3 元素数量计算

**计算公式**：
```
元素数量 = VL / sizeof(T) = 256B / sizeof(T)
```

**计算示例**：
- `vector_half`: 256B / 2B = 128 个元素
- `vector_float`: 256B / 4B = 64 个元素
- `vector_int8_t`: 256B / 1B = 256 个元素

### 1.4 寄存器使用示例

```cpp
__simd_vf__ inline void register_example()
{
    vector_half v_half;      // 128 个 half 元素
    vector_float v_float;    // 64 个 float 元素
    vector_int8_t v_int8;    // 256 个 int8_t 元素
    
    vector_bool mask_half = asc_create_mask_b16(PAT_ALL);
    vector_bool mask_float = asc_create_mask_b32(PAT_ALL);
    vector_bool mask_int8 = asc_create_mask_b8(PAT_ALL);
    
    asc_loadalign(v_half, src_half_addr);
    asc_loadalign(v_float, src_float_addr);
    asc_loadalign(v_int8, src_int8_addr);
    
    asc_add(v_half, v_half, v_half, mask_half);
    asc_add(v_float, v_float, v_float, mask_float);
    asc_add(v_int8, v_int8, v_int8, mask_int8);
    
    asc_storealign(dst_half_addr, v_half, mask_half);
    asc_storealign(dst_float_addr, v_float, mask_float);
    asc_storealign(dst_int8_addr, v_int8, mask_int8);
}
```

## 2. 掩码寄存器

### 2.1 掩码寄存器概述

掩码寄存器类型为 `vector_bool`，用于控制矢量计算中哪些元素参与计算。掩码的每个 bit 对应一个数据元素，bit 为 1 表示参与计算，为 0 表示不参与。

### 2.2 掩码位宽

掩码寄存器位宽为 VL / 8 = 256B / 8 = 32 字节。

**掩码位数与数据类型对应**：

| 数据位宽 | 掩码位数 | 说明 |
|---------|---------|------|
| 8 位数据 | 256 位 | 每个元素对应 1 位掩码 |
| 16 位数据 | 128 位 | 每个元素对应 1 位掩码 |
| 32 位数据 | 64 位 | 每个元素对应 1 位掩码 |
| 64 位数据 | 32 位 | 每个元素对应 1 位掩码 |

### 2.3 掩码创建接口

| 接口 | 适用数据类型 | 说明 |
|-----|-------------|------|
| `asc_create_mask_b8` | int8_t, uint8_t, fp8 等 | 创建 8 位数据掩码 |
| `asc_create_mask_b16` | half, int16_t, bfloat16 等 | 创建 16 位数据掩码 |
| `asc_create_mask_b32` | float, int32_t 等 | 创建 32 位数据掩码 |

### 2.4 掩码更新接口

| 接口 | 适用数据类型 | 说明 |
|-----|-------------|------|
| `asc_update_mask_b8` | int8_t, uint8_t, fp8 等 | 根据元素数量更新掩码 |
| `asc_update_mask_b16` | half, int16_t, bfloat16 等 | 根据元素数量更新掩码 |
| `asc_update_mask_b32` | float, int32_t 等 | 根据元素数量更新掩码 |

### 2.5 掩码使用示例

```cpp
__simd_vf__ inline void mask_example()
{
    vector_half src, dst;
    
    vector_bool mask_all = asc_create_mask_b16(PAT_ALL);  // 所有元素参与
    vector_bool mask_partial = asc_update_mask_b16(64);   // 前 64 个元素参与
    
    asc_loadalign(src, src_addr);
    
    asc_add(dst, src, src, mask_all);      // 所有 128 个元素参与
    asc_add(dst, src, src, mask_partial);  // 前 64 个元素参与
    
    asc_storealign(dst_addr, dst, mask_all);
}
```

## 3. 地址寄存器

### 3.1 地址寄存器概述

地址寄存器类型为 `iter_reg`，用于存储地址偏移量，支持在循环中自动自增，简化地址计算。

### 3.2 地址寄存器创建接口

| 接口 | 适用数据类型 | 说明 |
|-----|-------------|------|
| `asc_create_iter_reg_b8` | int8_t, uint8_t, fp8 等 | 创建 8 位数据地址寄存器 |
| `asc_create_iter_reg_b16` | half, int16_t, bfloat16 等 | 创建 16 位数据地址寄存器 |
| `asc_create_iter_reg_b32` | float, int32_t 等 | 创建 32 位数据地址寄存器 |

### 3.3 地址寄存器特点

| 特点 | 说明 |
|-----|------|
| 自动自增 | 每次使用后自动增加偏移量 |
| 简化地址计算 | 避免手动计算地址偏移 |
| 循环友好 | 适合循环处理数据 |

### 3.4 地址寄存器使用示例

```cpp
__simd_vf__ inline void iter_reg_example(__ubuf__ half* dst_addr, __ubuf__ half* src_addr,
                                          uint32_t total_length)
{
    constexpr uint32_t one_repeat_size = 128;  // VL / sizeof(half)
    uint32_t repeat_time = total_length / one_repeat_size;
    
    vector_half src, dst;
    vector_bool mask;
    iter_reg addr_reg;
    
    for (uint32_t i = 0; i < repeat_time; ++i) {
        addr_reg = asc_create_iter_reg_b16(one_repeat_size);  // 每次偏移 128 个元素
        mask = asc_create_mask_b16(PAT_ALL);
        
        asc_loadalign(src, src_addr, addr_reg);  // 自动更新地址
        asc_add(dst, src, src, mask);
        asc_storealign(dst_addr, dst, addr_reg, mask);  // 自动更新地址
    }
}
```

## 4. 非对齐寄存器

### 4.1 非对齐寄存器概述

非对齐寄存器用于处理地址未满足 32 字节对齐要求的数据。Regbase API 提供两种非对齐寄存器类型：

| 寄存器类型 | 说明 | 使用场景 |
|----------|------|---------|
| `vector_load_unalign` | 非对齐数据加载缓冲区 | 非对齐加载 |
| `vector_store_unalign` | 非对齐数据存储缓冲区 | 非对齐存储 |

### 4.2 非对齐加载流程

```
1. 初始化：asc_loadunalign_pre
2. 加载：asc_loadunalign
```

### 4.3 非对齐存储流程

```
1. 存储：asc_storeunalign
2. 尾块处理：asc_storeunalign_post
```

### 4.4 非对齐寄存器使用示例

```cpp
__simd_vf__ inline void unalign_example(__ubuf__ int8_t* dst_addr, __ubuf__ int8_t* src_addr)
{
    vector_int8_t src, dst;
    vector_load_unalign ureg0;   // 加载缓冲区
    vector_store_unalign ureg1;  // 存储缓冲区
    vector_bool mask;
    
    mask = asc_create_mask_b8(PAT_ALL);
    
    // 非对齐加载
    asc_loadunalign_pre(ureg0, src_addr);
    asc_loadunalign(src, ureg0, src_addr);
    
    // 计算
    asc_neg(dst, src, mask);
    
    // 非对齐存储
    asc_storeunalign(dst_addr, ureg1, dst, 256);
    asc_storeunalign_post(dst_addr, ureg1, 0);
}
```

## 5. 寄存器类型与 API 匹配

### 5.1 数据类型匹配表

| 数据类型 | 矢量寄存器 | 掩码接口 | 地址寄存器接口 |
|---------|----------|---------|---------------|
| int8_t, uint8_t | `vector_int8_t`, `vector_uint8_t` | `asc_create_mask_b8` | `asc_create_iter_reg_b8` |
| fp8 类型 | `vector_fp8_*` | `asc_create_mask_b8` | `asc_create_iter_reg_b8` |
| half | `vector_half` | `asc_create_mask_b16` | `asc_create_iter_reg_b16` |
| int16_t, uint16_t | `vector_int16_t`, `vector_uint16_t` | `asc_create_mask_b16` | `asc_create_iter_reg_b16` |
| bfloat16 | `vector_bfloat16_t` | `asc_create_mask_b16` | `asc_create_iter_reg_b16` |
| float | `vector_float` | `asc_create_mask_b32` | `asc_create_iter_reg_b32` |
| int32_t, uint32_t | `vector_int32_t`, `vector_uint32_t` | `asc_create_mask_b32` | `asc_create_iter_reg_b32` |

### 5.2 寄存器类型选择指南

| 场景 | 推荐寄存器类型 | 原因 |
|-----|-------------|------|
| 通用浮点计算 | `vector_half` | FP16 是 Ascend 最优性能类型 |
| 高精度计算 | `vector_float` | FP32 提供更高精度 |
| 整数计算 | `vector_int32_t` | 适配整数运算场景 |
| 数据打包 | `vector_int4x2_t` | 节省存储空间 |

## 6. 寄存器使用最佳实践

### 6.1 寄存器定义规范

```cpp
__simd_vf__ inline void compute_func()
{
    vector_half src0, src1, dst;    // 定义多个寄存器
    vector_bool mask;               // 定义掩码寄存器
    
    mask = asc_create_mask_b16(PAT_ALL);  // 初始化掩码
    
    asc_loadalign(src0, src0_addr);
    asc_loadalign(src1, src1_addr);
    asc_add(dst, src0, src1, mask);
    asc_storealign(dst_addr, dst, mask);
}
```

### 6.2 掩码复用

```cpp
__simd_vf__ inline void mask_reuse_example()
{
    vector_half src, dst0, dst1;
    vector_bool mask = asc_create_mask_b16(PAT_ALL);  // 创建一次
    
    asc_loadalign(src, src_addr);
    
    asc_add(dst0, src, src, mask);  // 复用掩码
    asc_mul(dst1, src, src, mask);  // 复用掩码
    
    asc_storealign(dst0_addr, dst0, mask);
    asc_storealign(dst1_addr, dst1, mask);
}
```

### 6.3 地址寄存器循环使用

```cpp
__simd_vf__ inline void iter_reg_loop_example(__ubuf__ half* dst_addr, __ubuf__ half* src_addr)
{
    vector_half src, dst;
    vector_bool mask;
    iter_reg addr_reg;
    
    for (uint32_t i = 0; i < 4; ++i) {
        addr_reg = asc_create_iter_reg_b16(128);
        mask = asc_create_mask_b16(PAT_ALL);
        
        asc_loadalign(src, src_addr, addr_reg);  // 地址自动更新
        asc_add(dst, src, src, mask);
        asc_storealign(dst_addr, dst, addr_reg, mask);
    }
}
```

## 7. 常见问题

### 7.1 数据类型与掩码不匹配

**问题**：掩码接口与数据类型不匹配导致计算错误。

**解决**：
```cpp
vector_half src;                            // 16 位数据
vector_bool mask = asc_create_mask_b8(...); // 错误：使用 b8 掩码

vector_bool mask = asc_create_mask_b16(...); // 正确：使用 b16 掩码
```

### 7.2 寄存器未初始化

**问题**：掩码寄存器未初始化导致计算错误。

**解决**：
```cpp
vector_bool mask;                    // 未初始化
asc_add(dst, src, src, mask);        // 错误

vector_bool mask = asc_create_mask_b16(PAT_ALL);  // 正确：初始化掩码
asc_add(dst, src, src, mask);
```

### 7.3 非对齐流程不完整

**问题**：非对齐加载/存储流程不完整导致数据丢失。

**解决**：
```cpp
asc_loadunalign(src, ureg, src_addr);          // 错误：缺少 pre

asc_loadunalign_pre(ureg, src_addr);           // 正确：完整流程
asc_loadunalign(src, ureg, src_addr);
```
