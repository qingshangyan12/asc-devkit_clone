# Membase API 同步控制

## 1. 同步概述

NPU采用多流水线并行执行架构，不同流水线之间的操作需要通过同步机制来协调执行顺序，确保数据依赖关系正确。

### 1.1 为什么需要同步

- **流水线并行**：不同流水线可以并行执行
- **数据依赖**：计算依赖搬运完成的数据
- **顺序保证**：确保操作按正确顺序执行

### 1.2 同步时机

```
搬运完成 → 同步 → 计算开始
计算完成 → 同步 → 搬出开始
```

## 2. 同步API分类

### 2.1 单核同步

| API | 功能 | 流水线 |
|-----|------|--------|
| `asc_sync` | 等待所有流水线完成 | PIPE_S |
| `asc_sync_pipe` | 等待指定流水线完成 | PIPE_S |
| `asc_sync_vec` | 同步所有流水线 | PIPE_S |
| `asc_sync_mte2` | 等待PIPE_MTE2完成 | PIPE_S |
| `asc_sync_mte3` | 等待PIPE_MTE3完成 | PIPE_S |
| `asc_sync_data_barrier` | 内存访问屏障 | PIPE_S |

### 2.2 核间同步

| API | 功能 |
|-----|------|
| `asc_sync_block_arrive` | 发送同步信号 |
| `asc_sync_block_wait` | 等待同步信号 |
| `asc_sync_notify` | 设置同步标志 |
| `asc_sync_wait` | 等待同步标志 |

## 3. 单核同步接口详解

### 3.1 asc_sync

```cpp
asc_sync();
```

**功能**：等待所有流水线操作完成。

**适用场景**：需要确保所有操作都完成时使用。

### 3.2 asc_sync_pipe

```cpp
asc_sync_pipe(PIPE_TYPE pipe);
```

**功能**：等待指定流水线操作完成。

**参数**：

| 参数值 | 说明 |
|-------|------|
| PIPE_MTE2 | 等待GM→UB/L1搬运完成 |
| PIPE_MTE3 | 等待UB/L1→GM搬运完成 |
| PIPE_MTE1 | 等待L1→L0搬运完成 |
| PIPE_V | 等待矢量计算完成 |
| PIPE_M | 等待矩阵计算完成 |
| PIPE_ALL | 等待所有流水线完成 |

### 3.3 asc_sync_vec

```cpp
asc_sync_vec();
```

**功能**：同步所有流水线。

### 3.4 asc_sync_mte2 / asc_sync_mte3

```cpp
asc_sync_mte2();
asc_sync_mte3();
```

**功能**：分别等待PIPE_MTE2和PIPE_MTE3流水线完成。

### 3.5 asc_sync_data_barrier

```cpp
asc_sync_data_barrier(uint64_t addr, uint32_t size);
```

**功能**：阻塞后续指令，等待指定内存区域的访问完成。

## 4. 核间同步接口详解

### 4.1 前置设置

```cpp
// 设置核间同步寄存器基地址
uint64_t ffts_addr = ...;
asc_set_ffts_base_addr(ffts_addr);
```

### 4.2 asc_sync_block_arrive

```cpp
asc_sync_block_arrive(PIPE_TYPE pipe, int64_t flag_id);
```

**功能**：发送同步信号到核间同步寄存器，设置同步点。

**参数**：
- `pipe`：流水线类型
- `flag_id`：同步标志ID，用于关联arrive和wait

### 4.3 asc_sync_block_wait

```cpp
asc_sync_block_wait(PIPE_TYPE pipe, int64_t flag_id);
```

**功能**：等待所有同步对象到达flagID对应的同步点。

**参数**：
- `pipe`：流水线类型
- `flag_id`：与arrive使用的flag_id相同

### 4.4 使用流程

```cpp
// 1. 设置核间同步基地址
asc_set_ffts_base_addr(ffts_addr);

// 2. 各核执行计算
// ...

// 3. 核0发送同步信号
int64_t flag_id = 1;
asc_sync_block_arrive(PIPE_S, flag_id);

// 4. 核1等待同步信号
asc_sync_block_wait(PIPE_S, flag_id);

// 5. 继续后续操作
```

## 5. 同步示例

### 5.1 矢量计算同步

```cpp
__aicore__ void vector_compute_demo()
{
    constexpr uint32_t length = 256;
    __ubuf__ half src[length];
    __ubuf__ half dst[length];
    
    // GM → UB
    asc_copy_gm2ub(src, src_gm, length * sizeof(half));
    
    // 同步等待搬运完成
    asc_sync_pipe(PIPE_MTE2);
    
    // 矢量计算
    asc_add(dst, src, src, length);
    
    // 同步等待计算完成
    asc_sync_pipe(PIPE_V);
    
    // UB → GM
    asc_copy_ub2gm(dst_gm, dst, length * sizeof(half));
    
    // 同步等待搬出完成
    asc_sync_pipe(PIPE_MTE3);
}
```

### 5.2 矩阵计算同步

```cpp
__aicore__ void matmul_demo()
{
    // GM → L1
    asc_copy_gm2l1(a_l1, matrix_a, M * K * sizeof(half));
    asc_copy_gm2l1(b_l1, matrix_b, K * N * sizeof(half));
    asc_sync_pipe(PIPE_MTE2);
    
    // L1 → L0A/L0B
    asc_copy_l12l0a(a_l0a, a_l1, ...);
    asc_copy_l12l0b(b_l0b, b_l1, ...);
    asc_sync_pipe(PIPE_MTE1);
    
    // 矩阵计算
    asc_mmad(c_l0c, a_l0a, b_l0b, M, K, N, ...);
    asc_sync_pipe(PIPE_M);
    
    // L0C → GM
    asc_copy_l0c2gm(matrix_c, c_l0c, M * N * sizeof(float));
    asc_sync_pipe(PIPE_MTE3);
}
```

### 5.3 多核同步

```cpp
__aicore__ void multi_core_demo()
{
    // 获取核信息
    int64_t block_idx = asc_get_block_idx();
    int64_t block_num = asc_get_block_num();
    
    // 设置核间同步基地址
    uint64_t config = *(__gm__ uint64_t*)ffts_addr;
    asc_set_ffts_base_addr(config);
    
    int64_t flag_id = 1;
    
    // 各核完成计算后
    // ...
    
    // 发送/等待同步信号
    asc_sync_block_arrive(PIPE_S, flag_id);
    asc_sync_block_wait(PIPE_S, flag_id);
    
    // 继续后续操作
}
```

### 5.4 流水线并行示例

```cpp
__aicore__ void pipeline_parallel()
{
    // 搬入第一块数据
    asc_copy_gm2ub(src0, src_gm + 0, block_size);
    
    // 同步
    asc_sync_pipe(PIPE_MTE2);
    
    // 计算第一块，同时搬入第二块
    asc_add(dst0, src0, src0, block_count);
    asc_copy_gm2ub(src1, src_gm + block_size, block_size);  // 可并行
    
    // 同步
    asc_sync_pipe(PIPE_V);
    asc_sync_pipe(PIPE_MTE2);
    
    // 计算第二块
    asc_add(dst1, src1, src1, block_count);
}
```

## 6. 同步约束说明

### 6.1 同步点位置

- **必须**在数据依赖的操作之间插入同步
- **避免**不必要的同步点，影响性能
- **理解**流水线并行特性，合理安排操作顺序

### 6.2 flag_id使用约束

- 不同同步组使用不同的flag_id
- flag_id取值范围参考硬件规格
- 同一同步组的arrive和wait必须使用相同的flag_id

### 6.3 核间同步基地址

- 使用核间同步前必须设置基地址
- 基地址由运行时系统提供

## 7. 同步最佳实践

### 7.1 最小化同步点

```cpp
// 不推荐：过多同步
asc_copy_gm2ub(src0, src_gm0, size);
asc_sync_pipe(PIPE_MTE2);  // 同步1
asc_copy_gm2ub(src1, src_gm1, size);
asc_sync_pipe(PIPE_MTE2);  // 同步2（可合并）

// 推荐：合并同步
asc_copy_gm2ub(src0, src_gm0, size);
asc_copy_gm2ub(src1, src_gm1, size);
asc_sync_pipe(PIPE_MTE2);  // 只需一次同步
```

### 7.2 利用流水线并行

```cpp
// 计算与搬运并行
asc_add(dst0, src0, src0, count);        // PIPE_V
asc_copy_gm2ub(src1, src_gm1, size);     // PIPE_MTE2，可并行

// 只需同步计算，搬运自动并行
asc_sync_pipe(PIPE_V);
```
