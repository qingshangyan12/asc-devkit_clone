# Membase API 数据搬运与计算

本章详细介绍数据搬运、矢量计算、矩阵计算、掩码操作、原子操作和系统变量的使用方法，帮助开发者掌握完整的算子开发流程。

---

## 1. 数据搬运

### 1.1 数据搬运概述

数据搬运是 AI Core 编程中最频繁的操作，负责在不同存储单元之间传输数据。理解搬运路径和流水线分配对于性能优化至关重要。

**存储层次与搬运路径**：

```
Global Memory (GM)
    ↓ ↑ PIPE_MTE2/PIPE_MTE3
Unified Buffer (UB) ← 矢量计算数据
    ↓ ↑ PIPE_MTE3
L1 Buffer ← 矩阵计算暂存
    ↓ ↑ PIPE_MTE1
L0A/L0B Buffer ← 矩阵输入
    ↓
L0C Buffer ← 矩阵结果
```

### 1.2 矢量数据搬运 API

| API 名称 | 功能 | 流水线 | 适用场景 |
|--------|------|--------|---------|
| `asc_copy_gm2ub` | GM → UB | PIPE_MTE2 | 矢量计算数据搬入 |
| `asc_copy_ub2gm` | UB → GM | PIPE_MTE3 | 矢量计算结果搬出 |
| `asc_copy_ub2ub` | UB → UB | PIPE_V | UB 内数据拷贝 |
| `asc_copy_ub2l1` | UB → L1 | PIPE_MTE3 | 数据暂存到 L1 |
| `asc_copy_gm2ub_align` | GM → UB（非对齐） | PIPE_MTE2 | 非对齐地址搬入 |
| `asc_copy_ub2gm_align` | UB → GM（非对齐） | PIPE_MTE3 | 非对齐地址搬出 |

### 1.3 矩阵数据搬运 API

| API 名称 | 功能 | 流水线 | 适用场景 |
|--------|------|--------|---------|
| `asc_copy_gm2l1` | GM → L1 | PIPE_MTE2 | 矩阵数据暂存 |
| `asc_copy_gm2l0a` | GM → L0A | PIPE_MTE2 | 左矩阵直接输入 |
| `asc_copy_gm2l0b` | GM → L0B | PIPE_MTE2 | 右矩阵直接输入 |
| `asc_copy_l12l0a` | L1 → L0A | PIPE_MTE1 | 左矩阵 L1 输入 |
| `asc_copy_l12l0b` | L1 → L0B | PIPE_MTE1 | 右矩阵 L1 输入 |
| `asc_copy_l0c2gm` | L0C → GM | PIPE_MTE3 | 矩阵结果输出 |
| `asc_copy_l0c2ub` | L0C → UB | PIPE_MTE3 | 矩阵结果到 UB |

### 1.4 数据搬运模式

#### 模式一：前n个数据搬运

```cpp
asc_copy_gm2ub(__ubuf__ void* dst, __gm__ void* src, uint32_t size);
```

**特点**：
- 连续搬运指定字节的数据
- 搬运数据大小要求 32 字节对齐
- 参数简洁，适合连续数据搬运

**示例**：
```cpp
asc_copy_gm2ub(src_buffer, src_gm, 1024 * sizeof(half));
asc_sync_pipe(PIPE_MTE2);
```

#### 模式二：高维切分搬运

```cpp
asc_copy_gm2ub(__ubuf__ void* dst, __gm__ void* src,
               uint16_t n_burst,    // 连续传输数据块个数
               uint16_t burst_len,  // 每块长度（32字节为单位）
               uint16_t src_gap,    // 源地址间隔
               uint16_t dst_gap);   // 目的地址间隔
```

**特点**：
- 支持非连续数据搬运
- 支持设置数据块间隔
- 适合复杂数据布局

**参数说明**：

| 参数 | 说明 | 单位 |
|-----|------|------|
| n_burst | 连续传输数据块个数 | 个数 |
| burst_len | 每块长度 | 32字节为单位 |
| src_gap | 源地址间隔 | 32字节为单位 |
| dst_gap | 目的地址间隔 | 32字节为单位 |

#### 模式三：同步搬运

```cpp
asc_copy_gm2ub_sync(__ubuf__ void* dst, __gm__ void* src, uint32_t size);
```

**特点**：
- 内部自动插入同步等待
- 易用性强，适合快速开发
- 性能略低于手动同步版本

### 1.5 搬运最佳实践

#### 对齐搬运优先

```cpp
// 推荐：对齐搬运
__ubuf__ half buffer[128];  // 自动 32B 对齐
asc_copy_gm2ub(buffer, src_gm, 128 * sizeof(half));

// 特殊情况：非对齐搬运
asc_copy_gm2ub_align(buffer, src_gm, size, offset);
```

#### 并行搬运优化

```cpp
// 多个搬运操作可并行执行
asc_copy_gm2ub(src0, src0_gm, size);
asc_copy_gm2ub(src1, src1_gm, size);
asc_copy_gm2ub(src2, src2_gm, size);
asc_sync_pipe(PIPE_MTE2);  // 只需一次同步
```

#### 流水线重叠

```cpp
asc_copy_gm2ub(src0, src0_gm, size);
asc_sync_pipe(PIPE_MTE2);

asc_add(dst0, src0, src0, count);  // 计算
asc_copy_gm2ub(src1, src1_gm, size);  // 同时搬运下一块

asc_sync_pipe(PIPE_V);
asc_sync_pipe(PIPE_MTE2);
```

## 2. 矢量计算

### 2.1 矢量计算概述

矢量计算通过 Vector 计算单元完成，源操作数和目的操作数存储在 Unified Buffer 中。Membase API 提供丰富的矢量计算接口，覆盖算术运算、数学函数、激活函数、比较运算、归约运算等。

### 2.2 计算模式对比

| 模式 | 特点 | 适用场景 | 参数复杂度 |
|-----|------|---------|-----------|
| 前 n 个数据计算 | 紧密排布读取，从第 0 位置顺序取 N 个数据 | 连续数据处理、简单场景 | 低 |
| 高维切分计算 | 支持设置迭代次数和数据步长 | 非连续数据、带步长计算 | 高 |
| 同步计算 | 内部自动插入同步操作 | 快速开发、原型验证 | 低 |

### 2.3 基础算术运算

| API 名称 | 计算公式 | 支持数据类型 |
|--------|---------|-------------|
| `asc_add` | dst = src0 + src1 | half, int16_t, int32_t, float |
| `asc_sub` | dst = src0 - src1 | half, int16_t, int32_t, float |
| `asc_mul` | dst = src0 × src1 | half, int16_t, int32_t, float |
| `asc_div` | dst = src0 ÷ src1 | half, float |
| `asc_abs` | dst = |src| | half, float |
| `asc_neg` | dst = -src | half, float |

**示例**：
```cpp
asc_add(dst, src0, src1, 128);           // 前 n 个数据计算
asc_add(dst, src0, src1, 2, 1, 1, 1, 8, 8, 8);  // 高维切分计算
asc_add_sync(dst, src0, src1, 128);      // 同步计算
```

### 2.4 标量运算

```cpp
asc_add_scalar(__ubuf__ half* dst, __ubuf__ half* src, half value, uint32_t count);
asc_mul_scalar(__ubuf__ half* dst, __ubuf__ half* src, half value, uint32_t count);
```

**计算公式**：
- `asc_add_scalar`: dst[i] = src[i] + value
- `asc_mul_scalar`: dst[i] = src[i] × value

**示例**：
```cpp
asc_add_scalar(dst, src, (half)1.0, 128);  // 每个元素加 1.0
```

### 2.5 数学函数

| API 名称 | 功能 | 计算公式 | 支持数据类型 |
|--------|------|---------|-------------|
| `asc_exp` | 自然指数 | e^x | half, float |
| `asc_log` | 自然对数 | ln(x) | half, float |
| `asc_sqrt` | 平方根 | √x | half, float |
| `asc_rsqrt` | 平方根倒数 | 1/√x | half, float |
| `asc_rcp` | 倒数 | 1/x | half, float |

**示例**：
```cpp
asc_exp(dst, src, 128);      // 计算 e^x
asc_sqrt(dst, src, 128);     // 计算 √x
```

### 2.6 激活函数

| API 名称 | 功能 | 计算公式 |
|--------|------|---------|
| `asc_relu` | ReLU | max(0, x) |
| `asc_leakyrelu` | Leaky ReLU | x > 0 ? x : α·x |

**示例**：
```cpp
asc_relu(dst, src, 128);                    // ReLU
asc_leakyrelu(dst, src, (half)0.1, 128);    // Leaky ReLU，α = 0.1
```

### 2.7 数据类型转换

| API 名称 | 转换方向 | 说明 |
|--------|---------|------|
| `asc_float2half` | float → half | FP32 转 FP16 |
| `asc_half2float` | half → float | FP16 转 FP32 |
| `asc_float2bfloat16` | float → bfloat16_t | FP32 转 BF16 |
| `asc_bfloat162float` | bfloat16_t → float | BF16 转 FP32 |
| `asc_half2int8` | half → int8_t | FP16 转 INT8 |
| `asc_int82half` | int8_t → half | INT8 转 FP16 |
| `asc_float2int32` | float → int32_t | FP32 转 INT32 |
| `asc_int322float` | int32_t → float | INT32 转 FP32 |

**示例**：
```cpp
asc_half2float(dst_float, src_half, 128);  // FP16 → FP32
asc_float2half(dst_half, src_float, 128);  // FP32 → FP16
```

### 2.8 比较运算

| API 名称 | 功能 | 输出 |
|--------|------|------|
| `asc_eq` | src0 == src1 | 比特位掩码 |
| `asc_ne` | src0 != src1 | 比特位掩码 |
| `asc_gt` | src0 > src1 | 比特位掩码 |
| `asc_lt` | src0 < src1 | 比特位掩码 |
| `asc_ge` | src0 >= src1 | 比特位掩码 |
| `asc_le` | src0 <= src1 | 比特位掩码 |

**示例**：
```cpp
asc_gt(mask_result, src0, src1, 128);  // 比较大于，结果为比特掩码
```

### 2.9 归约运算

| API 名称 | 功能 | 输出粒度 |
|--------|------|---------|
| `asc_datablock_reduce_sum` | DataBlock 内元素求和 | 每 32B 一个结果 |
| `asc_datablock_reduce_max` | DataBlock 内元素求最大值 | 每 32B 一个结果 |
| `asc_datablock_reduce_min` | DataBlock 内元素求最小值 | 每 32B 一个结果 |
| `asc_repeat_reduce_sum` | Repeat 内元素求和 | 一个结果 |
| `asc_repeat_reduce_max` | Repeat 内元素求最大值 | 一个结果 |
| `asc_repeat_reduce_min` | Repeat 内元素求最小值 | 一个结果 |

**示例**：
```cpp
asc_datablock_reduce_sum(dst, src, 1);  // 每个 DataBlock 求和
asc_repeat_reduce_sum(dst, src, 1);     // 整个 Repeat 求和
```

### 2.10 高维切分计算参数详解

#### repeatTime 参数

控制迭代次数，每个迭代处理 8 个 DataBlock（256 字节）。取值范围 [1, 255]。

#### dataBlockStride 参数

控制单次迭代内不同 DataBlock 间地址步长，单位为 DataBlock（32 字节）：
- 连续计算：设置为 1
- 非连续计算：大于 1（如设置为 2，表示间隔 1 个 DataBlock）

#### repeatStride 参数

控制相邻迭代间相同 DataBlock 的地址步长：
- 连续计算：设置为 8
- 非连续计算：大于 8
- 反复计算：设置为 0（对首部 8 个 DataBlock 反复读取）
- 部分重复：大于 0 且小于 8

**示例**：
```cpp
asc_add(dst, src0, src1, 
        2,   // repeat: 2 次迭代
        1,   // dst_block_stride: 连续
        2,   // src0_block_stride: 间隔 1 个 DataBlock
        2,   // src1_block_stride: 间隔 1 个 DataBlock
        8,   // dst_repeat_stride: 连续
        16,  // src0_repeat_stride: 间隔 8 个 DataBlock
        16); // src1_repeat_stride: 间隔 8 个 DataBlock
```

## 3. 矩阵计算

### 3.1 矩阵计算概述

矩阵计算通过 Cube 计算单元完成，主要用于矩阵乘加运算（MMAD）。理解矩阵计算的数据流和流水线分配对于高性能矩阵算子开发至关重要。

### 3.2 MMAD 运算

```cpp
asc_mmad(__cc__ float* c_matrix,
         __ca__ half* a_matrix,
         __cb__ half* b_matrix,
         uint16_t left_height,   // 左矩阵高度 M
         uint16_t n_dim,         // K 维度
         uint16_t right_width,   // 右矩阵宽度 N
         uint8_t unit_flag,
         bool k_direction_align,
         bool c_matrix_source,
         bool c_matrix_init_val);
```

**计算公式**: C = A × B + C

**参数说明**：

| 参数 | 说明 |
|-----|------|
| c_matrix | 结果矩阵地址（L0C） |
| a_matrix | 左矩阵地址（L0A） |
| b_matrix | 右矩阵地址（L0B） |
| left_height | 左矩阵高度 M |
| n_dim | K 维度 |
| right_width | 右矩阵宽度 N |
| unit_flag | 单元标志 |
| k_direction_align | K 方向对齐 |
| c_matrix_source | C 矩阵来源 |
| c_matrix_init_val | C 矩阵初始值 |

### 3.3 支持的数据类型组合

| 左矩阵(A) | 右矩阵(B) | 结果矩阵(C) |
|----------|----------|------------|
| half | half | float |
| float | float | float |
| bfloat16_t | bfloat16_t | float |
| int8_t | int8_t | int32_t |
| int4b_t | int4b_t | int32_t |

### 3.4 矩阵计算流水线

```
GM → L1 → L0A/L0B → L0C → GM
   ↓     ↓        ↓     ↓
MTE2  MTE1     PIPE_M  MTE3
```

**完整流程示例**：
```cpp
asc_copy_gm2l1(a_l1, matrix_a, M * K * sizeof(half));
asc_copy_gm2l1(b_l1, matrix_b, K * N * sizeof(half));
asc_sync_pipe(PIPE_MTE2);

asc_copy_l12l0a(a_l0a, a_l1, ...);
asc_copy_l12l0b(b_l0b, b_l1, ...);
asc_sync_pipe(PIPE_MTE1);

asc_mmad(c_l0c, a_l0a, b_l0b, M, K, N, ...);
asc_sync_pipe(PIPE_M);

asc_copy_l0c2gm(matrix_c, c_l0c, M * N * sizeof(float));
asc_sync_pipe(PIPE_MTE3);
```

## 4. 掩码操作

### 4.1 Mask 概述

Mask 用于控制矢量计算中哪些元素参与计算，bit 位为 1 表示参与计算，为 0 表示不参与。Membase API 通过全局 Mask 寄存器控制。

### 4.2 Mask 模式设置

```cpp
asc_set_mask_norm();   // Normal 模式，用于高维切分计算
asc_set_mask_count();  // Counter 模式，用于前 n 个数据计算
```

### 4.3 Mask 值设置

```cpp
asc_set_vector_mask(uint64_t mask1, uint64_t mask0);
```

**取值范围**：
- 16 位数据类型：mask0, mask1 ∈ [0, 2^64-1]，不同时为 0
- 32 位数据类型：mask1 为 0，mask0 ∈ (0, 2^64-1]
- 64 位数据类型：mask1 为 0，mask0 ∈ (0, 2^32-1]

### 4.4 Mask 使用示例

```cpp
uint64_t mask[2] = {0xFFFFFFFFFFFFFFFF, 0xFFFFFFFFFFFFFFFF};

asc_set_mask_norm();                  // 设置 Normal 模式
asc_set_vector_mask(mask[1], mask[0]); // 设置 Mask 值

asc_add(dst, src0, src1, 1, 1, 1, 1, 8, 8, 8);  // 高维切分计算
```

### 4.5 Mask 模式选择指南

| 计算模式 | 推荐 Mask 模式 | 原因 |
|---------|-------------|------|
| 前 n 个数据计算 | Counter 模式 | 自动计数，无需手动设置 |
| 高维切分计算 | Normal 模式 | 需要手动设置 Mask 值 |

## 5. 原子操作

### 5.1 原子操作概述

原子操作用于在多核并行计算场景下安全地更新 Global Memory 中的数据，避免数据竞争。

### 5.2 原子操作 API

| API 名称 | 功能 |
|--------|------|
| `asc_set_atomic_add_int8` | 开启 int8_t 类型原子累加 |
| `asc_set_atomic_add_int16` | 开启 int16_t 类型原子累加 |
| `asc_set_atomic_add_int` | 开启 int32_t 类型原子累加 |
| `asc_set_atomic_add_float16` | 开启 half 类型原子累加 |
| `asc_set_atomic_add_float` | 开启 float 类型原子累加 |
| `asc_set_atomic_add_bfloat` | 开启 bfloat16_t 类型原子累加 |
| `asc_set_atomic_max_*` | 开启原子比较取最大值 |
| `asc_set_atomic_min_*` | 开启原子比较取最小值 |
| `asc_set_atomic_none` | 清空原子操作状态 |

### 5.3 原子累加示例

```cpp
constexpr uint32_t length = 256;
__ubuf__ int8_t src0[length];
__ubuf__ int8_t src1[length];

asc_copy_ub2gm(dst_gm, src0, length * sizeof(int8_t));
asc_sync_pipe(PIPE_MTE3);

asc_set_atomic_add_int8();  // 开启原子累加
asc_copy_ub2gm(dst_gm, src1, length * sizeof(int8_t));
asc_set_atomic_none();      // 关闭原子操作
```

### 5.4 原子操作最佳实践

| 要点 | 说明 |
|-----|------|
| 开启时机 | 在需要原子操作前开启 |
| 关闭时机 | 原子操作完成后必须关闭 |
| 数据类型匹配 | 原子操作类型需与数据类型匹配 |

| 优化点 | 说明 | 效果 |
|-------|------|------|

## 8. 常见问题

### 8.1 搬运数据未对齐

**问题**：搬运数据大小未满足 32 字节对齐。

**解决**：
- 使用数组方式申请内存，自动对齐
- 使用非对齐搬运接口

### 8.2 同步点缺失

**问题**：缺少必要的同步操作导致数据竞争。

**解决**：
- 搬入操作后同步 PIPE_MTE2
- 计算操作后同步 PIPE_V
- 搬出操作后同步 PIPE_MTE3

### 8.3 Mask 未设置

**问题**：高维切分计算未设置 Mask 导致计算错误。

**解决**：
```cpp
asc_set_mask_norm();
asc_set_vector_mask(mask1, mask0);
```

### 8.4 原子操作未关闭

**问题**：原子操作完成后未关闭影响后续操作。

**解决**：
```cpp
asc_set_atomic_add_float();
asc_copy_ub2gm(dst_gm, data, size);
```
