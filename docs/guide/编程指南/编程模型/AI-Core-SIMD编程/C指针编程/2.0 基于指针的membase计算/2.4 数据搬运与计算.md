
## 2.4. 数据搬运

### 2.4.1 数据搬运概述

数据搬运是AI Core编程中最频繁的操作，负责在不同存储单元之间传输数据。

### 2.4.2 矢量数据搬运API

| API名称 | 功能 | 流水类型 |
|--------|------|---------|
| `asc_copy_gm2ub` | GM → UB | PIPE_MTE2 |
| `asc_copy_ub2gm` | UB → GM | PIPE_MTE3 |
| `asc_copy_ub2ub` | UB → UB | PIPE_V |
| `asc_copy_ub2l1` | UB → L1 | PIPE_MTE3 |
| `asc_copy_gm2ub_align` | GM → UB（非对齐搬运） | PIPE_MTE2 |
| `asc_copy_ub2gm_align` | UB → GM（非对齐搬运） | PIPE_MTE3 |

### 2.4.3 矩阵数据搬运API

| API名称 | 功能 | 流水类型 |
|--------|------|---------|
| `asc_copy_gm2l1` | GM → L1 | PIPE_MTE2 |
| `asc_copy_gm2l0a` | GM → L0A | PIPE_MTE2 |
| `asc_copy_gm2l0b` | GM → L0B | PIPE_MTE2 |
| `asc_copy_l12l0a` | L1 → L0A | PIPE_MTE1 |
| `asc_copy_l12l0b` | L1 → L0B | PIPE_MTE1 |
| `asc_copy_l0c2gm` | L0C → GM | PIPE_MTE3 |
| `asc_copy_l0c2ub` | L0C → UB | PIPE_MTE3 |

### 2.4.4 数据搬运模式

#### 前n个数据搬运

```cpp
asc_copy_gm2ub(__ubuf__ void* dst, __gm__ void* src, uint32_t size);
```

- 连续搬运指定字节的数据
- 搬运数据大小要求32字节对齐

#### 高维切分搬运

```cpp
asc_copy_gm2ub(__ubuf__ void* dst, __gm__ void* src,
               uint16_t n_burst,    // 连续传输数据块个数
               uint16_t burst_len,  // 每块长度（32字节为单位）
               uint16_t src_gap,    // 源地址间隔
               uint16_t dst_gap);   // 目的地址间隔
```

#### 同步搬运

```cpp
asc_copy_gm2ub_sync(__ubuf__ void* dst, __gm__ void* src, uint32_t size);
```

- 内部自动插入同步等待

## 2.4.2. 矢量计算

### 2.4.2.1 矢量计算概述

矢量计算通过Vector计算单元完成，源操作数和目的操作数存储在Unified Buffer中。

### 2.4.2.2 API类型说明

| API类型 | 特点 | 适用场景 |
|--------|------|---------|
| 前n个数据计算 | 紧密排布读取，从第0位置顺序取N个数据 | 连续数据处理 |
| 高维切分计算 | 支持间隔采样，灵活度高 | 非连续数据、带步长计算 |
| 同步计算 | 内部自动插入同步，易用性强 | 简单场景、快速开发 |

### 2.4.2.3 基础算术运算

| API名称 | 计算公式 | 支持数据类型 |
|--------|---------|-------------|
| `asc_add` | dst = src0 + src1 | half, int16_t, int32_t, float |
| `asc_sub` | dst = src0 - src1 | half, int16_t, int32_t, float |
| `asc_mul` | dst = src0 × src1 | half, int16_t, int32_t, float |
| `asc_div` | dst = src0 ÷ src1 | half, float |
| `asc_abs` | dst = |src| | half, float |
| `asc_neg` | dst = -src | half, float |

### 2.4.2.4 标量运算

```cpp
asc_add_scalar(__ubuf__ half* dst, __ubuf__ half* src, half value, uint32_t count);
asc_mul_scalar(__ubuf__ half* dst, __ubuf__ half* src, half value, uint32_t count);
```

### 2.4.2.5 数学函数

| API名称 | 功能 | 支持数据类型 |
|--------|------|-------------|
| `asc_exp` | 自然指数 e^x | half, float |

| `asc_sqrt` | 平方根 | half, float |
| `asc_rsqrt` | 平方根倒数 1/√x | half, float |
| `asc_rcp` | 倒数 1/x | half, float |

### 2.4.2.6 激活函数

| API名称 | 功能 | 计算公式 |

### 2.4.2.8 比较运算

### 2.4.2.9 归约运算

| API名称 | 功能 |
|--------|------|
| `asc_datablock_reduce_sum` | DataBlock内元素求和 |
| `asc_datablock_reduce_max` | DataBlock内元素求最大值 |
| `asc_datablock_reduce_min` | DataBlock内元素求最小值 |
| `asc_repeat_reduce_sum` | Repeat内元素求和 |
| `asc_repeat_reduce_max` | Repeat内元素求最大值 |
| `asc_repeat_reduce_min` | Repeat内元素求最小值 |

### 2.4.2.10 高维切分计算参数详解

#### repeatTime参数

控制迭代次数，每个迭代处理8个DataBlock（256字节）。取值范围[1, 255]。

#### dataBlockStride参数

控制单次迭代内不同DataBlock间地址步长，单位为DataBlock（32字节）：
- 连续计算：设置为1
- 非连续计算：大于1（如设置为2，表示间隔1个DataBlock）

#### repeatStride参数

控制相邻迭代间相同DataBlock的地址步长：
- 连续计算：设置为8
- 非连续计算：大于8
- 反复计算：设置为0（对首部8个DataBlock反复读取）
- 部分重复：大于0且小于8

## 2.4.3. 矩阵计算

### 2.4.3.1 矩阵计算概述

矩阵计算通过Cube计算单元完成，主要用于矩阵乘加运算（MMAD）。

### 2.4.3.2 MMAD运算

```cpp
asc_mmad(__cc__ float* c_matrix,
         __ca__ half* a_matrix,
         __cb__ half* b_matrix,
         uint16_t left_height,   // 左矩阵高度 M
         uint16_t n_dim,         // K维度
         uint16_t right_width,   // 右矩阵宽度 N
         uint8_t unit_flag,
         bool k_direction_align,
         bool c_matrix_source,
         bool c_matrix_init_val);
```

**计算公式**: C = A × B + C

### 2.4.3.3 支持的数据类型组合

| 左矩阵(A) | 右矩阵(B) | 结果矩阵(C) |
|----------|----------|------------|
| half | half | float |
| float | float | float |
| bfloat16_t | bfloat16_t | float |
| int8_t | int8_t | int32_t |
| int4b_t | int4b_t | int32_t |

### 2.4.3.4 矩阵计算流水线

```
GM → L1 → L0A/L0B → L0C → GM
   ↓     ↓        ↓     ↓
MTE2  MTE1     PIPE_M  MTE3
```

## 2.4.4. 掩码操作

### 2.4.4.1 Mask概述

Mask用于控制矢量计算中哪些元素参与计算，bit位为1表示参与计算，为0表示不参与。

### 2.4.4.2 Mask模式设置

```cpp
asc_set_mask_norm();  // Normal模式，用于高维切分计算
asc_set_mask_count(); // Counter模式，用于前n个数据计算
```

### 2.4.4.3 Mask值设置

```cpp
asc_set_vector_mask(uint64_t mask1, uint64_t mask0);
```

**取值范围**:
- 16位数据类型：mask0, mask1 ∈ [0, 2^64-1]，不同时为0
- 32位数据类型：mask1为0，mask0 ∈ (0, 2^64-1]
- 64位数据类型：mask1为0，mask0 ∈ (0, 2^32-1]

### 2.4.4.4 Mask使用示例

```cpp
uint64_t mask[2] = {6148914691236517205, 6148914691236517205};

asc_set_mask_norm();
asc_set_vector_mask(mask[1], mask[0]);

asc_add(dst, src0, src1, 1, 1, 1, 1, 8, 8, 8);
```

## 2.4.5. 原子操作

### 2.4.5.1 原子操作概述

原子操作用于在多核并行计算场景下安全地更新Global Memory中的数据。

### 2.4.5.2 原子操作API

| API名称 | 功能 |
|--------|------|
| `asc_set_atomic_add_int8` | 开启int8_t类型原子累加 |
| `asc_set_atomic_add_int16` | 开启int16_t类型原子累加 |
| `asc_set_atomic_add_int` | 开启int32_t类型原子累加 |
| `asc_set_atomic_add_float16` | 开启half类型原子累加 |
| `asc_set_atomic_add_float` | 开启float类型原子累加 |
| `asc_set_atomic_add_bfloat` | 开启bfloat16_t类型原子累加 |
| `asc_set_atomic_max_*` | 开启原子比较取最大值 |
| `asc_set_atomic_min_*` | 开启原子比较取最小值 |
| `asc_set_atomic_none` | 清空原子操作状态 |

### 2.4.5.3 原子累加示例

```cpp
constexpr uint32_t length = 256;
__ubuf__ int8_t src0[length];
__ubuf__ int8_t src1[length];

asc_copy_ub2gm(dst_gm, src0, length * sizeof(int8_t));
asc_sync_pipe(PIPE_MTE3);

asc_set_atomic_add_int8();
asc_copy_ub2gm(dst_gm, src1, length * sizeof(int8_t));
asc_set_atomic_none();
```
