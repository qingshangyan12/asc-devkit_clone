# Membase API 同步控制

本章介绍流水线同步机制、核间同步机制及同步控制最佳实践，帮助开发者正确管理 AI Core 多流水线并行执行，避免数据竞争，实现高性能并行计算。

---

## 1. 同步控制概述

### 1.1 为什么需要同步

AI Core 采用多流水线并行架构，不同类型的操作被分配到不同流水线执行：

```
搬运操作 → PIPE_MTE2 / PIPE_MTE3
计算操作 → PIPE_V / PIPE_M
标量操作 → PIPE_S
```

**并行执行的优势**：
- 多个搬运操作可并行执行
- 多个计算操作可并行执行
- 搬运和计算可流水线重叠

**同步的必要性**：
- 防止数据竞争（读取未完成写入的数据）
- 确保数据依赖正确（前序操作完成后执行后续操作）
- 保证计算结果正确性

### 1.2 同步类型

| 同步类型 | 作用范围 | 主要用途 |
|---------|---------|---------|
| 流水线同步 | 单核内 | 确保流水线执行顺序正确 |
| 核间同步 | 多核间 | 协调多核并行计算 |

## 2. 流水线同步

### 2.1 流水线类型回顾

| 流水线 | 类型标识 | 功能描述 |
|-------|---------|---------|
| PIPE_S | 标量流水线 | 指令分发和标量计算 |
| PIPE_V | 矢量计算流水线 | 向量计算单元执行 |
| PIPE_M | 矩阵计算流水线 | 矩阵乘加计算 |
| PIPE_MTE1 | 数据搬运流水线1 | L1 → L0A/L0B 搬运 |
| PIPE_MTE2 | 数据搬运流水线2 | GM → UB/L1/L0A/L0B 搬运 |
| PIPE_MTE3 | 数据搬运流水线3 | UB/L0C → GM 搬运 |
| PIPE_FIX | Fixpipe 流水线 | 结果处理与量化 |
| PIPE_ALL | 所有流水线 | 全流水线同步 |

### 2.2 同步 API

#### asc_sync_pipe

```cpp
__aicore__ inline void asc_sync_pipe(PipeType pipe_type);
```

**功能**：等待指定流水线完成当前操作。

**参数**：
| 参数 | 说明 | 取值 |
|-----|------|------|
| pipe_type | 流水线类型 | PIPE_MTE2, PIPE_MTE3, PIPE_V, PIPE_M, PIPE_ALL 等 |

**示例**：
```cpp
asc_copy_gm2ub(src, src_gm, size);
asc_sync_pipe(PIPE_MTE2);  // 等待搬入完成

asc_add(dst, src0, src1, count);
asc_sync_pipe(PIPE_V);     // 等待计算完成

asc_copy_ub2gm(dst_gm, dst, size);
asc_sync_pipe(PIPE_MTE3);  // 等待搬出完成
```

#### asc_sync

```cpp
__aicore__ inline void asc_sync();
```

**功能**：等待所有流水线完成当前操作。

**适用场景**：
- 算子结束时确保所有操作完成
- 需要全流水线同步的关键点

#### asc_sync_vec

```cpp
__aicore__ inline void asc_sync_vec();
```

**功能**：同步所有流水线，等同于 `asc_sync_pipe(PIPE_ALL)`。

#### asc_sync_mte2 / asc_sync_mte3

```cpp
__aicore__ inline void asc_sync_mte2();
__aicore__ inline void asc_sync_mte3();
```

**功能**：等待 PIPE_MTE2 / PIPE_MTE3 完成。

**等同于**：
```cpp
asc_sync_mte2();  // 等同于 asc_sync_pipe(PIPE_MTE2);
asc_sync_mte3();  // 等同于 asc_sync_pipe(PIPE_MTE3);
```

### 2.3 同步时机选择

| 操作类型 | 同步时机 | 同步流水线 |
|---------|---------|-----------|
| GM → UB 搬入后 | 搬入完成后 | PIPE_MTE2 |
| UB 计算后 | 计算完成后 | PIPE_V |
| UB → GM 搬出后 | 搬出完成后 | PIPE_MTE3 |
| L1 → L0A/L0B 搬入后 | 搬入完成后 | PIPE_MTE1 |
| 矩阵计算后 | 计算完成后 | PIPE_M |

### 2.4 流水线并行与同步

**并行执行示例**：
```cpp
asc_copy_gm2ub(src0, src0_gm, size);
asc_copy_gm2ub(src1, src1_gm, size);
asc_copy_gm2ub(src2, src2_gm, size);
asc_sync_pipe(PIPE_MTE2);  // 三个搬运操作只需一次同步

asc_add(dst0, src0, src1, count);
asc_add(dst1, src1, src2, count);
asc_sync_pipe(PIPE_V);     // 两个计算操作只需一次同步
```

**流水线重叠示例**：
```cpp
asc_copy_gm2ub(src0, src0_gm, size);
asc_sync_pipe(PIPE_MTE2);

asc_add(dst0, src0, src0, count);

asc_copy_gm2ub(src1, src1_gm, size);  // 可与计算并行
asc_sync_pipe(PIPE_V);
asc_sync_pipe(PIPE_MTE2);

asc_add(dst1, src1, src1, count);
```

## 3. 核间同步

### 3.1 核间同步概述

多核并行计算场景下，需要协调各核的执行顺序：
- 某些核需要等待其他核完成后再执行
- 多核结果汇总时需要同步
- 共享资源访问需要协调

### 3.2 核间同步 API

#### asc_set_ffts_base_addr

```cpp
__aicore__ inline void asc_set_ffts_base_addr(uint64_t addr);
```

**功能**：设置核间同步寄存器基地址。

**参数**：
| 参数 | 说明 |
|-----|------|
| addr | 核间同步寄存器基地址（由 Host 端分配） |

**使用时机**：算子初始化时设置。

#### asc_sync_block_arrive

```cpp
__aicore__ inline void asc_sync_block_arrive(PipeType pipe, int64_t flag_id);
```

**功能**：发送核间同步信号，表示当前核已完成某阶段工作。

**参数**：
| 参数 | 说明 |
|-----|------|
| pipe | 流水线类型 |
| flag_id | 同步标志 ID |

**工作原理**：
- 当前核发送信号，计数器 +1
- 多核场景下，计数器累加直到达到总核数

#### asc_sync_block_wait

```cpp
__aicore__ inline void asc_sync_block_wait(PipeType pipe, int64_t flag_id);
```

**功能**：等待核间同步信号，直到所有核都发送了信号。

**参数**：
| 参数 | 说明 |
|-----|------|
| pipe | 流水线类型 |
| flag_id | 同步标志 ID |

**工作原理**：
- 当前核等待计数器达到总核数
- 达到后继续执行，计数器清零

### 3.3 核间同步示例

```cpp
__aicore__ void multi_core_sync_demo()
{
    asc_init();
    
    uint64_t ffts_addr = *ffts_addr_ptr;
    asc_set_ffts_base_addr(ffts_addr);
    
    int64_t flag_id = 1;
    
    // 第一阶段：各核独立计算
    asc_copy_gm2ub(src, src_gm + block_idx * block_len, block_len * sizeof(half));
    asc_sync_pipe(PIPE_MTE2);
    
    asc_add(dst, src, src, block_len);
    asc_sync_pipe(PIPE_V);
    
    // 使用原子操作汇总结果
    asc_set_atomic_add_half();
    asc_copy_ub2gm(dst_gm, dst, block_len * sizeof(half));
    asc_set_atomic_none();
    asc_sync_pipe(PIPE_MTE3);
    
    // 发送信号：第一阶段完成
    asc_sync_block_arrive(PIPE_S, flag_id);
    
    // 等待所有核完成第一阶段
    asc_sync_block_wait(PIPE_S, flag_id);
    
    // 第二阶段：所有核完成后执行
    // ...
}
```

### 3.4 核间同步流程图

```
核0: 计算阶段1 → arrive(flag1) → wait(flag1) → 计算阶段2
核1: 计算阶段1 → arrive(flag1) → wait(flag1) → 计算阶段2
核2: 计算阶段1 → arrive(flag1) → wait(flag1) → 计算阶段2
...
         ↓              ↓               ↓
     独立执行      等待计数器        继续执行
                  达到总核数
```

## 4. 内存访问屏障

### 4.1 asc_sync_data_barrier

```cpp
__aicore__ inline void asc_sync_data_barrier();
```

**功能**：内存访问屏障，确保内存访问顺序正确。

**适用场景**：
- 原子操作前后
- 需要严格内存访问顺序的场景

### 4.2 使用示例

```cpp
asc_sync_data_barrier();  // 内存访问屏障

asc_set_atomic_add_float();
asc_copy_ub2gm(dst_gm, partial_sum, sizeof(float));
asc_set_atomic_none();

asc_sync_data_barrier();  // 确保原子操作完成
```

## 5. 同步控制最佳实践

### 5.1 同步点设置原则

| 原则 | 说明 |
|-----|------|
| 最少同步 | 合理规划同步点，避免过度同步 |
| 同类合并 | 同类操作只需一次同步 |
| 正确位置 | 在数据依赖关键点设置同步 |

### 5.2 矢量计算同步模式

```cpp
// 模式1：基本同步
asc_copy_gm2ub(src, src_gm, size);
asc_sync_pipe(PIPE_MTE2);
asc_add(dst, src, src, count);
asc_sync_pipe(PIPE_V);
asc_copy_ub2gm(dst_gm, dst, size);
asc_sync_pipe(PIPE_MTE3);

// 模式2：并行搬运
asc_copy_gm2ub(src0, src0_gm, size);
asc_copy_gm2ub(src1, src1_gm, size);
asc_sync_pipe(PIPE_MTE2);  // 合并同步
asc_add(dst, src0, src1, count);
asc_sync_pipe(PIPE_V);
asc_copy_ub2gm(dst_gm, dst, size);
asc_sync_pipe(PIPE_MTE3);

// 模式3：流水线重叠
asc_copy_gm2ub(src0, src0_gm, size);
asc_sync_pipe(PIPE_MTE2);

asc_add(dst0, src0, src0, count);
asc_copy_gm2ub(src1, src1_gm, size);  // 与计算重叠

asc_sync_pipe(PIPE_V);
asc_sync_pipe(PIPE_MTE2);

asc_add(dst1, src1, src1, count);
```

### 5.3 矩阵计算同步模式

```cpp
// GM → L1 → L0A/L0B → 计算 → L0C → GM
asc_copy_gm2l1(a_l1, matrix_a, size);
asc_copy_gm2l1(b_l1, matrix_b, size);
asc_sync_pipe(PIPE_MTE2);

asc_copy_l12l0a(a_l0a, a_l1, ...);
asc_copy_l12l0b(b_l0b, b_l1, ...);
asc_sync_pipe(PIPE_MTE1);

asc_mmad(c_l0c, a_l0a, b_l0b, ...);
asc_sync_pipe(PIPE_M);

asc_copy_l0c2gm(matrix_c, c_l0c, size);
asc_sync_pipe(PIPE_MTE3);
```

### 5.4 多核协同同步模式

```cpp
asc_set_ffts_base_addr(ffts_addr);
int64_t flag_id = 1;

// 第一阶段
compute_phase1();
asc_sync_block_arrive(PIPE_S, flag_id);
asc_sync_block_wait(PIPE_S, flag_id);

// 第二阶段（所有核完成后）
compute_phase2();
```

## 6. 性能优化要点

### 6.1 同步开销分析

| 同步类型 | 开销 | 优化建议 |
|---------|-----|---------|
| 流水线同步 | 低 | 合理合并同类同步 |
| 核间同步 | 较高 | 减少核间同步次数 |
| 全流水线同步 | 较高 | 仅在必要时使用 |

### 6.2 流水线并行最大化

```cpp
// 低效方式：每个操作后都同步
asc_copy_gm2ub(src0, src0_gm, size);
asc_sync_pipe(PIPE_MTE2);
asc_copy_gm2ub(src1, src1_gm, size);
asc_sync_pipe(PIPE_MTE2);
asc_copy_gm2ub(src2, src2_gm, size);
asc_sync_pipe(PIPE_MTE2);

// 高效方式：同类操作合并同步
asc_copy_gm2ub(src0, src0_gm, size);
asc_copy_gm2ub(src1, src1_gm, size);
asc_copy_gm2ub(src2, src2_gm, size);
asc_sync_pipe(PIPE_MTE2);  // 只需一次同步
```

### 6.3 流水线重叠

```cpp
asc_copy_gm2ub(src0, src0_gm, size);
asc_sync_pipe(PIPE_MTE2);

asc_add(dst0, src0, src0, count);
asc_copy_gm2ub(src1, src1_gm, size);  // 搬运与计算重叠

asc_sync_pipe(PIPE_V);
asc_sync_pipe(PIPE_MTE2);

asc_add(dst1, src1, src1, count);
```

## 7. 常见问题

### 7.1 同步点缺失

**问题**：缺少必要的同步操作导致数据竞争。

**现象**：
- 计算结果错误
- 数据读取到未完成写入的值

**解决**：
```cpp
asc_copy_gm2ub(src, src_gm, size);
asc_sync_pipe(PIPE_MTE2);  // 必须同步，否则计算可能读取未完成搬运的数据
asc_add(dst, src, src, count);
```

### 7.2 过度同步

**问题**：过多同步操作降低性能。

**解决**：
```cpp
// 错误：每个操作后都同步
asc_copy_gm2ub(src0, src0_gm, size);
asc_sync_pipe(PIPE_MTE2);
asc_copy_gm2ub(src1, src1_gm, size);
asc_sync_pipe(PIPE_MTE2);

// 正确：同类操作合并同步
asc_copy_gm2ub(src0, src0_gm, size);
asc_copy_gm2ub(src1, src1_gm, size);
asc_sync_pipe(PIPE_MTE2);
```

### 7.3 核间同步错误

**问题**：核间同步 flag_id 未正确管理导致同步失败。

**解决**：
- 每个 sync_block_arrive 和 sync_block_wait 使用相同的 flag_id
- 不同阶段使用不同的 flag_id
- flag_id 取值范围：[1, 7]

### 7.4 FFTS 基地址未设置

**问题**：核间同步未设置 FFTS 基地址导致同步失败。

**解决**：
```cpp
uint64_t ffts_addr = *ffts_addr_ptr;
asc_set_ffts_base_addr(ffts_addr);  // 必须先设置基地址
```

## 8. 同步控制完整示例

### 8.1 单核矢量计算

```cpp
__aicore__ void vector_compute_kernel()
{
    constexpr uint32_t length = 1024;
    
    __ubuf__ half src[length];
    __ubuf__ half dst[length];
    
    asc_copy_gm2ub(src, src_gm, length * sizeof(half));
    asc_sync_pipe(PIPE_MTE2);
    
    asc_add(dst, src, src, length);
    asc_sync_pipe(PIPE_V);
    
    asc_copy_ub2gm(dst_gm, dst, length * sizeof(half));
    asc_sync_pipe(PIPE_MTE3);
}
```

### 8.2 多核协同计算

```cpp
__aicore__ void multi_core_kernel()
{
    asc_init();
    
    uint64_t ffts_addr = *ffts_addr_ptr;
    asc_set_ffts_base_addr(ffts_addr);
    
    int64_t block_idx = asc_get_block_idx();
    int64_t block_num = asc_get_block_num();
    
    int64_t flag_id = 1;
    
    // 第一阶段：各核独立计算部分结果
    __ubuf__ half partial_result[1];
    compute_partial_result(partial_result);
    
    // 使用原子操作汇总到 GM
    asc_set_atomic_add_half();
    asc_copy_ub2gm(dst_gm, partial_result, sizeof(half));
    asc_set_atomic_none();
    asc_sync_pipe(PIPE_MTE3);
    
    // 核间同步：等待所有核完成汇总
    asc_sync_block_arrive(PIPE_S, flag_id);
    asc_sync_block_wait(PIPE_S, flag_id);
    
    // 第二阶段：读取汇总结果继续计算
    asc_copy_gm2ub(total_result, dst_gm, sizeof(half));
    asc_sync_pipe(PIPE_MTE2);
    
    // 继续计算...
}
```

### 8.3 流水线重叠示例

```cpp
__aicore__ void pipeline_overlap_kernel()
{
    constexpr uint32_t block_len = 512;
    
    __ubuf__ half block0[block_len];
    __ubuf__ half block1[block_len];
    __ubuf__ half result0[block_len];
    __ubuf__ half result1[block_len];
    
    // 第一块搬入
    asc_copy_gm2ub(block0, src_gm + 0 * block_len, block_len * sizeof(half));
    asc_sync_pipe(PIPE_MTE2);
    
    // 第一块计算，同时第二块搬入
    asc_add(result0, block0, block0, block_len);
    asc_copy_gm2ub(block1, src_gm + 1 * block_len, block_len * sizeof(half));
    
    // 同步计算和搬运
    asc_sync_pipe(PIPE_V);
    asc_sync_pipe(PIPE_MTE2);
    
    // 第二块计算
    asc_add(result1, block1, block1, block_len);
    asc_sync_pipe(PIPE_V);
    
    // 搬出结果
    asc_copy_ub2gm(dst_gm + 0 * block_len, result0, block_len * sizeof(half));
    asc_copy_ub2gm(dst_gm + 1 * block_len, result1, block_len * sizeof(half));
    asc_sync_pipe(PIPE_MTE3);
}
```
