# Membase API 编程概述

## 1. Membase API 简介

Membase API是AscendC C API的一类编程风格，基于内存地址指针进行操作。数据以指针形式传递，计算接口直接读取指针指向的内存数据，适合Atlas A3训练系列产品/Atlas A3推理系列产品和Atlas A2训练系列产品/Atlas A2推理系列产品。

### 1.1 核心特点

- **指针编程**：数据以指针地址形式传递，与传统C语言编程习惯一致
- **自动数据读取**：计算接口内部自动从指定地址读取数据
- **高维切分支持**：支持通过迭代参数控制数据步长和迭代次数
- **全局Mask控制**：通过设置全局Mask寄存器控制参与计算的元素

### 1.2 适用产品

| 产品 | 支持状态 |
|-----|---------|
| Atlas A3 训练系列产品/Atlas A3 推理系列产品 | ✓ |
| Atlas A2 训练系列产品/Atlas A2 推理系列产品 | ✓ |

## 2. 关键字说明

Membase API使用以下关键字修饰变量和函数：

| 关键字 | 描述 |
|-------|------|
| `__gm__` | 存储空间定义修饰符，表示变量位于Global Memory地址空间 |
| `__ubuf__` | 存储空间定义修饰符，表示变量位于Unified Buffer地址空间 |
| `__cbuf__` | 存储空间定义修饰符，表示变量位于L1 Buffer地址空间 |
| `__ca__` | 存储空间定义修饰符，表示变量位于L0A Buffer地址空间 |
| `__cb__` | 存储空间定义修饰符，表示变量位于L0B Buffer地址空间 |
| `__cc__` | 存储空间定义修饰符，表示变量位于L0C Buffer地址空间 |
| `__aicore__` | 执行空间限定符，表示函数只能在AI Core上执行 |

### 2.1 使用示例

```cpp
// Global Memory变量
extern __gm__ half* input_gm;

// Unified Buffer变量
__ubuf__ half src_buffer[128];
__ubuf__ half dst_buffer[128];

// AI Core执行函数
__aicore__ void my_kernel()
{
    // 函数体
}
```

## 3. API分类

### 3.1 矢量计算API

矢量计算通过Vector计算单元完成，源操作数和目的操作数存储在Unified Buffer中。

| API类型 | 接口示例 | 说明 |
|--------|---------|------|
| 算术运算 | `asc_add`, `asc_sub`, `asc_mul`, `asc_div` | 基础四则运算 |
| 标量运算 | `asc_add_scalar`, `asc_mul_scalar` | 矢量与标量运算 |
| 数学函数 | `asc_exp`, `asc_log`, `asc_sqrt`, `asc_rsqrt` | 指数、对数、开方等 |
| 激活函数 | `asc_relu`, `asc_leakyrelu` | ReLU系列 |
| 比较运算 | `asc_eq`, `asc_gt`, `asc_lt`, `asc_ge` | 比较并生成比特掩码 |
| 归约运算 | `asc_datablock_reduce_sum`, `asc_repeat_reduce_max` | DataBlock/Repeat内归约 |
| 类型转换 | `asc_half2float`, `asc_float2int32` | 数据类型转换 |
| 数据填充 | `asc_duplicate`, `asc_brcb` | 数据复制填充 |
| 数据选择 | `asc_select` | 根据掩码选择数据 |

### 3.2 数据搬运API

数据搬运负责在不同存储单元之间传输数据。

**矢量数据搬运**：

| API | 功能 | 流水线 |
|-----|------|--------|
| `asc_copy_gm2ub` | GM → UB | PIPE_MTE2 |
| `asc_copy_ub2gm` | UB → GM | PIPE_MTE3 |
| `asc_copy_ub2ub` | UB → UB | PIPE_V |
| `asc_copy_ub2l1` | UB → L1 | PIPE_MTE3 |
| `asc_copy_gm2ub_align` | GM → UB（非对齐） | PIPE_MTE2 |
| `asc_copy_ub2gm_align` | UB → GM（非对齐） | PIPE_MTE3 |

**矩阵数据搬运**：

| API | 功能 | 流水线 |
|-----|------|--------|
| `asc_copy_gm2l1` | GM → L1 | PIPE_MTE2 |
| `asc_copy_gm2l0a` | GM → L0A | PIPE_MTE2 |
| `asc_copy_gm2l0b` | GM → L0B | PIPE_MTE2 |
| `asc_copy_l12l0a` | L1 → L0A | PIPE_MTE1 |
| `asc_copy_l12l0b` | L1 → L0B | PIPE_MTE1 |
| `asc_copy_l0c2gm` | L0C → GM | PIPE_MTE3 |
| `asc_copy_l0c2ub` | L0C → UB | PIPE_MTE3 |

### 3.3 矩阵计算API

矩阵计算通过Cube计算单元完成。

| API | 功能 |
|-----|------|
| `asc_mmad` | 矩阵乘加运算 |
| `asc_mmad_sparse` | 稀疏矩阵乘加 |
| `asc_set_mmad_direction_m` | 设置M方向优先 |
| `asc_set_mmad_direction_n` | 设置N方向优先 |
| `asc_enable_hf32` | 开启HF32模式 |
| `asc_set_fp32_mode` | 开启FP32模式 |

### 3.4 同步控制API

## 4. 计算模式说明

Membase API提供三种计算模式：

### 4.1 前n个数据计算

从起始位置连续取N个数据进行计算，参数简洁，易于使用。

**函数原型**：
```cpp
__aicore__ inline void asc_add(__ubuf__ half* dst, __ubuf__ half* src0, 
                               __ubuf__ half* src1, uint32_t count)
```

**特点**：
- 紧密排布读取，从第0位置顺序取N个数据
- 参数简洁，仅需指定元素个数
- 适合连续数据处理场景

### 4.2 高维切分计算

支持设置迭代次数和数据步长，灵活处理非连续数据。

**函数原型**：
```cpp
__aicore__ inline void asc_add(__ubuf__ half* dst, __ubuf__ half* src0, 
                               __ubuf__ half* src1, uint8_t repeat,
                               uint8_t dst_block_stride, uint8_t src0_block_stride,
                               uint8_t src1_block_stride, uint8_t dst_repeat_stride,
                               uint8_t src0_repeat_stride, uint8_t src1_repeat_stride)
```

**特点**：
- 支持设置迭代次数（repeat）
- 支持设置单次迭代内DataBlock步长（block_stride）
- 支持设置迭代间DataBlock步长（repeat_stride）
- 适合非连续数据、带步长计算场景

### 4.3 同步计算

内部自动插入同步操作，简化编程。

**函数原型**：
```cpp
__aicore__ inline void asc_add_sync(__ubuf__ half* dst, __ubuf__ half* src0,
                                    __ubuf__ half* src1, uint32_t count)
```

**特点**：
- 内部自动插入同步等待
- 易用性强，适合快速开发
- 性能略低于手动同步版本

## 5. 流水线类型

AI Core上的操作被分配到不同流水线执行：

| 流水线 | 类型标识 | 功能描述 |
|-------|---------|---------|
| PIPE_S | 标量流水线 | 指令分发和标量计算 |
| PIPE_V | 矢量计算流水线 | 向量计算单元执行 |
| PIPE_M | 矩阵计算流水线 | 矩阵乘加计算 |
| PIPE_MTE1 | 数据搬运流水线1 | L1→L0A/L0B、L1→UB搬运 |
| PIPE_MTE2 | 数据搬运流水线2 | GM→L1、GM→L0A/L0B、GM→UB搬运 |
| PIPE_MTE3 | 数据搬运流水线3 | UB→GM、UB→L1搬运 |
| PIPE_FIX | Fixpipe流水线 | 结果处理与量化 |
| PIPE_ALL | 所有流水线 | 全流水线同步 |

### 5.1 流水线执行顺序

**矢量计算典型流程**：
```
数据搬运(GM→UB):  PIPE_MTE2
向量计算:         PIPE_V
数据搬运(UB→GM):  PIPE_MTE3
```

**矩阵计算典型流程**：
```
数据搬运(GM→L1):  PIPE_MTE2
数据搬运(L1→L0A): PIPE_MTE1
矩阵计算:         PIPE_M
结果搬运(L0C→GM): PIPE_MTE3
```

## 6. 最简示例

```cpp
#include "c_api/asc_simd.h"

extern __gm__ half* src0_gm;
extern __gm__ half* src1_gm;
extern __gm__ half* dst_gm;

__aicore__ void simple_add_kernel()
{
    constexpr uint32_t total_length = 128;
    
    // 定义UB内存
    __ubuf__ half src0[total_length];
    __ubuf__ half src1[total_length];
    __ubuf__ half dst[total_length];
    
    // GM → UB
    asc_copy_gm2ub(src0, src0_gm, total_length * sizeof(half));
    asc_copy_gm2ub(src1, src1_gm, total_length * sizeof(half));
    
    // 同步等待搬运完成
    asc_sync_pipe(PIPE_MTE2);
    
    // 矢量加法
    asc_add(dst, src0, src1, total_length);
    
    // 同步等待计算完成
    asc_sync_pipe(PIPE_V);
    
    // UB → GM
    asc_copy_ub2gm(dst_gm, dst, total_length * sizeof(half));
    
    // 同步等待搬出完成
    asc_sync_pipe(PIPE_MTE3);
}
```
