# 编程模型概述

**Ascend C** 是基于昇腾 AI 处理器（NPU）的一种高效编程范式。昇腾 AI 处理器的计算核心主要分为 **AI Core** 和 **AI CPU**。AI 处理器通过集成多个 AI Core 实现大规模并行计算，相比传统 CPU，其内部拥有更密集的计算单元和专用向量/矩阵指令集，特别适合深度学习模型中的训练和推理场景。

在 Ascend C 编程框架下，开发者可以根据算法特性选择不同的编程模型，以实现硬件性能的最大化释放。

---

## 1. 核心编程模型分类

昇腾 AI 处理器主要支持以下三种编程模型：

* **SIMD（Single Instruction Multiple Data）**：单指令多数据。通过单条指令触发多个数据的并行计算，是 AI Core 处理大规模向量和矩阵数据的核心方式。
* **SIMT（Single Instruction Multiple Thread）**：单指令多线程。通过单条指令管理多个线程并行执行，更擅长处理复杂的逻辑控制和离散数据访问。
* **AI CPU 编程**：利用 Device 侧的 AI CPU 完成不适合在 AI Core 上运行的算子任务。

### 表 1：编程模型对比与适用场景

| 编程模型 | 计算单元 | 核心特点 | 典型适用场景 |
| :--- | :--- | :--- | :--- |
| **SIMD 编程** | AI Core | 吞吐量极高，支持 SIMD 与 SIMT 混合编程。 | 矩阵计算、连续内存访问的矢量算子、融合算子。 |
| **SIMT 编程** | AI Core | 灵活的线程调度，支持复杂分支控制。 | 离散内存访问、逻辑复杂的矢量算子（需特定硬件支持）。 |
| **AI CPU 编程** | AI CPU | 具备通用计算能力，直接访问 Device 内存。 | 非矩阵类、分支密集型、不规则逻辑计算。 |

## 2. 编程模型深度解析

### 2.1 AI Core SIMD 编程
SIMD 是 AI Core 最基础且最高效的编程模式，旨在利用一条指令完成多组数据的计算。Ascend C 进一步提供了 **SIMD 与 SIMT 混合编程** 的高级方式，开发者可以在利用 SIMD 指令集高性能的同时，借鉴 SIMT 的编程习惯来管理数据流向。
* **优势**：极致的吞吐性能，完美契合张量计算。
* **参考**：详见 [3.3-AI Core SIMD 编程] 及 [SIMD 算子实现]。

### 2.2 AI Core SIMT 编程
SIMT 模式通过抽象出大量并行线程，简化了对离散数据访问和复杂条件分支的处理逻辑。该模式便于具备传统 GPU 开发经验的人员快速迁移。
* **注意**：目前 SIMT 编程仅支持 **Ascend 950PR/Ascend 950DT** 等特定系列硬件。
* **参考**：详见 [3.4-AI Core SIMT 编程] 及 [SIMT 算子实现]。

### 2.3 AI CPU 编程
AI CPU 位于 Device 侧，其内存访问能力与 AI Core 对等，但其指令集更偏向通用计算。它通常作为 AI Core 的有力补充，用于承载那些“计算量不大但逻辑极其复杂”的非矩阵类算子。
* **优势**：极强的逻辑控制能力，支持 C++ 标准库。
* **参考**：详见 [3.5-AI CPU 编程] 了解基础知识及开发流程。
