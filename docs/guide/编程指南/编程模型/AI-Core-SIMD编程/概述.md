# Reg矢量计算<a name="ZH-CN_TOPIC_0000002509863891"></a>

## 概念<a name="section1825793122916"></a>

针对Regbase架构，Ascend C提供一组基于SIMD Reg矢量寄存器进行Vector计算的基础API：Reg矢量计算API。
开发者使用此类API可以在Regbase架构芯片上灵活控制寄存器，实现更大的灵活性和更好的性能。

## 原理<a name="section1977234218287"></a>

在Regbase架构Vector的内存架构中，最靠近Vector计算单元的是SIMD的私有Reg矢量计算寄存器。单核内所有的Reg寄存器共享一个本地内存资源Unified Buffer(UB)。SIMD架构不支持从全局内存Global Memory(GM)加载数据到Reg矢量计算寄存器(Registers)，需要先将数据从全局内存GM搬运至UB，再通过显式的Load/Store相关接口，在UB和Registers之间传递数据。用户可以控制数据常驻Registers。

**图 1**  SIMD Reg矢量计算内存层级<a name="fig597318712265"></a>  
![](../../../figures/SIMD-Reg矢量计算内存层级.png "SIMD-Reg矢量计算内存层级")

SIMD Reg矢量计算编程架构中，通过发出指令到Reg矢量计算执行单元，执行单元从Registers读取数据，进行计算，计算结果写回Registers。DMA搬运单元负责在Registers和Local Memory之间搬运数据。

## 应用场景<a name="section1227863453815"></a>

基于寄存器的编程模型是指每次循环将一个VL长度的数据从从LocalTensor通过数据搬运指令加载到寄存器中，进行复杂的数学计算Compute后搬出到LocalTensor中，所有的计算逻辑均在寄存器中完成，从而减少LocalTensor间的数据搬运，大大提升了整体性能，具体流程如下所示：

![](../../../figures/微指令编程流程图.png)

以Add3VF函数为例，首先定义三个矢量数据寄存器srcReg0、srcReg1、srcReg2和dstReg以及掩码寄存器mask，每次将一个VL长度的数据使用数据搬运函数从src0、src1、src2搬入到数据寄存器srcReg0、srcReg1、srcReg2中，地址偏移是src0Addr+ i \* oneRepeatSize、src1Addr + i \* oneRepeatSize、src2Addr + i \* oneRepeatSize，然后调用Add函数，将结果存入到dstReg中（dstReg= srcReg0 + srcReg1 + srcReg2\)，mask表示参与Add计算的元素个数，最后调用数据搬运函数将结果从dstReg中搬出到dst。

Add的原型定义如下：

```
template <typename T = DefaultType, MaskMergeMode mode = MaskMergeMode::ZEROING, typename U>
__simd_callee__ inline void Add(U& dstReg, U& srcReg0, U& srcReg1, MaskReg& mask)
```

其中模板参数T表示操作数数据类型，MaskMergeMode表示mask未筛选的元素在dst中置零或者保留原值，UpdateMask函数用于更新参与计算的mask元素，每次循环都会消耗一个VL长度的元素。Load和Store函数用于数据的搬入搬出，Load\(srcReg0, src0Addr + i \* oneRepeatSize\)表示数据从UB搬入到srcReg0寄存器，起始地址是src0Addr + i \* oneRepeatSize，Store\(dstAddr+ i \* oneRepeatSize, dstReg,  mask\)表示将dstReg搬出到UB，目标地址是dstAddr + i \* oneRepatSize, mask表示有多少元素参与搬出。

Add3VF包含7个参数。dstAddr表示输出数据在UB首地址，src0Addr、src1Addr和src1Addr表示输入数据在UB首地址。count表示输入数据参与计算的元素个数，repeatTimes表示循环次数，oneRepeatSize表示每次循环参与的数据量。

```
// SIMD函数
template <typename T> 
__simd_vf__ inline void Add3VF(__ubuf__ T* dstAddr, __ubuf__ T* src0Addr, __ubuf__ T* src1Addr, __ubuf__ T* src2Addr, uint32_t count,  uint32_t oneRepeatSize, uint16_t repeatTimes) 
{     
    AscendC::Reg::RegTensor<T> srcReg0;
    AscendC::Reg::RegTensor<T> srcReg0;
    AscendC::Reg::RegTensor<T> dstReg;
    AscendC::Reg::MaskReg mask;
    for (uint16_t i = 0; i < repeatTimes; ++i) {
        mask = AscendC::Reg::UpdateMask<T>(count);
        AscendC::Reg::Load(srcReg0, src0Addr + i * oneRepeatSize);  
        AscendC::Reg::Load(srcReg1, src1Addr + i * oneRepeatSize);
        AscendC::Reg::Load(srcReg2, src2Addr + i * oneRepeatSize);
        AscendC::Reg::Add(dstReg, srcReg0, srcReg1, mask);
        AscendC::Reg::Add(dstReg, dstReg, srcReg2, mask);
        AscendC::Reg::Store(dstAddr + i * oneRepeatSize, dstReg , mask);
    }
}

template <typename T> 
__aicore__ inline void Compute()      
{  
     AscendC::LocalTensor<T> dst = outQueueZ.AllocTensor<T>();     
     AscendC::LocalTensor<T> src0 = inQueueX.DeQue<T>();
     AscendC::LocalTensor<T> src1 = inQueueY.DeQue<T>();
     constexpr uint32_t oneRepeatSize = AscendC::GetVecLen()/sizeof(T);
     uint32_t count = 512;
     // 向上取整，计算repeat
     uint16_t repeatTimes = AscendC::CeilDivision(count, oneRepeatSize);
     __ubuf__ T* dstAddr = (__ubuf__ T*)dst.GetPhyAddr();
     __ubuf__ T* src0Addr = (__ubuf__ T*)src0.GetPhyAddr();
     __ubuf__ T* src1Addr = (__ubuf__ T*)src1.GetPhyAddr();
     asc_vf_call<AddVF<T>>(dstAddr, src0Addr, src1Addr, count, oneRepeatSize, repeatTimes);
     outQueueZ.EnQue(dst);
     inQueueX.FreeTensor(src0);
     inQueueY.FreeTensor(src1);
}
```
