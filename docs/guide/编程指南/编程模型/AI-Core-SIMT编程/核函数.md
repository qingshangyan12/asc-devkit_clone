# 核函数<a name="ZH-CN_TOPIC_0000002554438935"></a>

## 核函数的定义<a name="section962384613331"></a>

Ascend C支持开发者自定义核函数来扩展C++，核函数在AI处理器上执行时实际是若干线程在并行执行，每个线程有独立的寄存器和栈，共同完成数据计算任务。

核函数的定义示例如下：

```
 __global__ void kernel_name(argument list)
```

定义核函数时需要遵循以下规则：

-   使用函数类型限定符\_\_global\_\_， 标识它是一个核函数。
-   核函数必须具有void返回类型。
-   核函数参数列表需遵循[函数参数列表限制](../../../技术附录/CPP标准支持/语法限制/函数.md#section_kernel_function_argument_list)。

## 核函数的调用<a name="section33493239410"></a>

算子程序中的函数可以分为三类：host侧执行函数、核函数（device侧执行）、device侧执行函数（除核函数之外）。下图以Kernel直调算子开发方式为例，描述三者的调用关系：

-   host侧执行函数可以调用其它host执行函数，也就是通用C/C++编程中的函数调用；也可以通过<<<...\>\>\>调用核函数。
-   核函数可以调用除核函数之外的其它device侧执行函数。
-   device侧执行函数（除核函数之外）使用类型限定符\_\_aicore\_\_标识，可以调用同类的其它device侧执行函数。

![](../../../figures/算子程序中三种函数间的调用关系.png "算子程序中三种函数间的调用关系")

Host侧通过内核调用符<<<...\>\>\>的语法形式调用核函数，如下所示：

```
kernel_name<<<grid_dim, block_dim, dynamic_mem_size, stream>>>(args...)
```

执行配置由4个参数决定，详细用法说明参考[核函数配置](../../语言扩展层/SIMT-BuiltIn关键字.md#section97005415463)：

-   grid_dim：int或dim3类型，用于指定网格（grid）的维度与规模，grid_dim.x * grid_dim.y * grid_dim.z等于启动的线程块总数。
-   block_dim：int或dim3类型，用于指定每个线程块（block）的维度与规模，block_dim.x * block_dim.y * block_dim.z等于每个线程块包含的线程数。
-   dynamic_mem_size：size_t类型，该参数指定除静态分配的内存外，本次调用为每个线程块动态分配的共享内存字节数，单位为Byte，默认设置为0。具体用法请参考[共享内存](./内存层级.md#section66329146410)中的“动态申请”部分；
-   stream：aclrtStream类型指针，指定关联的流，用于维护异步操作的执行顺序。
