# 异构系统<a name="ZH-CN_TOPIC_0000002394061301"></a>

一个基于昇腾处理器的异构系统通常包含CPU与昇腾NPU。其中，CPU称为Host；NPU称为Device。

基于昇腾的应用程序通常包含两部分：一部分运行在Host CPU上，使用标准C/C++编程；另一部分运行在NPU上，使用Ascend C编程语言编写。运行在NPU上的代码称为[核函数Kernel](./AI-Core-SIMD编程/核函数.md)，需由Host代码调用执行。Host代码与核函数可编写在同一个.asc 后缀文件中，由毕昇编译器完成异构编译。执行程序时，Host进程会将任务（Task）下发到NPU后，但是不会等待NPU把任务执行完成就立即返回，NPU随即开始通过任务调度器选择空闲的AI Core进行调度，由AI Core执行下发的任务。其中AI Core是指NPU的核心计算单元，是NPU内部的“最小计算单元”。

一枚NPU芯片通常集成多个AI Core，可并行处理不同的数据块，大幅提升整体计算吞吐量，为提升计算效率，NPU上通常有多个AI Core并发执行，每个AI Core一般处理不同的数据。传统上，AI Core 遵循SIMD（Single Instruction Multiple Data，单指令多数据流）模型，通过一条指令同时操作多个数据实现并行计算。从Ascend 950PR/Ascend 950DT架构开始，作为SIMD的补充（主要用于辅助离散类矢量算子开发），AI Core也支持SIMT（Single Instruction Multiple Thread，单指令多线程）模型，通过一条指令驱动多个线程并行执行。
