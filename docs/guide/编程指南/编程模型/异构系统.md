# 异构系统<a name="ZH-CN_TOPIC_0000002394061301"></a>

一个基于昇腾处理器的异构系统通常包含 CPU 与昇腾 NPU。其中，CPU 及其内存称为 Host 与 Host Memory；NPU 及其内存称为 Device 与 Device Memory。

基于昇腾的应用程序通常包含两部分：一部分运行在 Host CPU 上，使用标准 C/C++ 编程；另一部分运行在 NPU 上，使用 Ascend C 编程语言编写。运行在 NPU 上的代码称为[核函数Kernel](./AI-Core-SIMD编程/核函数.md)，需由 Host 代码调用执行。Host 代码与核函数可编写在同一个 .asc 后缀文件中，由毕昇编译器完成异构编译。执行程序时，Host进程会将任务（Task）下发到NPU后，但是不会等待NPU把任务执行完成就立即返回，NPU随即开始通过任务调度器向计算核（AI Core，AI 处理器的计算核心）并执行下发的任务。

为提升计算效率，NPU 上通常有多个AI Core并发执行，每个AI Core一般处理不同的数据。传统上，AI Core 遵循 SIMD（Single Instruction Multiple Data，单指令多数据流） 模型，通过一条指令同时操作多个数据实现并行计算。从 Ascend 950PR/Ascend 950DT架构开始，作为 SIMD 的补充（主要用于辅助离散类矢量算子开发），AI Core 也支持 SIMT（Single Instruction Multiple Thread，单指令多线程） 模型，通过一条指令驱动多个线程并行执行。
