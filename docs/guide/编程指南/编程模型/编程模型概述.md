# 编程模型概述<a name="ZH-CN_TOPIC_0000002554090609"></a>
本章从宏观层面介绍通用概念与Ascend C编程模型，不涉及任何特定框架与编程语言。此处引入的术语和概念是 Ascend C 各类编程方式的基础，后续章节将展开介绍这些编程方式。

## 1. 异构计算系统
Ascend C 编程模型假设系统是一个异构计算系统，由通用处理器（Host）和 AI 处理器（Device）组成。

- **Host**： 指代 CPU 及其直接连接的内存（Host Memory）。Host 负责应用程序的整体逻辑控制、运行时管理（如设备管理、内存分配、Stream 管理）以及任务下发。
- **Device**： 指代 AI 处理器（如昇腾 950 系列）及其直接连接的显存（Device Memory）。Device 负责执行计算密集型任务，如大规模矩阵运算和向量运算。

在某些 SoC 架构中，两者可能集成在同一芯片内；而在大型系统中，一个 Host 可能会管理多个 Device。

### 协同机制与执行流

Ascend C 应用程序始终从 Host 侧启动执行。Host 通过调用 APIs 实现以下关键行为：

1. 数据传输： 在 Host Memory 与 Device Memory 之间进行双向数据拷贝。
2. 核函数启动（Kernel Launch）： 将计算任务（Kernel）下发至 Device 运行。
3. 同步与异步： 等待数据传输或计算任务完成。

### 并行执行与内核（Kernels）

在 Device 上执行的代码被称为 Device Code，而由 Host 触发并在 AI Core 上运行的特定函数被称为 核函数（Kernel）。启动一个 Kernel 意味着启动了大量的计算任务（Task）在多个计算核心（AI Core）上并行执行。

## 2. 核心编程模型
在异构计算系统中，Device侧的计算任务并非千篇一律。为了兼顾计算的高吞吐与逻辑的灵活性，昇腾AI处理器在Device侧提供了不同的硬件执行单元。开发者需要根据任务特性（如数据分布、计算密集度、逻辑复杂度等）选择最匹配的编程模型。

目前，昇腾平台主要支持以下三种编程模型，分别对应AI Core的极致并行能力和AI CPU的通用计算能力：
- SIMD（Single Instruction Multiple Data）：单指令多数据。这是 AI Core 处理大规模张量（Tensor）数据的核心方式。通过单条指令触发多个数据的并行计算，实现极高的浮吐量。
- SIMT（Single Instruction Multiple Thread）：单指令多线程。通过单条指令管理多个线程并行执行，更擅长处理复杂的逻辑控制和离散数据访问。
- AI CPU 编程：利用 Device 侧的通用处理器（AI CPU）完成不适合在 AI Core 上运行的非规则计算任务。


### 表 1：编程模型对比与适用场景

| 编程模型 | 计算单元 | 核心特点 | 典型适用场景 |
| :--- | :--- | :--- | :--- |
| **SIMD 编程** | AI Core | 吞吐量极高，支持 SIMD 与 SIMT 混合编程。 | 矩阵计算、连续内存访问的矢量算子、融合算子。 |
| **SIMT 编程** | AI Core | 灵活的线程调度，支持复杂分支控制。 | 离散内存访问、逻辑复杂的矢量算子（需特定硬件支持）。 |
| **AI CPU 编程** | AI CPU | 具备通用计算能力，直接访问 Device 内存。 | 非矩阵类、分支密集型、不规则逻辑计算。 |

## 3. 编程模型深度解析

### 2.1 AI Core SIMD 编程
SIMD 是 AI Core 最基础且最高效的编程模式，旨在利用一条指令完成多组数据的计算。Ascend C 进一步提供了 **SIMD 与 SIMT 混合编程** 的高级方式，开发者可以在利用 SIMD 指令集高性能的同时，借助SIMT的线程模型简化复杂控制流与离散数据访问的开发难度。
* **优势**：极致的吞吐性能，完美契合张量计算。
* **参考**：详见 [AI Core SIMD编程](AI-Core-SIMD编程/) 及 [SIMD算子实现](../../算子实践参考/SIMD算子实现/)。

### 2.2 AI Core SIMT 编程
SIMT 模式通过抽象出大量并行线程，简化了对离散数据访问和复杂条件分支的处理逻辑。该模式便于具备传统 GPU 开发经验的人员快速迁移。
* **注意**：目前 SIMT 编程仅支持 **Ascend 950PR/Ascend 950DT** 等特定系列硬件。
* **参考**：详见 [AI Core SIMT编程](AI-Core-SIMT编程/) 及 [SIMT算子实现](../../算子实践参考/SIMT算子实现/)。

### 2.3 AI CPU 编程
AI CPU 位于 Device 侧，其内存访问能力与 AI Core 对等，但其指令集更偏向通用计算。它通常作为 AI Core 的有力补充，用于承载那些“计算量不大但逻辑极其复杂”的非矩阵类算子。
* **优势**：极强的逻辑控制能力，支持 C++ 标准库。
* **参考**：详见 [AI CPU编程](AI-CPU编程.md) 了解基础知识及开发流程。
