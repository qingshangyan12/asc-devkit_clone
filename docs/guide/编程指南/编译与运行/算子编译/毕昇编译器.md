# 毕昇编译器简介<a name="ZH-CN_TOPIC_0000002457558450"></a>

毕昇编译器是专为昇腾AI处理器设计的异构编译器，原生支持AscendC算子代码的编译，可将用户编写的算子程序高效转换为二进制可执行文件或动态库。编译器的可执行文件名为 bisheng，支持 x86、aarch64 等多种主机平台，并直接提供对设备侧AI Core架构的指令集编译支持。借助毕昇编译器，开发者可以更高效、便捷地完成面向昇腾平台的算子开发与优化工作。

-   目前，编译器支持如下型号：
    -   Ascend 950PR/Ascend 950DT
    -   Atlas A3 训练系列产品/Atlas A3 推理系列产品
    -   Atlas A2 训练系列产品/Atlas A2 推理系列产品
    -   Atlas 推理系列产品

##  Ascend C 源码文件和头文件

| 文件扩展名  | 描述 | 内容 |
|--|--|--|
|.c| C 源码文件 | 只有 Host-only 代码 | 
|.cpp, .cc, .cxx | C++ 源码文件| 只有 Host-only 代码 | 
|.h, .hpp, .hh, .hxx | C/C++ 头文件| Device 代码， Host 代码， Host/Device混合代码 | 
|.asc | Ascend C 源码文件| Device 代码， Host 代码， Host/Device混合代码 | 

-   异构编译场景中的编程相关约束请参考[约束说明](约束说明.md)。
-   如果需要了解更多的毕昇编译器的基础知识，详细内容请参考[《毕昇编译器用户指南》](https://www.hiascend.com/document/redirect/CannCommunityBiSheng)
