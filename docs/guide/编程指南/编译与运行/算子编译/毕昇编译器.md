# 毕昇编译器简介<a name="ZH-CN_TOPIC_0000002457558450"></a>

毕昇编译器是一款专为昇腾AI处理器设计的编译器，支持异构编程扩展，可以将用户编写的昇腾算子代码编译成二进制可执行文件和动态库等形式。<br>
毕昇编译器的可执行程序命名为bisheng，支持x86、aarch64等主机系统，并且原生支持设备侧AI Core架构指令集编译。<br>
通过使用毕昇编译器，用户可以更加高效地进行针对昇腾AI处理器的编程和开发工作

-   目前，编译器支持如下型号：
    -   Ascend 950PR/Ascend 950DT
    -   Atlas A3 训练系列产品/Atlas A3 推理系列产品
    -   Atlas A2 训练系列产品/Atlas A2 推理系列产品
    -   Atlas 推理系列产品

-   异构编译场景中的编程相关约束请参考[约束说明](约束说明.md)。
-   如果需要了解更多的毕昇编译器的基础知识，详细内容请参考《毕昇编译器用户指南》
