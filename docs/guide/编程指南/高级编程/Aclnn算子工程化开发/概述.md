## 2 什么是工程化算子开发

工程化算子开发是指基于**自定义算子工程**完成算子实现、编译部署和调用验证的开发方式。自定义算子工程通常由 msopgen 工具根据算子原型定义生成，工程中包含算子原型定义、Host 侧 Tiling 实现、Kernel 侧计算实现和 CMake 编译配置等文件。

对于新手，可以先把几个关键词理解为：

| 名称 | 含义 |
|------|------|
| 算子原型 | 描述算子的输入、输出、属性、数据类型、格式、Shape 推导等信息 |
| Host 侧 | 运行在 CPU 侧的准备逻辑，例如 Shape 推导、Tiling 计算、workspace 大小设置 |
| Kernel 侧 | 运行在 AI Core 上的计算逻辑，是算子真正执行计算的部分 |
| Tiling | 根据输入 Shape、数据类型等信息切分计算任务，并把 Kernel 需要的参数传下去 |
| aclnn 单算子 API | 算子工程编译后基于算子原型自动生成的 C 语言 API，应用程序可通过该接口直接调用自定义算子 |

工程化开发的优势在于：代码结构规范统一、易于维护；同时天然支持多种集成方式，开发者可以借助 CANN 框架快速完成算子的端到端验证和部署。

| 集成方式 | 说明 | 适用场景 |
|---------|------|---------|
| 单算子 API 调用 | 通过生成的 aclnn 接口直接调用算子，基于 C 语言 API 执行算子 | 算子功能验证、单算子调用、动态网络调用 |
| 算子入图 | 补充 Shape 推导等入图适配代码后，基于图 IR 执行自定义算子 | 图模式、IR 构图、多算子组合 |
| AI 框架调用 | 在工程化算子基础上增加框架插件适配后，通过 PyTorch/TensorFlow 等框架调用自定义算子 | 融入 AI 训练或推理流程 |

## 5 前置条件

- **CANN 软件安装**：参考[环境准备](../../../../入门教程/环境准备.md)完成 CANN 软件包安装。需要在 NPU 上实际运行算子时，还需要安装并正确配置驱动固件。
- **开发环境配置**：使用 CANN 运行用户登录环境，并执行 `source ${INSTALL_DIR}/set_env.sh` 设置环境变量。`${INSTALL_DIR}` 请替换为 CANN 软件安装路径，root 用户默认安装路径为 `/usr/local/Ascend/cann`。
- **算子工程工具链**：需要能正常使用 msopgen、CMake、Python、GCC/G++ 等工具。具体版本要求以当前 CANN 软件包和工程模板要求为准。

**环境自检清单**：
| 检查项 | 检查命令 | 预期结果 |
|--------|---------|---------|
| CANN 版本 | `cat $ASCEND_HOME_PATH/version.info` | 版本号 ≥ 9.0.0 |
| 驱动固件版本 | `npu-smi info` | 显示设备信息，无报错 |
| CMake 版本 | `cmake --version` | 版本 ≥ 3.19 |
| GCC 版本 | `g++ --version` | 版本 ≥ 9.4 |
| Python | `python3 --version` | 版本 ≥3.9 |
| 环境变量 | `echo $ASCEND_HOME_PATH` | 指向 CANN 安装路径，非空 |
