# 概述

> 类型：基础

## 什么是工程化算子开发

工程化算子开发是指基于**自定义算子工程**（由 msopgen 工具生成的算子代码骨架，包含算子原型定义、Host 侧 Tiling 实现、Kernel 侧计算实现和 CMake 编译配置）完成算子实现、编译部署、单算子 API 调用等一系列流程的开发方式。该流程是 Ascend C 算子开发的标准流程，适用于将自定义算子集成到 CANN 框架中运行。

工程化开发的优势在于：代码结构规范统一、易于维护；同时天然支持多种集成方式，开发者可以借助 CANN 框架快速完成算子的端到端验证和部署。

| 集成方式 | 说明 | 适用场景 |
|---------|------|---------|
| 单算子 API 调用 | 通过生成的 aclnn 接口直接调用算子，无需构图 | 算子功能验证、独立部署 |
| 算子入图 | 将算子注册到 Ascend Graph 计算图中，由图引擎调度执行 | 多算子组合、性能优化 |
| AI 框架调用 | 通过 PyTorch/TensorFlow 等框架调用自定义算子 | 融入 AI 训练或推理流程 |

## 前置条件

- **CANN 软件安装**：参考[环境准备](../../../../入门教程/环境准备.md)完成驱动固件和 CANN 软件包的安装
- **开发环境配置**：确保开发环境和运行环境已正确配置，包括环境变量设置

**环境自检清单**：

| 检查项 | 检查命令 | 预期结果 |
|--------|---------|---------|
| CANN 版本 | `cat $ASCEND_HOME_PATH/version.info` | 版本号 ≥ 8.0.RC1 |
| 驱动固件版本 | `npu-smi info` | 显示设备信息，无报错 |
| CMake 版本 | `cmake --version` | 版本 ≥ 3.16（CMakePresets 场景需 ≥ 3.19） |
| GCC 版本 | `g++ --version` | 版本 ≥ 7.5 |
| 环境变量 | `echo $ASCEND_HOME_PATH` | 指向 CANN 安装路径，非空 |
