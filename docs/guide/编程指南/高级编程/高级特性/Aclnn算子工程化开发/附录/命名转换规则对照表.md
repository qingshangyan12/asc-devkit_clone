# 命名转换规则对照表

> 类型：参考

## 转换规则概述

在自定义算子工程中，算子类型（类名）采用**大驼峰**命名方式，而算子实现文件名称和核函数名称均采用**下划线**命名方式。框架在编译和运行时按照以下4条规则自动完成转换：

1. **首字符大写转小写**：首字符的大写字符直接转换为小写字符。
2. **小写/数字后遇大写插入下划线**：大写字符的前一个字符为小写字符或数字时，在大写字符前插入一个下划线"\_"，并将该大写字符转换为小写。
3. **连续大写中最后一个大写后接小写时插入下划线**：大写字符前一个字符为大写字符且后一个字符是小写字符时，在该大写字符前插入一个下划线"\_"，并将其转换为小写。
4. **其他大写字符直接转小写**：不符合上述条件的大写字符直接转换为小写，小写字符保持不变。

## 对照表

下表列出了常见算子名称的转换示例：

| 算子类型（大驼峰） | 文件名/核函数名（下划线） | 转换说明 |
|---|---|---|
| AddCustom | add\_custom | 基础示例：Add→add，Custom前插入下划线→\_custom |
| ReduceMaxCustom | reduce\_max\_custom | Max前插入下划线（x后遇大写M） |
| MatmulCustom | matmul\_custom | 基础示例：Matmul→matmul，Custom前插入下划线 |
| BatchNormCustom | batch\_norm\_custom | Norm前插入下划线（h后遇大写N） |
| Conv2DCustom | conv2d\_custom | 数字2后D直接转小写d（规则4），Custom前插入下划线 |
| SoftmaxCustom | softmax\_custom | Softmax→softmax，Custom前插入下划线 |
| ReluCustom | relu\_custom | Relu→relu，Custom前插入下划线 |
| LayerNormCustom | layer\_norm\_custom | Norm前插入下划线（r后遇大写N） |
| SliceCustom | slice\_custom | Slice→slice，Custom前插入下划线 |
| GatherV2Custom | gather\_v2\_custom | V前插入下划线（r后遇大写V），数字2后无大写 |
| SplitVCustom | split\_v\_custom | V前插入下划线（t后遇大写V） |
| TransposeCustom | transpose\_custom | Transpose→transpose，Custom前插入下划线 |
| OneHotCustom | one\_hot\_custom | Hot前插入下划线（e后遇大写H） |
| TopKCustom | top\_k\_custom | K前插入下划线（p后遇大写K） |

## 特殊情况说明

### 连续大写字母

当算子类型中包含连续大写字母（如缩写词）时，需特别注意规则3的应用：

- **AbcAAc** → `abc_a_ac`：第一个A前面是小写c，所以插入下划线变为`_a`；第二个A前面是大写A、后面是小写c，触发规则3，插入下划线变为`_a`；最后的c保持不变。
- **Conv2D** → `conv2d`：D前面是数字2，触发规则2... 实际按规则4处理（D是连续大写的一部分或末尾大写），直接转小写d。
- **GRUCell** → `gru_cell`：RU是连续大写，U后面是小写C（Cell），触发规则3，在C前（实际是在U处）插入下划线，最终为`gru_cell`。

### 首字母大写

首字母大写直接转小写，不插入下划线：

- **Add** → `add`
- **Reduce** → `reduce`

### 数字与字母相邻

- 数字后遇大写字母：按规则2处理，插入下划线。例如 `GatherV2` → `gather_v2`（V前插入下划线）。
- 小写字母后遇数字再遇大写：数字本身不触发插入，大写前如果是数字，按规则2处理。

### 工程中的实际影响

在自定义算子工程中，默认情况下开发者需要保证以下三者一致：

| 项目 | 命名方式 | 示例 |
|---|---|---|
| 算子类型（类名/OP\_ADD参数） | 大驼峰 | `AddCustom` |
| 算子实现文件名称 | 下划线 | `add_custom.cpp` |
| 核函数名称 | 下划线 | `add_custom` |

通常情况下，使用 msOpGen 工具创建算子工程时，只需在原型定义 json 文件中将算子类型设为大驼峰命名，工具会自动生成符合下划线命名规则的文件名和核函数名。手动编写时需要自行遵守上述转换规则。

如果需要修改算子实现文件名称（例如为不同 AI 处理器型号使用不同的实现文件），可以通过 CMakeLists.txt 中的 `npu_op_kernel_sources` 函数指定 Kernel 入口文件，此时文件名不必遵循上述转换规则。详细用法请参考 [npu_op_kernel_sources](./cmake函数参考.md#npu_op_kernel_sources)。

更多原型定义相关信息请参考[算子原型定义](../设计与实现/算子原型定义.md)。
