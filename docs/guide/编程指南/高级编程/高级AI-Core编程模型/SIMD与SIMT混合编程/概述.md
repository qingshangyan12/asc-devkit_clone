# 概述<a name="ZH-CN_TOPIC_0000002563469514"></a>

Ascend C支持SIMD和SIMT两种编程方式，SIMD基于向量寄存器与指令，实现高效的数据并行处理，SIMT能够简化复杂算子与不规则控制流的开发。两种编程方式有各自的优势场景，而独立的编程方式无法充分利用硬件全部算力，因此提供了SIMD与SIMT混合编程方式。SIMD与SIMT混合编程是SIMD编程的一种补充能力，支持开发者根据算子特征进行精细化映射：规则的逐元素elementwise操作通过SIMD获得高带宽和高算力利用率，不规则或包含分支的计算通过SIMT来缓解发散和控制复杂度。在系统层面，这有利于提高硬件利用率和能效；同时，也更便于进行算子融合和数据复用等优化。综上分析，混合编程适用于算子功能既包含SIMD擅长的连续规整计算，也包含SIMT擅长的离散访问等任务的场景。
