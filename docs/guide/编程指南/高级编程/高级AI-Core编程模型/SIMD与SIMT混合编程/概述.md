# 概述<a name="ZH-CN_TOPIC_0000002563469514"></a>

Ascend C支持SIMD和SIMT两种编程方式，SIMD基于向量寄存器与指令，实现高效的数据并行处理，SIMT能够简化复杂算子与不规则控制流的开发。两种编程方式有各自的优势场景，而独立的编程方式无法充分利用硬件全部算力，因此提供了SIMD与SIMT混合编程方式（下文简写为混合编程）。混合编程是SIMD编程的一种补充能力，支持开发者根据算子特征进行精细化映射：规则的逐元素elementwise操作通过SIMD获得高带宽和高算力利用率，不规则或包含分支的计算通过SIMT来缓解发散和控制复杂度。在系统层面，这有利于提高硬件利用率和能效；同时，也更便于进行算子融合和数据复用等优化。
综上分析，混合编程适用于算子功能既包含SIMD擅长的连续规整计算，也包含SIMT擅长的离散访问等任务的场景。以下列举部分混合编程的适用场景：

-  复杂分支判断的算子，适合使用SIMT完成计算任务，而输入输出的数据搬运较规整连续，适合使用SIMD搬运类口完成数据拷贝。例如[floor_mod样例](https://gitcode.com/cann/asc-devkit/tree/master/examples/01_simd_cpp_api/04_best_practices/03_fusion_compute_practices/simt_and_simd_floor_mod)。

-  离散访问场景，适合使用SIMT完成计算任务，当所需访问的数据量远小于UBuffer可用空间时，可以使用SIMD搬运接口完成数据拷贝，使SIMT编程能够直接从Unified Buffer读取数据，提高内存访问效率。例如[gather小包搬运样例](https://gitcode.com/cann/asc-devkit/blob/master/examples/01_simd_cpp_api/04_best_practices/03_fusion_compute_practices/simt_gather_with_ub)。

-  某些算子，在大shape场景，使用SIMD并行计算效率更高，而在小shape不规整场景，则适合使用SIMT完成计算，因此可以区分算子场景，分别使用两个编程方式实现算子功能，提升泛化场景整体性能。

混合编程作为高级编程方式，要求开发者至少对[SIMD编程模型](../../../编程模型/AI-Core-SIMD编程/AI-Core-SIMD编程.md)和[SIMT编程模型](../../../编程模型/AI-Core-SIMT编程/AI-Core-SIMT编程.md)有一定的了解。本章节将从以下几个方面展开介绍混合编程：
-   **[抽象硬件架构](抽象硬件架构.md)**: 介绍了SIMD与SIMT混合编程场景的硬件架构，介绍VF（Vector Function）运行机制及SIMT VF、SIMD VF等概念。

-   **[函数层级](函数层级.md)**：详细介绍了混合编程场景的核函数定义、调用方式及执行配置，VF函数及各类函数的调用关系。

-   **[内存层级](内存层级.md)**：展示混合编程场景的内存层级，重点介绍了VF之间的通信方式，UB内存作为共享内存是如何分配与管理的。

-   **[编码示例](编码示例.md)**：以实际样例展示混合编程关键语法，包括`asc_vf_call`调用SIMT VF函数和`<<<>>>`核函数启动配置。
