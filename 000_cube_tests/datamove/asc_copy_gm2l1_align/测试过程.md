# asc_copy_gm2l1_align 测试过程

## API 概要
- **API**: `asc_copy_gm2l1_align_sync(__cbuf__ half* dst, __gm__ half* src, n_burst, len_burst, left_pad, right_pad, data_sel, l2_cache, src_stride, dst_stride)`
- **头文件**: `c_api/asc_simd.h` → `cube_datamove.h`
- **流水线**: PIPE_MTE2
- **功能**: GM → L1 带对齐/填充的劈裂搬运，支持 10 种数据类型
- **适用架构**: dav-3510 (Ascend 950PR/950DT)

## 测试方法
- **类型**: 数据搬运类 API
- **验证方式**: GM→L1(align)→L0A→MMAD(B=ones)→L0C→GM, 间接验证 L1 数据正确性

## 测试场景
| 场景 | 说明 |
|------|------|
| 单 burst 无 padding | n_burst=1, len_burst=8(32B), half 类型 |

## 精度门限
- max_error < 0.001f

## 编译运行
```bash
bash build_and_run.sh
```
