# asc_set_gm2l1_pad 测试过程

## API 概要
- **API**: `asc_set_gm2l1_pad(uint32_t pad_val)`
- **头文件**: `c_api/asc_simd.h` → `cube_datamove.h`
- **流水线**: PIPE_S
- **功能**: 设置 GM→L1 搬运的 Pad 填充模式
- **适用架构**: dav-3510 (Ascend 950PR/950DT)

## 测试方法
- **类型**: 数据搬运/config 类 API (PIPE_S)
- **验证方式**: 设置 pad_mode=0 → GM→L1→L0A→MMAD→L0C→GM, 间接验证 pad 配置不破坏流水线

## 测试场景
| 场景 | 说明 |
|------|------|
| 无 Pad 模式 | pad_mode=0, 完整 MMAD 流水线验证 |

## 精度门限
- max_error < 0.001f

## 编译运行
```bash
bash build_and_run.sh
```
