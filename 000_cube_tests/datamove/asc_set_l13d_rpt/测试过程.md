# asc_set_l13d_rpt 测试过程

## API 概要
- **API**: `asc_set_l13d_rpt(asc_load3d_v2_config& config)`
- **头文件**: `c_api/asc_simd.h` → `cube_datamove.h`
- **流水线**: PIPE_S
- **功能**: 设置 Load3Dv2 的 repeat 参数
- **适用架构**: dav-3510 (Ascend 950PR/950DT) (通用 API)

## 测试方法
- **类型**: 数据搬运/config 类 API (PIPE_S)
- **验证方式**: 配置 repeat=1 后执行完整 MMAD 流水线，验证配置不破坏正常搬运

## 测试场景
| 场景 | 说明 |
|------|------|
| repeat=1 默认 | config_unit.repeat=1, 完整 MMAD 验证 |

## 精度门限
- max_error < 0.001f

## 编译运行
```bash
bash build_and_run.sh
```
