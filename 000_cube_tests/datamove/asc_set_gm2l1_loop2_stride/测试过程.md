# asc_set_gm2l1_loop2_stride 测试过程

## API 概要
- **API**: `asc_set_gm2l1_loop2_stride(uint64_t loop2_src_stride, uint64_t loop2_dst_stride)`
- **头文件**: `c_api/asc_simd.h` → `cube_datamove.h`
- **流水线**: PIPE_S
- **功能**: 设置 GM→L1 数据搬运的外循环步长
- **适用架构**: dav-3510 (Ascend 950PR/950DT) only

## 测试方法
- **类型**: 数据搬运/config 类 API (PIPE_S)
- **验证方式**: 设置 loop_size + loop_stride → GM→L1→L0A→MMAD→L0C→GM, 间接验证双级循环配置正确

## 测试场景
| 场景 | 说明 |
|------|------|
| loop2 stride 默认 | loop1_size=1, loop2_size=2, loop2_stride=0 |
| 失效验证 | 搬运后恢复 loop_size=1 |

## 精度门限
- max_error < 0.001f

bash build_and_run.sh
