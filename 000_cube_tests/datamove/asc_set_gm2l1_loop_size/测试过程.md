# asc_set_gm2l1_loop_size 测试过程

## API 概要
- **API**: `asc_set_gm2l1_loop_size(uint64_t loop1_size, uint64_t loop2_size)`
- **头文件**: `c_api/asc_simd.h` → `cube_datamove.h`
- **流水线**: PIPE_S
- **功能**: 设置 GM→L1 数据搬运的内/外循环次数
- **适用架构**: dav-3510 (Ascend 950PR/950DT) only

## 测试方法
- **类型**: 数据搬运/config 类 API (PIPE_S)
- **验证方式**: 设置 loop1_size=2 → GM→L1(双块)→L0A→MMAD→L0C→GM, 间接验证双块搬运

## 测试场景
| 场景 | 说明 |
|------|------|
| 双块搬运 | loop1=2, 每块 256B (16×16 half 分形) |
| 复位验证 | 搬运后恢复 loop_size=1 |

## 精度门限
- max_error < 0.001f

## 编译运行
```bash
bash build_and_run.sh
```
