# asc_mmad_sync 测试过程

## API 概要
- **API**: `asc_mmad_sync(__cc__ float* c, __ca__ half* a, __cb__ half* b, left_height, n_dim, right_width, unit_flag, disable_gemv, c_matrix_source, c_matrix_init_val)`
- **头文件**: `c_api/asc_simd.h` → `cube_compute.h`
- **流水线**: PIPE_M (带自动同步)
- **功能**: 矩阵乘加 (half×half→float) 的同步版本，自动插入同步指令
- **适用架构**: dav-3510 (Ascend 950PR/950DT)

## 测试方法
- **类型**: 计算类 API
- **验证方式**: asc_mmad_sync 执行 MMAD → L0C→GM → 与 CPU 矩阵乘结果比较

## 测试场景
| 场景 | 说明 |
|------|------|
| 单核单分形 | 16×16 half×half→float 矩阵乘 |

## 精度门限
- max_error < 0.001f

## 编译运行
```bash
bash build_and_run.sh
```
