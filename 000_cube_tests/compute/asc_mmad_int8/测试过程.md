# asc_mmad_int8 测试过程

## API 概要
- **API**: `asc_mmad(__cc__ int32_t* c, __ca__ int8_t* a, __cb__ int8_t* b, ...)`
- **头文件**: `c_api/asc_simd.h` → `cube_compute.h`
- **流水线**: PIPE_M
- **功能**: int8 矩阵乘加 (int8×int8→int32)
- **适用架构**: dav-3510 (Ascend 950PR/950DT)

## 测试方法
- **类型**: 计算类 API
- **验证方式**: asc_mmad (int8 重载) 执行 MMAD → L0C→GM → 与 CPU int8 矩阵乘结果比较 (精确匹配)

## 测试场景
| 场景 | 说明 |
|------|------|
| 单核单分形 | 16×16 int8×int8→int32 矩阵乘 |

## 精度门限
- max_diff == 0 (int32 整数精确匹配)
