# asc_set_l0c2gm_config 测试过程

## API 概要
- **API**: `asc_set_l0c2gm_config(uint64_t relu_pre, uint64_t quant_pre, bool enable_unit_flag)`
- **头文件**: `c_api/asc_simd.h` → `cube_compute.h`
- **流水线**: PIPE_S
- **功能**: 设置 L0C→GM 数据搬运时的随路量化参数
- **适用架构**: dav-3510 (Ascend 950PR/950DT)

## 测试方法
- **类型**: 计算/config 类 API (PIPE_S)
- **验证方式**: 设置 `quant_pre=F322F16` (float→half 量化) → 执行 MMAD 生成 float 结果 → L0C→GM 搬运时应用量化 → 将输出与 CPU 端 `float→half→float` 仿真值比较

## 测试场景
| 场景 | 说明 |
|------|------|
| 单核单分形 | 16x16 half 矩阵乘 (A=递增, B=全1) |
| 量化模式 | F322F16 (float → half) |

## 精度门限
- max_error < 0.02f (half 精度误差容忍)

## 编译运行

```bash
bash build_and_run.sh
```
