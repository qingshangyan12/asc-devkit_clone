# asc_set_l0c2gm_nz2nd 测试过程

## API 概要
- **API**: `asc_set_l0c2gm_nz2nd(uint64_t nd_num, uint64_t src_nd_stride, uint64_t dst_nd_stride)`
- **头文件**: `c_api/asc_simd.h` → `cube_compute.h`
- **流水线**: PIPE_S
- **功能**: 设置 L0C→GM 数据搬运时的 NZ→ND 格式转换参数
- **适用架构**: dav-3510 (Ascend 950PR/950DT) only

## 测试方法
- **类型**: 计算/config 类 API (PIPE_S)
- **验证方式**: 设置 NZ2ND 参数 (nd_num=1, src_nd_stride=1, dst_nd_stride=N_SIZE) → 执行 MMAD → L0C→GM 使能 NZ2ND → 验证输出为 ND (行主序) 格式并与 CPU 真值比较

## 测试场景
| 场景 | 说明 |
|------|------|
| 单核单分形 | 16x16 half 矩阵乘 |
| NZ2ND 转换 | NZ 格式 (列主序分形) → ND 格式 (行主序) |

## 精度门限
- max_error < 0.001f

## 编译运行

bash build_and_run.sh
