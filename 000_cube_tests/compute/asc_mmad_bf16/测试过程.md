# asc_mmad_bf16 测试过程

## API 概要
- **API**: `asc_mmad(__cc__ float* c, __ca__ bfloat16_t* a, __cb__ bfloat16_t* b, ...)`
- **头文件**: `c_api/asc_simd.h` → `cube_compute.h`
- **流水线**: PIPE_M
- **功能**: bfloat16 矩阵乘加 (bf16×bf16→float)
- **适用架构**: dav-3510 (Ascend 950PR/950DT)

## 测试方法
- **类型**: 计算类 API
- **验证方式**: asc_mmad (bf16 重载) 执行 MMAD → L0C→GM → 与 CPU bfloat16 矩阵乘结果比较

## 测试场景
| 场景 | 说明 |
|------|------|
| 单核单分形 | 16×16 bf16×bf16→float 矩阵乘 |

## 精度门限
- max_error < 0.02f (bf16 只有 ~7 bit 尾数精度)

## 编译运行
```bash
bash build_and_run.sh
```
