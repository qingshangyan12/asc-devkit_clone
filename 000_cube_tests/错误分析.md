## CANN 9.0.0-beta.2 规避方案

```c
struct fp4x2_e1m2_t { uint8_t v; };
struct fp4x2_e2m1_t { uint8_t v; };
struct fp8_e4m3fn_t { uint8_t v; };
struct fp8_e5m2_t   { uint8_t v; };
struct fp8_e8m0_t   { uint8_t v; };
struct int4b_t      { uint8_t v; };
```
