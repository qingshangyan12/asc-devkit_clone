# 批量替换芯片版本标签

## 目的
芯片版本的标签，由原先的html标签格式，改成了html注释格式

原先：
```html
<cann-filter npu-type="950">
    xxxxx
</cann-filter>
```

现在：
```html
<!-- npu="950" id1 -->
xxx
<!-- end id1 -->
```

你的工作就是将文档中所有类似的标签进行替换。

## 详细细节
1. `<cann-filter npu-type="950">`这个中间的npu-type就是芯片版本
2. `<!-- npu="950" id1 -->`中的npu也是芯片版本，是原来的芯片版本对应的。

3. `<!-- npu="950" id1 -->`中的id，后面跟上的数字，在文档中递增，从1开始，第二次出现这种注释标签，就变成2，以此类推。
4. 芯片版本可能有多个，会用逗号隔开，参考原先的芯片写法就可以。
