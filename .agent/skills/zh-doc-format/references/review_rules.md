## 7. 链接与锚点

- 外部文档链接用仓上标准长链（hiascend detail 链接），不用 redirect 短链。
- 章节引用写实际存在的章节路径；拿不准时打开链接核实目录。
- 新增 md 的 `<a name>` 锚点：全仓无引用即删除；有引用保留；仓库存量锚点不动。

## 8. HTML 标签

- 新增 md 不保留不必要的 HTML 语法标签（`<a name>`、`<br>` 等）。
- 删除前 grep 全仓确认无引用；被 3 个以上文件引用的锚点必须保留。
- 修改文件中的存量 HTML 不在整改范围（检视意见针对"新增 md"）。

## 9. 英文版对照

| 中文规则 | 英文执行 |
|---|---|
| 斜杠并列 → 顿号/与 | `asc_min`/`asc_max` → `asc_min` and `asc_max` |
| 破折号 → 冒号/比如 | ` — ` → `,` / `;` / `For example,` |
| 称谓统一 | hybrid programming → SIMD and SIMT hybrid programming |

## 10. 修改纪律

- 一类一类改，每类改完全文复扫确认清零。
- 排除代码块、行内代码、链接、URL、HTML 标签再判断标点类问题。
- 每处改动先判语义再选改法，避免机械替换破坏句意。
- 改完在 PR 描述或回复中逐条对应检视意见编号。
