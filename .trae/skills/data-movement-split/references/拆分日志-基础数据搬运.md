# 拆分日志：基础数据搬运

源文档：`docs/api/SIMD-API/基础API/Memory数据搬运/DataCopy/基础数据搬运.md`
接口：DataCopy

> **说明**：每个通路按函数原型进一步拆分为两个功能文档——连续数据搬运（count 参数）和高维切分数据搬运（repeatParams 参数），两套文档参数说明相互独立。

## 全部数据通路

| 数据通路（逻辑） | 数据通路（物理） | 是否在本次拆分范围内 | 拆分后文档 |
|:---|:---|:---:|:---|
| GM -> VECIN | **GM -> UB** | ✅ 是 | `GMToUB连续数据搬运(DataCopy).md`、`GMToUB高维切分数据搬运(DataCopy).md` |
| GM -> A1、B1、C1 | GM -> L1 Buffer | ❌ 否 | — |
| VECIN -> VECCALC / VECCALC -> VECOUT | **UB -> UB** | ✅ 是 | `UBToUB连续数据搬运(DataCopy).md`、`UBToUB高维切分数据搬运(DataCopy).md` |
| VECOUT / CO2 -> GM | **UB -> GM** | ✅ 是 | `UBToGM连续数据搬运(DataCopy).md`、`UBToGM高维切分数据搬运(DataCopy).md` |
| VECIN/VECCALC/VECOUT -> TSCM/A1/B1 | UB -> L1 Buffer | ❌ 否 | — |
| A1、B1、C1 -> C2PIPE2GM | L1 Buffer -> Fixpipe Buffer | ❌ 否 | — |
| C1 -> C2 | L1 Buffer -> BiasTable Buffer | ❌ 否 | — |
| A1、B1 -> GM | L1 Buffer -> GM | ❌ 否 | — |
| C1 -> C2（类型不一致） | L1 Buffer -> BiasTable Buffer | ❌ 否 | — |
