0.1分层角色

层角色代表类型
Verb统一入口，消除同名重载风暴Compute / Load / Store
Atom可复用策略对象（Tag + Trait）VecAtom / LoadAtom / StoreAtom
Tag指令族标识（空类型）vec::Add / load::UbAlign
Trait正交行为配置VecTrait / RegLoadTrait
Operand寄存器操作数工厂MakeRegTensor / MakeMaskReg
Inst下沉到 asc_*Inst::Add::Run / UbAlign::Run

5调用链

用户写法
  Compute(MakeVec(vec::Add{}, VecTrait{MERGING}), dst, a, b, mask)
       │              │
       │              └─ MakeVec → VecAtom<VecTraits<Add, Trait>>
       └─ Compute → atom.Call → VecInstOf<Add>::Inst::Run / Select::Run

  Load(MakeLoad(load::UbAlign{}), a, ubPtr)
       └─ LoadAtom<UbAlign>::Call → Inst::RegLoad::UbAlign::Run → asc_loadalign
