# C API UB 到 UB 搬运样例

本样例迁移自 `01_simd_cpp_api/03_basic_api/00_data_movement/copy_ub2ub`，覆盖其三种输出语义：

- 场景 1：连续搬运 512 个 `int32_t`；
- 场景 2：从 `[18, 64]` 输入的每行取前 8 个元素，紧凑写为 `[18, 8]`；
- 场景 3：与场景 2 保持相同结果。原样例的 Counter-mask 指令形式没有独立 C API 对应形式，因此改用 C API 二维 UB 搬运完成相同数据选择。

通过 `-DSCENARIO_NUM=1|2|3` 选择场景；未定义时为场景 1。本样例仅经静态核对，未编译或运行。
