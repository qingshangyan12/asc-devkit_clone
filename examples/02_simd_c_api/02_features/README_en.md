# Features Sample Introduction

## Overview

This directory contains synchronization control, data movement, and performance optimization samples implemented using Ascend C C_API.

## Sample List

| Directory Name | Description |
| -------------- | ----------- |
| [00_sync_and_async](./00_sync_and_async) | Uses the Add operator to demonstrate synchronous interfaces, asynchronous interfaces, and fine-grained synchronization control for asynchronous pipelines. |
| [01_data_movement](./01_data_movement) | Demonstrates data movement features and optimization methods. |
| [02_reg_vector_compute](./02_reg_vector_compute) | Demonstrates Vector computation optimization methods based on Reg programming interfaces. |
| [03_matrix_compute](./03_matrix_compute) | Demonstrates optimization methods for Cube matrix computation. |
