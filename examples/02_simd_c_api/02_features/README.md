# Features样例介绍
 
## 概述
 
本目录包含基于Ascend C C_API实现的同步控制、数据搬运和性能优化样例。
 
## 样例列表
 
| 目录名称  | 功能描述 |
| --------- | --------- |
| [00_sync_and_async](./00_sync_and_async) | 基于Add算子展示同步接口、异步接口以及异步流水的精细化同步控制。 |
| [01_data_movement](./01_data_movement) | 展示数据搬运相关的特性和优化方法。 |
| [02_reg_vector_compute](./02_reg_vector_compute) | 展示基于Reg编程接口实现的Vector计算优化方法。 |
| [03_matrix_compute](./03_matrix_compute) | 展示Cube矩阵计算相关的优化方法。 |
