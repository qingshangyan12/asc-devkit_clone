# SIMD与SIMT混合编程维测样例介绍

## 概述

本目录提供 Ascend C SIMD与SIMT混合编程场景下的维测与问题定位样例，帮助开发者理解混合编程中资源配置、内存访问边界和异常定位方法。

## 样例列表

| 目录名称 | 功能描述 | 支持的产品 |
| ------------------------------------------------------------ | ---------------------------------------------------- | --- |
