# 编译样例介绍

## 概述

本样例介绍了基于Ascend C的自定义算子编译、打包和部署的实现方法。

## 样例列表

| 目录名称 | 功能描述 |
| --------- | --------- |
| [custom_op](./custom_op) | 本样例介绍了自定义算子工程的编译、打包和部署流程 |
| [custom_op_static_lib](./custom_op_static_lib) | 本样例介绍了自定义算子静态库的编译和调用方法 |
| [parallel_ops_package](./parallel_ops_package) | 本样例介绍了多Vendor并行编译、打包和部署的实现方法 |
