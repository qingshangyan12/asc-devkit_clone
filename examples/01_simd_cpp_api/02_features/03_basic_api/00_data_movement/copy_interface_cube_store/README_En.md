# Tensor API Copy Cube Store Interface Example

`COPY_ROUTE=0..2` covers `L0C->GM/UB/L1`, while `SCENARIO_NUM=0..2` covers the three call forms. Only route 0 accepts `QUANT_MODE=0/1/2`; Tensor Quant uses FixBuffer internally without a public L1-to-FixBuffer call. All three routes use data golden checks. Regional S0 copies `32x16` across M fractals, while S2 copies `16x32` across N fractals. L0C-to-GM S1 covers a complete `32x32` NZ-to-ND copy; Tensor Quant uses factors 1.0 and 0.5 for the first and second 16-column slices to verify quant-slice switching. L0C-to-UB is exported by AIV after cross-core synchronization and checks the untouched sentinel area; S1 uses a `16x32` Tensor slice view that preserves the parent NZ stride. L0C-to-L1 uses a `float` L0C source and a `half` L1 destination, with `F322F16` inferred inside Tensor API; it is read back through L1-to-UB-to-GM in NZ physical order, and S0/S2 also check the untouched sentinel area. Generate data with `python3 scripts/gen_data.py --route <n> --quant-mode <n>`; route 2 validation must use `--route 2`. Build and run with the same route, scenario, and quant mode, then pass those three values to `scripts/verify_result.py`. This directory contributes 15 combinations.
