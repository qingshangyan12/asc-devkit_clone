# Tensor API Copy Cube Scale Interface Example

This is a single-tile `M=N=32, K=128` MXFP4 Matmul. `COPY_ROUTE=0/1` covers `L1->L0ScaleA/B`, and `SCENARIO_NUM=0..2` covers all three call forms. Baseline and test scales use position-dependent exponents 126, 127, and 128 across M/N fractals and K groups, so wrong offsets, strides, or missing regional updates produce distinct results. ScaleA S0/S2 copy `32x2` and `16x4`; ScaleB S0/S2 copy `4x16` and `2x32`. The baseline and overlay MTE1 writes are explicitly serialized, and the bfloat16 MX MMAD output is checked element by element. The generator requires `en_dtypes` and the verifier requires `ml_dtypes`. Generate input data, configure and run the example, then invoke the verifier with the matching route and scenario. There are 6 combinations.
