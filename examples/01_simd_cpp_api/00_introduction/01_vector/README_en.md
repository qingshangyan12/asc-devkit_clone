# Vector Sample Introduction

## Overview

Vector computation samples based on Ascend C, covering multiple implementation styles including static Tensor, TQue/TPipe, and RegBase/VF fusion.

## Sample List

| Directory Name | Description |
| -------------- | ----------- |
| [add](./add) | Static Tensor programming implementation |
| [gelu](./gelu) | GELU example based on LocalMemoryAllocator and RegBase/VF fusion |
| [add_tpipe_tque](./add_tpipe_tque) | TQue and TPipe programming implementation |
