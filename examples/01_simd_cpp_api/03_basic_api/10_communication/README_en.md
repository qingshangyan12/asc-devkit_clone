# Communication Examples

This directory provides Ascend C communication examples that query topology links through HCCL Resource APIs, create communication channels, and copy data between ranks.

## Example List

| Directory Name | Function Description |
| --- | --- |
| [hccl_link_select](./hccl_link_select) | Queries UB_MEM links under MESH/CLOS topologies, registers memory, creates channels, and verifies remote data movement |
