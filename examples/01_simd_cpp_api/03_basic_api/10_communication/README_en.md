# Communication API Samples

## Overview

This directory contains API samples related to communication. The samples are based on Ascend C's `<<<>>>` direct invocation method, supporting implementation of both the main function and kernel function in the same file.

## Sample List

| Directory Name | Description | Supported Products |
| ------- | -------- | --- |
| [ain_test](./ain_test) | This sample verifies that the `adv_api/ain/ain.h` header and the device-side Ain class can be compiled in an Ascend C project. | Ascend 950PR/Ascend 950DT |
