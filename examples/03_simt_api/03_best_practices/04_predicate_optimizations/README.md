# Predicate Optimizations样例介绍

## 概述

谓词（Predicate）优化相关样例，通过<<<>>>直调的实现方式，介绍SIMT编程方式下分支发散的谓词化调优思路。当前提供了数学接口分支链路的谓词优化案例，展示按分支体长短与命中情况取舍谓词化与真跳转的优化方法。

## 样例列表

| 目录名称                                               | 功能描述                                                                                        |
| ------------------------------------------------------ | ----------------------------------------------------------------------------------------------- |
| [predicate_optimization](./predicate_optimization)   | 样例以数学接口`hlog10`、`j0f`的分支链路为例，对比"命中即提前return"与"统一return、谓词化直线执行"等分支组织方式，展示predicate（谓词）优化的性能收益与适用场景。 |
