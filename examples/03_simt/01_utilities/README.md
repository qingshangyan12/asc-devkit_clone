# Utilities样例介绍
## 概述
基于Ascend C SIMT编程的简单样例，通过printf、clock等API介绍上板打印、时钟打点等维测方法，适用于调试阶段。

## 算子开发样例
|  目录名称                                                   |  功能描述                                              |
| -------------------------- | -------------------- |
| [00_printf](./00_printf) | 本样例展示上板打印功能使用方法。 |
| [01_asserk](./01_assert/) | 本样例展示上板assert断言的功能。 |
| [02_cpu_debug](./02_cpu_debug/) | 本样例展示孪生调试功能。 |
| [03_platform](./03_platform/) | 本样例展示获取如何获取平台信息。 |
| [04_profiling](./04_profiling/) | 本样例展示如何获取profiling性能数据。|
| [05_camodel](./05_camodel/) | 本样例展示仿真模式如何进行性能分析。|
| [06_clock](./06_clock/) | 本样例展示打点功能的使用方法。 |
