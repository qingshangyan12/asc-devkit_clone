# Mmad_Performance样例
## 概述
本样例介绍基于基础API实现矩阵数据搬运样例，主要基于两个接口：LoadData / DataCopy

## 支持的产品
- Atlas A3 训练系列产品/Atlas A3 推理系列产品
- Atlas A2 训练系列产品/Atlas A2 推理系列产品

## 目录结构介绍
```
├── mmad_performance
│   ├── cases                            // 输入case的构造csv
│   ├── load_data.asc  // Ascend C算子实现 & 调用样例
│   ├── data_copy.asc
│   ├── scripts
│   │   ├── run_test.py                  // 批跑脚本
│   ├── CMakeLists.txt                   // 编译工程文件
│   └── batch_run.sh                     // 批跑入口
```


## 算子描述
- 算子功能：
  矩阵计算的搬入是AscendC编程框架中用于数据搬运的核心接口系列，主要实现Global Memory或L1到L0A/L0B之间的数据高效传输。该接口系列提供了多种数据搬运模式，能够满足矩阵计算中左右矩阵等数据的搬运需求，通常与Mmad接口配合使用。



## 编译运行
在本样例根目录下执行如下步骤，编译并执行算子。
- 配置环境变量  
  请根据当前环境上CANN开发套件包的[安装方式](../../../../docs/quick_start.md#prepare&install)，选择对应配置环境变量的命令。
  - 默认路径，root用户安装CANN软件包
    ```bash
    source /usr/local/Ascend/cann/set_env.sh
    ```

  - 默认路径，非root用户安装CANN软件包
    ```bash
    source $HOME/Ascend/cann/set_env.sh
    ```

  - 指定路径install_path，安装CANN软件包
    ```bash
    source ${install_path}/cann/set_env.sh
    ```
  
- 样例执行
  ```bash
  bash batch_run.sh
  ```
  执行结果如下，说明性能测试成功。
  ```bash
  ✅ 用例 [] 执行成功
  ```
