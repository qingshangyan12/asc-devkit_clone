# Utilities样例介绍
## 概述
基于Ascend C SIMT编程的简单样例，通过printf、clock等API介绍上板打印、时钟打点等维测方法，适用于调试阶段。

## 算子开发样例
|  目录名称                                                   |  功能描述                                              |
| -------------------------- | -------------------- |
| [00_printf](./00_printf) | 本样例通过Ascend C SIMT编程实现简单算子，在算子中添加printf调测接口，展示上板打印功能使用方法。 |
| [06_clock](./06_clock/) | 本样例通过Ascend C SIMT编程实现了简单Gather算子，同时clock打点接口，展示打点功能的使用方法。 |
