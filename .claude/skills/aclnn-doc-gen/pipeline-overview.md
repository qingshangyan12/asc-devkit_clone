# ACLNN 文档生成流程说明

## 流程概览

| 阶段 | 说明 | 耗时占比 |
|------|------|:-------:|
| **预处理** | 自动扫描算子代码，准备后续各阶段所需的基础数据 | ~2% |
| **信息提取** | 从算子源码中分析产品支持情况、参数定义、约束条件和返回值 | ~35% |
| **公式推导 & 接口对比**（并行） | 推导算子计算公式；同时对比当前接口与历史版本或变体接口的差异 | ~15% |
| **文档生成** | 汇总前序阶段成果，按文档规范生成完整 API 参考文档草稿 | ~35% |
| **校验修正** | 对草稿进行一致性检查和规范用语审校 | ~13% |
