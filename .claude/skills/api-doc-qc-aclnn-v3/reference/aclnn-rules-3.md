# aclnn 领域质检规则 - 可读性检查详细说明

**重要提示：**

- 仅使用本文件中明确定义的规则进行检查
- 规则名称、规则级别必须与本文件完全一致

## 3. 可读性检查

此类检查仅基于文档内容，不需要读取代码。

| 规则名称                         | 描述                                                                  | 级别 |
| -------------------------------- | --------------------------------------------------------------------- | ---- |
| 一段接口参数拦截前后参数名一致性 | 检查拦截表格中描述列的参数名是否与参数说明中的参数名一致              | 严重 |
| API 名称前后文一致性             | 检查 API 名称是否与标题、函数原型、接口标题、调用示例等上下文保持一致 | 严重 |
| 产品支持度一致性                 | 检查产品支持情况表格与后文芯片差异化描述是否一致                      | 严重 |

### 一段接口参数拦截前后参数名一致性

第一段接口（aclnnXxxGetWorkspaceSize）的**返回值**拦截表格的"描述"列中用到的的参数名必须与**参数说明**里的参数名一致。

**检查方法：**

1. 找到参数说明表中的参数名列表
2. 找到拦截校验表"描述"列中提及的所有参数名
3. 对比两者是否一致（不包括“tensor”）

### API 名称前后文一致性

- 目标：API 名称。例如："Xxx"
- 规则：
  1. 与文章一级标题一致（# aclnnXxx）
  2. 与函数原型一致（aclnnXxxGetWorkspaceSize，aclnnXxx）
  3. 与一阶段接口标题一致（aclnnXxxGetWorkspaceSize）
  4. 与二阶段接口标题一致（aclnnXxx）
  5. 与二阶段接口参数说明表中"workspaceSize"参数的"描述"中"由第一段接口 aclnnXxxGetWorkspaceSize 获取"一致
  6. 调用示例里“中文注释”和“LOG_PRINT”的所有 Xxx 保持一致（// 调用 aclnnXxx 第一段接口）

### 产品支持度一致性

- 规则：文中所有章节的产品差异化描述要与 `## 产品支持情况` 表内容一致。

**反例：**

- 产品支持表里写到：| `<term>`Atlas 200I/500 A2 推理产品`</term>`             |    ×     |
  但是下文出现 Atlas 200I 产品的描述。
