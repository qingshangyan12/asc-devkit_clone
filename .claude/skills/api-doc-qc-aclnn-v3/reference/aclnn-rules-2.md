# aclnn 领域质检规则 - 完备性检查详细说明

**重要提示：**

- 仅使用本文件中明确定义的规则进行检查
- 规则名称、规则级别必须与本文件完全一致

## 2. 完备性检查

此类检查仅基于文档内容，不需要读取代码。

| 规则名称                 | 描述                                                             | 级别 |
| ------------------------ | ---------------------------------------------------------------- | ---- |
| 函数原型缺少使用场景说明 | 检查函数原型章节是否有两段式接口调用流程说明                     | 一般 |
| 返回码描述缺失           | 检查两段式接口的每个函数接口是否有返回值说明                     | 严重 |
| 一段接口参数拦截描述缺失 | 检查一段接口（GetWorkspaceSize）的返回值后是否有参数拦截校验表格 | 严重 |
| 确定性说明缺失           | 检查约束说明章节是否有确定性计算说明                             | 严重 |
| 缺少调用示例描述         | 检查调用示例章节是否包含编译运行说明和代码示例                   | 一般 |

### 函数原型缺少使用场景说明

1. 检查位置在 `##函数原型`标题之下到具体函数代码段之间。
2. 检查是否有类似话术，只要能体现接口调用流程即可，"先调用 aclnnXxxGetWorkspaceSize，再调用 aclnnXxx"

### 返回码描述缺失

无论哪一段接口，每段接口的每个 `## 函数接口`都需要有**返回值**。例如：`aclnnStatus：返回状态码，具体参见 [aclnn 返回码](../../../docs/context/aclnn 返回码.md)。`

### 一段接口参数拦截描述缺失

1. 位置：必须归属在两段式接口的第一段 `aclnnXxxGetWorkspaceSize`接口的**返回值**后的下一行。
2. 话术：必须在拦截表上方有使用场景说明。例如：`第一段接口会完成入参校验，出现以下场景时报错：`（语义类似即可）
3. 表格：拦截表必须存在，且字段必须为{返回值、错误码、描述}

### 确定性说明缺失

1. 位置：必须归属在 `## 约束说明`的段落里。
2. 话术：必须有“确定性”关键字。例如：`- 确定性计算：\n\t - aclnnXxx 默认确定性实现`。

### 缺少调用示例描述

1. 位置：必须归属在 `## 调用示例`的段落里。
2. 必须有"编译与运行"类似的文字说明。例如：`示例代码如下，仅供参考，具体编译和执行过程请参考 [编译与运行样例](../../../docs/context/编译与运行样例.md)。`
3. 必须要有代码段
