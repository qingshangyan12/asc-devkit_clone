## 4. 正确性检查

**重要：正确性检查必须读取实际代码文件才能进行判断，严禁仅根据文档推测！**

| 规则名称           | 描述                                   | 级别 | 需读取的代码文件   |
| ------------------ | -------------------------------------- | ---- | ------------------ |
| API 函数原型一致性 | 检查文档中的函数原型部分与代码的一致性 | 严重 | op_api/aclnn_xxx.h |

### API 函数原型一致性

**验证步骤：**

1. 读取 `op_api/aclnn_xxx.h`文件（如 `op_api/aclnn_addcmul.h`）（检测到同级目录下有对应头文件就检测，没有就不检测）
2. 找到函数声明
3. 对比文档中"## 函数原型"部分的函数签名

**检查内容：**

- 函数名是否一致
- 参数类型是否一致
- 参数名是否一致
- 参数顺序是否一致
- 返回类型是否一致

文档中"## 函数原型"部分应和"op_api/aclnn_xxx.h"中的函数定义一致。
