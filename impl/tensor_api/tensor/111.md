# 类型判断用 struct

| 名称 | 文件 | 说明 |
|------|------|------|
| `IsTileTensor` | `local_tensor_impl.h` | 是否为 `LocalTensor<TensorAttribute<...>>` |
| `HasDereference` | `local_tensor_impl.h` | SFINAE：是否可 `*` 解引用 |
| `is_layout` | `layout_definition.h` | 是否为 `Layout<...>` |
| `IsFrameLayoutTrait` | `layout_frame.h` | 是否为带 `type`、`C0_ELEMENT` 的 frame trait |
| `IsHardwareMem` | `pointer_mem_impl.h` | 是否为 `HardwareMemPtr<...>`（含迭代器递归） |
| `IsPtrTrait` | `pointer_pattern.h` | 是否已有 `typename T::type` |
| `IsMemPtrIterator` | `pointer_pattern_impl.h` | 是否可解引用（迭代器/指针） |
| `IsStaticLayout` | `layout_size.h` | `static constexpr bool value`，静态布局判定 |
| `include_dynamic_type` | `layout_size.h`（`IsStaticLayout` 内 private） | 递归/tuple 上是否含“动态”类型 |
