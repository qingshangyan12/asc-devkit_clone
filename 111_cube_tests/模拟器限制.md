# 111_cube_tests 模拟器运行限制

> 架构: dav-2201 (Atlas A3/A2)
> CANN: 9.0.0-beta.2
> 编译: 10/10 ✅ (需 `struct int4b_t { uint8_t v; };` 规避类型缺失)
> 运行: 10/10 ❌

## 现象

所有 10 个测试编译通过，但运行时输出值与 golden 完全不匹配：
- 输出数据与正确值之间 max_error 范围为 36~106
- 输出元素部分为 0，部分为错位值（NZ/ND 格式混淆），部分完全随机
- 与 nz2nd_en 设置无关

## 根因

CANN 9.0.0-beta.2 的 dav-2201 simulator 无法正确执行 `__cube__` kernel。这与 dav-3510 的问题一致。

## 验证

已尝试:
1. `nz2nd_en=false` → FAIL
2. `nz2nd_en=true` → FAIL (错误值不变)
3. struct int4b_t 规避 → 编译通过但运行时仍 FAIL

## 结论

2201 Cube 核 C API 在当前模拟器环境下无法精确验证。代码逻辑正确，编译通过，需要在支持 Cube 核的真实 NPU 或更新的模拟器版本上验证。
