# asc_set_fp32_mode 测试过程

## API 概要
- **API**: `asc_set_fp32_mode()` — PIPE_S, 设置 MMAD 的 FP32 模式(不做舍入)
- **头文件**: `c_api/asc_simd.h` → `cube_compute.h`
- **适用架构**: dav-2201

## 测试方法
- **类型**: 计算类 API
- **验证方式**: asc_set_fp32_mode 设置FP32模式 → asc_mmad_sync 执行 16×16 float×float→float MMAD → L0C→GM → 与 CPU 矩阵乘结果比较

## 测试场景
| 场景 | 说明 |
|------|------|
| 单核单分形 | 16×16 float×float→float 矩阵乘, FP32模式无舍入 |

## 精度门限
- max_error < 0.001f

## 编译运行
```bash
bash build_and_run.sh
```
