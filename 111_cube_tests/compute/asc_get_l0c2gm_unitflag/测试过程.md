# asc_get_l0c2gm_unitflag 测试过程

## API 概要
- **API**: `asc_get_l0c2gm_unitflag()` — PIPE_S, 获取当前 unit_flag 设置值
- **头文件**: `c_api/asc_simd.h` → `cube_compute.h`
- **适用架构**: dav-2201

## 测试方法
- **类型**: 读取类 API (冒烟测试) + 计算类验证
- **验证方式**: 
  1. asc_get_l0c2gm_unitflag 获取当前 unit_flag 值 → 验证为 0 (默认值)
  2. 同时执行 16×16 half×half→float MMAD 完整流水线验证 kernel 正常工作

## 测试场景
