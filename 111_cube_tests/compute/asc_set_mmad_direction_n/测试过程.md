# asc_set_mmad_direction_n 测试过程

## API 概要
- **API**: `asc_set_mmad_direction_n()` — PIPE_S, 设置 MMAD 优先 N 方向计算
- **头文件**: `c_api/asc_simd.h` → `cube_compute.h`
- **适用架构**: dav-2201

## 测试方法
- **类型**: 计算类 API
- **验证方式**: asc_set_mmad_direction_n 设置方向 → asc_mmad_sync 执行 16×16 half×half→float MMAD → L0C→GM → 与 CPU 矩阵乘结果比较

## 测试场景
| 场景 | 说明 |
|------|------|
| 单核单分形 | 16×16 half×half→float 矩阵乘, N方向优先 |

## 精度门限
- max_error < 0.001f
