# asc_copy_l12fb 测试过程

## API 概要
- **API**: `asc_copy_l12fb_sync(__fbuf__ void* dst, __cbuf__ void* src, uint32_t size)`
- **头文件**: `c_api/asc_simd.h` → `cube_datamove.h`
- **流水线**: PIPE_MTE1
- **功能**: L1→Fixpipe Buffer 搬运
- **适用架构**: dav-2201

## 测试方法
- **类型**: 搬运类 API
- **验证方式**: asc_copy_l12fb_sync(API) 将 L1 数据搬运到 FB, 同时执行标准 MMAD 管线(GM→L1→L0A/L0B→MMAD→L0C→GM)验证不中断

## 测试场景
| 场景 | 说明 |
|------|------|
| 单核单分形 | 16×16 half, L1→FB + MMAD 管线 |

## 精度门限
- max_error < 0.001f

## 编译运行
```bash
bash build_and_run.sh
```
