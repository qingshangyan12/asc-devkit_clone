# asc_copy_l0c2l1 测试过程

## API 概要
- **API**: `asc_copy_l0c2l1_sync(__cbuf__ void* dst, __cc__ float* src, uint16_t n_size, uint16_t m_size, uint32_t dst_stride, uint16_t src_stride, uint8_t unit_flag_mode, uint64_t quant_pre, uint8_t relu_pre, bool enable_channel_split, bool enable_nz2nd_en)`
- **头文件**: `c_api/asc_simd.h` → `cube_datamove.h`
- **流水线**: PIPE_FIX
- **功能**: L0C→L1 搬运 (2201 9-param 版本)
- **适用架构**: dav-2201

## 测试方法
- **类型**: 搬运类 API
- **验证方式**: MMAD→L0C→asc_copy_l0c2l1_sync(API)→L1→asc_copy_l12l0c→L0C→GM, roundtrip 精度验证

## 测试场景
| 场景 | 说明 |
|------|------|
| 单核单分形 | 16×16 half→float, L0C→L1 roundtrip |

## 精度门限
- max_error < 0.001f
