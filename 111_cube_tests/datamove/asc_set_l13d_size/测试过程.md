# asc_set_l13d_size 测试过程

## API 概要
- **API**: `asc_set_l13d_size(uint64_t value)`
- **头文件**: `c_api/asc_simd.h` → `cube_datamove.h`
- **流水线**: PIPE_S
- **功能**: 设置 L1 Buffer 3D 边界值 (2201 特有)
- **适用架构**: dav-2201

## 测试方法
- **类型**: 配置类 API
- **验证方式**: asc_set_l13d_size(API) 设置 L1 3D 边界值=1024, 执行标准 MMAD 管线验证不中断

## 测试场景
| 场景 | 说明 |
|------|------|
| 单核单分形 | 16×16 half, size=1024 + MMAD 管线 |

## 精度门限
- max_error < 0.001f

```bash
bash build_and_run.sh
```
