# asc_copy_gm2l1_pad1 测试过程

## API 概要
- **API**: `asc_copy_gm2l1_pad1_sync(__cbuf__ void* dst, __gm__ void* src, uint32_t size)`
- **头文件**: `c_api/asc_simd.h` → `cube_datamove.h`
- **流水线**: PIPE_MTE2
- **功能**: GM→L1 PAD_MODE1 搬运
- **适用架构**: dav-2201 (Atlas A3 Train/Infer, Atlas A2 Train/Infer)

## 测试方法
- **类型**: 搬运类 API
- **验证方式**: GM→asc_copy_gm2l1_pad1_sync(API)→L1→L0A→MMAD→L0C→GM, 精度验证通过 MMAD 间接校验

## 测试场景
| 场景 | 说明 |
|------|------|
| 单核单分形 | 16×16 half, pad1 搬运 |

## 精度门限
- max_error < 0.001f

bash build_and_run.sh
